1　描述流体运动的方法（课件 3.1）

课件 3.1 节共 32 页（P6–P32），是整章的"语言课"：先补齐研究流动所必需的力学与场的概念，再给出拉格朗日、欧拉两套描述方法，并把欧拉法与质点导数（物质导数）配套建立起来。

1.1　预备知识：质点受力与流体动压强

1.1.1　流体质点所受的力

两种分类（概念题高频）

按作用方式质量力（与质量成正比、作用于每一个质点上，如重力、惯性力）与表面力（与作用面积成正比，如压力、切应力）。

按物理意义惯性力——由质点本身的流速变化所产生；粘性力——由流层与流层之间、质点与质点之间存在流速差异所引起。

课件原话："流体由静到动，就会产生惯性力、粘性力，这两种力由流速在空间的分布和随时间的变化所决定。"这句话正是 §3.1 要引入速度场的根本原因——流速场的分布决定了流体所受力。

1.1.2　流体动压强

课件 P7、P8

pxx + pyy + pzz = pξξ + pηη + pζζ = 常量，   粘性流体：p = (1/3)(pxx + pyy + pzz)

  • 任何一点在三个正交方向的压强的平均值是一个常数，不随这三个正交方向的选取而改变，该平均值即该点的压强值。
  • 下角标约定：第一个下角标表示作用面的方位，第二个表示应力的方向（如 pxy 为作用在 x 面上、沿 y 方向的应力）。
  • 无粘性流体动压强 p = p(x, y, z, t)；粘性流体 pxx ≠ pyy ≠ pzz，取三者平均为动压强。
  • 课件特别声明：流体流动时的压强和流体静压强，一律称为压强（不再分"静压强/动压强"两套名字）。

1.1.3　场与流场

场（field）：布满了某种物理量的空间，且该物理量光滑连续。流场：充满运动的连续流体的空间，流场中每个流体质点均有确定的运动要素。流体的运动参数包括速度 u、加速度 a、压强 p、密度 ρ、温度 T、力 F 等。课件 P4 的学习目标给出了本章的"总纲"：

课件 P4

ρ = ρ(x,y,z,t)，  p = p(x,y,z,t)，  V = V(x,y,z,t)，  T = T(x,y,z,t)

求解流体流动问题实际上就是求解上述函数的问题——函数一旦确定，流动即确定。

1.2　拉格朗日法（随体法、质点法）

着眼点：跟踪每一个流体质点，通过追踪每个质点的运动历程来获得整个流场的运动规律（课件用"警察抓小偷""长时间曝光"作比喻）。t = t0 时各质点处于不同位置，用初始坐标 (a, b, c) 作为区分不同质点的"标签"，任一质点的轨迹为

拉格朗日表达式

S = S(a,b,c,t)：   x = x(a,b,c,t)，  y = y(a,b,c,t)，  z = z(a,b,c,t)

(a, b, c, t) 称为拉格朗日变数。两种读法：①(a, b, c) 取定 → 上式代表该质点的运动轨迹（迹线）；②t 取定 → 代表 t 时刻各流体质点的位置分布。

由于 (a, b, c) 与 t 无关，速度与加速度就是轨迹对时间的偏导数：

速度、加速度

V = ∂S/∂t：  u = ∂x/∂t，  v = ∂y/∂t，  w = ∂z/∂t

a = ∂2S/∂t2：  ax = ∂u/∂t = ∂2x/∂t2，  ay = ∂v/∂t，  az = ∂w/∂t

其他物理量也写成拉格朗日形式：ρ = ρ(a,b,c,t)，p = p(a,b,c,t)，T = T(a,b,c,t)。

小结（课件 P17）

优点是沿用理论力学的质点分析法、易于理解；缺点是 x = x(a,b,c,t) 这类函数极难找到，实际操作很复杂困难，因此流体力学研究中很少使用。

1.3　欧拉法（空间点法）

着眼点：着眼于不同流体质点通过空间固定点的流动行为，观察者相对坐标系固定不动。先分析某一空间点上不同时刻的流动参数（实际是不同时刻流经该处的流体质点的流动参数），再转向另一空间点，直至遍历所有空间点。欧拉法把流动参数写成空间坐标与时间的函数：

欧拉表达式

ρ = ρ(x,y,z,t)，  p = p(x,y,z,t)，  T = T(x,y,z,t)，  V = ui + vj + wk

u = u(x,y,z,t)，  v = v(x,y,z,t)，  w = w(x,y,z,t)

(x, y, z, t) 称为欧拉变数。读法：①(x, y, z) 取定 → 代表不同时刻流过该点的不同流体质点的速度；②t 取定 → 代表各空间位置上流体质点的速度空间分布，即速度场。

三条必须记住的提醒（课件 P21）
  1. 同一空间点，不同时刻流经该处的质点不同；
  2. 同一时刻，不同空间点上流经的质点也不同；
  3. 欧拉法不需全程跟踪流体质点，但研究具体物理过程时需局部跟踪研究对象，否则无意义。

两种方法同名不同角色的陷阱：两式都含 (x, y, z)，但拉格朗日法中 (x, y, z) 是质点运动轨迹的三个分量、是因变量；欧拉法中 (x, y, z) 是坐标位置、是自变量。这是概念题的高频考点。

课件小结：欧拉法可广泛应用场论知识、数学困难较少、实验中易于测量，因此被普遍采用——本课程全部采用欧拉法。（课件 P18 历史注记：欧拉 1755 年建立理想不可压流体运动微分方程组即欧拉方程；六年后拉格朗日引入流函数概念、建立理想流体无旋运动的动力学条件并提出复位势法。）

1.4　质点导数（随体导数、物质导数）——本章最重要的推导

定义：流体质点的物理量对时间的变化率，称为该物理量的质点导数。在拉格朗日法中，某物理量的质点导数就是该物理量对时间的偏导数，故 DS/Dt = V、DV/Dt = a。但在欧拉法中给出的是空间分布，同一空间点在不同时刻被不同流体质点占据，因此不能把质点导数简单理解为对时间的偏导数。

1.4.1　推导（课件 P26）

t 时刻某质点位于 M(x, y, z)，速度为 v = ui + vj + wk；设流场中某物理量为 B(x, y, z, t)。经 Δt 后该质点运动到 N(x + uΔt, y + vΔt, z + wΔt)，该物理量变为 B(x + uΔt, y + vΔt, z + wΔt, t + Δt)。由定义

DB/Dt = limΔt→0 [ B(x+uΔt, y+vΔt, z+wΔt, t+Δt) − B(x,y,z,t) ] / Δt

把分子作泰勒级数展开并略去高阶项，取 Δt → 0，得

质点导数公式

DB/Dt = ∂B/∂t + u·∂B/∂x + v·∂B/∂y + w·∂B/∂z  =   ∂B/∂t + (v·∇)B

D/Dt = ∂/∂t + (v·∇)　称物质导数算子

1.4.2　两项的物理意义

项名称物理含义为 0 时表示
∂B/∂t局部导数（当地导数）固定空间点上因时间变化引起的物理量变化反映流场的非定常性；为 0 表示 B 不随时间变化
(v·∇)B迁移导数（对流导数）同一时刻因空间位置变化引起的物理量变化反映流场的非均匀性；为 0 表示 B 在空间均匀分布

易错提醒

① 定常流动中当地加速度为零，但迁移加速度不一定为零（定常非均匀流中质点仍在加速，如渐缩管恒定流动）；② 均匀流动中迁移加速度为零，但当地加速度不一定为零（如等径管中流量缓慢变化）。③ 求加速度时漏写迁移项，是最常见的失分点。

1.5　不可压流体与均质流体的概念澄清

三个层次严格区分（课件 P31–P32）

不可压流体每个流体质点的密度在流动过程中保持不变，即 dρ/dt = ∂ρ/∂t + u∂ρ/∂x + v∂ρ/∂y + w∂ρ/∂z = 0，但密度可以随时间和空间位置变化（分层流动）。

均质流体密度在空间上处处相等，∂ρ/∂x = ∂ρ/∂y = ∂ρ/∂z = 0。

不可压均质流体只有它才是 ρ = 常量（既不随时间也不随空间变化）。工程上绝大部分不可压流体属于均质流体，因此工程上一说"不可压流体"就理解为 ρ = const。

例 3-1（课件 P48–P51）求流线与迹线
题目：已知流场中的速度分布 V = (x + t)i + (−y + t)j，即 u = x + t、v = −y + t。求 t = 0 时刻过 A 点（−1, −1）的流线方程与迹线方程。

① 求流线（t 视为常数）二维流线方程

dx/(x + t) = dy/(−y + t)  ⟹  ln(x + t) = −ln(t − y) + C  ⟹  (x + t)(t − y) = C（双曲线族）

代入 t = 0、(x, y) = (−1, −1) 得 C = 1，故所求流线为 xy = 1。
流线方向由速度方向定：把 t = 0、(1, 1) 代入得 u = −1（沿 x 负方向）、v = +1（沿 y 正方向），合速度方向即流线方向。

② 求迹线（t 是自变量）二维迹线方程

dx/dt = x + t，  dy/dt = −y + t　（均为标准的一阶线性微分方程 dy/dt + P(t)y = Q(t)）

解得 x = C1et − t − 1、y = C2e−t + t − 1；由 t = 0 时 x = −1、y = −1 得 C1 = C2 = 0，

x = −t − 1，  y = t − 1  ⟹  过 A 点的迹线方程 x + y = −2

③ 思考（课件 P51）若在已知速度表达式中除去 t 项、变为定常流动 V = xi − yj，则流线方程 dx/x = dy/(−y) 与迹线方程 dx/dt = x、dy/dt = −y 都得 xy = 1，二者重合——这与 §3.3 的结论一致：定常流动中流线、迹线、染色线三线合一。

答：流线 xy = 1（t = 0 时刻过 A 点）；迹线 x + y = −2。

2　定常流动和非定常流动（课件 3.2）

课件 3.2 节共 5 页（P33–P37），只讲一件事：怎样判断流动是否定常，以及"定常"这个概念的两个重要陷阱。

2.1　定义与判据

定义

若流场中任一空间点 (x, y, z) 上各个流动参数都不随 t 变化，即 ∂ρ/∂t = ∂p/∂t = ∂V/∂t = ∂T/∂t = 0，则称定常（恒定）流动，否则称非定常流动。定常流动的参数表达式不再含 t：ρ = ρ(x,y,z)、p = p(x,y,z)、V = V(x,y,z)。

课件列举的非定常例子：室内空气在打开或关闭窗门瞬间的流动；海洋涨潮落潮时的流动；管道在开闭期间所产生的压力波动。本课程以定常流动为主——后面 §3.5 的连续性方程、§3.6–3.8 的能量方程都建立在定常前提上。

2.2　两条重要注意

必记
  1. 非定常流动是绝对的，定常流动是相对的。各空间点参数随时间变化不显著时，可视为定常流动——这是一种简化处理（例如水箱水位下降极慢时的出流常按定常计算）。
  2. 流动是否定常与坐标系的选择有关。判断方法：观测任一固定空间点处的流速是否随时间变化。
例（课件 P37）船在水中航行
题目：船以恒定速度在水中航行，船体周围的绕流是定常流动还是非定常流动？

情形 1人在岸上，坐标建立在岸上：船体相对观察者不断改变位置，固定空间点处的速度随时间变化 → 非定常流动。

情形 2人在船上，坐标建立在船上：各空间点处的速度不随时间变化 → 定常流动。

二者描述的是同一个物理现象，差别只在于坐标系的选择，涉及坐标变换与相对运动原理。

答：与坐标系选择有关——岸上观察为非定常，船上观察为定常。
与 §3.1 的呼应：定常 ≠ 均匀

课件 §3.2 只解决"随时间变不变"的问题；"随空间位置变不变"的问题在 §3.7 用均匀流/非均匀流、渐变流/急变流来回答。四个组合（定常均匀、定常非均匀、非定常均匀、非定常非均匀）是概念题的常客：等直径长直管的恒定流动是定常均匀流；恒定流动中的渐缩管是定常非均匀流（当地加速度为 0，迁移加速度不为 0）。

3　流线和迹线（课件 3.3）

课件 3.3 节（P38–P53）给出三种"线"的定义与方程、流线的三条性质，以及流管、流面与流量的概念。这一节是运动学的核心，也是概念题的富矿。

3.1　迹线

定义：任一流体质点在流场中的运动轨迹，属拉格朗日描述方法。设 t 时刻过 A(x, y, z) 的微元迹线为 ds = dxi + dyj + dzk，速度 V = ui + vj + wk，由 ds = Vdt 得

迹线方程

dx/u = dy/v = dz/w = dt  （等价于 dx = udt，dy = vdt，dz = wdt）

这里 x、y、z 是 t 的函数，需要求解微分方程才能得到迹线；t 是自变量，是"时间过程"的记录。

3.2　流线

定义：某一时刻，流场中的一条假想曲线，曲线上各点的速度矢量方向与该点的切线方向相同，属欧拉描述方法。由 ds 与 V 方向一致、对应分量成比例得

流线方程

dx/u = dy/v = dz/w  （t 为常数、作参数处理）

  • 任何瞬时流场中可绘制无数条流线；流线的引入对定性刻画流场具有重要意义（类比磁场中的磁力线）。
  • 流线密处流速大、疏处流速小——这是从流线图读流速的依据。
  • 流线形状随 t 改变（非定常流动）；定常流动中流线形状与位置不随时间变化。

流线的重要性质（课件 P44–P45）

性质一：流线通常彼此不相交

理由：若两条流线相交，则交点处将有两个不同的速度方向，与该点速度唯一矛盾。

性质二：过某一点有多条流线，不外乎三种情况
  1. V = 0 —— 交点为驻点（如机翼前缘、钝体正前方的滞止点，三条流线在此交汇）；
  2. V → ∞ —— 交点是源或汇；
  3. 两条流线相切（切点流速唯一且相同）。

除这三种情况外，流线不能相交、不能分支、不能转折。

3.3　染色线（脉线、纹线）

定义：在一段时间内，从流场中同一固定点连续注入的染料（或示踪物质）所形成的线，反映的是不同时刻通过该点的不同流体质点在某一瞬时的位置连线。课件指出：染色线目前还没有确切的数学方程。工程实例：尖拱细长旋成体背风面旋涡流动、三角翼前缘涡、翼尖涡的染色液显示。

3.4　迹线、流线、染色线的区别与联系（必考）

名称定义数学方程描述方法
迹线同一流体质点在不同时刻所处位置的连线dx/u = dy/v = dz/w = dt拉格朗日：t 变、质点不变
流线同一时刻流线上不同流体质点的速度方向线dx/u = dy/v = dz/w欧拉：t 不变、质点变
染色线不同时刻流过同一点的不同流体质点的连线无确切方程混合：t 变、质点也变
结论

非定常流动：流线 ≠ 迹线 ≠ 染色线；   定常流动：流线 = 迹线 = 染色线

易错提醒

① 三条"线"只是几何图像，不能说明流体是否在加速，也不能直接给出流量；② 判断"流线与迹线是否重合"必须先判断流动是否定常；③ 流线方程中 t 是常数，迹线方程中 t 是自变量——两者的微分方程形式相同但含义截然不同，这是例 3-1 中二者结果不同的根本原因。

3.5　流面、流管与流量

定义

流面：某一时刻 t，在流场中取一条不是流线的曲线，通过曲线上所有点的流线组成的面。

流管：某一时刻 t，在流场中取一条封闭的、不是流线的曲线，通过曲线上所有点的流线组成的管状体；流管的流面也称管壁。

流管性质：某一时刻流体不会穿越管壁——因为管壁由流线组成，沿管壁法向速度为零。流管可以是假想的，也可以是真实的（一维管道流动中管壁即为真实流管）。定常流动中流管的形状和位置不随时间变化。

流量：体积流量＝单位时间内流过某一面积的流体的体积（m3/s）；质量流量＝单位时间内流过某一面积的流体的质量（kg/s）；通量＝单位面积内的流量。在流管任一截面 A 上取微元面积 dA、法向单位矢量 n、速度矢量 v，则

课件 P53

dQ = v·n dA，  dm = ρv·n dA；   Q = ∫A v·n dA，  Qm = ∫A ρv·n dA

4　一元流动模型（课件 3.4）

课件 3.4 节（P54–P59）回答一个关键问题：真实的流动是三元（三维、非均匀）的，怎样才能用代数方程求解？答案是引入"元流—总流—断面平均流速"这一套一元化模型。

4.1　一维、二维、三维流动

流动维数数学特征典型例子
三维（三元）流动u = u(x, y, z, t)绕机翼、绕船体的流动
二维（二元）流动∂ux/∂z = ∂uy/∂z = 0，即 u = u(x, y, t)无限宽平板间流动、长直渠道中的流动
一维（一元）流动流动参数只是一个空间坐标和时间变量的函数，u = u(s, t)管道、明渠中的断面平均流动

4.2　流束、过流断面、元流与总流

四个概念

流束：充满流管的一束流体。过流断面：垂直于流束的断面。

元流：流束的过流断面无限小时，这根流束称为元流。对元流来说 u = f(s)，三元流动就转变为一元流动问题。

总流：把整个流动看作由无数元流相加，则该流动称为总流（整根管道、整条渠道中的流动）。

总流的过流断面：垂直于总流全部流线的断面——课件特别强调它不都是平面（只有在渐变流段才可近似取为平面）。

4.3　断面流量与断面平均流速

元流的体积流量 dQ = u dA；整个过流断面 A 上的体积流量为

课件 P58

Q = ∫A u dA  （m3/s）

断面平均流速是一个假想的流速：假定在过流断面上各点都以相同的平均流速流过，这时通过该过流断面的体积流量仍与各点以真实流速流动时所得到的体积流量相同。于是

一元化的关键公式

v = Q/A = (1/A)∫A u dA，   Q = vA，   且 v = v(s)

易错提醒

① 必须区分点速度 u（元流、流线上的速度）与断面平均流速 v（总流参数），连续性方程 v1A1 = v2A2 中的 v 必须是断面平均值；② 一元化是有代价的——它为补偿断面流速分布不均而引入了动能修正系数 α（§3.8）与动量修正系数 β（附录 B），工程上常近似取 α ≈ 1、β ≈ 1，但题目给出具体值时必须代入。

5　连续性方程（课件 3.5）

课件 3.5 节（P60–P65）是质量守恒在一元流动中的表达式，形式最简单、适用最广，是所有流动问题求解的第一步。

5.1　连续性条件与理论依据

连续性条件：流体连续地充满所占据的空间，当流体流动时在其内部不形成空隙。理论依据是质量守恒定律——若在某一定时间内流出的流体质量和流入的流体质量不相等，则这封闭曲面内一定会有流体密度的变化，以便使流体仍然充满整个封闭曲面内的空间；如果流体不可压缩，则流出的流体质量必然等于流入的流体质量。

5.2　推导

在管道中取过流断面 1-1、2-2（面积 A1、A2），假定流体的运动是连续的、定常的。dt 时间内：流入质量 ρ1A1v1dt = ρ1Q1dt，流出质量 ρ2A2v2dt = ρ2Q2dt。由质量守恒

恒定总流连续性方程

可压缩流体：  ρ1Q1 = ρ2Q2  即   ρ1v1A1 = ρ2v2A2

不可压缩流体：  Q1 = Q2  即   v1A1 = v2A2  （元流与总流均适用）

5.3　推广形式与分支管路

  • 沿程多个断面：Q1 = Q2 = … = Q，v1A1 = v2A2 = … = vA = 常数；
  • 由此得 v1 : v2 : v3 : … = 1/A1 : 1/A2 : 1/A3 : …，即断面平均流速与断面面积成反比；
  • 有分支时（三通管道分流）：Q1 = Q2 + Q3，即 v1A1 = v2A2 + v3A3；合流时反号（一般形式 ∑Q入 = ∑Q出）。

课件结论：通过总流各过流断面的体积流量相等；连续性方程确立了总流断面平均流速沿流向随断面面积的变化规律。（与三元微分形式的联系：∂ρ/∂t + ∂(ρu)/∂x + ∂(ρv)/∂y + ∂(ρw)/∂z = 0，不可压时 ∇·V = 0。）

易错提醒

连续性方程只要求连续、定常、断面间无质量源汇，不要求无粘、也不要求不可压缩（可压缩时用密度形式）。它给出的是平均流速（流量）关系，不能替代能量方程求压强——求流速+压强必须两个方程联立。

例 5-1（自编典型题）串联与分支管路的流量分配
题目：水在管路中作恒定流动。断面 1-1 处管径 d1 = 300 mm，断面平均流速 v1 = 1.2 m/s；下游先后经过渐缩管与三通：断面 2-2 管径 d2 = 200 mm，随后分为两支，支管 A 的管径 dA = 150 mm、断面平均流速 vA = 2.0 m/s，支管 B 的管径 dB = 100 mm。求断面 2-2 的流速 v2、总流量 Q1 与支管 B 的流速 vB。

①面积与总流量（不可压）：A1 = πd12/4 = π×0.32/4 = 0.07069 m2，Q1 = v1A1 = 1.2×0.07069 = 0.0848 m3/s。

②断面 2-2（在分支之前，全部流量通过）：A2 = π×0.22/4 = 0.03142 m2，v2 = Q1/A2 = 0.0848/0.03142 = 2.70 m/s（也可由 v2 = v1(d1/d2)2 = 1.2×1.52 = 2.70 m/s 直接得到）。

③分支：AA = π×0.152/4 = 0.01767 m2，QA = 2.0×0.01767 = 0.03534 m3/s；AB = π×0.12/4 = 0.007854 m2，QB = Q1 − QA = 0.0848 − 0.03534 = 0.04946 m3/s；vB = QB/AB = 0.04946/0.007854 = 6.30 m/s。

校核：vAAA + vBAB = 0.03534 + 0.04946 = 0.0848 = v1A1 ✔

答：v2 = 2.70 m/s；Q1 = 0.0848 m3/s；vB = 6.30 m/s。

6　恒定元流能量方程（课件 3.6）

课件 3.6 节共 32 页（P66–P97），是本章的第一个重点。它先建立系统与控制体两个基本概念，再用功能原理推出理想流体元流的伯努利方程，最后给出两个经典应用（小孔出流、皮托管）与四个例题。

6.1　系统与控制体

比较项系统（System）控制体（Control Volume）
定义包含着确定不变物质的任何集合体；流体力学中指由任何确定流体质点组成的团体被流体所流过、相对于某个坐标系而言固定不变的任何体积；其边界称控制面
边界边界随流体一起运动，边界上没有质量交换边界相对坐标系固定；控制面上可以发生质量交换（流体可流进流出）
受力边界上受到外界的表面力控制面上受到外界作用于控制体内流体上的力
能量边界上存在能量的交换控制面上存在能量的交换
与 F = ma 对应F 为作用于系统上所有外力的合力，a 为系统的平均加速度F 为作用于控制体边界面上所有作用于流体上外力的合力
对应观点Lagrange 观点Euler 观点

控制体是不变的，但占据控制体的流体质点随时间变化；控制体的形状可根据需要而定。从控制体角度来说，连续性方程就是在系统内不存在源和汇的情况下系统的质量不随时间变化，即 dm/dt = 0，(d/dt)∫∫∫ρ dτ = 0。

6.2　伯努利方程的推导（功能原理）

元流特性：在恒定流条件下元流的形状不随时间变化。依据：功能原理——dt 时间内该段元流外力所作的功，等于流段机械能量的增量。

系统与控制体的选取：取 t 时刻元流 1-2 中所有流体质点作为系统；取元流 1-2 断面之间的空间体积为控制体，t 时刻系统与控制体重合。dt 后断面 1-1 移至 1′-1′、2-2 移至 2′-2′。

三步推导

① 压力作功断面 1-1′：高度 Z1、面积 dA1、速度 u1，dt 内位移 u1dt，受压力 p1dA1，作正功 p1dA1u1dt；断面 2-2′：受压力 p2dA2，作负功 p2dA2u2dt。侧壁压力垂直于流线不做功。净功

(p1 − p2) dQ dt

② 机械能增量dt 内 1′-1′ 与 2-2 之间公共空间的位能没变、定常流动时该空间内各点流速也没变，故能量变化只包括 2′-2′ 段的增加量与 1′-1′ 段的减少量。两段体积均为 dQdt，质量 m = ρdQdt，动能 (1/2)mv2，位能 mgz：

动能增量 = γdQdt[u22/(2g) − u12/(2g)]，   位能增量 = γdQdt(Z2 − Z1)

③ 令压力作功 = 动能增量 + 位能增量

(p1 − p2)dQdt = γdQdt(Z2 − Z1) + γdQdt(u22 − u12)/(2g)

总能量方程式（课件 P77）

(p1 + γZ1 + γu12/2g) dQ = (p2 + γZ2 + γu22/2g) dQ

两边除以 γdQ（即化为单位重量流体的能量），得理想不可压缩流体恒定流元流能量方程：

伯努利方程（元流 / 流线）

z1 + p1/(ρg) + u12/(2g) = z2 + p2/(ρg) + u22/(2g) = 常数  （沿同一元流 / 同一流线）

等价形式：单位质量能量 gz + p/ρ + u2/2 = 常数（J/kg）；单位体积能量 ρgz + p + ρu2/2 = 常数（Pa，即静压 + 动压 = 总压）。另一条等价推导路线：沿流线对欧拉运动微分方程 −(1/ρ)∂p/∂s − g∂z/∂s = u∂u/∂s 积分即得同一方程。

6.3　适用条件（6 条，缺一不可）

理想流体元流伯努利方程的适用范围
  1. 理想流体（无粘性）；
  2. 不可压缩均质流体；
  3. 在重力作用下；
  4. 定常流动；
  5. 沿同一流线（或同一微元流束）流动；
  6. 控制体内无流体机械做功。

物理含义：无粘流体的定常流动，沿同一元流（沿同一流线），单位重量流体的机械能守恒。

6.4　控制体内有流体机械时的功率

设流体机械（泵、风机、水轮机）的功率为 WS，则

课件 P80

WS = mg[ ( z1 + p1/(ρg) + V12/(2g) ) − ( z2 + p2/(ρg) + V22/(2g) ) ]

  • WS 也称为流体机械的轴功率；
  • 流体机械对流体做功时（泵、风扇）WS > 0；
  • 流体对流体机械做功时（涡轮、风力发电机的风轮）WS < 0；
  • 只要知道单位时间净流出控制体的流体机械能，就可以得到流体机械的功率。

6.5　物理意义与几何意义

项物理意义（单位重量流体的能量）几何意义（水头）别称
z位能（重力势能）——单位位能位置水头、高度水头比位能
p/(ρg)压能（压强势能）——单位压能压强水头、测压管高度比压能
u2/(2g)动能——单位动能速度水头、流速高度比动能
Hp = z + p/(ρg)单位势能测压管水头（静力水头）—
H = z + p/(ρg) + u2/(2g)单位机械能总水头—

物理意义：理想不可压缩的重力流体作定常流动时，在同一流线的不同点上或同一微元流束的不同截面上，单位重量流体的位能、压强势能和动能之和等于常数。几何意义：沿同一流线（或微元流束）各点的位置水头、压强水头和速度水头之和保持不变，即总水头是一常数——无粘性流体的恒定流动，沿同一元流各断面的总水头相等，总水头线是水平线。

测压管水头（静力水头） Hp = z + p/(ρg) 表明断面测压管水面相对于基准面的高度，表示单位重量流体具有的势能，称单位势能。（与 §3.10 的呼应：H = Hp + u2/(2g)，即由总水头线减去速度水头即可得测压管水头线。）

6.6　应用一：小孔出流（托里拆利公式）

一贮液容器侧壁开一小孔形成自由射流，求孔口速度。设想一条流线，在流线上取两点：①位于自由液面，②位于出孔截面。

课件 P84

①处：p1 = pa，V1 = 0；②处（出口外紧邻出口）：p2 = pa，V2 = V；z1 − z2 = h

V = √(2gh)  （理论值，托里拆利公式）  →   V = cv√(2gh)

成立的理由（三条假设）：小孔出流时自由面的水位下降速度 V1 与小孔出流速度相比可以忽略不计，流动可假设是定常的；不计粘性损失；由于是小孔，中心点处速度可以近似代表小孔速度。实际流动中粘性不可忽略，实际速度略低于理论值，引入速度系数 cv，实验表明 cv ≈ 0.97。

6.7　应用二：皮托管（测速管）

a 点压强水头由测速管量测（管口正对来流，测得总压/滞止压强），b 点压强水头由测压管量测（测得静压）。对 a、b 两点列无粘性流体元流伯努利方程（b 点为驻点，速度为零）：

课件 P85–P87

z + pa/γ + 0 = z + pb/γ + u2/(2g)  ⟹  u2/(2g) = (pa − pb)/γ = hV

u = √(2g(pa − pb)/γ) = √(2ghV)  →   u = φ√(2ghV)

φ 为流速修正系数（考虑粘性效应及探头对流场的干扰），一般由实验确定，通常 φ = 0.98～1.05。皮托管测定气流时：

气体用皮托管

u = φ√( 2γ′hV / ρ )，   其中 pa − pb = (γ′ − γ)hV，γ′ 为测压管内工作液体重度

对于气体有 γ ≪ γ′，故 pa − pb ≈ γ′hV。注意：皮托管测的是点速度 u，要得到流量还需配合断面流速分布积分（Q = ∫udA）。

6.8　例题

例 3-2（课件 P89–P90）机翼绕流求三点压强
题目：在海平面上不可压均质理想气流流过一个机翼，远前方来流静压 p∞ = 101200 N/m2、流速 V∞ = 100 m/s；机翼上 A、B、C 三点的速度分别为 VA = 0、VB = 150 m/s、VC = 50 m/s，空气密度 ρ = 1.255 kg/m3，流动定常。求三点的压强。

思路流动定常、理想、不可压，且不计重力（或三点同高），故伯努利常数（总压）在全流场通用：先由远前方条件定出该常数，再逐点求压强。用总压形式 p + ρV2/2 = p0。

p0 = p∞ + ρV∞2/2 = 101200 + 1.225×(100)2/2 = 101200 + 6125 = 107325 Pa

（课件在数值计算中取 ρ = 1.225 kg/m3。）

  • A 点为驻点（VA = 0）：pA = p0 = 107325 Pa；
  • pB = p0 − ρVB2/2 = 107325 − 0.6125×22500 = 93825 Pa；
  • pC = p0 − ρVC2/2 = 107325 − 1531 = 105794 Pa。

物理结论：流速大的地方压强小（B 点流速最大、压强最低），这正是机翼升力与空化现象的根源。

答：pA = 107325 Pa，pB = 93825 Pa，pC = 105794 Pa。
例 3-3（课件 P91–P92）绕固定轴旋转流动：证明伯努利常数是 r 的函数
题目：二维绕固定轴旋转流动，周向速度 vθ 正比于半径 r，即 vθ = kr（理想不可压流体，不考虑重力影响）。试证明伯努利常数 C 是 r 的函数。

①沿流线（等半径圆周）写伯努利方程：p + (1/2)ρvθ2 = C；对半径取导数

∂C/∂r = ∂p/∂r + ρvθ·∂vθ/∂r

②在半径 r 处取微元流体 ABCD（径向 dr、周向 dθ）作受力分析：法向压力必须平衡微元的离心力，即"外侧压力 − 两侧面压力的径向投影 − 内侧压力 = 微元离心力"，略去高阶小量得

∂p/∂r = ρvθ2/r　（这就是流体作圆周运动时的径向压强梯度公式）

③代入 vθ = kr：

∂C/∂r = ρk2r + ρkr·k = 2ρk2r ≠ 0

∂C/∂r ≠ 0 说明 C 随 r 变化，即伯努利常数在全流场不是同一个常数（只在同一条流线上为常数）——这正是"伯努利方程只能沿同一流线使用"的原因。

答：∂p/∂r = ρvθ2/r，代入 vθ = kr 得 ∂C/∂r = 2ρk2r ≠ 0，故 C 是 r 的函数。
例 3-3 拓展（课件 P93–P94）Lamb 涡模型：vθ = K/r
题目：如果速度场是 vθ = K/r，试证明能量方程的积分常数对整个流场是不变的。

仍用 ∂C/∂r = ∂p/∂r + ρvθ∂vθ/∂r，并代入圆周运动的 ∂p/∂r = ρvθ2/r：

∂C/∂r = ρvθ2/r + ρvθ(−K/r2) = ρK2/r3 − ρK2/r3 = 0

答：∂C/∂r = 0，积分常数在全流场不变（无旋流动中伯努利常数全场通用）。

6.9　粘性流体元流的伯努利方程

7　过流断面的压强分布（课件 3.7）

课件 3.7 节共 20 页（P4–P23），回答一个此前被回避的问题：压强在垂直于流线的方向上怎样变化？结论是"渐变流过流断面上压强按静水规律分布"，这正是总流能量方程能把 z + p/γ 提出积分号的前提。

7.1　问题的提出：流速变化的两种方式

流体质点受力包括压强、粘性力、惯性力、重力。惯性力与质点流速有关，因此需要考虑流速的变化。总流中流速的变化包括两部分：

  • 流速大小的变化 → 出现直线惯性力 → 压强沿流向变化（§3.6 元流能量方程已处理）；
  • 流速方向的变化 → 出现离心惯性力 → 压强沿断面变化（本节要处理的内容）。

7.2　均匀流动与非均匀流动

类型数学判据几何与物理特征
均匀流动(u·∇)u = 0，迁移加速度为零质点流速的大小和方向均不变；流线为相互平行的直线，过流断面为平面
非均匀流动(u·∇)u ≠ 0，迁移加速度不为零流速随流向变化，又分渐变流与急变流

课件的均匀流例子：ux = ux(y)，uy = uz = 0，且 ∂ux/∂x = ∂uz/∂z = 0（两平板间、管中层流）。

极易混淆：均匀流 ≠ 等速直线流动

应把均匀流与"完全不随空间位置而变的等速直线流动 u = const"相区别：前者指流动沿着流线方向不变（但沿垂直流线方向可以变，如管内层流的速度剖面），后者指流动沿着空间任何方向都不变。后者只是均匀流的一个特例。

均匀流中不存在惯性力，因此在均匀流空间是重力、压力和粘性力的平衡。特别地，在均匀流过流断面上，粘性力对垂直于流速方向的过流断面上的压强变化不起作用——此时过流断面上仅需考虑重力和压力的平衡，与静止流体所考虑的一致。这正是下面结论的物理依据。

7.3　核心结论：均匀流过流断面上压强按静水规律分布

推导（课件 P10–P11）：取轴线 n-n 位于均匀流断面上的微小柱体为控制体，柱体长 l、横断面 ΔA、与铅直方向成倾角 α，两断面高程 Z1、Z2，压强 p1、p2。受力分析：

  • 柱体重力在 n-n 方向的分量 Gcos α = ρglΔAcos α；
  • 作用在柱体两端的压力 p1ΔA 与 p2ΔA；
  • 侧表面压力垂直于 n-n 轴，在 n-n 轴上的投影为 0；两端的切向力在 n-n 轴上的投影也为 0。
力平衡（课件 P11）

p1ΔA + γ·lΔAcos α = p2ΔA，  而 lcos α = Z1 − Z2

⟹  p1 + γ(Z1 − Z2) = p2  ⟹  Z1 + p1/γ = Z2 + p2/γ

结论（本节最重要的一句话）

均匀流过流断面上压强分布服从流体静力学规律，即断面上各点的测压管水头 z + p/γ = 常数、压强按 p = p0 + ρgh 分布。注意：不同断面上的测压管水头并不相同，考虑黏性后下游断面的水头降低（所以总水头线与测压管水头线才有坡度，见 §3.10）。

7.4　渐变流与急变流

类型定义与判据压强分布特征
渐变流（缓变流）非严格的均匀流、接近于均匀流。四条定义：①流线近似于平行直线；②惯性力忽略不计；③过流断面近似于平面；④过流断面上压强分布可认为服从流体静力学规律断面上 z + p/γ = 常数，测压管水头是常数；压强按静水规律分布
急变流流速沿流向变化显著的流动（弯管、闸门后、突扩突缩、阀门、孔口边缘处）断面上测压管水头不是常数；流线明显弯曲，离心力方向压强增加、流速减小
关键判断

渐变流和急变流之间没有明确的界限，取决于惯性力是否可以忽略。工程上的取断面经验：把计算断面取在直管段、距弯头/阀件/进出口不小于 3～5 倍管径处，并保证断面与流线垂直。

急变流实例：锐缘孔口的压强分布（课件 P17–P18）

当孔口边缘为锐缘时，流线在边沿处发生显著弯曲：边缘 A 点与大气相连，故该点处压强为 0；沿离心力方向（指向流束中心）压强迅速增大；到达孔口流束中心时流速接近于 0、压强几乎达到水箱底部的压强值。课件用虚线表示静压强分布——这说明孔口断面上 z + p/γ 远非常数，直接把"孔口断面压强等于大气压"当作条件使用是错误的。

7.5　急变流的工程应用：弯管流量计

例 3-5（课件 P19–P22）弯管流量计
题目：利用弯管（弯头）内外侧的压强差来测量流量。已知弯管中心线曲率半径 R、管径 D、内外侧测压管液面差 h，流体密度 ρ。试导出流量公式。

① 取控制体半径 r 处的微元，径向厚度 dr、所对应的圆心角 dθ、管道轴向宽度 b。

② 受力与离心力平衡（课件原式，注意红线下划出的三项）

(p + dp)(r + dr)dθ·b  −  (p + ½dp)dr·½dθ·2b  −  p·rdθ·b  =  ρrdθdrb·v2/r

（左起三项依次为：外侧压力、控制体两侧面压力的径向投影、内侧压力；右端为控制体的离心力。）

整理得 dp/dr = ρv2/r——课件特别标注：这里的速度是截面速度的平均流速。

③ 积分求流量（v 视为常数）

∫pipo dp = ∫riro ρ(v2/r)dr  ⟹  po − pi = ρv2ln(ro/ri)

由测压管读数 po − pi = ρgh  ⟹  v = √( gh / ln(ro/ri) )

Q = vA = (πD2/4)·√( gh / ln(ro/ri) )

通常弯管的中心线曲率半径记为 R，则 ro = R + D/2、ri = R − D/2，故

Q = (πD2/4)·√( gh / ln[ (R + D/2)/(R − D/2) ] )

实际情况下弯管内存在速度分布、二次流和弯曲损失，所以通常写成带修正系数的形式 Q = ξ(πD2/4)√( gh / ln(ro/ri) )，ξ 由实验标定。

答：dp/dr = ρv2/r；Q = (πD2/4)√( gh/ln(ro/ri) )，工程形式 Q = ξ(πD2/4)√( gh/ln(ro/ri) )。
例 3-6（课件 P23）均匀流动中某点压强的求法
题目：水在管中作均匀流动，管路上装有水柱测压管（B、C）与水银测压计（D、E），已知各液面高度，求管中 A 点的压强 pA。

关键认识水在管中均匀流动时，过流断面上压强服从流体静力学规律，即 z + p/(ρg) = c。因此可以像静力学那样逐段用等压面与液柱高度换算，由测压管读数反求 pA。

注意要区分静止流体与运动流动：静止流体中同一水平面（同种连通流体）压强相等；而运动流动中只有均匀流（渐变流）过流断面上才成立 z + p/γ = c，非均匀流的急变流断面上不能这样用。

答：由 z + p/γ = c 沿测压管逐段换算即得 pA（具体数值取决于图中液面高度）。

  • 把"均匀流"当成"等速直线流动"，或反过来把等速直线流动的特殊结论套到管道均匀流上；

8　恒定总流能量方程式（课件 3.8）

课件 3.8 节共 17 页（P24–P43），把元流伯努利方程沿断面"放大"为总流能量方程——关键是三类积分的处理，其中动能积分引入了动能修正系数 α。

8.1　从元流到总流：方程两边乘以 ρg dQ 后积分

出发点（含损失的实际流体元流方程，断面 1-1、2-2 取渐变流断面）：

元流方程

z1 + p1/(ρg) + u12/(2g) = z2 + p2/(ρg) + u22/(2g) + h′l1−2

两边同乘以 ρgdQ，并在断面（流量）上积分：

课件 P28

∫A1(Z1 + p1/(ρg) + u12/(2g))ρgdQ = ∫A2(Z2 + p2/(ρg) + u22/(2g))ρgdQ + ∫Q h′l1−2ρgdQ

即 ∫A1(p1 + γZ1 + γu12/2g)dQ = ∫A2(p2 + γZ2 + γu22/2g)dQ + ∫Qγh′l1−2dQ。下面分三种类型分别积分。

8.2　三类积分

一、势能积分（可用静水分布直接提出积分号）

因为在渐变流断面上压强分布服从静水规律，Z + p/γ = C（常数），故

∫(p1 + γZ1)dQ = ∫(p1/γ + Z1)γdQ = (p1/γ + Z1)∫γdQ = (p1/γ + Z1)γQ

表示单位时间通过该断面的流体势能。

二、动能积分（必须引入动能修正系数 α）

∫Qγu12/(2g)dQ = ∫Aγu13/(2g)dA = (γ/2g)∫Au13dA

用断面平均流速 v = Q/A = ∫AudA/A，引入动能修正系数 α：

动能修正系数

α = ∫Au3dA / ∫Av3dA = ∫Au3dA / (v3A)

(γ/2g)∫Au3dA = (γ/2g)·αv3A = γQ·αv2/(2g)

表示单位时间通过该断面的流体动能（用断面平均流速表示的动能须乘 α 才是真实动能）。

断面流速分布α 值备注
流速均匀分布α = 1理想化的活塞式流动
圆管内充分发展的层流α = 2抛物线分布，umax = 2v，见下
一般湍流（紊流）α = 1.05～1.1 ≈ 1工程计算常取 1
补充：泊肃叶流动（Poiseuille flow）与 α = 2 的来源

泊肃叶流动是圆管内充分发展、定常、不可压、牛顿流体的层流。最典型的特征是：速度在圆管截面上不是均匀分布，而是抛物线分布。对于压差驱动的泊肃叶流动，dp/dx 前带负号是为了保证 u > 0（流动方向上压力降低）；圆管中最大速度与平均速度的关系为 umax = 2v。把抛物线速度分布代入 α 的定义式积分即得 α = 2。

三、能量损失积分

∫Qγh′l1−2dQ = hl1−2γQ，  hl1−2 为平均单位能量损失（按流量加权的平均值）

表示单位时间通过该断面的流体克服 1-2 段阻力做功所损失的能量。

8.3　总流能量方程（本章第二个核心公式）

总流总能量方程

(Z1 + p1/γ + α1v12/2g)γQ = (Z2 + p2/γ + α2v22/2g)γQ + hl1−2γQ

物理含义：单位时间流入上游断面的能量 = 单位时间流出下游断面的能量 + 流段所损失的能量。令断面全部单位机械能 H = Z + p/γ + αv2/(2g)，则 H1γQ = H2γQ + hl1−2γQ。两边除以 γQ 得单位重量流体的能量方程：

恒定总流能量方程式 / 恒定总流伯努利方程

Z1 + p1/γ + α1v12/(2g) = Z2 + p2/γ + α2v22/(2g) + hl1−2

符号含义与取值要求
Z1、Z2选定的 1、2 渐变流断面上任一点相对于选定基准面的高程
p1、p2相应断面同一选定点的压强，且必须同时用相对压强或同时用绝对压强
v1、v2相应断面的平均流速
α1、α2相应断面的动能修正系数
hl1−21、2 两断面间的平均单位水头损失
水头损失的两种成分

沿程水头损失：沿管长均匀发生的均匀流损失（写在水头线上是斜直线）。局部水头损失：局部障碍引起的急变流损失，如管道弯头、接头、闸阀、水表等（写在水头线上是台阶式的铅直下降）。

8.4　适用条件

  1. 定常流动——对于流速随时间变化缓慢的流动，方程仍然适用；
  2. 不可压缩流体——包括压缩性极小的液体流动与 Ma ≤ 0.3 的气体流动；
  3. 适用于渐变流断面——对于管路系统进口处的急变流动不适用；但对于断面流速不大、离心惯性力不显著，或者断面流速项在能量方程中占比很小的情况，可将断面划在急变流处近似求解。

8.5　有能量输入/输出的实用形式

泵、风机（输入能量 H_i）

Z1 + p1/γ + α1v12/2g + Hi = Z2 + p2/γ + α2v22/2g + hl1−2

Hi——输入的单位能量（扬程，m）

水轮机、汽轮机（输出能量 H₀）

Z1 + p1/γ + α1v12/2g = Z2 + p2/γ + α2v22/2g + H0 + hl1−2

H0——输出的单位能量（工作水头，m）

功率换算（课件原话）

单位能量 × ρgQ = 功率，即 N泵 = ρgQHi/η，  N水轮机 = ρgQH0·η（η 为机械效率）

8.6　流动分流

当管路在中间分流时（1 分为 2、3 两支），对 1-2 与 1-3 分别列能量方程：

Z1 + p1/γ + α1v12/2g = Z2 + p2/(ρg) + α2v22/2g + hl1−2  与   = Z3 + p3/(ρg) + α2v32/2g + hl1−3

分流影响的是 hl1−2、hl1−3，但不影响总流能量方程的表达形式。

本节易错提醒（最高频）
  • 断面上的压强 p 和位置高度 Z 必须取同一点的值。例如明渠流动可取在液面，也可取在渠底，但一条方程中必须统一为同一点；
  • 两个断面取了不同基准面，或一端用相对压强、一端用绝对压强；
  • 题给 α = 1.1 等具体值时漏乘 α，或把 α 同时乘在方程两边；
  • 把"总水头线水平"的理想流体结论套用到实际（黏性）流体；
  • 求流量时忘掉 hw 中含有未知 v，应当与 hw = ζv2/2g 联立。

9　能量方程的应用（课件 3.9）

课件 3.9 节共 16 页（P44–P59），把总流能量方程用到四类工程问题上：文丘里流量计、气蚀校核、虹吸与泵管路。方法是"能量方程 + 连续性方程联立"。

9.1　解题步骤（课件 P47，必背）

四步法
  1. 分析流动——判断是否定常、是否渐变流、有无机械与分支；
  2. 划分断面——取已知压强或已知压差的断面（一般取自由液面、管道进出口）；
  3. 选择基准面——一般选择最低点，使 z ≥ 0；
  4. 写出方程——必要时与连续性方程联立求解。

课件补充：断面可取在管流出口以后，也可取在有压管流中。结合连续性方程之后，能量方程可以求 ◆流速 ◆压强 ◆流速和压强。

9.2　文丘里流量计

取进口断面 1-1（面积 A1、直径 d1）与喉部断面 2-2（面积 A2、直径 d2），取基准面使 Z = 0、略去损失：

能量方程 + 连续性方程

0 + p1/γ + v12/2g = 0 + p2/γ + v22/2g  ⟹  p1/γ − p2/γ = v22/2g − v12/2g = Δh

v1(π/4)d12 = v2(π/4)d22  ⟹  v2/v1 = (d1/d2)2  ⟹  v22/v12 = (d1/d2)4

代入得 (d1/d2)4·v12/2g − v12/2g = Δh，故

文丘里流量计（水平放置）

v1 = √(2gΔh) / √[ (d1/d2)4 − 1 ]

Q = v1(π/4)d12 = (π/4)d12·√(2gΔh) / √[ (d1/d2)4 − 1 ] = K√(Δh)

仪器常数 K = (π/4)d12·√(2g) / √[ (d1/d2)4 − 1 ]，K 只和 d1、d2 有关

以上是基于理想流体模型的结果。实际流动有水头损失与结构误差，引入流量系数 μ 修正：

实际流量

Q = μK√(Δh)，  μ = 0.95～0.98（课件 P52 写 0.95~0.98，P54 写 0.96~0.98）

斜放文丘里流量计（课件 P53–P54）

v1 = 1/√[ (d1/d2)4 − 1 ] · √( 2g[ (z1 + p1/(ρg)) − (z2 + p2/(ρg)) ] )

Q = v1A1 = [ (πd12/4) / √((d1/d2)4 − 1) ]·√( 2g[ (z1 + p1/ρg) − (z2 + p2/ρg) ] ) = K√(Δh)，同样 Q = μK√(Δh)

注意读数换算：Δh → ((ρ′ − ρ)/ρ)Δh（水 ρ—水银 ρ′；气 ρ—液体 ρ′）

压差计读数换算（课件 P55，推导必会）

设 U 形压差计内液体重度 γ′、读数差 Δh，两侧液面高 h1、h2，则

p1 + ρgh1 = p2 + ρgh2 + ρ′gΔh  ⟹  (p1/(ρg) + h1) − (p2/(ρg) + h2) = (ρ′/ρ)Δh

而 h1 − h2 = Z1 − Z2 + Δh，故  (p1/(ρg) + Z1) − (p2/(ρg) + Z2) = ((ρ′ − ρ)/ρ)Δh

特例：水—水银（ρ′/ρ = 13.6）时 Δh → 12.6Δh；测气体时 ρ ≪ ρ′，近似 Δh ≈ (ρ′/ρ)Δh。

9.3　关于气蚀（空化、空蚀）

什么是气蚀

低压区产生汽化，高压区气泡破灭空化；它造成流量减小，对机械壁面造成疲劳破坏，这种有害作用称气蚀（空蚀）。凡是流速大、压强低的部位（文丘里喉部、泵吸入口、虹吸管顶部、水轮机尾水管、弯管内侧）都要作气蚀校核，判据是该点绝对压强必须大于当地温度的汽化压强 pv。

例 3-7（课件 P56–P58）文丘里收缩管的气蚀校核
题目：大气压强 97.3 kPa，粗管径 d1 = 150 mm，水温 40 ℃，收缩管直径 d2 应限制在什么条件下才能保证不出现空化（不考虑损失）？

① 查物性水温 40 ℃ 查表得 ρ = 992.2 kg/m3、汽化压强 pv = 7.38 kPa。换算为水头：

pa/(ρg) = 97.3×103/(992.2×9.807) = 10 m，  pv/(ρg) = 7.38×103/(992.2×9.807) = 0.76 m

② 对 1-1（水库自由液面）与 2-2（喉部）列能量方程——必须用绝对压强

10 + 10 = v22/2g + 0.76  ⟹  v22/2g = 19.24 m

③ 对 1-1 与 3-3（出口）列能量方程——可用相对压强：10 = v32/2g，故 v32 = 2×9.807×10 = 196.1，v3 = √196.1 = 14.00 m/s。

④ 连续性方程联立v2/v3 = (d3/d2)2 = (150/d2)2；由 v2 = √(2×9.807×19.24) = 19.43 m/s 得

(150/d2)2 = 19.43/14.00 = 1.387  ⟹  150/d2 = 1.178  ⟹  d2 = 127.3 mm

答：d2 ≥ 127 mm（收缩管直径不得小于约 127 mm，否则喉部将发生空化）。

9.4　文丘里流量计算例

例 9-1（自编典型题，数据参照教材通行例题）文丘里流量计测流量
题目：水平安装的文丘里流量计，进口直径 d1 = 100 mm，喉部直径 d2 = 50 mm，进口与喉部间接一 U 形水银压差计，读数 Δh = 100 mm。水的重度 γ = 9.8 kN/m3，水银重度 γ′ = 13.6γ，流量系数 μ = 0.96。求管道流量 Q。

① 读数换算(p1 − p2)/γ = (γ′/γ − 1)Δh = (13.6 − 1)×0.1 = 1.26 m 水柱。

② 能量方程与连续性取管轴线为基准面（z1 = z2），v2 = v1(d1/d2)2 = 4v1，

(p1 − p2)/γ = (v22 − v12)/2g = (16v12 − v12)/2g = 15v12/2g

⟹ 15v12/(2×9.8) = 1.26  ⟹  v1 = √(2×9.8×1.26/15) = 1.28 m/s

③ 流量Q理 = v1A1 = 1.28×π×0.12/4 = 1.005×10−2 m3/s；Q = μQ理 = 0.96×1.005×10−2 = 9.65×10−3 m3/s ≈ 9.6 L/s

校验：直接用通式 Q = μA1√( 2gΔh / [1 − (d1/d2)4] ) = 0.96×0.007854×√(19.6×1.26/0.9375) = 9.57×10−3 m3/s，与上一致 ✔

答：Q ≈ 9.6×10−3 m3/s（约 9.6 L/s）。

9.5　虹吸管

例 9-2（自编典型题，数据参照教材通行例题）虹吸管的流量与最高点真空度
题目：图示虹吸管，管径 d = 100 mm，上游水面到下游水面的高差 H = 3 m，虹吸管最高点 A 高出上游水面 h = 2 m。已知自上游水面至 A 断面的水头损失 hw1A = 0.5 m，自上游水面至出口断面的总水头损失 hw = 1.0 m。求：①管内流速与流量；②A 点真空度；③校核 A 点是否会发生汽化（20 ℃ 水汽化压强 pv = 2.4 kPa，大气压 pa = 98 kPa）。

① 取上游水面 1-1 与出口断面 2-2（两断面 p = 0 表压、v ≈ 0 或出口为大气压）列能量方程：

H = v2/2g + hw  ⟹  v2/2g = 3 − 1.0 = 2.0 m  ⟹  v = √(2×9.8×2.0) = 6.26 m/s

Q = vA = 6.26×π×0.12/4 = 4.92×10−2 m3/s ≈ 49.2 L/s

② 由 1-1 到 A 断面列能量方程（A 断面 zA = H + h）：

H = zA + pA/γ + v2/2g + hw1A  ⟹  pA/γ = −h − v2/2g − hw1A = −2 − 2.0 − 0.5 = −4.5 m

pA = −4.5×9.8 = −44.1 kPa（表压），即真空度 44.1 kPa（等价 4.5 m 水柱）

③ 汽化校核绝对压强 pA,abs = 98 − 44.1 = 53.9 kPa ≫ pv = 2.4 kPa，不会发生汽化，虹吸作用可靠。若把 A 点抬高，使真空度接近 (pa − pv)/γ ≈ 9.8 m 水柱，则虹吸管将因水柱断裂而失效——这就是工程上虹吸高度一般不超过 7 m 的原因。

答：v = 6.26 m/s，Q ≈ 49.2 L/s；A 点真空度 44.1 kPa；不会汽化。

9.6　泵与管路

例 9-3（自编典型题，数据参照教材通行例题）水泵扬程与功率
题目：水泵自水池抽水，吸水管与压水管直径均为 d = 50 mm，流量 Q = 10 L/s。水池液面高程 z1 = 0，出水池液面高程 z2 = 20 m（两液面均与大气相通、面积很大）。已知自水池液面至出水池液面的总水头损失 hw = 3 m，水泵效率 η = 0.85。求：①水泵扬程 Hp；②泵的有效功率与轴功率。

① 取两液面为计算断面（p1 = p2 = 0 表压、v1 ≈ v2 ≈ 0），在两断面间加入泵的输入水头 Hp：

z1 + p1/γ + α1v12/2g + Hp = z2 + p2/γ + α2v22/2g + hw

Hp = z2 − z1 + hw = 20 + 3 = 23 m

② 功率管内流速 v = Q/A = 0.01/1.963×10−3 = 5.09 m/s，但其速度水头在两液面断面均为零，故不出现。

N有效 = γQHp = 9.8×103×0.01×23 = 2.254×103 W = 2.25 kW

N轴 = N有效/η = 2.25/0.85 = 2.65 kW

结论：扬程由静扬程（液面高差）与管路水头损失之和决定，与泵本身的安装位置无关；出水池液面升高或管路阻力增大（流量增大、管径减小、弯头增多），所需扬程均随之增大。

答：Hp = 23 m；N有效 = 2.25 kW；N轴 = 2.65 kW。
例 9-4（自编典型题，数据参照教材通行例题）泵的吸上高度与汽蚀校核
题目：离心泵从敞口水池抽 20 ℃ 的水，流量 Q = 30 L/s，吸水管直径 d = 150 mm，吸水管总水头损失 hw = 1.2 m，泵样本给出的允许吸上真空度 [Hs] = 6.0 m，当地大气压 pa = 98 kPa，20 ℃ 水汽化压强 pv = 2.4 kPa。求：①吸水管内流速；②泵的最大允许安装高度 Hg。

① 流速与水头A = π×0.152/4 = 1.767×10−2 m2，v = Q/A = 0.03/0.01767 = 1.70 m/s，v2/2g = 1.702/19.6 = 0.147 m。

② 由允许吸上真空度定义[Hs] = Hg + v2/2g + hw（教材通行写法），故

Hg = [Hs] − v2/2g − hw = 6.0 − 0.147 − 1.2 = 4.65 m

③ 校核泵进口处绝对压强水头 ps/γ = pa/γ − [Hs] = 98×103/9.8×103 − 6.0 = 10.0 − 6.0 = 4.0 m，远大于 pv/γ = 2.4×103/9.8×103 = 0.245 m，故不会汽蚀。若水温升高或海拔升高（pa 降低），须对 [Hs] 作修正后再计算。

10　总水头线和测压管水头线（课件 3.10）

课件 3.10 节共 9 页（P60–P68），把能量方程"图形化"。它解决的是能量方程本身解决不了的问题：能量方程只能算出某些断面的流速与压强，要了解全线的流速与压强分布，就要画水头线。

10.1　为什么需要水头线

用能量方程求解一元流动，可以求出某些断面的流速和压强，但并不能给出一元流动全线的流速和压强；解决这个问题需要画出总水头线和测压管水头线。

两条线的定义

总水头线：以水流本身高度的尺寸比例，直接绘在水流上，这样连成的线为总水头线；总水头线用沿水流线逐段减去水头损失给出。

测压管水头线：各断面测压管连成的线即为测压管水头线，由总水头线减去流速水头画出。

课件 P65 强调：4 根线具有能量意义——总水头线、测压管水头线、水流轴线、基准面线。

10.2　基本关系式

课件 P62

总水头 H = z + p/γ + αv2/2g  （位置水头 + 压强水头 + 流速水头）

H1 = H2 + hl1−2  或   H2 = H1 − hl1−2  （总水头沿程只减不增）

测压管水头 Hp = H − αv2/(2g)  （即总水头线向下量取流速水头高度）

课件 P63 的图 3-28 给出了各量的几何含义：基准面以上量取 Z1、Z2（水流轴线高度）；Hp1、Hp2（测压管水头）位于水流轴线之上 p1/γ、p2/γ 处；再向上量取 α1v12/2g、α2v22/2g 即得总水头 H1、H2；两断面总水头之差就是该段的水头损失 hl1−2。

10.3　沿程损失与局部损失的不同画法

画水头线的两条规则
  • 沿程损失可假设为沿管线均匀发生，在总水头线上表现为沿管长倾斜下降的直线；
  • 局部损失假设在局部障碍物处集中发生，表现为在障碍物处铅直下降的台阶。
  • 对于渐缩/渐扩管，可近似处理为将水头损失看做在全长上均匀分布，而不是集中在一点。

课件 P64 的图 3-29（水头损失的计算）给出了一个典型管路的损失构成：水箱出口入口损失 0.5v12/2g；渐缩管段沿程损失 3.5v12/2g；大小头处局部损失 0.1v12/2g；第二管段沿程损失 2v22/2g；两个断面的高差为 8.2 m。作水头线时，逐段把上述损失从总水头中减去即可。

10.4　作水头线的方法与要点

  1. 先定基准面，画出水流轴线（=位置水头线 z）；
  2. 从起始断面（一般取自由液面，此时 H 就等于液面高程）出发，向上量取 H1；
  3. 沿流向逐段减去水头损失得总水头线：沿程段画斜直线，局部障碍处画铅直台阶；
  4. 由总水头线向下量取各断面的流速水头 αv2/2g（流速大的地方量得多、流速小的地方量得少）得测压管水头线；
  5. 校核三条规律：总水头线只降不升；测压管水头线可升可降（渐缩管中流速增大、压强下降，Hp 线下降；渐扩管中相反）；测压管水头线可高于或低于水流轴线（低于轴线表示出现真空/负压，如虹吸管顶部、泵吸入口）。
例 3-8（课件 P66–P68）水箱引水管：求流量并作水头线
题目：用直径 d = 100 mm 的水管从水箱引水，水管水面与管道出口断面中心高差 H = 4 m，水位保持恒定，水头损失 hw = 3 m 水柱。试求水管流量，并作出水头线。

① 列能量方程以 0-0 为基准面（取管道出口断面中心所在水平面），取水箱自由液面 1-1（p1 = 0、v1 ≈ 0、z1 = H）与管道出口断面 2-2（p2 = 0、z2 = 0）：

H + 0 + 0 = v22/2g + hw  ⟹  v2 = √(2g(H − hw)) = √(2×9.8×1) = 4.43 m/s

Q = v2A2 = 4.43×(π×0.12/4) = 0.035 m3/s（课件写 0.35 m3/s，系课件笔误，按 A2 = 7.854×10−3 m2 计算应为 0.035 m3/s）

② 作水头线（课件图，见下）总水头线由液面高程 H = 4 m 起，沿管长线性下降到出口断面的 1 m（下降量恰为 hw = 3 m）；测压管水头线由 H − v22/2g = 4 − 1 = 3 m 起，同样线性下降到出口断面的 1 m。出口断面处两线重合，因为按本例数据恰有 v22/2g = H − hw = 1 m；一般情形下出口断面处测压管水头线与水流轴线相交（p = 0），总水头线仍在轴线之上 v2/2g 处。

答：v2 = 4.43 m/s，Q = 0.035 m3/s；总水头线由 4 m 线性降到 1 m，测压管水头线由 3 m 线性降到 1 m。
定性作水头线的常见题型（课件 P67–P68）

给定管路纵剖面图（水箱、渐缩段、弯头、阀门、出口、下游水池等），要求定性画出总水头线与测压管水头线。解题套路：①起点取上游液面（总水头 = 液面高程）；②在进口、弯头、阀门、突扩突缩处画铅直下降台阶；③在等直径管段画斜直线；④终点落在下游液面高程（若出口淹没）或出口断面的总水头处；⑤测压管水头线 = 总水头线 − 流速水头，注意流速大处两线间距大、渐扩管中测压管水头线可能出现上升、测压管水头线低于管轴线表示该处为负压（真空）。

本节易错提醒
  • 把总水头线画成"沿程升高"或在有泵处画成升高时的方向错误（有泵时总水头线在该处铅直上升，上升量等于泵的扬程；有阀门/弯头处铅直下降）；
  • 等直径管段误画成水平（实际有水头损失，应画成斜直线）；
  • 测压管水头线与总水头线之间的间距漏掉 α 或当成常数（间距 = 该断面的流速水头，随流速变化）；
  • 把明渠流动的"测压管水头线即水面线"结论套到有压管流上。

B.1　动量方程的形式与符号

恒定总流动量方程（矢量式）

∑F = ρQ( β2v2 − β1v1 )

直角坐标分量式（最常用）

∑Fx = ρQ( β2v2x − β1v1x )

∑Fy = ρQ( β2v2y − β1v1y )

∑Fz = ρQ( β2v2z − β1v1z )

β 为动量修正系数 β = ∫Au2dA/(v2A)，含义是"真实动量 / 以断面平均流速计算的动量"；圆管层流 β = 4/3，湍流 β ≈ 1.02~1.05，工程计算常取 β ≈ 1。

正确使用动量方程的四条约定
  1. 取控制体并画出控制面；动量方程是矢量方程，必须先规定坐标正向（或投影方向），再定正负；
  2. ∑F 是作用于控制体内流体上的一切外力：两端断面的压力、控制体表面的切力（常忽略）、重力、以及固体边界对流体的作用力 R；
  3. 求出的 R 是"管壁（或固体）作用在流体上的力"；题目若问"水流对管壁的作用力"，答案是 −R（大小相等、方向相反，牛顿第三定律）；
  4. 动量方程只给出合力关系，断面压强通常还要用能量方程先求出——所以动量问题往往是"能量方程 + 连续性方程 + 动量方程"三式联用。

B.2　典型题：渐变弯管中水流对管壁的作用力

典型题（自编典型题，题型参照《水力学》《工程流体力学》通行例题，"水流对弯管的作用力"）
题目：水平放置的渐缩弯管，水流由断面 1-1 流向断面 2-2 并在水平面内转 90° 弯。已知 d1 = 200 mm、d2 = 150 mm，流量 Q = 0.1 m3/s，断面 1-1 中心相对压强 p1 = 20 kPa，断面 2-2 中心相对压强 p2 = 15 kPa，水的密度 ρ = 1000 kg/m3，不计弯管段的水头损失与重力影响（管轴水平）。取 β1 = β2 = 1。求水流对弯管的作用力。

① 连续性方程求流速

A1 = π×0.22/4 = 3.142×10−2 m2，v1 = Q/A1 = 0.1/0.03142 = 3.18 m/s

A2 = π×0.152/4 = 1.767×10−2 m2，v2 = Q/A2 = 0.1/0.01767 = 5.66 m/s

② 规定坐标与投影方向设 x 轴沿断面 1-1 的流速方向（进口流向），y 轴沿断面 2-2 的流速方向（出口流向）。则

v1：( v1x, v1y ) = ( 3.18, 0 )；  v2：( v2x, v2y ) = ( 0, 5.66 )

③ 受力分析作用于控制体内流体上的外力（水平面内）：断面 1-1 的压力 p1A1（沿 +x）、断面 2-2 的压力 p2A2（沿 −y），以及管壁对流体的作用力 R（设分量为 Rx、Ry）。

④ 列动量方程

x 向：p1A1 + Rx = ρQ(v2x − v1x) = 1000×0.1×(0 − 3.18) = −318 N

p1A1 = 20×103×3.142×10−2 = 628.4 N  ⟹  Rx = −318 − 628.4 = −946.4 N

y 向：−p2A2 + Ry = ρQ(v2y − v1y) = 1000×0.1×(5.66 − 0) = 566 N

p2A2 = 15×103×1.767×10−2 = 265.1 N  ⟹  Ry = 566 + 265.1 = 831.1 N

⑤ 合力与方向

R = √(946.42 + 831.12) = √(895 672 + 690 727) = √1 586 399 = 1259.5 N ≈ 1.26 kN

方向与 +x 轴的夹角：tan θ = 831.1/(−946.4) ⟹ θ = 180° − 41.3° = 138.7°（即指向第二象限、斜向后上方）

⑥ 由牛顿第三定律水流对弯管的作用力 F = −R：大小 1.26 kN，方向与 R 相反（θ′ = 138.7° − 180° = −41.3°，即与进口流速方向成 −41.3°、斜向弯管的外侧），相当于把弯管往出口流向的反侧推——这正是弯管处必须设置镇墩（固定支墩）的原因。

答：水流对弯管的作用力大小约 1.26 kN，方向与进口流速方向成 −41.3°（斜向前下方）；管壁对流体的作用力与之等值反向，指向第二象限、与进口流速方向成 138.7°。
动量方程类题目易错提醒
  • 矢量性：忘记投影、把矢量当标量直接相加，或未统一坐标正向；
  • 对象混淆：求出的 R 是"固体给流体的力"，题目要"水流对固体的力"时必须取反；
  • 漏掉端面压力：动量方程右端是动量差（通常很小，几百牛），左端的压力项（几百千牛量级）绝不能漏，否则结果相差几个数量级；
  • 压强未先求：端面压强必须用能量方程 + 连续性方程先算出（或由题给），不能凭空设为零（射流冲击自由射流才可用 p = 0）；
  • 把 β 漏乘（题给 β ≠ 1 时），或把 α 误用到动量方程中。

练习 1　文丘里流量计 + 压差计读数换算（自编典型题）
题目：水平安装的文丘里流量计，进口直径 d1 = 200 mm，喉部直径 d2 = 100 mm，进出口之间接水银 U 形压差计，读数 Δh = 120 mm。水的重度 γ = 9.8 kN/m3，水银重度 γ′ = 13.6γ，流量系数 μ = 0.96。求：①进口断面平均流速 v1；②管道流量 Q；③仪器常数 K，并验证 Q = μK√(Δh′)。

① 读数换算Δh′ = (γ′/γ − 1)Δh = (13.6 − 1)×0.120 = 1.512 m 水柱

② 由能量方程求流速取管轴线为基准面，v2 = v1(d1/d2)2 = 4v1：

v22/2g − v12/2g = (16 − 1)v12/2g = Δh′

v1 = √( 2×9.8×1.512/15 ) = √1.9757 = 1.406 m/s

③ 流量Q理 = v1A1 = 1.406×(π×0.22/4) = 1.406×0.031416 = 0.04417 m3/s；Q = μQ理 = 0.96×0.04417 = 0.0424 m3/s ≈ 42.4 L/s

④ 仪器常数校验K = (A1√(2g))/√[(d1/d2)4 − 1] = 0.031416×4.427/√15 = 0.03591；Q = μK√(Δh′) = 0.96×0.03591×√1.512 = 0.96×0.03591×1.2297 = 0.0424 m3/s ✔

答：v1 = 1.41 m/s；Q = 4.24×10−2 m3/s（42.4 L/s）；K = 0.0359，与 Q = μK√(Δh′) 一致。
练习 2　虹吸管：流量、最高点真空度与汽化校核（自编典型题）
题目：虹吸管管径 d = 150 mm，上游水面到下游水面的高差 H = 4 m，虹吸管最高点 A 高出上游水面 3 m，自上游水面到出口的总水头损失 hw = 1.5 m，自上游水面到 A 点水头损失 hw1A = 0.8 m。20 ℃ 水的汽化压强 pv = 2.4 kPa，当地大气压 pa = 98 kPa。求：①管内流速与流量；②A 点真空度；③判断能否正常工作。

① 能量方程求流速取上游水面 1-1 与出口断面 2-2：

H = v2/2g + hw  ⟹  v2/2g = 4 − 1.5 = 2.5 m  ⟹  v = √(19.6×2.5) = 7.00 m/s

A = π×0.152/4 = 1.767×10−2 m2，Q = vA = 7.00×1.767×10−2 = 0.1237 m3/s ≈ 123.7 L/s

② A 点真空度由 1-1 到 A 断面（zA = H + 3 = 7 m）：

H = zA + pA/γ + v2/2g + hw1A  ⟹  pA/γ = 4 − 7 − 2.5 − 0.8 = −6.3 m

pA = −6.3×9.8 = −61.7 kPa（表压），真空度 61.7 kPa

③ 校核pA,abs = 98 − 61.7 = 36.3 kPa > pv = 2.4 kPa，不会汽化，虹吸管能正常工作。但真空度已接近 6.3 m 水柱，若再抬高 A 点或增大流量（损失增大），则水柱可能断裂。

答：v = 7.00 m/s，Q = 0.124 m3/s；A 点真空度 61.7 kPa；能正常工作。
练习 3　水泵装置：扬程与功率（自编典型题）
题目：水泵将水从水池 1 送到水池 2，两水池液面高差 5 m（水池 2 的液面标高 5 m，水池 1 液面标高 0），两液面均与大气相通、面积很大。管路总水头损失 hw = 8 m，流量 Q = 0.5 m3/s，水的重度 γ = 9.8 kN/m3，泵的效率 η = 0.82，传动效率取 1.0。求：①泵的扬程 Hp；②泵的有效功率与轴功率；③配套电机功率（取裕量 1.1）。

① 扬程取两液面为断面，得 Hp = z2 − z1 + hw = 5 + 8 = 13 m。

② 功率

N有效 = γQHp = 9.8×103×0.5×13 = 6.37×104 W = 63.7 kW

N轴 = N有效/η = 63.7/0.82 = 77.7 kW

③ 配套电机N电机 = 1.1N轴 = 1.1×77.7 = 85.5 kW（选标准 90 kW 电机）。

要点：扬程 = 静扬程（液面高差）+ 水头损失，与安装位置无关；功率换算一律用"单位能量 × ρgQ"。

练习 4　文丘里管的空化（气蚀）校核（自编典型题）
题目：水（20 ℃，ρ = 998 kg/m3，汽化压强 pv = 2.4 kPa）沿水平管路流动，管路直径 d1 = 150 mm，进口断面中心相对压强 p1 = 40 kPa，流量 Q = 0.05 m3/s，当地大气压 pa = 98 kPa。管路中接入一文丘里收缩段，为保证不出现空化，收缩段（喉部）直径 d2 至少应为多少？（不计收缩段水头损失）

① 进口流速A1 = π×0.152/4 = 1.767×10−2 m2，v1 = Q/A1 = 0.05/0.01767 = 2.83 m/s，v12/2g = 2.832/19.6 = 0.409 m。

② 允许的最低绝对压强喉部压强不得低于汽化压强，取极限条件 p2,abs = pv = 2.4 kPa。进口绝对压强 p1,abs = pa + p1 = 98 + 40 = 138 kPa。（求绝对压强时须加大气压；也可全程用绝对压强列方程）

③ 能量方程（用绝对压强，水平管 z1 = z2）

p1,abs/γ + v12/2g = p2,abs/γ + v22/2g

p1,abs/γ = 138×103/(998×9.8) = 14.11 m，  p2,abs/γ = 2.4×103/(998×9.8) = 0.245 m

v22/2g = 14.11 + 0.409 − 0.245 = 14.27 m  ⟹  v2 = √(19.6×14.27) = 16.72 m/s

④ 连续性方程定直径v2/v1 = (d1/d2)2 ⟹ (d1/d2)2 = 16.72/2.83 = 5.91 ⟹ d1/d2 = 2.431

d2 = 150/2.431 = 61.7 mm  ⟹  为保证不空化，应取 d2 ≥ 62 mm

要点：①涉及汽化/空化的计算必须统一用绝对压强，进口表压要加大气压；②喉部流速越大、压强越低，因此收缩比不能过大；③工程上除限制 d2 外，还可提高进口压强或降低水温（降低 pv）。

答：d2 ≥ 61.7 mm（取不小于 62 mm），否则喉部压强将降至汽化压强以下而发生空化。
练习 5　等直径管路：流量 + 水头线绘制（自编典型题）
题目：水箱通过直径 d = 100 mm、长 L = 50 m 的水平管路向大气自由出流，水箱液面高出管道出口中心 H = 5 m，水箱液面保持恒定（面积很大）。已知管路沿程阻力系数 λ = 0.025，出口局部损失系数 ζ = 1.0，进口损失忽略不计。取 g = 9.8 m/s2。求：①管内流速与流量；②沿程水头损失与局部水头损失；③画出总水头线与测压管水头线的关键数值。

① 能量方程 + 损失表达式联立取水箱液面 1-1（p1 = 0、v1 ≈ 0、z1 = 5 m）与出口断面 2-2（p2 = 0、z2 = 0）：

H = v2/2g + hw，  hw = λ(L/d)v2/2g + ζv2/2g = (0.025×50/0.1 + 1.0)v2/2g = 13.5v2/2g

⟹ 5 = (1 + 13.5)v2/2g = 14.5v2/2g  ⟹  v2/2g = 5/14.5 = 0.3448 m  ⟹  v = √(19.6×0.3448) = 2.60 m/s

Q = vA = 2.60×(π×0.12/4) = 2.60×7.854×10−3 = 0.0204 m3/s ≈ 20.4 L/s

② 损失分配hf = 12.5×0.3448 = 4.31 m（沿程）；hj = 1.0×0.3448 = 0.345 m（局部，出口）。校核：hw = 4.31 + 0.345 = 4.655 m，H − v2/2g = 5 − 0.345 = 4.655 m ✔

③ 水头线关键数值（基准面取管道轴线）

  • 总水头线：起点在进口断面处 H = 5 m，沿程均匀线性下降 4.31 m，到出口前降至 5 − 4.31 = 0.69 m；出口局部损失处再铅直下降 0.345 m，到出口断面为 0.345 m（= v2/2g，与水流轴线的高度差即为流速水头）；
  • 测压管水头线 = 总水头线 − 流速水头（本例各断面流速相同，流速水头恒为 0.345 m，两线平行），故 Hp 由进口的 5 − 0.345 = 4.655 m 线性降至出口前的 0.345 m，出口断面处 Hp = 0（与水流轴线相交，即出口压强为大气压）；
  • 校核规律：总水头线只降不升 ✔；出口断面测压管水头线落在水流轴线上（p = 0）✔；沿程段两线平行（等直径、流速不变）✔。

要点：凡"损失与流速有关"的题目，必须把能量方程与 hw = (λL/d + ∑ζ)v2/2g 联立求解——不能把 hw 当作已知常数代入。

答：v = 2.60 m/s，Q = 0.0204 m3/s；hf = 4.31 m，hj = 0.345 m；总水头线由 5 m 线性降至 0.345 m（出口前 0.69 m 处再铅直下降 0.345 m），测压管水头线由 4.655 m 降至出口的 0（与轴线相交）。
练习 6　动量方程：水平等径 90° 弯管中水流对管壁的作用力（自编典型题，题型参照通行教材"水流对弯管的作用力"经典例题）
题目：水平放置的等直径 90° 弯管（管轴在水平面内），管径 d = 200 mm，水流量 Q = 0.10 m3/s，弯管进口断面 中心相对压强 p1 = 20 kPa，弯管出口断面中心相对压强 p2 = 18 kPa，水的密度 ρ = 1000 kg/m3，取 β1 = β2 = 1.0，不计弯管段水头损失。求水流对弯管的作用力（大小与方向）。

① 流速（等径管，进出口流速大小相同）A = π×0.22/4 = 3.142×10−2 m2，v = Q/A = 0.1/0.03142 = 3.18 m/s

② 规定坐标取 x 轴沿进口流速方向，y 轴沿出口流速方向（两者垂直）。则 v1 = (3.18, 0)、v2 = (0, 3.18)。

③ 外力分析断面 1-1 的压力 p1A 沿 +x；断面 2-2 的压力 p2A 沿 −y；管壁对流体的作用力 R（分量 Rx、Ry）；重力与管轴垂直（水平弯管）不影响水平面内的平衡。

④ 动量方程

x 向：p1A + Rx = ρQ(0 − v) = 1000×0.1×(0 − 3.18) = −318 N

p1A = 20×103×3.142×10−2 = 628.4 N  ⟹  Rx = −318 − 628.4 = −946.4 N

y 向：−p2A + Ry = ρQ(v − 0) = 318 N

p2A = 18×103×3.142×10−2 = 565.6 N  ⟹  Ry = 318 + 565.6 = 883.6 N

⑤ 合力R = √(946.42 + 883.62) = √(895 672 + 780 749) = √1 676 421 = 1294.8 N ≈ 1.29 kN

这是管壁作用在流体上的力，方向与 +x 成 θ = 180° − arctan(883.6/946.4) = 180° − 43.1° = 136.9°。

⑥ 牛顿第三定律水流对弯管的作用力大小同为 1.29 kN，方向与进口流速方向成 136.9° − 180° = −43.1°，即斜向弯管的外侧。工程意义：弯管处必须设置镇墩（固定支墩）承受这一推力；管径大、流速高、压强高时该力可达数十千牛。

答：水流对弯管的作用力约 1.29 kN，方向与进口流速方向成 −43.1°（斜向弯管外侧）。
