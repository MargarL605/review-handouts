读前须知：这门课到底在讲什么

先给你一张地图，否则后面每一章都会像突然冒出来的。 工程热力学只做一件事：算清楚「热量、功、能量」在机器里是怎么进、怎么出、怎么变形的。 为此它必须回答三个层层递进的问题：能量守恒吗（第一定律）？能量往哪个方向走（第二定律）？某种工质的能量到底怎么算（状态方程与比热）。 七章内容就是这三问的展开。
章它要回答的问题它在整门课里的位置
第 1 章 基本概念我们在研究「哪一团东西」？用什么量描述它？语言与语法：系统、状态参数、准静态、可逆、功、热——后面所有章节都用这套词说话。这一章没学透，后面每一句都读不懂。
第 2 章 理想气体这团气体的 p、v、T 之间什么关系？它的内能、焓怎么算？工质的"身份证"：给出 pV=RT、cp、cv、κ。没有它，第一定律只是一个算不出来的符号式子。
第 3 章 第一定律能量守恒在这团气体身上具体写成什么式子？核心发动机：q=Δu+w（闭口）与 q=Δh+wt（开口）。整门课一半的计算题都从这两个式子出发。
第 4 章 热力过程与压气机过程一旦被规定（定压/定容/定温/定熵/多变），各个量能不能直接算出来？第一定律的实战应用：把 pvn=常数 代进第一定律，得到一整套"套公式就能算"的结果；压气机是它的工程出口。
第 5 章 第二定律为什么有些过程虽然能量守恒却永远不发生？损失了多少做功能力？方向的法官：熵、卡诺定理、克劳修斯不等式、孤立系统熵增、i=T0Δsiso。判断"能不能实现"和"损失多大"全靠它。
第 6 章 微分关系式熵、焓、内能这些量，能不能只用 p、v、T 的可测量表示出来？数学工具箱：吉布斯方程、麦克斯韦关系。它把"测不出来的 s"换成"量得出来的 p、v、T"，是第 5 章的理论后台。
第 7 章 水蒸气水不是理想气体，那它的过程怎么算？真实工质：相变、蒸汽表、h-s 图。电厂、锅炉、汽轮机全用它，是理想气体方法失效后的替代方案。
把这门课想成记账。 你家的钱（能量）只有两个来路：赚（吸热 q）和别人替你还账（外界做功 w）；只有两个去路：花掉（对外做功）和存起来（内能 u 增加）。 第一定律就是「收支必须平衡」这条铁律。第二定律说：钱可以全花掉，但手续费（熵产）一定存在，而且这笔手续费换不回钱来——这就是"做功能力损失"。 整门课，就是在不同的账户（闭口系统、开口系统、稳定流动）上，把这张收支表列清楚。

0.1 三个贯穿全课的符号约定（先背下来，后面不再重复）

约定内容为什么这样定
热量 q系统吸热为正（q>0 吸热，q<0 放热）与"存钱为正"一致，让 q=Δu+w 写成加法最自然
功 w系统对外做功为正（w>0 膨胀做功，w<0 外界压缩）与"花出去为正"一致

✗ 温度不换算就代进公式。例：t1=27 ℃、t2=127 ℃，若直接写 T2/T1=127/27=4.7，正确值是 400/300=1.33。

第 1 章 基本概念：把「一团气体」变成可以计算的对象

这一章不教你算任何一道工程题，但它决定你后面七章能不能读懂题。 你面对一台机器，第一件事不是套公式，而是回答两个问题：我要研究的到底是哪一部分物质？它的边界画在哪里？ 边界画错了，能量方程里就会多出一项、少掉一项，后面全错。这就是"系统"这个概念存在的唯一理由。 第二件事是：这团东西现在是什么状况？必须有几个数字能把它唯一确定下来，否则"状态变了多少"就无从谈起。这就是"状态参数"。 第三件事：它从 A 变成 B，中间走的是哪条路？不同的路，功和热完全不同——这就是"过程"。 三件事说完，才能谈功和热的计算。
先想一个生活中的场景。 家里的空调在制冷。你要算"这个月电费涨了多少"，你得先划清一件事：只算空调，还是算整个家？ 如果只算空调，那冰箱、照明、路由器都是"外界"，它们跟空调之间的电、热交换都要单独记账； 如果算整个家，那冰箱和空调之间的空气热交换就成了"内部事务"，互相抵消，不用记。 两种划法都能算出正确答案，但只有一种最省事。热力学里的"选系统"，就是这道选择题。

1.1 热力系统：研究对象 + 边界 + 外界

1.1.1 三个词的定义，以及为什么必须"人为"划线

三个定义

系统（热力系统）：被人为地从周围环境中划分出来、作为研究对象的那部分物质。它可以是一团气体、一台压缩机里的全部工质，也可以是整台锅炉。

边界：系统与外界的分界面。它不一定是真实存在的壁面——可以是假想的几何面，可以是固定不动的，也可以是运动、变形的（比如活塞端面、正在收缩的气团表面）。

外界（环境）：边界以外、与系统发生相互作用的一切物体。

请注意"人为"这两个字。同样是压缩空气，你可以把"气缸里的空气"当系统，也可以把"空气 + 活塞 + 气缸"一起当系统。 前者边界取在气缸内壁，后者边界取在气缸外壁。选哪个不是对错问题，而是哪个让方程更简单的问题。这是这门课第一个、也是最重要的自由。

1.1.2 划分依据一：按「边界上交换什么」分三类

类型边界上允许穿过的东西典型例子与含义
闭口系统
(封闭系统)		 可以有热、可以有功；没有质量穿过 活塞气缸里的定量气体、密封罐头里的空气。系统内质量恒定，这是它最本质的特征，也是"闭口"两个字的由来。
开口系统
(控制体积)		 除了热、功，还有质量流进流出 正在充气的储气罐、流经汽轮机的蒸汽、连续工作的压气机。工程上绝大多数设备都是开口的。
绝热系统 热被挡住（q=0），功和质量仍可穿过 包了很厚保温层的容器、过程进行得极快来不及换热的设备（如喷管、扩压管）。注意：绝热只是"没有热交换"，不等于"没有功"，更不等于"没有能量交换"。
孤立系统 什么都不许穿过：无热、无功、无质量 系统 + 参与换热的所有外界，一起打包。第 5 章判断过程能否发生，就在孤立系统上做文章（Δsiso ≥ 0）。
易错三连 ✗ "绝热系统就是孤立系统。" ✓ 绝热系统还可能有功和质量的交换。孤立系统才是什么都不交换。
✗ "开口系统里的质量一定在变。" ✓ 进多少出多少时质量可以不变，叫稳定流动——这正是第 3 章的重点，也是最省事的一类开口系统。
✗ "边界必须是真实壁面。" ✓ 边界可以是假想面（例如从大气里"切"出一块空气当系统）。

1.1.3 划分依据二：按「成分」分两类

工程上的工质有两种来源：

  • 纯物质：化学成分单一，例如纯水、纯氮。第 7 章的水蒸气就是纯物质。
  • 混合物：多种成分，例如空气（N2、O2、Ar 等）、烟气、燃气。第 2 章最后一节专门讲混合物的算法。

为什么要在意这个区分？因为"纯物质"和"混合物"在相变时的行为完全不同——纯水在一个固定压力下只有一个沸腾温度，而盐水沸腾温度会随浓度变。这门课前面用的空气、氮气都按混合物或纯物质分别处理，第 7 章则专门对付相变。

看懂例 1-1　三句话判断系统类型

下列各情况中，若把斜体部分取作系统，它属于闭口、开口还是绝热系统？

  1. 用打气筒给自行车胎打气，取打气筒内的空气为系统；
  2. 同上，取自行车内胎里的空气为系统（正在被打气）；
  3. 蒸汽流经汽轮机，取汽轮机内腔的蒸汽为系统。

解　判断只有一个动作：看边界上有没有质量穿过。

  1. 打气筒内的空气：活塞在推，筒内空气质量在变（新空气不断被吸进），有质量进出 → 开口系统。若取"某一次吸气后活塞封死的那部分空气"，则为闭口。
  2. 内胎里的空气：进气阀在往胎里灌气，胎内空气质量在增加，有质量进入 → 开口系统。
  3. 汽轮机内腔的蒸汽：蒸汽不断流入、流出，开口系统；又因为汽轮机外壳包了保温层、且流动极快，通常还按绝热处理（q=0），但仍向外输出轴功 wt。

关键动作：先在图上把边界画出来，再问"有没有质量穿过这条线"。这一招在第 3 章选能量方程时还要用一次。

1.2 状态与状态参数：给一团工质"拍一张身份证"

为什么需要"状态参数"？ 因为热力学只关心"宏观上这团东西现在怎么样"，而不关心每个分子怎么飞。 一团 1 kg 空气，在 300 K、100 kPa 下，不管里面分子怎么乱撞，只要这三个数字确定，它的内能 u、熵 s、比容 v 就全都确定了。 换句话说：少数几个可测量的量，就能把整团工质的状态"锁死"。这几个量就叫状态参数。 没有它们，你连"初态"和"终态"都写不出来，更谈不上算差值。
状态参数就像体检报告上的指标。 你去体检，医生不会记录"你身上每个细胞在干什么"，只记身高、体重、血压、体温这些宏观指标。 这些指标一旦确定，你的"健康状态"就被描述清楚了。热力学里的 p、v、T、u、h、s 就是工质的体检指标。 而"你今年胖了几斤"这种过程量（相当于功和热），取决于你怎么吃的，不是某一时刻的状态。

1.2.1 状态参数的定义与四大性质

状态参数：描述系统所处状态、其数值只取决于当前状态而与达到该状态的历史无关的宏观物理量。

这句话可以拆成四条可操作的性质，考试全靠这四条：

状态参数的四个数学性质（后面每一章都在用）
  1. 单值性：给定状态，参数有唯一确定的值。所以"某状态的温度"是能说的。
  2. 路径无关性：ΔT = T2 − T1，不管中间怎么绕。所以循环一圈后 Δu=0、Δs=0、Δh=0。
  3. 全微分性：可写成 dz = Mdx + Ndy，且 ∮dz = 0。第 6 章的麦克斯韦关系就是从这里来的。
  4. 可加性分类：与质量成正比的叫广延量（V、U、H、S），与质量无关的叫强度量（p、T）。广延量除以质量得到比参数（v、u、h、s），比参数也是强度量。这就是为什么公式里一会儿大写 V、一会儿小写 v，写错就全错。

1.2.2 三个最基本的状态参数：p、v、T

（1）压力 p：分子撞击壁面的宏观表现

从分子运动论看，压力就是大量分子不断撞击容器壁、把动量传给壁面的结果。宏观上定义为单位面积上的垂直作用力：

p = Fn / A　　[Pa] = [N/m2]

但在工程上，压力表读出来的数不是这个 p。压力表的原理是"拿被测压力和大气压比大小"，它显示的只是差值。于是必须分清三个压力：

名称定义什么时候用
绝对压力 p以绝对真空（p=0）为基准的真实压力一切热力学公式只能用绝对压力（pV=RT、q=Δh+wt…）
表压力 pepe = p − pb，压力表的读数（p > pb 时）工程仪表读数、题目给"表压"时
真空度 HH = pb − p，真空表的读数（p < pb 时）凝汽器、真空容器、水泵吸入口
一条式子解决全部换算 当 p > pb：p = pb + pe　　　当 p < pb：p = pb − H 大气压 pb 是随时变化的量（随海拔、天气变），题目不给就取标准大气压 101.325 kPa。表压力和真空度都是"相对量"，不能当状态参数用。

（2）比容 v 与密度 ρ：单位质量的"占地方"

v = V / m　[m3/kg]　　　　ρ = m / V = 1 / v　[kg/m3]

请务必分清三兄弟，这是全课最容易写错的地方之一：

  • V（大写）：总容积，单位 m3，是广延量；
  • v（小写）：比容，单位 m3/kg，是强度量；
  • Vm 或 vm：摩尔容积，单位 m3/kmol，注意与 v 差一个摩尔质量。

（3）温度 T：分子平均动能的量度

热力学温度 T（单位 K）与摄氏温度 t（单位 ℃）的关系是：

T = t + 273.15　[K]

热力学第一、第二定律的所有公式里，T 必须是 K。原因很简单：只有用 K，pV=RT 才是正比关系，η=1−T2/T1 才有意义。用 ℃ 代入，得到的数在物理上没有任何意义。

易错三连 ✗ 把"表压 30 kPa"直接代进 pV=mRT。 ✓ 必须先加 pb：p=101.325+30=131.325 kPa。
✗ 把 v 和 V 混用，算出"比容 3 m3"。 ✓ 先看题目给的是质量还是容积；给了质量才谈得上 v。
✗ 温度差 Δt 与 ΔT 是相等的，但温度比值绝不能混用。 ✓ ΔT=Δt 可以互换；T2/T1 必须换算成 K。

1.2.3 液柱测压计：把压力变成看得见的高度

最常用的测压工具是 U 形管。原理极简单：同一静止流体、同一水平面上的压力相等（这叫连通器原理，本质是静力学平衡）。

由连通器原理，从开口端液面沿同一水平面走到管的另一侧，压力相等：

U 形管公式的推导（一步不跳）
  1. 取开口端液面为基准高度，该面上方通大气，压力为 pb。
  2. 从该面向下走 h 到达管底同一水平面，液体静压增加 ρgh，故该水平面上的压力为 pb + ρgh。
  3. 在管底这一水平面上，左侧与右侧是同一种静止液体、同一高度，压力必然相等。
  4. 左侧液面上方就是被测气体，压力为 p。于是
p = pb + ρgh　（测高于大气压的气体）
  1. 若被测压力低于大气压，则管内液体被"吸"上去，读数表示的是真空度：
H = ρgh，p = pb − H

注意：公式里的 h 永远是竖直高度差，不是斜管长度 L。若管子倾角为 α，则 h = L sinα。

看懂例 1-2　最简单的绝对压计算

某容器内气体压力由 U 形管测得：管内为水银，两端液面差 h=200 mm，开口端通大气，当地大气压 pb=101.325 kPa，水银密度 ρ=13600 kg/m3，取 g=9.81 m/s2。求容器内气体的绝对压力。

解　液面差说明被测压力高于大气压。

p = pb + ρgh = 101325 + 13600×9.81×0.200 = 101325 + 26683 = 1.28×105 Pa = 128 kPa

单位一定要统一到 Pa：h 用 m、ρ 用 kg/m3、g 用 m/s2。h=200 mm 写成 0.2 m，是这一步唯一的坑。

模仿例 1-3　斜管测压计（对应计算练习 1-4）

锅炉烟道中烟气压力用上部开口的斜管测压计测量。已知斜管倾角 α=30°，压力计用密度 ρ=800 kg/m3 的酒精，斜管中液柱长度 L=200 mm，当地大气压力 pb=0.1 MPa。求烟气的绝对压力。

解　

  1. 先把斜长换成竖直高度：h = L sinα = 0.200 × sin30° = 0.200 × 0.5 = 0.100 m。
  2. 再算液柱产生的表压：pe = ρgh = 800 × 9.807 × 0.100 = 784.6 Pa ≈ 0.785 kPa。
  3. 烟道内是负压（引风机抽着），所以这是真空度，绝对压力为
    p = pb − ρgh = 100 − 0.785 = 99.2 kPa
答　表压约 0.785 kPa（真空度），烟气绝对压力约 99.2 kPa。

这道题最大的陷阱是单位：0.785 kPa 不是 0.785 MPa，两者差 1000 倍。酒精密度只有水的 0.8 倍，200 mm 斜管的竖直高度只有 100 mm，产生的压力差不到 1 kPa——这正好说明锅炉烟道的负压很小。计算练习 1-4 的标准答案就是 0.7845 kPa / 102.1 kPa（若按大气压 101.325 kPa 且为正压计）。

应考例 1-4　多支压力表的综合读数（对应简答题"绝对压力与表压力"）

容器 A 被隔板分成 A、B 两室，如课本图 1-7 所示。已知当地大气压 pb=0.1013 MPa，压力表 1 读数 pe1=0.294 MPa，压力表 2 读数 pe2=0.04 MPa。求压力表 3 的读数应为多少 MPa。

解　这类题的通用套路是：先把每个表换算成绝对压，再在连通处用"同一水平面压力相等"建方程。

  1. A 室绝对压：pA = pb + pe1 = 0.1013 + 0.294 = 0.3953 MPa。
  2. 压力表 2 测的是 B 室相对大气的压力：pB = pb + pe2 = 0.1013 + 0.04 = 0.1413 MPa。
  3. 压力表 3 接在 A、B 之间，读数是两者之差（A 高 B 低）：
    pe3 = pA − pB = 0.3953 − 0.1413 = 0.254 MPa
答　压力表 3 的读数为 0.254 MPa。

若 B 室是真空（pB < pb），第 2 步要改成 pB = pb − H，符号一错答案就差了 2pb。所以读题时第一件事：圈出"表压/真空度/绝对压"这三个词。

1.3 平衡状态与状态公理：为什么"两个参数就够了"

为什么非要"平衡"？ 前面说"给定状态，参数唯一确定"，这句话只有在平衡状态下才成立。 如果气缸里一半 500 ℃、一半 20 ℃，你根本无法回答"这团气体的温度是多少"——因为它没有一个温度。 所以"平衡"不是一个可有可无的假设，它是"状态参数存在"的前提。而"参数有几个是独立的"，则由状态公理给出。

1.3.1 什么叫热力平衡：四个"不再变化"

系统在不受外界影响的条件下（没有温差、压差、化学势差造成的推动力），如果宏观性质长期不随时间变化，就说它处于热力平衡状态。它包含四个方面：

平衡类型判据不满足时会怎样
热平衡系统各部分温度相等，无热量净传递有温差 → 热量流动 → 状态在变
力平衡系统各部分压力相等，无相对位移趋势有压差 → 气体流动、活塞移动
化学平衡各部分化学成分不随时间变化，无化学反应有反应 → 成分变、放热吸热
相平衡各相之间无净相变（如冰水共存时温度固定）有净蒸发/凝结 → 各相质量在变
三个概念别混 平衡 ≠ 均匀：平衡只要求"不再变化"，不要求"处处一样"。重力场中的水，底部压力比顶部大，但它是平衡的。
稳定 ≠ 平衡：稳定指"不随时间变"，但可能有外界持续输入维持（比如稳定流动）。平衡是"没有外界影响也能一直不变"。
平衡态是一个理想概念：真实系统总有微小涨落。热力学把它当作可以无限接近的极限来处理。

1.3.2 状态公理：简单可压缩系统只要两个独立参数

状态公理：对于简单可压缩系统（只进行体积功、没有化学反应的系统），确定其平衡状态的独立状态参数数目等于 n + 1，其中 n 是系统与外界交换的可逆功的种类数。

工程上最常见的简单可压缩系统只交换体积功一种（n=1），所以只需要 2 个独立参数就能确定状态。

为什么是 2 个？可以这样理解：

为什么"两个参数定死一个状态"
  1. 系统有多少个状态参数？理论上无穷多：p、v、T、u、h、s、cp…
  2. 但它们不是互相独立的。比如理想气体有 pV=mRT，只要知道 p、v、T 中的任意两个，第三个就定死了。
  3. 而 u、h、s 又都是 p、v、T 的函数（第 2、6 章给出具体表达式）。所以只要 p、v、T 中定了两个，全部参数就都定了。
  4. 结论：用一个平面坐标系就能画出状态图——横轴 v、纵轴 p，叫 p-v 图；横轴 s、纵轴 T，叫 T-s 图。图上一个点 = 一个平衡状态。
f(p, v, T) = 0　　← 状态方程（第 2 章会给出理想气体的具体形式 pv=RT）
看懂例 1-5　判断能不能"定死"状态

下列说法是否正确：(1) 给定 1 kg 空气的 p 和 T，其状态就确定了；(2) 给定 p 和 v，其温度就确定了？

解　(1) 正确。简单可压缩系统只要两个独立参数。(2) 也正确，因为 T = pv/R 可直接算出。但要注意：(1) 中"1 kg"这个条件不能少——如果不给质量，p、T 相同的两团气体，容积可以不同，说明"系统"没定死。

考试里"给定两个参数能否确定状态"的题，判据永远是：是不是简单可压缩系统 + 有没有给定质量/其他约束。

1.4 准静态过程与可逆过程：把"变化"变成能积分的曲线

为什么非要有"准静态"这个奇怪的东西？ 因为如果活塞一下子被抽掉，气体瞬间乱成一团，中间每个时刻的 p、T 到底是多少？没人知道，也画不出来。 那么功 w=∫pdv 就没法算。工程上必须想个办法，让过程"慢到每一刻都近似平衡"，这样每一刻都能用状态参数描述，曲线才画得出来、才积得了分。 准静态不是物理上必须的，而是数学上必须的。

1.4.1 准静态过程：无限缓慢的过程

准静态过程（准平衡过程）：过程进行得无限缓慢，使系统在每一瞬间都无限接近平衡状态的过程。它的数学标志是：过程在状态图上可以表示为一条连续的曲线。

怎样才算"无限缓慢"？判据是：过程进行的时间 ≫ 系统内部建立平衡所需的时间（弛豫时间）。所以"慢"是相对的——对气体来说几秒钟可能已经很快，对金属块来说几小时也许还不够。

1.4.2 可逆过程：能原路返回且不留痕迹

可逆过程：系统完成某一过程后，若能沿原路径逆向进行，使系统与外界全部恢复原状而不留下任何变化，则该过程为可逆过程。

可逆过程必须同时满足两个条件：

  1. 是准静态过程（内部可逆）；
  2. 没有任何耗散效应：无摩擦、无黏性、无电阻、无塑性变形、无温差传热。
最关键的区分 准静态 ≠ 可逆。 准静态只要求"内部每刻平衡"；可逆还要求"没有摩擦、温差等耗散"。 一个缓慢下降的重物带动搅拌器搅水，过程可以很慢（准静态），但有摩擦生热，不可逆。 反过来说：可逆一定准静态，准静态不一定可逆。 这句话是简答题的标准答案。
用"橡皮筋"和"面团"来记。 橡皮筋拉长后松手能完全恢复——近似可逆。面团被捏成形状后再"恢复"，表面看形状回来了，但内部已经发生了塑性变形（耗散），所以不可逆。 判断标准永远是：除了系统本身，外界有没有留下改变？

1.4.3 为什么要引入"可逆"这个理想模型

因为可逆过程能做一件不可逆过程做不到的事：让功和热都能用状态参数积分出来。

  • 可逆膨胀功：w = ∫pdv（曲线下面积）
  • 可逆过程传热量：q = ∫Tds（T-s 图下面积）
  • 可逆循环的净功 = p-v 图上闭合曲线围成的面积

而这些积分只对可逆过程成立。真实过程都不可逆，但可以这样处理：用可逆过程把初终态连起来算差值，实际过程的不可逆程度另用熵产修正——这就是第 5 章的思路。

1.5 功、热量与内能：三类"能量账目"

这三样东西是整门课的主角，但它们的"身份"完全不同。 内能 u 是状态参数（存在账户里的钱）；功 w 和热 q 是过程量（转账记录），不是状态参数，不能说"这团气体含有多少热量"。 把它们分清，第一定律就再也不会写错。

1.5.1 功：p-v 图下面积

体积功的定义是"力 × 位移"。气体膨胀时，对活塞的作用力是 pA，活塞移动 dx，于是：

  3. 对 1 kg 工质，两边除以质量：δw = p dv。

1.5.3 内能与焓：先记住，第 2、3 章再展开

热力学能（内能）u：系统内部分子热运动动能与分子间位能的总和。它是状态参数，单位 J/kg 或 kJ/kg。

焓 h：定义一个组合量 h ≡ u + pv，单位同 u。它也是状态参数。注意：焓没有独立的物理意义，它是一个"为了书写方便而人为定义"的量——但这个定义让开口系统的能量方程变得极其简洁（第 3 章见分晓）。

系统总能量 E：内能 + 宏观动能 + 重力位能，E = U + ½mc2 + mgz。

易错三连 ✗ "这团气体含有 500 kJ 的热量。" ✓ 只能说"它含有 500 kJ 的内能"。热量只在传递过程中存在。
✗ "焓就是热量。" ✓ 焓是状态参数 h=u+pv；只有在定压、只做体积功时，qp=Δh，两者数值才相等。
✗ "物体速度越快，内能越大。" ✓ 速度增加的是宏观动能，不是内能。内能只看温度和分子间位能。

1.6 第一定律的第一眼：能量守恒怎么写

第一定律其实只是一句话：进来的 = 出去的 + 存起来的。 但它写在不同的系统上，样子完全不一样。这一节只做一件事：把三种写法摆在一起，让你看到它们是同一个道理的三种方言。
记账。 吸热 q 是"收入"，对外做功 w 是"支出"，内能增加 Δu 是"存款增加"。收入 − 支出 = 存款增加，这就是 q − w = Δu。 移项得 q = Δu + w。整门课的第一定律计算，都是在这条式子上做加减。
系统能量方程（1 kg 工质）什么时候用它
闭口系统q = Δu + w定量工质、活塞气缸、储气罐（未充放气时）
开口系统
（稳定流动）		q = Δh + wt换热器、喷管、扩压管、汽轮机、压气机——工程设备绝大多数属于这一类
循环∮δq = ∮δw（因为 ∮du=0）热机、制冷循环、热泵

为什么开口系统里冒出了 h 而不是 u？因为流动的工质除了带进内能，还把"推进功" pv 一起带进带出，两者合起来正好是 u+pv=h。这个推导在第 3 章会一步一步做，现在只需记住结论。

模仿例 1-6　用第一定律反推未知量

气体在某过程中吸入热量 12 kJ，同时热力学能增加 20 kJ。问此过程是膨胀还是压缩？对外所做的功是多少（不考虑摩擦）？

解　由闭口系统能量方程

Q = ΔU + W　⟹　W = Q − ΔU = 12 − 20 = −8 kJ

W<0 说明外界对气体做功，即过程是压缩过程，外界需消耗 8 kJ 功。

答　压缩过程，外界对气体做功 8 kJ。

这类题唯一的难点是符号：先按约定（吸热为正、对外做功为正）把已知量带符号写进方程，再解方程。不要凭"感觉"判断正负，感觉会错，方程不会。

应考例 1-7　循环过程的能量账（课本例 1-2 型）

定量工质经过一个由四个过程组成的循环 1-2-3-4-1，其中 1-2 与 3-4 为定容过程。已知表中数据，试补全空格，判断该循环是正循环还是逆循环，并求循环净功与净吸热。

过程1-22-33-44-1
ΔU / kJ?30−35?
W / kJ0250?
Q / kJ−20???

解　两把钥匙：(i) 每个过程 Q=ΔU+W；(ii) 循环一圈 ∮ΔU=0。

  1. 过程 1-2（定容，W=0）：
    ΔU12 = Q12 − W12 = −20 − 0 = −20 kJ
  2. 过程 2-3：Q23 = ΔU23 + W23 = 30 + 25 = 55 kJ。
  3. 过程 3-4（定容，W=0）：Q34 = ΔU34 + 0 = −35 kJ。
  4. 过程 4-1：先用闭环条件求 ΔU41。
    ∮ΔU = (−20) + 30 + (−35) + ΔU41 = 0　⟹　ΔU41 = +25 kJ
  5. 再由 Q41 = ΔU41 + W41。为求 W41，用另一条闭环条件 ∮W = ∮Q：
    ∮Q = −20 + 55 − 35 + Q41；∮W = 0 + 25 + 0 + W41
    代入 Q41 = 25 + W41 解得 W41 = 15 kJ，Q41 = 40 kJ。
  6. 终检：∮W = 0+25+0+15 = 40 kJ；∮Q = −20+55−35+40 = 40 kJ。两者相等 ✓。
答　补全后：1-2（−20，0，−20）；2-3（30，25，55）；3-4（−35，0，−35）；4-1（+25，15，40）。 净功 40 kJ > 0，所以是正循环（热机）；净吸热也是 40 kJ（其中 1-2、3-4 为放热共 55 kJ，2-3、4-1 为吸热共 95 kJ，95−55=40）。

循环题的通法：先在每个过程内用 Q=ΔU+W，再用闭合条件 ∮ΔU=0 与 ∮Q=∮W 把首尾接起来。这类题永远不要试图求"某个状态的内能绝对值"——内能的零点可以任取，能求的只有差值。最后一格的 40 kJ 就是用 ∮Q=∮W 自查出来的，做完一定要这么检一遍。

第 2 章 理想气体：给工质办一张能随时查的"身份证"

第 1 章学会了说"这团气体处在什么状态"，但还不会算。 要算出 p、v、T 之间怎么连动，要算出一团气体升温 100 ℃ 需要多少热量，要算出它的内能和熵——都缺一张"工质的身份证"。 这一章就发这张身份证，它只有四行信息：状态方程（pv=RT）、比热容（cp、cv）、内能与焓（u=cvT、h=cpT）、熵（Δs 的三个常用式）。 后面第 3、4、5 章的每一个计算，都是在这四行信息上做的。
理想气体 = 高考物理里那个"忽略空气阻力"的假设。 真实气体有分子体积、有分子间引力，很难算。物理学家说：如果压力不太高、温度不太低，分子之间离得很远，引力和体积都可以忽略——这样一简化，公式立刻变得极其简单，而且算出来误差常常不到 1%。 所以"理想气体"不是一个真实存在的东西，而是一个在特定条件下非常好用的近似模型。 什么时候失效？压力高（比如 20 MPa）、温度低（接近液化）的时候。第 2 章最后一节专门讲这个边界在哪。

2.1 理想气体的状态方程：三个公式，一个意思

2.1.1 从玻意耳、盖-吕萨克、查理三条实验定律合成

历史上，人们先用实验分别找到了三条规律：

  • 玻意耳定律（等温）：p1v1 = p2v2　（T 不变时，pv=常数）
  • 盖-吕萨克定律（等压）：v1/T1 = v2/T2　（p 不变时，v/T=常数）
  • 查理定律（等容）：p1/T1 = p2/T2　（v 不变时，p/T=常数）
三条定律怎么合成一个方程
  1. 把三式写成统一形式：pv/T = 常数。这个常数对一定量的某种气体是固定的。
  2. 实验发现，1 kmol 的任何气体在标准状态下都占 22.4 m3（阿伏伽德罗定律），于是可以定出这个常数只与物质的量有关。
  3. 写成最通用的三种形式：
pv = RT　（1 kg 工质，R 为气体常数，J/(kg·K)）
pV = mRT　（m kg 工质，V 为总容积）
pV = nRTm　（n kmol 工质，Rm=8.314 kJ/(kmol·K) 为通用气体常数）

三式的区别只在于"用质量还是用摩尔数"、"用比容还是用总容积"。做题时先问自己：题目给的是 kg 还是 kmol？给的是 v 还是 V？

气体常数 R 与通用气体常数 Rm 的关系（必背）
R = Rm / M　　（M 为摩尔质量，kg/kmol）
例：空气 M=28.97 ⟹ R = 8.314/28.97 = 0.287 kJ/(kg·K)；氧气 M=32 ⟹ R=0.2598；氮气 M=28 ⟹ R=0.2968；CO2 M=44 ⟹ R=0.189。 这几个数在考试中会反复出现，建议直接记住空气、氧气、氮气、CO2 四个。

2.1.2 标准状态：一切换算的原点

标准状态（标态）：t0 = 0 ℃（T0=273.15 K），p0 = 101.325 kPa。此状态下各种气体的摩尔容积 Vm0 = 22.414 m3/kmol。

标准状态是干什么用的？工程题目经常给"标准状态下 3500 m3/h 的空气"，而计算要用 kg/s，这时就必须换算：

标准状态下的体积流量 ↔ 质量流量
  1. 先算标态密度：ρ0 = p0/(RT0)。对空气：101325/(287×273.15) = 1.293 kg/m3。
  2. 质量流量 ṁ = ρ0 × V0（单位 kmol 或 m3/h 时要除以 3600 换成秒）。
  3. 若要用任意状态下的体积流量，则 V = mRT/p。

记住：质量不随状态变，体积随状态变。所以先把体积折成标态体积或质量，再往别的状态换，永远最安全。

看懂例 2-1　最基础的三个量互求

1 kg 空气，p=0.2 MPa，t=27 ℃，求其比容。

解　

  1. 先换温度：T = 27 + 273.15 = 300.15 K，取 300 K。
  2. 由 pv = RT 得
    v = RT/p = 0.287 × 300 / (0.2×103) = 86.1/200 = 0.4305 m3/kg
答　v = 0.43 m3/kg。

单位是这一题唯一的坑：p 必须换成 Pa（0.2 MPa = 2×105 Pa），R 用的 0.287 对应 kPa·m3/(kg·K)，所以 p 用 kPa 也可以（200 kPa），结果一样。只要 R、p、v 单位配套就行。

模仿例 2-2　储气罐充气，求压入的质量（计算练习 2-3 型）

把 CO2 压入容积 3 m3 的储气罐，起始表压力 pe1=30 kPa，终了表压力 pe2=0.3 MPa，温度由 t1=45 ℃ 升至 t2=70 ℃，当地大气压 101.325 kPa。求压入的 CO2 质量。

解　

  1. 先把表压换成绝对压：p1 = 101.325 + 30 = 131.325 kPa；p2 = 101.325 + 300 = 401.325 kPa。
  2. 温度换 K：T1 = 45+273.15 = 318.15 K，T2 = 70+273.15 = 343.15 K。
  3. 由状态方程求质量：
    m1 = p1V/(RT1) = 131.325×3/(0.189×318.15) = 393.98/60.13 = 6.55 kg
    m2 = p2V/(RT2) = 401.325×3/(0.189×343.15) = 1203.98/64.86 = 18.56 kg
  4. 压入质量：Δm = m2 − m1 = 18.56 − 6.55 = 12.01 kg。
答　压入 CO2 约 12.0 kg。

这类"储气罐质量变化"题的通用式可以一步写完：Δm = V(p2/T2 − p1/T1)/R。写这一步之前，务必确认 p 已经加了大气压、T 已经换成 K。

应考例 2-3　标准状态与任意状态的换算（计算练习 2-5 型）

风机在标准状态时每小时可送 300 m3 空气。若外界温度升高到 27 ℃、大气压力降低至 99.3 kPa，而风机每小时仍送 300 m3，求该风机送风的质量流量是否改变？送风的质量流量是多少？

解　

  1. 标态下质量流量：ṁ = ρ0V0 = 1.293 × 300/3600 = 0.10775 kg/s。
  2. 非标态下：ρ = p/(RT) = 99.3/(0.287×300.15) = 99.3/86.14 = 1.153 kg/m3。
  3. 新质量流量：ṁ′ = 1.153 × 300/3600 = 0.0961 kg/s。
答　质量流量改变了，由 0.1078 kg/s 降到 0.0961 kg/s（减少了约 10.8%）。因为风机按体积送风，空气变稀（密度变小）后，同样的体积里装的质量就少了。

这道题考的是一个很实用的判断：风机、水泵这类设备给的是体积流量，温度、压力一变，质量流量就跟着变。锅炉送风、空调送风都必须做这项修正。注意题目问的是"是否改变"，先答"改变"再给数值，别只写数字。

2.2 比热容：算热量必须先有它

为什么不能直接用 q = cmΔt？ 中学的 Q=cmΔt 在热力学里不够用，因为它默认"加热方式只有一种"。可现实中同样是升温 1 K，定容加热和定压加热需要的热量不一样——定压时气体还要顶开活塞对外做功。 所以必须定义两个比热：cv 和 cp。这就是这一节的全部动机。

2.2.1 四个比热的定义

名称定义式含义与单位
定容比热 cvcv = (∂u/∂T)v = δqv/dT容积不变时，1 kg 工质升温 1 K 所需热量，kJ/(kg·K)
定压比热 cpcp = (∂h/∂T)p = δqp/dT压力不变时，1 kg 工质升温 1 K 所需热量
容积比热 cV′cV′ = cv/v0标态下 1 m3 气体升温 1 K 的热量，kJ/(m3·K)
摩尔比热 CmCm = Mc1 kmol 气体升温 1 K 的热量，kJ/(kmol·K)

2.2.2 迈耶公式：cp − cv = R，为什么？

迈耶公式的完整推导（三步，一步不跳）
  1. 定容加热：容积不变，不做膨胀功（w=0）。由第一定律 qv = Δu + 0 = Δu，所以 cv = du/dT，即 du = cv dT。
  2. 定压加热：压力不变，气体膨胀做功 w = pΔv。由第一定律：
    qp = Δu + pΔv = Δ(u + pv) = Δh
    所以 cp = dh/dT，即 dh = cp dT。
  3. 两者相减：由焓的定义 h = u + pv，对理想气体 pv = RT，故
    h = u + RT　⟹　dh = du + R dT　⟹　cpdT = cvdT + RdT
    两边约去 dT：
cp − cv = R　　（迈耶公式）

物理意义：定压比定容多出来的那部分热量 R，正好等于"顶开活塞"所做的功 pΔv = RΔT（按 1 kg、升温 1 K 计）。

再定义一个非常有用的无量纲数——比热比（绝热指数）：

κ = cp/cv　　⟹　cp = κR/(κ−1)，cv = R/(κ−1)
常用气体的比热值（考试基本就这几个）
气体R / kJ(kg·K)−1cpcvκ
空气0.2871.0040.7171.40
O20.25980.9170.6571.395
N20.29681.0390.7421.40
CO20.1890.8460.6571.288

2.2.3 定值比热、真实比热、平均比热：三种精度

真实气体的比热随温度升高而变大（温度高，分子振动、转动被激发得更充分）。这带来一个实际选择：

方法怎么用精度与场合
定值比热把 cp 当常数，q = cp(T2−T1)最简单，温度不高时误差约 1–3%。考试最常用，题目不给数据时默认用它
真实比热用 cp = a0+a1T+a2T2+a3T3 代入积分 q=∫cpdT最准，但要积分、要查系数表，手算麻烦
平均比热查表得 cpm|0t2，用 q = cpm(t2−t1)精度好、只需查表做减法，工程计算的主流
易错三连（平均比热） ✗ 直接查 cpm|0t2 就当作"从 t1 到 t2 的平均比热"。 ✓ 表里给的是"从 0 ℃ 到 t ℃"的平均值，必须做差：q = cpm|0t2·t2 − cpm|0t1·t1。
✗ 把"平均比热"当成"两个温度下比热的算术平均"。 ✓ 平均比热的定义是积分平均（面积相等），不是算术平均。
✗ 用 cp 去算 Δu、用 cv 去算 Δh。 ✓ 死死记住：Δu = cvΔT，Δh = cpΔT。反了就是零分。
模仿例 2-4　三种比热算法对比（对应计算练习 2-14）

锅炉空气预热器在定压下将空气由 t1=25 ℃ 加热到 t2=250 ℃，空气流量在标准状态下 V0=3500 m3/h。求每小时加给空气的热量：(1) 按平均比热；(2) 按真实比热经验公式；(3) 按定值比热。

解　先统一质量流量：ṁ = ρ0V0/3600 = 1.293×3500/3600 = 1.257 kg/s = 4525 kg/h。

  1. 定值比热：Δh = cpΔt = 1.004×225 = 225.9 kJ/kg，Q̇ = 1.257×225.9 = 284.0 kW。
  2. 平均比热：查表 cpm|0250 = 1.0115、cpm|025 = 1.005，则
    Δh = 1.0115×250 − 1.005×25 = 252.88 − 25.13 = 227.75 kJ/kg，Q̇ = 286.3 kW
  3. 真实比热：cp = 1.0058 + 0.0000807T，积分得 Δh = 1.0058ΔT + (0.0000807/2)(T22−T12) = 233.76 kJ/kg，Q̇ = 293.9 kW。
答　三种算法分别得到 284.0 / 286.3 / 293.9 kW，彼此相差 1%～3.5%。温度范围越大、温度越高，定值比热误差越大（见图 2-4），所以精确计算要用平均比热或真实比热。

2.3 内能、焓与熵：理想气体的四个"计算器"

2.3.1 内能和焓只与温度有关（焦耳定律）

为什么理想气体的 u 只是 T 的函数
  1. 理想气体没有分子间作用力，所以没有"分子间位能"。
  2. 内能只剩分子热运动动能，而动能只与温度有关。
  3. 因此 u = f(T)，与 p、v 无关。同理 h = u+RT = f(T)。
  4. 由此得到两个最重要的差分式：
Δu = cv(T2−T1)　　Δh = cp(T2−T1)

这两个式子对理想气体的任何过程都成立（不只是定容、定压！），因为 u、h 是状态参数，只与初终温有关。

易错三连 ✗ "只有定容过程才能用 Δu=cvΔT。" ✓ 任何过程都能用！cv 只是"定容比热"这个名字，它的定义是 (∂u/∂T)v，与过程无关。
✗ "理想气体的内能与压力有关。" ✓ 无关。等温膨胀时 p 降、v 升，但 u 不变——这正是计算练习 3-8、4-3 的关键。
✗ 把 cvΔT 写成 cvΔt 就错了。 ✓ 温差 ΔT=Δt，两者数值相同，可以互换。

2.3.2 熵变的三个常用公式

由第 1 章的 δq=Tds 与第一定律 δq=du+pdv，可以得到理想气体熵变的三条常用式（推导见第 5 章，这里先给结果并说明什么时候用哪条）：

理想气体 Δs 的三个公式
  1. 以 (T, v) 为变量：ds = cvdT/T + Rdv/v
    Δs = cv ln(T2/T1) + R ln(v2/v1)
  2. 以 (T, p) 为变量（把 dv/v = dT/T − dp/p 代进去）：
    Δs = cp ln(T2/T1) − R ln(p2/p1)
  3. 以 (p, v) 为变量：
    Δs = cv ln(p2/p1) + cp ln(v2/v1)

三式完全等价，选哪条只看题目给了什么：给了 v 用第 1 式，给了 p 用第 2 式，两者都给用第 3 式。

符号判据（考试最常错的地方） 压力项前面是负号：升压（p2>p1）使熵减小；体积项前面是正号：膨胀（v2>v1）使熵增大。温度升高使熵增大。 一个快速自查：等温压缩时 T 不变、p 升、v 降，熵应该减小 ⟹ 代入第 2 式得 −Rln(p2/p1)<0 ✓

2.4 理想气体混合物：空气就是混合物

为什么不直接用"空气"这一种气体？ 因为空气是 N2、O2、Ar、CO2 的混合物，它的 R、cp、cv 都是由各组分"按比例平均"出来的。工程上还常遇到烟气、燃气、湿空气（第 8 章），全是混合物。 更实际的原因是：题目常常给出各组分，要求你算出混合物的气体常数和比热——这是必考题型。

2.4.1 两大类分法：质量分数与摩尔分数

混合物有两种描述方式，取决于你手上是"秤"还是"量"：

量定义换算关系
质量分数 gigi = mi/m，Σgi=1由 gi 求 wi：wi = (gi/Mi)/Σ(gi/Mi)
摩尔分数 wiwi = ni/n，Σwi=1由 wi 求 gi：gi = wiMi/Σ(wiMi)
分压力 pipi = wip（道尔顿定律）分压力之和 = 总压 p
分容积 ViVi = wiV（亚美格定律）分容积之和 = 总容积 V
混合物的三个"折合"参数
  1. 折合气体常数：Req = ΣgiRi = Rm/Meq，其中折合摩尔质量 Meq = ΣwiMi = 1/Σ(gi/Mi)。
  2. 折合比热：cp = Σgicpi，cv = Σgicvi。
  3. 校核：算完必须验证 cp − cv = Req，不等就说明中间某步算错了。
模仿例 2-5　由摩尔分数求折合参数

已知空气的摩尔分数：wN₂=0.79，wO₂=0.21。求空气的折合摩尔质量、折合气体常数、折合定压比热。

解　

  1. 折合摩尔质量：M = ΣwiMi = 0.79×28 + 0.21×32 = 22.12 + 6.72 = 28.84 kg/kmol（书上常取 28.97，差异来自忽略了 Ar 和 CO2）。
  2. 折合气体常数：R = 8.314/28.84 = 0.288 kJ/(kg·K)。
  3. 折合定压比热：cp = 0.79×1.039 + 0.21×0.917 = 0.821 + 0.193 = 1.014 kJ/(kg·K)。
  4. 校核：cv = cp − R = 1.014 − 0.288 = 0.726，与 0.717 接近 ✓。
答　M=28.84 kg/kmol，R=0.288 kJ/(kg·K)，cp=1.014 kJ/(kg·K)。

2.5 真实气体：理想模型失效之后

2.5.1 压缩因子：一把"偏离程度"的尺子

z = pv/(RT)　　z=1 为理想气体，z≠1 为真实气体

用 对比参数（pr=p/pcr，Tr=T/Tcr）可以查"通用压缩因子图"。对应态原理说的是：各种气体只要对比参数相同，z 就大致相同——这就把"查图"从"每种气体一张图"变成了"所有气体共用一张图"。

2.5.2 范德瓦尔方程：给理想气体加两项修正

(p + a/vm2)(vm − b) = RmT
修正项修正了什么物理含义
a/vm2分子间的引力引力让分子撞壁时的动量减小，真实压力比理想值低，所以要把它"加回去"
−b分子本身的体积可活动的空间比总容积小，要扣掉 b
关于计算练习 2-19 的重要提示（务必读） 原题：0.5 kg CH4 装在 5 L 容器内，温度 100 ℃，分别用理想气体方程和范德瓦尔方程算压力。 这道题的题面数据有问题：CH4 的 b = 0.0427 m3/kg，而 5 L 装 0.5 kg 时比容只有 v = 0.005/0.5 = 0.01 m3/kg，比 b 还小——意味着"分子体积比容器还大"，范德瓦尔方程必然算出负压力（约 −8.2 MPa），失去物理意义。 正确做法是：① 理想气体方程照算，得 p ≈ 19.3 MPa；② 明确指出范德瓦尔方程在此已超出适用范围，题面 5 L 极可能是 5 m3（或 0.05 kg）之误；③ 若按 5 m3 重算，则 v=10 m3/kg，两个方程结果接近。这样答才是完整的。

  6. 压缩因子 z 偏离 1 说明什么？（真实气体偏离理想气体，分子体积与作用力不可忽略）

第 3 章 热力学第一定律：把"能量守恒"写成能算的式子

第 2 章有了工质的"身份证"，但还没有"记账本"。 第 1 章说了 q=Δu+w 这句话，可它只是四个字母。这一章要做三件事： ① 把这句话在不同系统上写成不同的具体形式（闭口怎么写、开口怎么写、循环怎么写）； ② 说清楚为什么开口系统的方程里冒出来一个 h 而不是 u——这是全章最容易被扣分的地方； ③ 学会"划零法"：拿到任何一台设备，先问三句（绝热吗？做功吗？动能位能能忽略吗？），把方程里没用的项划掉。 第 3 章是全书计算题的主战场，计算练习里的 3-13、3-14、3-17、3-18、3-19 全在这一章。
第一定律就是"记账"。 你的钱包（内能 U）只有一个变化方式：收入减支出。 收入 = 吸热 Q；支出 = 对外做功 W。于是 ΔU = Q − W，移项就是 Q = ΔU + W。 闭口系统是"钱只在自己口袋里进出"；开口系统是"还有一笔钱要跟着货一起进出仓库"——那笔跟着货走的钱，就是焓 h。

3.1 闭口系统能量方程：最简单的那本账

3.1.1 三种写法，其实是同一句话

写法适用对象说明
Q = ΔU + W任何闭口系统（m kg）总热量、总功、总内能
q = Δu + w1 kg 工质小写字母 = 比参数，单位 kJ/kg
δq = du + δw微元过程δ 与 d 的区别见下面的易错三连
∮δq = ∮δw循环（回到初态）因为 ∮du=0
符号约定（整本书统一，不然后面全错） 吸热为正（q>0），放热为负；系统对外做功为正（w>0），外界对系统做功为负。 这个约定和国际上"对系统做功为正"的写法相反，做题时务必按课本约定，否则所有正负号都会翻。
易错三连 ✗ 把 δw 写成 dw。 ✓ w 是过程量，没有"全微分"，只能用 δ。状态量才配 d，过程量只能配 δ。
✗ "Q=ΔU+W 只对可逆过程成立。" ✓ 这个式子对任何闭口过程都成立（可逆、不可逆都行），因为它只是能量守恒。只有把 W 具体写成 ∫pdV 时才要求可逆。
✗ 循环过程里用 ΔU≠0。 ✓ 循环回到初态，∮du = 0，所以 ∮q = ∮w（净吸热 = 净功）。

3.1.2 膨胀功怎么算：w = ∫pdv

若过程可逆，系统对外做的膨胀功就是 p-v 图上曲线下的面积：

w = ∫12pdv　（可逆过程；面积在 v 增大的方向为正）
三种常见过程的可逆膨胀功（后面第 4 章还要用）
  1. 定容：dv=0 ⟹ w = 0。
  2. 定压：p 提出积分号 ⟹ w = p(v2−v1) = R(T2−T1)。
  3. 定温（理想气体）：p=RT/v ⟹ w = RT ln(v2/v1) = RT ln(p1/p2)。
模仿例 3-1　封闭容器内的定容加热（计算练习 3-14）

在封闭的容器内装有 V = 2 m3 的空气，其温度 t1 = 20 ℃、压力 p1 = 500 kPa。若使压力提高到 p2 = 1 MPa，问需要将容器内空气加热到多高温度？此间空气吸收多少热量？

解　

  1. 判系统：容器封闭、容积不变 ⟹ 闭口系统 + 定容过程（W=0）。
  2. 求终温：定容过程 p/T = 常数，
    T2 = T1p2/p1 = 293.15 × 1000/500 = 586.3 K（t2 = 313.2 ℃）
  3. 求质量：m = p1V/(RT1) = 500×2/(0.287×293.15) = 1000/84.13 = 11.89 kg。
  4. 求热量：定容 W=0，故 Q = ΔU = mcv(T2−T1) = 11.89×0.717×(586.3−293.15) = 11.89×0.717×293.15 = 2498 kJ。
答　需加热到 586.3 K（313.2 ℃），吸收热量约 2.50×103 kJ。

定容题只有一句话：W=0，所以 Q=ΔU=mcvΔT。别忘了先用状态方程找质量，题目给的 2 m3 和 500 kPa 就是用来算质量的。

3.2 开口系统：为什么冒出来一个"焓"

这是全章最需要"想通"的一节。 闭口的账很好记：进来的热、出去的功。可一旦系统是开口的（压气机、汽轮机、换热器、喷管……）， 除了热和轴功，还有"工质本身带着能量进来、带着能量出去"。 更麻烦的是，工质进出时还要被前面的流体推进来、把前面的流体推出去，这两份"推挤功"也必须记进账本。 把"内能"和"推挤功"捆在一起，就得到了一个新的状态量——焓。焓不是人为定义的怪东西，它是"流动的工质所携带的总能量（去掉宏观动能位能）"。

3.2.1 焓的定义与物理意义

h ≡ u + pv　　（比焓，kJ/kg）；　H = U + pV
为什么开口系统用 h 而不用 u（一句话讲透）
  1. 1 kg 工质流进系统时，它自己带着内能 u1；
  2. 同时，它被后面的流体推着走，这个推挤过程对系统做了 p1v1 的功；
  3. 所以这 1 kg 工质"带进来"的总能量是 u1 + p1v1 = h1；
  4. 同理，流出去的那 1 kg 带走的能量是 h2。
  5. 于是账本里进出两项自然写成 h1、h2——焓就是这么被"逼"出来的。

记法：焓 = 内能 + 流动功。"流动的工质，它的能量要用焓来记账。"

3.2.2 稳定流动能量方程：五个能量项

q = (h2 − h1) + (c22 − c12)/2 + g(z2 − z1) + ws
项含义工程上怎么办
h2−h1焓差（内能 + 流动功）永远保留，是主角
(c22−c12)/2宏观动能差汽轮机、换热器、压气机常忽略；喷管、扩压管必须保留
g(z2−z1)重力位能差气体几乎总忽略；水泵、水轮机有时要留
ws轴功（机器轴上传进/传出的功）汽轮机/压气机/泵保留；换热器、喷管为 0
q热量保温良好的设备取 0（绝热）
"划零法"：四台设备的专用公式，全是这一条方程划出来的
设备划掉什么剩下的式子
汽轮机（透平）绝热 q=0、动能位能忽略ws = h1 − h2
压气机 / 泵绝热 q=0、动能位能忽略ws = h2 − h1（耗功）
换热器不做功 ws=0、动能位能忽略q = h2 − h1
喷管 / 扩压管绝热 q=0、不做功 ws=0、位能忽略c2 = √(2(h1−h2)+c12)
这四行就是简答题第 8–12 题的标准答案模板，务必背下推导过程而不只是结果。
应考例 3-2　CO2 的 Δu 与 Δh：定值比热 vs 平均比热（计算练习 3-13）

1 kg CO2 由 p1=800 kPa、t1=900 ℃ 膨胀到 p2=120 kPa、t2=600 ℃。用定值比热和平均比热计算其热力学能、焓的变化；如果膨胀中未与外界交换热量，求所做的技术功。

解　

  1. 定值比热：ΔT = 900 − 600 = 300 K（注意：ΔT = Δt）。
    Δu = cvΔT = 0.657 × 300 = 197.1 kJ/kg
    Δh = cpΔT = 0.846 × 300 = 253.8 kJ/kg
  2. 平均比热（查表法）：CO2 的 cpm|0600 ≈ 1.0756、cpm|0900 ≈ 1.1223 kJ/(kg·K)：
    Δh = 1.1223×900 − 1.0756×600 = 1010.1 − 645.4 = 364.7 kJ/kg
    Δu = Δh − RΔT = 364.7 − 0.189×300 = 364.7 − 56.7 = 308.0 kJ/kg
    或用真实比热表（表 2-3）的摩尔系数积分：Δh = Rm·∫[22.257+59.8084×10−3T−35.01×10−6T2+7.4693×10−9T3]dT/44.01 ≈ 290.9 kJ/kg，与此同量级。
  3. 技术功（绝热）：绝热稳定流动 q=0，由 q = Δh + wt 得
    wt = −Δh = −253.8 kJ/kg（定值比热）/ −364.7 kJ/kg（平均比热）
    负号表示气体对外做技术功（膨胀机输出功）。
答　定值比热：Δu=197.1、Δh=253.8 kJ/kg，wt=−253.8 kJ/kg；平均比热：Δu=308.0、Δh=364.7 kJ/kg，wt=−364.7 kJ/kg。高温下两种算法的差别可达 40%，所以题目给"平均比热表"时必须用后者。

记住三条：① Δu=cvΔT、Δh=cpΔT，别反；② ΔT=Δt；③ 平均比热的算法是"cpm|0t2·t2 − cpm|0t1·t1"，绝不是两个值的算术平均。

应考例 3-3　储气罐充气：开口系统的"非稳定"问题（计算练习 3-9 型）

一个储气罐从压缩空气总管充气，如图 3-18。总管内的压缩空气参数为 500 kPa、25 ℃。充气开始时，罐内压缩空气参数恒定（初态）为 50 kPa、10 ℃。求充气终了时罐内空气的温度。设充气过程在绝热条件下进行，且充气到罐内压力等于总管压力时停止。

解　这是开口 + 非稳定流动（罐内质量在变），必须用"控制体积"记账。

  1. 取系统：取罐内空间为控制体积，边界固定、只进气不出气。
  2. 写能量方程：绝热 Q=0、不做功 W=0、忽略动能位能，则
    minhin = m2u2 − m1u1　　且 min = m2 − m1
  3. 整理：把 min 代入，得
    (m2−m1)hin = m2u2 − m1u1
  4. 用理想气体关系化简：取 u=cvT、h=cpT、m=pV/(RT)，V 恒定，整理得
    T2 = (κTin)/(1 + (p1/p2)(κTin/T1 − 1))
    推导要点：把 m1、m2 都用 p、T 表示后约去 V/R。
  5. 代入：κ=1.4，Tin=298.15 K，T1=283.15 K，p1=50、p2=500 kPa：
    T2 = (1.4×298.15)/(1 + 0.1×(1.4×298.15/283.15 − 1)) = 417.4/(1 + 0.1×0.4741) = 417.4/1.0474 = 398.5 K
答　充气终了罐内温度为 398.5 K（约 125 ℃）。比总管温度高，因为进入的气体带着流动功进来，把能量"堆"在罐里了。

这类题的通用套路：先写控制体积的能量方程 → 用质量守恒消掉 min → 用理想气体把 m 换成 pV/(RT) → 整理出只含 T 的式子。如果题目说"充气到与总管压力相等"，就用 p2 = pin（本题即 500 kPa）；如果说"充了 m kg"，就直接用质量做未知量。

3.3 绝热节流：最简单也最容易错的"等焓"过程

为什么节流是等焓的
  1. 绝热：q = 0。
  2. 不输出轴功：ws = 0。
  3. 进出口管径相同或动能差可忽略：Δc2/2 ≈ 0；位能差忽略。
  4. 代入稳定流动方程 0 = Δh + 0 + 0 + 0 ⟹ h1 = h2。

但要注意：等焓不等于可逆。节流靠的是流体内部的剧烈摩擦与涡流，熵一定增加（s2>s1），在 T-s 图上是一条向右下方的曲线，绝不是等熵线。

易错三连（节流） ✗ 认为节流后温度一定下降。 ✓ 理想气体节流后 T 不变（h只与T有关）；真实气体多数降温，但氢、氦在常温下节流会升温。
✗ 把节流画成 T-s 图上的等熵线。 ✓ 节流不可逆，s 必增大。
✗ 用 h1=h2 推出 T1=T2。 ✓ 只有理想气体才成立；真实气体必须查 h-s 图或水蒸气表。

模仿例 3-4　两股空气绝热混合（计算练习 3-17）

温度 t1=500 ℃、质量流量 ṁ1=120 kg/h 的空气流Ⅰ，与温度 t2=200 ℃、质量流量 ṁ2=210 kg/h 的空气流Ⅱ相混合。设混合前后的压力都相等，求混合后的温度。

解　

  1. 取系统：混合室为控制体积，开口稳定流动。
  2. 方程：绝热 Q=0、不做功、动能位能忽略、压力相等则无流动功差，能量守恒为
    ṁ1h1 + ṁ2h2 = (ṁ1+ṁ2)h3
  3. 用 cp 常数化简：h=cpT 约去 cp：
    T3 = (ṁ1T1 + ṁ2T2)/(ṁ1+ṁ2)
  4. 代入：T1=773.15 K、T2=473.15 K：
    T3 = (120×773.15 + 210×473.15)/330 = (92778 + 99362)/330 = 192140/330 = 582.2 K = 309.1 ℃
答　混合后温度约 309 ℃。它落在两股气流温度之间且靠近流量大的那一边——这是绝热混合的必然规律，可用来快速检验答案。

混合题的"秒杀式"：绝热混合 = 按质量流量加权平均温度（比热相同的前提下）。若两种气体比热不同，则要用 ṁcp 加权：T3 = ΣṁicpiTi/Σṁicpi。

模仿例 3-5　活塞气缸定压膨胀（计算练习 3-19）

配有活塞的气缸，内有 1 kg 空气、容积 0.03 m3。若使气体在 2068.4 kPa 压力下定压膨胀直到温度是原来的两倍，试计算空气热力学能、焓的变化及过程中的热量和功量交换。

解　

  1. 初温：T1 = p1V1/(mR) = 2068.4×0.03/(1×0.287) = 62.05/0.287 = 216.2 K。
  2. 终温：T2 = 2T1 = 432.4 K，ΔT = 216.2 K。
  3. Δu、Δh：
    Δu = cvΔT = 0.717×216.2 = 155.0 kJ/kg
    Δh = cpΔT = 1.004×216.2 = 217.1 kJ/kg
  4. 功：定压 W = p(V2−V1) = mRΔT = 1×0.287×216.2 = 62.05 kJ。
  5. 热量：定压 Q = ΔH = mcpΔT = 217.1 kJ。校核：Q = ΔU+W = 155.0+62.05 = 217.05 ✓
答　ΔU=155.0 kJ、ΔH=Q=217.1 kJ、W=62.05 kJ。

定压过程三件套：W=pΔV=mRΔT；Q=ΔH=mcpΔT；ΔU=mcvΔT。三式必须满足 Q=ΔU+W，这是交卷前最后一道保险。

应考例 3-6　压气机的理论耗功（第 7 章预热）

空气由 p1=0.1 MPa、t1=27 ℃ 绝热压缩到 p2=0.4 MPa。若按可逆绝热（定熵）压缩，求 1 kg 空气的耗功与出口温度。

第 4 章 理想气体热力过程及气体压缩：四张"套路表"走遍全章

这是全书最"套路化"、也最容易拿分的一章。 前面两章给了工具（pv=RT、Δu=cvΔT、q=Δu+w），这一章教你把工具用在具体的四种过程上： 定容、定压、定温、定熵（绝热）。每种过程只需要记住四句话：过程方程是什么、谁不变、w 怎么算、q 怎么算。 然后再把四种过程"合并"成多变过程（pvn=常数）——这一招把四种情况变成一条公式，最后用它来处理压气机。 计算练习的 4-1、4-2、4-3、4-4、4-6、4-9 全是这一章。
四个过程 = 四条"固定的路"。 从同一个起点出发去同一个终点区，走不同的路，做的功、换的热都不一样（第 1 章讲过功是过程量）。 四种基本过程就是四条最"好走"的路：要么压力不变，要么容积不变，要么温度不变，要么不换热。 选对了路，积分就能算出来——这就是本章的全部意义。

4.1 分析热力过程的"四步法"

拿到任何一个过程题，永远按这四步走
  1. 认过程：题目说定压、定容、定温、绝热、还是给了 n？写出过程方程（pvn=常数，n 取 0、1、κ、±∞ 就对应四种基本过程）。
  2. 定状态：用过程方程 + 状态方程，求出初终态的 p、v、T 中缺的那个。
  3. 算三个量：Δu=cvΔT、Δh=cpΔT、w=∫pdv（按过程方程积分）。
  4. 用第一定律求 q：q = Δu + w。绝热时反过来用：q=0 ⟹ w=−Δu。

第 4 步是最容易被忽略的"保险"：只要 q、Δu、w 三者不满足 q=Δu+w，就一定算错了。

定压p = 常数（n=0）ppΔv = RΔTq = Δh = cpΔT
定温pv = 常数（n=1）TRT ln(v2/v1) = RT ln(p1/p2)q = w（因 Δu=0）
定熵（绝热）pvκ = 常数（n=κ）s[R/(κ−1)](T1−T2) = (p1v1−p2v2)/(κ−1)0（w = −Δu）
定熵过程的三个"派生关系"（必须记牢，考试直接用）
T2/T1 = (v1/v2)κ−1　　 p2/p1 = (v1/v2)κ　　 T2/T1 = (p2/p1)(κ−1)/κ
第三个式子是压气机、喷管题里最常用的——它直接从压比给出温比，省掉求比容的一步。

4.2.1 定容与定压：最简单的两个

看懂例 4-1　定容与定压的组合过程（课本例 4-1）

0.3 Nm3 的氧气，在 t1=45 ℃、p1=103.2 kPa 下盛于可移动活塞的圆筒中。先在定压下加热（1-2），然后在定容下冷却到初温 45 ℃（2-3），已知定容冷却终了时 p3=58.8 kPa。求这两个过程中 Δu、Δh、Δs、q、w。

解　氧气 R=259.8 J/(kg·K)、cv=0.657、cp=0.917 kJ/(kg·K)。

  1. 初态比容：v1 = RT1/p1 = 259.8×318/(103.2×103) = 0.80 m3/kg。
  2. 点 3：T3=T1=318 K，又 p3v3=p1v1 ⟹ v3 = 103.2×0.8/58.8 = 1.40 m3/kg。
  3. 点 2：2-3 定容 ⟹ v2=v3=1.40；1-2 定压 ⟹ p2=p1。故 T2 = T1v2/v1 = 318×1.40/0.8 = 556.5 K。
  4. 质量：m = p0V0/(RT0) = 101325×0.3/(259.8×273) = 0.4286 kg。
  5. 1-2（定压）：
    Δu = 0.657×(556.5−318) = 156.7 kJ/kg；Δh = 0.917×238.5 = 218.7 kJ/kg
    w = RΔT = 0.2598×238.5 = 62.0 kJ/kg；q = Δh = 218.7 kJ/kg
    Δs = cpln(T2/T1) = 0.917×ln(556.5/318) = 0.512 kJ/(kg·K)
  6. 2-3（定容）：ΔT = 318−556.5 = −238.5 K，
    Δu = −156.7；Δh = −218.7；w = 0；q = Δu = −156.7 kJ/kg
    Δs = cvln(T3/T2) = 0.657×ln(318/556.5) = −0.367 kJ/(kg·K)
答　1-2：Δu=156.7、Δh=218.7、w=62.0、q=218.7、Δs=+0.512；2-3：Δu=−156.7、Δh=−218.7、w=0、q=−156.7、Δs=−0.367（均为 kJ/kg 或 kJ/(kg·K)）。

这类"两段拼接"题的关键是找出中间点 2 的状态——只要 2 点确定了，两段就都是简单题。找 2 点靠的就是"定压段 p 不变、定容段 v 不变"这两个条件。

4.2.2 定温与定熵：需要积分的那两个

模仿例 4-2　定温压缩与定熵膨胀（计算练习 4-4 / 4-2 型）

5 kg 氧气在 30 ℃ 下定温压缩，容积由 3 m3 变为 0.6 m3，问该过程中工质吸收或放出多少热量？输入或输出了多少功量？热力学能、焓和熵的变化各为多少？

解　氧气 R=0.2598 kJ/(kg·K)。T = 303.15 K 不变。

  1. 定温 ⟹ Δu = 0、Δh = 0（理想气体 u、h 只与 T 有关）。
  2. 功：
    W = mRT ln(V2/V1) = 5×0.2598×303.15×ln(0.6/3) = 393.8×(−1.609) = −633.8 kJ
    负号表示外界对气体做功（压缩）。
  3. 热：Q = ΔU + W = 0 + (−633.8) = −633.8 kJ，即气体放热 633.8 kJ。
  4. 熵变：
    ΔS = mR ln(V2/V1) = 5×0.2598×(−1.609) = −2.09 kJ/K
    定温压缩熵减小——压缩使分子活动空间变小，秩序变"整齐"。
答　ΔU=ΔH=0；W=Q=−633.8 kJ（外界做功 633.8 kJ、气体放热 633.8 kJ）；ΔS=−2.09 kJ/K。

定温过程有个漂亮的对称：q = w（因为 Δu=0），而且 w = TΔs。这两个式子在计算练习 4-3、4-4 里反复出现。

应考例 4-3　四种过程同题对比（计算练习 4-2，最典型的"压轴小题"）

1 kg 空气，初态 p1=0.5 MPa、t1=150 ℃。分别经下列过程膨胀到 p2=0.1 MPa：(1) 可逆绝热膨胀；(2) 不可逆绝热膨胀，终温 T2=300 K；(3) 可逆定温膨胀；(4) 可逆多变膨胀，n=2。求各过程的膨胀功和熵变，并把各过程画在同一张 p-v 图和 T-s 图上比较。

解　初态：T1 = 423.15 K，v1 = RT1/p1 = 0.287×423.15/500 = 0.2429 m3/kg。

  1. (1) 可逆绝热：T2 = T1(p2/p1)(κ−1)/κ = 423.15×(0.2)0.2857 = 423.15×0.6310 = 267.0 K。
    w = cv(T1−T2) = 0.717×156.15 = 112.0 kJ/kg；Δs = 0
  2. (2) 不可逆绝热（T2=300 K）：绝热仍 q=0，故 w = −Δu = cv(T1−T2) = 0.717×123.15 = 88.3 kJ/kg。
    Δs = cpln(T2/T1) − Rln(p2/p1) = 1.004×ln(300/423.15) − 0.287×ln(0.2) = −0.343 + 0.462 = +0.119 kJ/(kg·K)
    正值——不可逆绝热必熵增，这是第 5 章熵增原理的第一个例子。
  3. (3) 可逆定温：T 不变，
    w = RTln(p1/p2) = 0.287×423.15×ln5 = 121.4×1.609 = 195.4 kJ/kg
    Δs = Rln(p1/p2) = 0.287×1.609 = +0.462 kJ/(kg·K)
  4. (4) 多变 n=2：T2 = T1(p2/p1)(n−1)/n = 423.15×(0.2)0.5 = 423.15×0.4472 = 189.2 K。
    w = R(T1−T2)/(n−1) = 0.287×233.95/1 = 67.1 kJ/kg
    Δs = cvln(T2/T1) + Rln(v2/v1)
    其中 v2/v1 = (p1/p2)1/n = 50.5 = 2.236，故 Δs = 0.717×ln(0.4472)+0.287×ln(2.236) = −0.577+0.231 = −0.346 kJ/(kg·K)
答　(1) w=112.0、Δs=0；(2) w=88.3、Δs=+0.119；(3) w=195.4、Δs=+0.462；(4) w=67.1、Δs=−0.346（kJ/kg 与 kJ/(kg·K)）。同样的初终压，四条路做的功差别巨大——定温最多（195.4），多变 n=2 最少（67.1）。

这类题一定要自己画图：在 p-v 图上，四条线都从同一点出发、终点压力相同，但 v2 各不相同；曲线越"鼓"到右上，做功越多。在 T-s 图上，可逆绝热是竖直线（s 不变），不可逆绝热画在它右边（s 增大），定温是水平线，n=2 介于二者之间。考试常要求"画出这几条线的相对位置"，只要能体现出可逆绝热在最左、不可逆绝热在其右、定温最右就得满分。

4.3 多变过程：一条公式收编全部

为什么要有"多变"？ 因为真实机器里的压缩、膨胀既不是等温也不是绝热——有散热但不充分，有摩擦但不剧烈。真实过程夹在"定温"和"定熵"之间。 工程师想：能不能用一个"可调"的指数 n 来统一描述？能。令 pvn = 常数，n 取 0 就是定压、取 1 就是定温、取 κ 就是定熵、取 ±∞ 就是定容。 一条式子把四种情况全包了，这就是多变过程的威力。
多变过程的四个通用公式（推导一遍，以后直接套）
  1. 过程方程：pvn = 常数 ⟹ p2/p1 = (v1/v2)n，T2/T1 = (p2/p1)(n−1)/n。
  2. 膨胀功：由 w=∫pdv 与 p=p1v1n/vn 积分：
    w = R(T1−T2)/(n−1) = (p1v1−p2v2)/(n−1)
  3. 技术功：由 wt=−∫vdp 积分得
    wt = n·w = nR(T1−T2)/(n−1)
    这是多变过程独有的漂亮关系：技术功 = n × 膨胀功。（定温时 n=1 两者相等；定熵时 n=κ，正是上一节的 wt=κw。）
  4. 热量：由 q = Δu + w：
    q = cv(T2−T1) + R(T1−T2)/(n−1) = cn(T2−T1)
    其中 cn = cv(n−κ)/(n−1) 叫多变比热。
易错三连（多变过程） ✗ 把多变比热的分母写成 κ−1。 ✓ 是 cn = cv(n−κ)/(n−1)，分母永远是 n−1。分子上是 n−κ（记住"n 减 κ"）。
✗ 用 wt = (p1v1−p2v2)/(n−1) 去算技术功。 ✓ 那是膨胀功。技术功是 n 倍。
✗ 遇到 n=1（定温）时直接套 w = R(T1−T2)/(n−1)。 ✓ 分母为 0 会爆。定温必须单独用 w=RTln(v2/v1)。
应考例 4-4　多变过程已知 q 与初终态，反求全部（计算练习 4-1）

1 kg 空气在可逆多变过程中吸热 40 kJ，其容积增大为 v2=10v1，压力降低为 p2=p1/8，设比热容为定值，求过程中热力学能的变化、膨胀功、轴功以及焓和熵的变化。

解　关键：先用两个状态关系定出 n。

  1. 求 n：由 p2/p1 = (v1/v2)n：(1/8) = (1/10)n ⟹ n = ln8/ln10 = 0.9031。
  2. 求温度比：T2/T1 = p2v2/(p1v1) = (1/8)×10 = 1.25，即 T2 = 1.25T1。
  3. 用 q 定 T1：由 q = cn(T2−T1)，先算
    cn = cv(n−κ)/(n−1) = 0.717×(0.9031−1.4)/(0.9031−1) = 0.717×(−0.4969)/(−0.0969) = 3.677 kJ/(kg·K)
    于是 40 = 3.677×0.25T1 ⟹ T1 = 43.52 K，T2 = 54.40 K，ΔT = 10.88 K。
  4. 五大量：
    Δu = cvΔT = 0.717×10.88 = +7.80 kJ/kg
    Δh = cpΔT = 1.004×10.88 = +10.92 kJ/kg
    w = R(T1−T2)/(n−1) = 0.287×(−10.88)/(−0.0969) = +32.22 kJ/kg
    wt = n·w = 0.9031×32.22 = +29.10 kJ/kg
    Δs = cvln(T2/T1)+Rln(v2/v1) = 0.717×ln1.25+0.287×ln10 = 0.160+0.661 = +0.821 kJ/(kg·K)
  5. 三条校核：q = Δu+w = 7.80+32.22 = 40.00 ✓；q = cnΔT = 3.677×10.88 = 40.0 ✓；Δs = q/Tlm = 40/48.76 = 0.820 ✓（Tlm=ΔT/ln(T2/T1)）。
答　Δu=+7.80、Δh=+10.92、w=+32.22、wt=+29.10 kJ/kg，Δs=+0.821 kJ/(kg·K)。注意 n=0.903 < 1，所以 wt 比 w 略小。

这道题最容易翻车的地方是n 的算法：见到"v 增大 10 倍、p 降到 1/8"，不要慌，直接写 n=ln(p1/p2)/ln(v2/v1) = ln8/ln10。得到 n<1 不奇怪——它对应"边膨胀边吸热很多"的过程。所有答案都能用 q=Δu+w 自查，这是本题最值钱的一步。

4.4 压气机：多变过程的"工程应用"

压气机是本章唯一的"机器"。 它的任务很简单：把气体从低压压到高压。但工程上关心的是要花多少功。 压气机的功不是膨胀功 w=∫pdv，而是技术功 wt = −∫vdp——因为它是"靠压力差把流体挤进去"的设备，功的大小取决于 p-v 图曲线左侧的面积。 记住一句话：压气机算 wt，而且 wt 的积分是 ∫vdp，不是 ∫pdv。
压气机耗功公式（一种过程三种结果）

由 wt = ∫12vdp（可逆），把 v = v1(p1/p)1/n 代入积分：

定温压缩（n=1）：wt = p1v1 ln(p2/p1) = RT1 ln(p2/p1)
多变压缩：wt = [n/(n−1)]p1v1[(p2/p1)(n−1)/n−1]
绝热（定熵）压缩（n=κ）：wt = [κ/(κ−1)]p1v1[(p2/p1)(κ−1)/κ−1]

三式都是正数（压气机耗功），单位 kJ/kg。比较大小：定温 < 多变 < 定熵——这就是工程上要给压气机加冷却的原因：越接近定温，耗功越少。

模仿例 4-5　三种压缩方式比较（计算练习 4-6 型）

6 kg 空气由初态 p1=0.3 MPa、t1=30 ℃，经过不同的过程膨胀到同一终压 p2=0.1 MPa：(1) 定温；(2) 定熵；(3) n=1.2 的多变。试比较不同过程中空气对外所做的功及进行的热交换和终态温度。

解　T1 = 303.15 K，m = 6 kg。三过程的共同点：初终压力相同，p2/p1 = 1/3。

  1. (1) 定温：T2=T1=303.15 K，Δu=0，
    W = mRT1ln(p1/p2) = 6×0.287×303.15×ln3 = 522.0×1.0986 = 573.5 kJ，Q=W=573.5 kJ
  2. (2) 定熵：T2 = 303.15×(1/3)0.2857 = 303.15×0.7248 = 219.8 K，
    W = mcv(T1−T2) = 6×0.717×83.35 = 351.6 kJ，Q=0
  3. (3) 多变 n=1.2：T2 = 303.15×(1/3)0.2/1.2 = 303.15×(1/3)0.1667 = 303.15×0.8326 = 252.4 K，
    W = mR(T1−T2)/(n−1) = 6×0.287×50.75/0.2 = 87.4/0.2 = 436.7 kJ
    Q = ΔU + W = 6×0.717×(252.4−303.15) + 436.7 = −218.3 + 436.7 = +218.4 kJ（吸热）
答　三过程终温 303.2 / 219.8 / 252.4 K，做功 573.5 / 351.6 / 436.7 kJ，换热 +573.5 / 0 / +218.4 kJ。定温做功最多（膨胀时气体温度不降，压力全靠体积膨胀来降），定熵做功最少但不需要热。

这题的价值在于让你看清："做功多少"和"终温高低"是不同的问题。定温做功最多但终温不降；定熵做功最少却冷得最厉害。工程上选择哪种，取决于你要功还是要低温。

4.4.1 余隙容积：为什么压气机不能"一次压到很高"

余隙容积与容积效率 活塞走到上死点时，不可能把气体全部推出去——留的那点空间叫余隙容积 Vc。它带来的后果是：吸气量减少。
λ = V有效吸气/Vh = 1 − c[(p2/p1)1/n−1]　（c=Vc/Vh 为余隙比）
压比越大，λ 越小；当 p2/p1 大到某个值时 λ=0，压气机"一点气也吸不进"——这就是单级压缩的极限。 所以高压比必须分多级，并在级间加冷却。
为什么多级压缩 + 中间冷却能省功（用图讲）
  1. 单级从 p1 压到 p2，T 会升得很高，p-v 图上的压缩线鼓得很右——面积大，耗功多。
  2. 分成两级：一级压到 px，然后在定压下把气体冷却回 T1（等压冷却，体积缩小），再压到 p2。
  3. 冷却使第二级的起点"退回左上方"，第二段压缩线整体左移——省下的正是那块鼓出去的面积（图 4-5 左图的灰色单级线与其右侧）。
  4. 最优的中间压力使两级压比相等：
px = √(p1p2)　⟹　px/p1 = p2/px = √(p2/p1)

这个结论可以推广：z 级压缩时，每级压比都等于总压比的 z 次方根，此时总耗功最小。这就是简答题第 25 题的标准答案核心。

应考例 4-6　两级压缩的中间压力与总耗功（简答题 25 的算例）

空气由 p1=0.1 MPa、t1=27 ℃ 经两级压缩到 p2=1.0 MPa，两级之间进行定压中间冷却，把气体冷却到 27 ℃。设各级均为可逆绝热压缩，求最佳中间压力 px、各级出口温度与总耗功，并与单级压缩比较。

解　

  1. 最佳中间压力：px = √(p1p2) = √(0.1×1.0) = 0.316 MPa。每级压比 = √10 = 3.162。
  2. 各级出口温度：T = 300×3.1620.2857 = 300×1.3865 = 415.9 K（142.7 ℃）。
  3. 每级耗功：wt = cp(T−T1) = 1.004×115.9 = 116.4 kJ/kg。
  4. 两级总耗功：2×116.4 = 232.8 kJ/kg。
  5. 单级对比：单级压比 10，T = 300×100.2857 = 300×1.9307 = 579.2 K， wt = 1.004×279.2 = 280.4 kJ/kg。两级比单级省 47.6 kJ/kg（约 17%）。
答　px=0.316 MPa；各级出口 415.9 K；总耗功 232.8 kJ/kg；比单级（280.4 kJ/kg）省 17.0%。若级数更多、或压缩过程越接近定温（wt=RTln10=198.4 kJ/kg），耗功还能继续下降。

答题时务必写清"最佳中间压力对应各级压比相等"这一判据，并指出"级间冷却回初温"是省功的前提。只写数字不写这两句，简答题会被扣分。

  2. 定温过程的 w 和 q 为什么相等？（T 不变 ⟹ Δu=0 ⟹ q=w）
  3. 多变过程的技术功为什么等于 n 倍膨胀功？（wt=−∫vdp 与 w=∫pdv 在 pvn=C 下相差因子 n）

  5. 多级压缩为什么要中间冷却？最佳中间压力怎么定？（冷却省功；px=√(p1p2) 使各级压比相等）
  6. 余隙容积的存在对压气机有什么影响？（减小有效吸气量，λ 随压比增大而降低，压比过大时 λ=0）

第 5 章 热力学第二定律：管"往哪走"和"能走多远"

为什么：第 3、4 章你会发现一个尴尬的事实——第一定律从不禁止"热全部变成功"，也从不禁止"热量自己从低温跑到高温"。它们只是不违反能量守恒而已。可现实中你见不到一块冰自己烧开，也见不到热机的效率超过某个天花板。第一定律管的是"账平不平"，第二定律管的是"这步棋合不合规矩"。这一章要回答三件事：①什么过程可能发生、什么不可能；②可能的过程里，最多能取出多少功（效率天花板）；③实际做不到那么多功，亏掉的那部分怎么算、叫什么。
打个比方：把能量想象成水。第一定律是"水量守恒"——水不会凭空出现或消失。第二定律是"水位"——水只能从高处往低处流，你能用水轮机取功，是因为有落差。同样多的水，放在 100 m 高处能发很多电，摊平在地上就一点电也发不出来——能量不仅有"多少"，还有"品位"。第 5 章整章就是把"品位"这件事说清楚：高温热、电能、机械能的品位高，低温热、环境温度的热品位低。

5.1 第二定律到底在说什么：三种说法，一件事

为什么：课本一上手就给克劳修斯表述和开尔文-普朗克表述，看起来像两条互不相干的句子。其实它们是同一件事的两种说法，考试让你"说明两者等价"就是在考这个。

5.1.1 从"热机的天花板"发现问题

先看一个纯代数的事实。任何热机从高温热源吸热 Q1、向低温冷源放热 Q2、对外做功 W，由循环的第一定律：

W = Q1 − Q2， ηt = W / Q1 = 1 − Q2 / Q1

光看这个式子，只要让 Q2 → 0 就能让 ηt → 100%，而 Q2 = 0 一点不违反能量守恒。可从来没有人造出过这样的机器。也就是说，一定有某个第一定律之外的规律在限着 Q2 不能太小。这就是第二定律要抓的东西。

5.1.2 两种经典表述

表述内容它禁止了什么
克劳修斯（Clausius）不可能把热量从低温物体自发地传到高温物体而不引起其他变化。禁止"热自己倒流"。冰箱能把热从冷藏室搬到房间，但要耗电——"不引起其他变化"这个限定词是关键。
开尔文-普朗克（Kelvin-Planck）不可能制造出这样的循环发动机：只从单一热源吸热，让它完全变成功，而不产生其他影响。禁止"效率 100%"。所以任何热机必须有冷源。
第二类永动机上面那种"只吸一个热源的热、全部变成功"的机器，就叫第二类永动机。它不违反能量守恒（不违反第一定律），但违反第二定律，所以造不成。
为什么这两种说法是一回事（互相推导）
  1. 假设克劳修斯表述不成立（能自发把热从低温搬到高温，且不耗功）。那么让一台热机从高温热源吸热 Q1、做功 W、向低温放热 Q2；再用"自发搬运"把这份 Q2 原封不动搬回高温热源。净效果：高温热源一点没变，低温热源一点没变，而机器对外净输出了 W。这正是一台只从单一热源取热、全部变功的机器 → 违反开尔文-普朗克表述。
  2. 反过来假设开尔文-普朗克表述不成立（存在单热源热机，吸 Q 全变 W）。把它输出的 W 拿去做功驱动一台热泵（或直接摩擦生热），把热量 Q 送进高温物体。净效果：低温物体放掉 Q，高温物体得到 Q，其他什么都没变 → 热量自发从低温到了高温 → 违反克劳修斯表述。
  3. 两条路都推出了矛盾，所以两种表述等价：否定任一条必然否定另一条。
  4. 答题模板："若克劳修斯表述不成立，则可造出单热源热机，违反开尔文表述；反之亦然。故二者等价，都是第二定律的表述。"
易错三连

× "第二定律说热量不能从低温传到高温。" —— 错。冰箱天天在干这件事，第二定律禁止的是不花代价地自发进行。

× "第二类永动机违反能量守恒。" —— 错。它不违反第一定律（能量是守恒的），它违反的是第二定律。第一类永动机才是违反第一定律的。

× "不可逆过程就是不能反向进行的过程。" —— 不准确。是"反向进行后无法让系统和外界同时恢复原状"。有的过程能反向（比如缓慢压缩回去），只是外界留下了痕迹。

5.2 卡诺循环：给效率画一条天花板

为什么：要证明"效率有上限"，就必须先造一个"最好的循环"当标尺。卡诺（1824 年，比第一定律还早 26 年）用纯逻辑造出了这把标尺。它的价值不在能实现，而在于它给出了任何热机都不能超越的界限。

5.2.1 卡诺循环的四个过程

卡诺循环由四个可逆过程组成，工质在两个恒温热源 T1、T2 之间来回：

过程名称特征换热/做功
1 → 2可逆定温膨胀与高温热源 T1 接触，T 不变吸热 q1 = T1(s2 − s1)，对外做功
2 → 3可逆绝热膨胀与热源脱开，q = 0对外做功，温度由 T1 降到 T2
3 → 4可逆定温压缩与低温冷源 T2 接触放热 q2 = T2(s2 − s1)，外界对系统做功
4 → 1可逆绝热压缩与热源脱开外界做功，温度由 T2 升回 T1

5.2.2 卡诺效率的推导：只用面积，不用积分

推导：ηc = 1 − T2/T1
  1. 看 T-s 图上的面积。矩形的高是 T1 − T2，宽是 Δs = s2 − s1，所以矩形面积 = (T1 − T2)Δs。
  2. 循环净功就等于这个面积。因为 T-s 图上循环围出的面积 ∮Tds = w0，而 Tds = δq，所以 ∮δq = w0。
  3. 吸热量是上边那条线的"面积"：q1 = T1Δs（在 T 恒定下，q = ∫Tds = T1Δs）。
  4. 放热量是下边那条线：q2 = T2Δs。
  5. 代入效率定义：
    ηc = 1 − q2/q1 = 1 − (T2Δs)/(T1Δs) = 1 − T2/T1
  6. 注意 Δs 被约掉了——这是整个推导最关键的一步。它说明：卡诺效率只与两个热源的温度有关，与工质是什么、吸多少热、体积怎么变，全都没关系。
必记结论（4 条，简答题常考）

① ηc 只取决于 T1、T2，与工质性质、循环大小无关。要提高效率，就提高 T1 或降低 T2（工程上就是"提高蒸汽初温、降低冷凝压力"）。

② ηc 永远小于 1。只有当 T1 = ∞ 或 T2 = 0 K 时才等于 1，都不可能。

③ 若 T1 = T2，则 ηc = 0：只有单一热源时无法实现循环 → 单热源热机不可能。

④ 一切工作于同样两个热源之间的循环，效率都不可能超过 ηc；可逆时等于它，不可逆时小于它。

例 5-1 · 看懂

卡诺循环工作于 600 ℃ 与 40 ℃ 两个热源之间，每秒从高温热源取热 100 kJ。求 (1) 卡诺循环热效率；(2) 循环功率；(3) 每秒排向冷源的热量。

解

第 1 步 · 温度换成 K（这一步错了后面全错）

T1 = 600 + 273.15 = 873.15 K， T2 = 40 + 273.15 = 313.15 K

第 2 步 · 套卡诺效率公式

ηc = 1 − 313.15/873.15 = 1 − 0.3586 = 0.6414

第 3 步 · 功率（每秒 100 kJ，所以 Q̇1 = 100 kJ/s = 100 kW）

P = ηc · Q̇1 = 0.6414 × 100 = 64.14 kW

第 4 步 · 排热量

Q̇2 = Q̇1 − P = 100 − 64.14 = 35.86 kW

第 5 步 · 校核（卡诺循环的"温度比 = 热量比"是最快的验算）

Q̇1/T1 = 100/873.15 = 0.11453， Q̇2/T2 = 35.86/313.15 = 0.11453 ✓

答：ηc = 64.14%；P = 64.14 kW；Q̇2 = 35.86 kW。

这道题的"经验"：卡诺题只有两个动作——换 K，然后写 T1/T2 = q1/q2。这个比例关系比记效率公式更好用，因为它直接给你热量的答案。

5.2.3 卡诺定理与克劳修斯不等式

卡诺循环只是"一个"循环，为什么能当所有热机的标准？靠的是下面这条定理。

卡诺定理（两个推论）

定理一：在相同温度的两个恒温热源之间工作的一切循环，其热效率不可能大于可逆循环的热效率。

定理二：在相同温度的两个恒温热源之间工作的一切可逆循环，热效率都相等，且等于卡诺循环效率 ηc = 1 − T2/T1。

合起来：ηt ≤ ηc，等号只在可逆时成立。这个不等式就是判断"某台机器是否可能"的唯一标准。

克劳修斯不等式：把卡诺定理写成一个可算的式子
  1. 对任意循环，把热源切成无穷多个温度 Ti 的微热源，每个微热源给工质的热量是 δQi。
  2. 若循环可逆，则每个微小环节都能当成卡诺循环的一部分，有 δQi/Ti = 0 的总和为零：
    ∮ (δQ/T)rev = 0
  3. 若循环不可逆，由卡诺定理 ηt < ηc，可以证明吸热项"打折"、放热项"加重"，从而
    ∮ (δQ/T) ≤ 0 …… 等号可逆，小于号不可逆
  4. 这就是克劳修斯不等式。它的用途：算出一个循环的 ∮δQ/T，若结果 > 0，则这个循环绝对不可能实现（这正是"判断热机能否实现"类题目的唯一判据）。
例 5-2 · 模仿

有一循环发动机，工作于热源 T1 = 1000 K 及冷源 T2 = 400 K 之间，从热源取热 1000 kJ 而做功 700 kJ。问该循环发动机能否实现？

解

第 1 步 · 先算它的实际效率

ηt = W/Q1 = 700/1000 = 0.70

第 2 步 · 再算它所在温区的天花板

ηc = 1 − T2/T1 = 1 − 400/1000 = 0.60

第 3 步 · 比较：ηt = 70% > ηc = 60%，违反卡诺定理。

第 4 步 · 用克劳修斯不等式再验一遍（两条路都要会，考试可能指定方法）

∮δQ/T = Q1/T1 − Q2/T2 = 1000/1000 − 300/400 = 1 − 0.75 = +0.25 > 0

克劳修斯不等式要求 ≤ 0，而这里算出 +0.25，为正 → 不可能实现。

答：不能实现。它的效率 70% 超过了同温区的卡诺效率 60%；等价地，其 ∮δQ/T = +0.25 > 0，违反克劳修斯不等式。

判据总结：算 ∮δQ/T，正数 = 绝不可能，零 = 可逆（理想），负数 = 不可逆但可能。三个符号对应三种结论，一句话背下来。

5.3 熵：第二定律的"尺子"

为什么：克劳修斯不等式里那个 ∮δQ/T 对可逆循环恒等于零。一个"绕一圈积分为零"的量，在数学上必然对应一个状态函数（就像重力绕一圈做功为零，所以有重力势能）。这个新的状态函数就是熵。换句话说：熵不是谁拍脑袋定义的，它是从"可逆循环 ∮δQ/T = 0"里被迫长出来的。
推导：熵的定义与"为什么它是状态量"
  1. 可逆循环：∮(δQ/T)rev = 0（5.2.3 已证）。
  2. 数学事实：若某个微元量 δX 沿任意闭合路径积分恒为零，则 δX 必是某个函数的全微分，即 δX = dF。所以 δQrev/T 是一个全微分。
  3. 给它起个名字——这个新状态函数的微分定义为
    ds = (δQ/T)rev [kJ/(kg·K)]， dS = (δQ/T)rev [kJ/K]
    这里 s 是比熵（1 kg 的熵），S 是总熵。
  4. 它为什么是状态量：任意两态之间，Δs = ∫12(δq/T)rev 只与 1、2 两态有关，与走哪条可逆路径无关（这正是第 1 章"状态参数"的定义）。所以可以像 p、v、T 一样列表、查表、画图。
  5. 注意一个坑：定义式里的 δq 必须是可逆的热量。如果过程不可逆，不能用实际的热量去算 Δs——必须另找一条连接同样初终态的可逆路径来算。这是本章最容易翻车的地方。

5.3.1 熵方程：把"熵变"拆成两块

对不可逆过程，克劳修斯不等式给 ∮δQ/T < 0。做同样的"切开"操作可以推出，任何过程的熵变都可以写成两项之和：

ds = δq/T + δsg， Δs = ∫δq/T + sg， sg ≥ 0
项名字来源可正可负？
∫δq/T熵流 sf由传热带进/带出系统的熵。吸热为正，放热为负，绝热为零。可正可负（看吸热还是放热）
sg熵产由系统内部不可逆因素（摩擦、温差传热、节流、自由膨胀、混合……）产生的熵。永远 ≥ 0，只有可逆时才为 0
必记结论

熵产 sg 是"不可逆程度的度量"。算出 sg > 0，说明过程不可逆；sg = 0，可逆；若算出 sg < 0，那这个循环或设备一定不可能存在——这和第 5.2 节"∮δQ/T > 0 不可能"是同一件事的两种说法。

绝热过程的熵变 = 熵产（因为 δq = 0）。所以"绝热"不等于"等熵"：只有可逆绝热才是等熵。这个区分是判断题的高频陷阱。

5.3.2 理想气体熵变的三个常用式（第 2 章已推，这里换个角度理解）

由 ds = du/T + pdv/T（吉布斯方程，第 6 章细讲），代入理想气体关系可得三式：

Δs = cv ln(T2/T1) + R ln(v2/v1)
Δs = cp ln(T2/T1) − R ln(p2/p1)
Δs = cv ln(p2/p1) + cp ln(v2/v1)
易错三连（符号）

× "压力比总是放在 ln 里加号前面。" —— 记法：体积变大（膨胀）→ 熵增，所以 v 比出现在加号项；压力变大（压缩）→ 熵减，所以 p 比出现在减号项。用"膨胀增熵、压缩减熵"来定符号。

× 用 cp 的式子算定容过程。 —— 三个式子对任意过程都成立（因为熵是状态量），只要初终态定了就能用，不必管中间走的是定容还是定压。选哪个式子只取决于你手上已知的是哪两个参数。

× 绝热了就直接写 Δs = 0。 —— 只有可逆绝热才是 0。不可逆绝热 Δs = sg > 0。

5.4 熵增原理与做功能力损失

为什么：单看一个系统，它的熵可以增、可以减（放热就减）。但把"系统和与它换热的所有外界"打包成一个孤立系统，这个大盘子的熵就只增不减。这条规律叫熵增原理，它是第二定律最普适、最好用的一种写法——因为判断"能不能发生"时，你只需要算一个数：孤立系统的总熵变。
推导：熵增原理（从熵方程出发）
  1. 对孤立系统：它与外界无热交换、无质量交换，所以熵流 sf = 0。
  2. 代入熵方程 Δs = sf + sg，得
    Δsiso = sg ≥ 0
  3. 三种情形：> 0 不可逆（真实过程都是这种）；= 0 可逆（理想极限）；< 0 不可能发生。
  4. 推论（"熵减不可能"）：孤立系统里如果有某一部分熵减少，必定有另一部分熵增加得更多，总量仍然只增不减。

5.4.1 从"熵增"到"功亏了"：i = T0Δsiso

熵增原理只告诉你"可不可能"，但工程上更关心"亏了多少"。这里的桥，是下面这个思想实验：

推导：为什么"做功能力损失 = T0 × 孤立系统熵增"
  1. 取环境温度 T0（通常 293 K 或 298 K）作为唯一冷源。在这个环境里，一份热量 Q 最多能变成的功是卡诺功：
    Wmax = Q(1 − T0/T)
  2. 假如某不可逆过程让一份本来可以"完整利用"的能量出现了熵产 Δsiso，那么这份熵产相当于把 Qloss = T0Δsiso 的热量降级成了环境温度的热。
  3. 环境温度的热量一点功也变不出来（因为 T = T0 时卡诺效率为零）。所以这部分就是彻底扔掉的功：
    i = T0 Δsiso （做功能力损失，又叫㶲损失 l）
  4. 它的意义：把"熵"这个抽象量翻译成了"千瓦"——可以直接和电费、煤耗挂钩。这就是"能量贬值"的定量表达。

5.4.2 冷量与热量：为什么"制冷比制热更费功"

同样的 Q，温度不同，"含功量"差得很远。两个常用公式（第 5.5 节焓与㶲里会正式引入，这里先用）：

对象可用能（㶲）说明
温度 T > T0 的热量 QEx,Q = Q(1 − T0/T)热量温度越高，越"值钱"。100 ℃ 的热水远比 30 ℃ 的洗澡水值钱。
温度 T < T0 的冷量 Q0Ex,Q0 = Q0(T0/T − 1)注意是"冷量"—从低温处取走的热。温度越低，同样的冷量越值钱。
例 5-3 · 模仿

某热泵循环工作于热源 t1 = 500 ℃ 与冷源 t2 = 20 ℃ 之间，它是一个 a-b-c-d-a 的不可逆循环。a-b 为可逆等温吸热，b-c 为不可逆绝热膨胀（工质熵增 0.1 kJ/(kg·K)），c-d 为可逆等温放热，d-a 为可逆绝热压缩。工质为 1 kg 空气，热源放热 q1 = 1000 kJ/kg。求循环净功及孤立系统做功能力损失，并验证 i = T0Δsiso。

解

第 1 步 · 热源侧熵变（热源放热 1000 kJ，温度 773 K）

Δs1 = −q1/T1 = −1000/773 = −1.294 kJ/(kg·K)

第 2 步 · 冷源侧熵变（冷源吸热 q2，且工质在 b-c 多产生了 0.1，这部分熵最终也随放热进了冷源）

Δs2 = |Δs1| + 0.1 = 1.294 + 0.1 = 1.394 kJ/(kg·K)

第 3 步 · 反推冷源吸热量（冷源温度 293 K 恒定）

q2 = T2Δs2 = 293 × 1.394 = 408.4 kJ/kg

第 4 步 · 循环净功与效率

ηt = 1 − q2/q1 = 1 − 408.4/1000 = 0.5916
w0 = q1 − q2 = 1000 − 408.4 = 591.6 kJ/kg

第 5 步 · 孤立系统熵增（工质绕一圈熵变为零，所以只算两个热源）

Δsiso = Δs1 + Δs2 = −1.294 + 1.394 = +0.1 kJ/(kg·K)

第 6 步 · 两条路算损失，互相验证

路 A（先算最大可能功，再相减）：同温区卡诺效率 ηc = 1 − 293/773 = 0.6209，最大功 w0,max = 1000 × 0.6209 = 620.9 kJ/kg， l = 620.9 − 591.6 = 29.3 kJ/kg。

路 B（直接用公式）：l = T0Δsiso = 293 × 0.1 = 29.3 kJ/kg。

答：w0 = 591.6 kJ/kg，ηt = 59.16%，l = 29.3 kJ/kg，两种算法完全一致，验证了 i = T0Δsiso。

这道题的"经验"：这类题的骨架永远是"熵变 → 由熵变反推热量 → 由热量算功"。为什么能反推热量？因为在恒温热源上 q = TΔs，只要温度恒定，熵变和热量就是一回事。

5.5 两道"必考大题"的完整解法

为什么：上面的例题是"课本型"。真正考试里有两类题几乎必出：①混合/充气求熵变（考你会不会分开算再相加）；②不可逆过程求做功能力损失（考你会不会正确圈定"孤立系统"的边界）。这两类题的共同难点都不是公式，而是"边界画到哪"。
例 5-4 · 应考（混合求熵变）

某刚性绝热容器，用隔板分成容积相等的两部分，各为 0.1 m³。一边是温度 40 ℃、压力 0.4 MPa 的空气，另一边是温度 20 ℃、压力 0.2 MPa 的空气。抽去隔板后两部分空气均匀混合而达到热平衡。求混合过程引起的空气熵的变化。

解

第 1 步 · 分别算两部分的质量（V1 = V2 = 0.1 m³）

m1 = p1V/(RT1) = 400×0.1/(0.287×313.15) = 40/89.87 = 0.4451 kg
m2 = p2V/(RT2) = 200×0.1/(0.287×293.15) = 20/84.13 = 0.2377 kg

第 2 步 · 能量守恒求混合温度（刚性、绝热 → W = 0、Q = 0 → ΔU = 0；两边都是空气，cv 相同可约掉）

Tm = (m1T1 + m2T2)/(m1 + m2) = (139.38 + 69.68)/0.6828 = 306.19 K = 33.04 ℃

第 3 步 · 求混合后的压力（总容积 0.2 m³）

pm = m总RTm/V总 = 0.6828×0.287×306.19/0.2 = 300.0 kPa

第 4 步 · 分别算两部分的熵变（注意：压力比是"终压/初压"，升压为正、降压为负）

A 部分（40 ℃，原 p = 400 kPa → 300 kPa，降压）：

Δs1 = cpln(Tm/T1) − Rln(pm/p1) = 0.717×(−0.02248) − 0.287×(−0.28768) = −0.01612 + 0.08256 = +0.06644
ΔS1 = 0.4451 × 0.06644 = +0.02957 kJ/K

B 部分（20 ℃，原 p = 200 kPa → 300 kPa，升压）：

Δs2 = 0.717×ln(306.19/293.15) − 0.287×ln(300/200) = 0.717×0.04352 − 0.287×0.40546 = +0.03120 − 0.11637 = −0.08517
ΔS2 = 0.2377 × (−0.08517) = −0.02025 kJ/K

第 5 步 · 相加

ΔS = S1 + S2 = 0.02957 − 0.02025 = +0.00932 kJ/K

答：混合过程空气总熵变 ΔS = +0.00932 kJ/K（为正，说明该混合过程不可逆，且是孤立系统内部发生的，符合熵增原理）。

这道题的"经验"有三条：①先分后合——各部分的熵变必须分开算再相加，不能先求平均参数再整体算；②符号靠"升压/降压"和"升温/降温"两个判据定，不要死记公式；③两条支路的熵变一正一负、量级相近，这是这类题的典型结构——两股气流混合的总熵增往往是个小数，但绝不为负。若你算出负数，说明符号错了。

例 5-5 · 应考（不可逆循环求做功能力损失）

设工质在热源 T = 1000 K 和冷源 T0 = 300 K 之间进行不可逆循环。当工质从热源吸热时存在 20 K 温差，向冷源放热时也存在 20 K 温差，其余两个过程为定熵膨胀及定熵压缩过程。(1) 求循环热效率；(2) 热源每提供 1000 kJ 的热量，做功能力损失是多少？(3) 该孤立系统做功能力损失是否符合 i = T0Δsiso？

解

第 1 步 · 看清两处温差在哪

热源 1000 K，工质吸热时比热源低 20 K → 工质吸热温度 T1′ = 980 K。
冷源 300 K，工质放热时比冷源高 20 K → 工质放热温度 T2′ = 320 K。

第 2 步 · 工质侧循环是"可逆"的（两个定熵 + 两个定温，温差只在工质与热源之间）

ηt = 1 − T2′/T1′ = 1 − 320/980 = 1 − 0.3265 = 0.6735

第 3 步 · 吸放热量与净功（热源提供 1000 kJ 给工质，工质全收）

q1 = 1000 kJ， w = ηtq1 = 673.5 kJ， q2 = 326.5 kJ

第 4 步 · 最大可能功（同温区卡诺）

ηc = 1 − 300/1000 = 0.70， wmax = 0.70 × 1000 = 700 kJ

第 5 步 · 做功能力损失（路 A：功差）

i = wmax − w = 700 − 673.5 = 26.5 kJ

第 6 步 · 路 B：算孤立系统熵增再乘 T0

孤立系统 = 热源 + 冷源 + 工质。工质绕一圈熵变为 0，所以只算两个源：

Δs热源 = −1000/1000 = −1.000 kJ/K（放出 1000 kJ）
Δs冷源 = +326.5/300 = +1.0883 kJ/K（收到 326.5 kJ）
Δsiso = −1.000 + 1.0883 = +0.0883 kJ/K
i = T0Δsiso = 300 × 0.0883 = 26.5 kJ ✓

第 7 步 · 回答第 (3) 问：两条路都得到 26.5 kJ，完全符合 i = T0Δsiso。

答：(1) ηt = 67.35%；(2) i = 26.5 kJ；(3) 符合，因为 T0Δsiso = 300 × 0.0883 = 26.5 kJ，与功差法一致。

这道题的"经验"（最重要的一条）：题目给的"20 K 温差"不是让你把 T 当 1000/300 用，而是要你判断谁的熵变按哪个温度算。热源的熵变永远用热源自己的温度（1000 K、300 K），工质的熵变才用 980 K、320 K。一旦把这两个温度搞混，路 B 就算不出 26.5。这也是本课最典型的"概念题伪装成计算题"。

⚠ 口径提示（不同教材/不同老师可能要求另一种算法）

本题的两种理解，答案不同，考试前请务必确认老师用哪一种：

口径一（上式，本讲义采用）：只把"热源温度差造成的不可逆"算进孤立系统熵产，即工质与热源之间不计入——相当于把工质和热源之间的换热视为"在热源温度下传热"。结果 i = 26.5 kJ，与"卡诺功 700 − 实际功 673.5"完全自洽。

口径二（把两处 20 K 温差都算进去）：热源 1000 K → 工质 980 K 的传热本身也产熵： ΔSg1 = 1000×(1/980 − 1/1000) = 0.0204 kJ/K； 工质 320 K → 冷源 300 K 同理：ΔSg2 = 326.5×(1/300 − 1/320) = 0.0680 kJ/K。 加上热源/冷源两端的 −1.000 + 1.0883，总 ΔSiso = 0.2154 kJ/K，则 i = 300 × 0.2154 = 64.6 kJ。

怎么判断该用哪个：看题目问的是"循环的损失"还是"整个装置连同换热过程的损失"。问"循环热效率 + 循环的损失"，用口径一；问"这套装置总的做功能力损失"，用口径二。两者都写出来，是最稳的答法。

第 7 章 水蒸气：一路"不听话"的工质

为什么：前六章几乎所有的计算都建立在 pv = RT 上。可电厂、锅炉、汽轮机里的工质全都是水蒸气——它在湿蒸汽区根本不服从理想气体方程，压缩因子可以只有 0.5 甚至更低。这时候所有"cpΔT"、"RTln(v2/v1)" 全部失效。替代方案只有一个：查表/查图。所以这一章不是教你新公式，而是教你怎么查、怎么在查完之后接上第一定律。
打个比方：理想气体像"按公式算工资"——底薪 × 工时，好算。水蒸气像"按工资表查"——不同岗位、不同级别对应不同的数，你只能查表。而水蒸气的"表"之所以存在、之所以好查，是因为它在湿蒸汽区只有一个自由度：只要告诉我压力，温度、比容、焓、熵就全都定了。这一个自由度是整章的钥匙。

7.1 相变与相图：水为什么有"两个平台"

为什么：要理解水蒸气的一切特殊性，先得看清"水→汽"这个过程在坐标图上长什么样。一旦你脑子里有那张图，后面查表、判断湿蒸汽还是过热蒸汽，都不用背。

7.1.1 三个相、三条线、两个特殊点

名称是什么数值（水）
三相点固、液、汽三相共存唯一的一个状态点t = 0.01 ℃，p = 611.2 Pa
临界点液、汽差别消失的极限点。超过它，无论加多大压力都不能使气体液化tc = 374.15 ℃，pc = 22.12 MPa，vc = 0.003147 m³/kg
熔化线固 ↔ 液的界线水的这条线向左倾（反常！）
汽化线液 ↔ 汽的界线，从三相点出发、终止于临界点这就是"饱和蒸汽压曲线"
升华线固 ↔ 汽的界线干冰、霜的形成走这条线
易错三连

× "超过临界温度，加压就能液化。" —— 不能。临界温度之上，无论多大压力都只能得到"超临界流体"，得不到液体。这是液化石油气、超临界 CO₂ 萃取的理论依据。

× "三相点是水的冰点。" —— 不是。三相点是 0.01 ℃（611 Pa），冰点是 0 ℃（101.325 kPa）。两者差 0.01 K，因为冰点处还有空气溶入等因素。

× "湿蒸汽是'湿的'。" —— 完全不是。"湿蒸汽"指饱和液 + 饱和汽的混合物，工程上叫"湿"只是沿用习惯，它可能烫得要命（比如汽轮机排汽）。

7.2 定压发生过程：五段路，两个平台

为什么：把 1 kg 0 ℃ 的水在 1 个大气压下一直加热到过热蒸汽，这条路径是整章的主干。你必须能闭着眼睛画出它在 T-s 图和 p-v 图上的形状，并说出每一段的名字、每一段的热量怎么算。
推导：定压加热水的五个阶段
  1. a → b：水的预热（未饱和水）。温度从 t0 升到饱和温度 ts。这一段水还是液体，吸热使温度上升：q = cp,水(ts − t0)。在 T-s 图上是一段向右上的斜线。
  2. b 点：饱和水。第一个"平台"的起点。此时水刚好要开始沸腾，参数记作 v′、h′、s′。
  3. b → c：定压汽化。温度不变、压力不变，水一边吸热一边变成蒸汽。这一段是水平线——这就是第一个平台。吸收的热量叫汽化潜热 r = h″ − h′。
  4. c 点：干饱和蒸汽。最后一滴水刚好变成汽，参数记作 v″、h″、s″。b、c 之间任意一点都是湿蒸汽，用干度 x 描述：
x = m汽/(m汽 + m液) （0 ≤ x ≤ 1）
hx = h′ + x(h″ − h′) = h′ + xr， 同理 vx = v′ + x(v″ − v′)， sx = s′ + x(s″ − s′)
  1. c → d：过热。继续加热，温度重新上升，成为过热蒸汽。过热程度用过热度 t − ts 表示。
必记结论：湿蒸汽区只有一个自由度

在湿蒸汽区，定压线 = 定温线（两线重合）。所以饱和蒸汽表只给压力（或只给温度）一列自变量就够了——另一个自动确定。这就是为什么查表时你只需要一个数：给 p，就查到 ts、v′、v″、h′、h″、s′、s″、r。

反过来，过热区有两个自由度，所以过热蒸汽表必须给两个自变量（通常是 p 和 t）。

易错三连（判断"是湿蒸汽还是过热蒸汽"）

× 给了压力和温度就直接当理想气体套 pv = RT。 —— 必须先判断状态！做法：查该压力下的 ts，若题给 t > ts → 过热蒸汽；若 t = ts → 饱和（还需 x 才能定）；若给了 x 或给了两个"湿区参数"→ 湿蒸汽。

× 干度 x 用于过热蒸汽。 —— x 只在湿蒸汽区（b 到 c 之间）有意义，过热区 x 无定义。

× 湿蒸汽的焓用 h′ 或 h″ 近似。 —— 必须按 hx = h′ + xr 插值。用 h′ 会把焓算小很多（r 通常上千 kJ/kg，误差能到 50% 以上）。

7.3 水蒸气表与 h-s 图：工程上怎么"查"

为什么：考试允许查表，但很多人不会查——不知道查哪个表、给了什么查什么、查完怎么用干度修正。这一节把查表动作拆成固定套路。

7.3.1 三张表，各管一段

表适用区自变量给出什么
饱和水与饱和蒸汽表（按压力排列）湿蒸汽区（含 b、c 两点）pts、v′、v″、h′、h″、r、s′、s″
饱和水与饱和蒸汽表（按温度排列）同上，但已知的是温度t同上（含对应的 ps）
未饱和水与过热蒸汽表预热段（a→b）、过热段（c→d）p 和 tv、h、s

7.3.2 查表的固定四步

查表四步法（任何水蒸气题都这么开头）
  1. 先判区。已知 p 和 t：查该 p 下的 ts。t < ts → 未饱和水；t = ts → 饱和；t > ts → 过热蒸汽。已知 p 和 x → 直接湿蒸汽。
  2. 查两个端点。湿蒸汽查 h′、h″（或 s′、s″）；过热蒸汽查该 p、t 处的 h、s。
  3. 湿蒸汽用干度插值。hx = h′ + x(h″ − h′)。这一步不能省。
  4. 最后才套第一定律。算功、算热、算效率。绝不要指望用 cpΔT。

7.3.3 h-s 图为什么好用

对绝热过程（汽轮机、喷管），q = 0，所以 Δh = −wt——功就是焓差。在 h-s 图上，竖直方向的距离直接就是功，一眼就能读出"理想绝热膨胀能出多少功"和"实际出了多少功"，中间差的垂直段就是损失。这就是电厂工程师人手一张莫里尔图的原因。

7.4 水蒸气的基本热力过程

为什么：第 4 章那套"四种基本过程 + 多变过程"的公式表，对水蒸气统统不能用（因为 pv ≠ RT）。但过程本身还是那几种，所以解题方法要换：用"过程特征"定终态，用表查初终态参数，用第一定律算功热。
过程过程特征（用来定终态）怎么算功和热
定容v1 = v2w = 0，q = Δu = Δh − vΔp
定压p1 = p2w = p(v2 − v1)，q = Δh（定压即等焓差）
定温t1 = t2（湿区就是定压）q = TΔs（可逆），w = q − Δu
绝热s1 = s2（可逆绝热）wt = h1 − h2；先由 s 定终态，再查 h
例 7-1 · 模仿（汽轮机绝热膨胀）

水蒸气进入汽轮机时 p1 = 3 MPa、t1 = 400 ℃，绝热膨胀到 p2 = 0.1 MPa。求 (1) 若为可逆绝热膨胀，单位质量做功多少；(2) 膨胀终点是湿蒸汽还是过热蒸汽，干度多少。

解

第 1 步 · 判进口状态。3 MPa 下的 ts ≈ 233.9 ℃，题给 400 ℃ > 233.9 ℃ → 过热蒸汽。

第 2 步 · 查进口参数（过热蒸汽表，3 MPa / 400 ℃）

h1 ≈ 3231 kJ/kg， s1 ≈ 6.921 kJ/(kg·K)

第 3 步 · 用"可逆绝热 = 等熵"定终态：s2 = s1 = 6.921。

第 4 步 · 查 0.1 MPa 的饱和参数，判断终态在哪一区

s′(0.1 MPa) ≈ 1.303， s″(0.1 MPa) ≈ 7.359 kJ/(kg·K)

因为 s′ < s2 = 6.921 < s″，所以终态落在湿蒸汽区。

第 5 步 · 反求干度

x2 = (s2 − s′)/(s″ − s′) = (6.921 − 1.303)/(7.359 − 1.303) = 5.618/6.056 = 0.928

第 6 步 · 用干度算终态焓（0.1 MPa 下 h′ ≈ 417.5，h″ ≈ 2675）

h2 = h′ + x(h″ − h′) = 417.5 + 0.928×(2675 − 417.5) = 417.5 + 2095 = 2513 kJ/kg

第 7 步 · 算功（绝热、忽略动能位能变化，wt = h1 − h2）

wt = 3231 − 2513 = 718 kJ/kg

答：可逆绝热做功约 718 kJ/kg；终态为湿蒸汽，干度 x2 ≈ 0.93。

这道题的"经验"（水蒸气的万能套路）：①判区 → ②查进口 → ③按过程特征定出口的状态量（等熵 / 等容 / 等压）→ ④用 s 或 v 反求干度 x → ⑤用 x 算 h → ⑥套第一定律。中间永远不要想着用 cp、κ、pv^κ 这些东西。数值会随用哪张表略有出入（本题 h1 若取 3230.9、h″ 取 2675.5，结果在 715～720 之间都算对），关键是方法和判区正确。

考试高频追问：为什么汽轮机排汽要"湿"？

因为湿蒸汽的 h 比同压力下的过热蒸汽低得多，能多取出功（wt = h1 − h2）。但干度也不能太低——低于 0.88 左右，水滴会高速撞击叶片造成侵蚀（水蚀）。所以工程上既要"尽量湿"又要"不太湿"，这个矛盾正是"中间再热"技术存在的理由之一（第 9、10 章会讲）。
