读前须知：动力学到底在算什么

先把地图给你，否则后面每一节都像突然冒出来的。 动力学只回答一个问题：力和运动之间是什么关系？ 牛顿第二定律 ma = ΣF 是全部内容的源头，但它只是一个微分方程。 这句话意味着两件事，也就分出了两条路：

路一（求导）：运动已知 → 求两次导数得加速度 → 代进方程 → 解出未知的力。
路二（积分）：力已知 → 列微分方程 → 积分两次 → 得到运动规律。

路二往往积不出来（因为力可能是位置、速度、时间的复杂函数），于是人们发明了两种"不用解微分方程"的捷径： 把方程对时间积一次，得到动量定理（第 2 部分）；把方程对某点取矩，得到动量矩定理（第 3 部分）。 这两条定理之所以是"捷径"，是因为它们在积分之后只跟"开始"和"结束"两个状态有关，中间过程多复杂都不用管。

三部分的关系，一句话说清：

部分核心方程解决什么问题典型考法
一 · 质点动力学 ma = ΣF 一个质点的运动与受力互相求解 求张力、求轨迹、求脱离位置
二 · 动量定理 ΣF = d(mv)/dt，积分得 I = mv2 − mv1 一堆物体组成的系统、流体冲击、变质量（火箭） 求平均冲力、求管壁受力、火箭速度
三 · 动量矩定理 dLO/dt = ΣMO，对定轴 Jzε = ΣMz 转动、刚体平面运动、纯滚动 求角加速度、求摩擦、求转动惯量
三部分不是三个独立的知识块，而是同一个 ma = ΣF 的三次"变形"。 所以你在第 2、3 部分遇到的每一个式子，都能在第 1 部分找到它的原形：
· 动量定理 = 第 1 部分方程对时间积分；
· 质心运动定理 = 第 1 部分方程对整个系统求和（内力消掉）；
· 动量矩定理 = 第 1 部分方程两边叉乘矢径 r；
· 定轴转动方程 Jε = ΣM = 动量矩定理在刚体上的特例。

看懂这一层，三部分就只需要学一遍。这份讲义会在每处显式标出"这一步对应第 1 部分的哪一句"。

读法建议（三条，都很实在）

第一条：受力图必须亲手画。动力学 90% 的错误不是算错，是受力图漏了某个力（最常见：漏掉摩擦力、把支持力画反、把"人对地面的力"和"地面对人的力"搞混）。 不画图就开始列方程，几乎一定出错。

第二条：每一步都问"这是矢量式还是标量式"。矢量式能直接相加；标量式必须在同一个方向上才成立。 把矢量分量混着加，是第二大错误来源。

第三条：算出结果先做"量纲 + 极限"两个检查。量纲不对一定错； 把参数推向极端（比如质量趋近无穷、角度趋近 0）看结果合不合理，能抓住大部分符号错误。
本讲义使用的符号约定（与你三份课件一致，避免抄错）：
· 粗体表示矢量（如 v、a、F），斜体表示标量或分量；
· m 质量，t 时间，x、y、z 直角坐标，τ 切向，n 法向，r、φ 极坐标；
· v 速率，a 加速度，ω 角速度，ε 角加速度，J 转动惯量，L 动量矩，M 力矩；
· qm 质量流量（kg/s），ρ 密度，A 截面积，Q 体积流量（m³/s）。

第 1 部分　质点动力学：力决定加速度，加速度决定运动

这一部分只做一件事：把 ma = ΣF 用起来。 听起来简单，但"用起来"包含四个决定，考试考的就是这四个决定：
① 判断是哪类问题（已知运动求力，还是已知力求运动）；
② 选坐标系（把矢量方程拆成几个标量方程）；
③ 画受力图（到底有哪些力、朝向哪儿）；
④ 解方程（求导，或积分，或解代数方程）。

下面四节就按这四个决定依次展开，最后用两个典型约束（单摆、圆柱面）和两个典型力（阻力、有心力）把整套流程走一遍。

1.1 动力学只有两类问题

为什么先讲这个：因为问法决定解法。同样一道题，问"张力多大"和问"多久落地"，解法方向完全相反。 很多人做不出来，不是不会算，是一开始就没分清题目在问哪一类。

第一类（正问题）：已知运动，求力。题目会告诉你位置随时间怎么变 r(t)，或者速度怎么变，让你求某个力（张力、支持力、摩擦力）。

做法：r(t) →（求导）→ v →（求导）→ a →（代进方程）→ ΣF = ma

注意：求导得到的是合加速度，它对应合力。要得到某一个力，还得把受力图上其他力都写出来，从合力里"减掉"。

第二类（反问题）：已知力，求运动。题目给出受力情况（重力、弹簧力、阻力）和初始条件，让你求运动规律。

做法：列微分方程 m dv/dt = ΣF →（积分）→ v(t) →（再积分）→ r(t)

难点：积分能不能做出来，取决于力是"谁的函数"。这就是 1.4 节要讲的内容——先看力里带什么变量，再选积分路线。

考场上怎么快速判断？看题目给的条件：
· 给了"位置 / 速度 / 加速度的表达式" → 第一类，放心大胆求导；
· 给了"受力情况 + 初速度 / 初位置" → 第二类，准备好积分；
· 给了"一个角度或一个位置，问那一瞬间的力" → 第一类，但只需要算那一瞬间的加速度（常用 an = v²/ρ）。
例 1-1 · 看懂（第一类问题的最小样本）

小物块质量 m = 2 kg，在半径 R = 0.5 m 的水平圆轨道上以恒定速率 v = 3 m/s 运动。求轨道对小物块的作用力大小。

第 1 步 · 判断类型。给了"速率恒定 + 圆轨道"，运动完全已知 → 第一类问题，求力。

第 2 步 · 求加速度。速率恒定 ⇒ 切向加速度 aτ = dv/dt = 0；只有法向加速度：

an = v²/R = 3²/0.5 = 18 m/s²，方向指向圆心

第 3 步 · 写方程。水平面内只有轨道给的力 F（法向），竖直方向重力与支持力平衡，不影响水平运动：

F = m an = 2 × 18 = 36 N

答：轨道对小物块的作用力 36 N，方向指向圆心。

经验：匀速圆周运动是"加速度不为零但切向加速度为零"的最典型情形。 只要看到"匀速率 + 曲线"，就直接写 an = v²/ρ、aτ = 0，不必再求导。

1.2 牛顿三定律：什么时候能用，什么时候不能用

为什么必须讲这个：因为 ma = ΣF 有一个前提——必须在惯性参考系里用。 你在加速的电梯里、在转弯的公交车里做实验，"不受力也有加速度"，定律就失效了。 考试里如果出现"车厢以加速度 a 运动，求车厢内小球的偏角"，考的就是这件事。

第一定律（惯性定律）：不受力（或合力为零）时，物体保持静止或匀速直线运动。

它的真正作用不是"描述运动"，而是定义了惯性参考系：第一定律成立的参考系，就叫惯性系。地球（近似）是惯性系；加速的车厢、旋转的圆盘都不是。

第二定律：F = ma（更原始的形式是 F = d(mv)/dt）。

第二定律的四个性质，考试爱考概念题：
· 瞬时性：力一撤，加速度立刻为零（不是"速度慢慢消失"）；
· 矢量性：加速度永远与合力同方向，与速度方向无关（可以相反，那就是减速）；
· 叠加性：各力产生的加速度可以矢量相加，所以可以先分解再合成；
· 适用范围：惯性系中的宏观低速物体（高速要用相对论，微观要用量子力学——这两句话考试常作为"下列说法错误的是"的选项）。

第三定律：FAB = −FBA，作用力与反作用力等值、反向、共线、同时存在、作用于两个不同物体。

最常见的错误：把"作用力与反作用力"和"二力平衡"搞混。二力平衡作用于同一个物体、可以抵消； 作用力与反作用力作用于两个物体、永远不能抵消。这一点在第 2 部分会变成"内力成对消掉"的关键依据。

例 1-2 · 模仿（非惯性系里怎么算）

车厢以恒定加速度 a0 水平向右加速。车厢内用细线悬挂一个小球（质量 m），球相对车厢静止。求细线与竖直方向的夹角 θ 和线中张力 F。

第 1 步 · 选参考系。若在地面（惯性系）看：小球与车厢一起向右加速，加速度就是 a0，这最省事，不要去用车厢参考系（那是非惯性系，需要补惯性力）。

第 2 步 · 受力图。小球只受两个力：重力 mg（向下）、张力 F（沿线指向悬点，与竖直方向成 θ 角）。

第 3 步 · 分解并列方程。取水平向右为 x、竖直向上为 y：

水平：F sinθ = m a0    竖直：F cosθ − mg = 0

第 4 步 · 解。两式相除消去 F：

tanθ = a0/g  ⟹  θ = arctan(a0/g)
F = mg/cosθ = m√(g² + a0²)

答：θ = arctan(a0/g)，F = m√(g² + a0²)。

经验：凡是"加速的车厢 / 电梯 / 车厢里的单摆"，一律站到地面（惯性系）去算， 把加速度写在运动方向上，就不会漏掉惯性力的问题。只有当题目明确要求"在车厢参考系中分析"时，才引入惯性力 m a0（方向与加速度相反），结果完全一样。

1.3 把矢量方程拆开：三种坐标系

为什么必须拆：因为 F = ma 是一个矢量方程，等价于三个标量方程。 直接拿矢量做代数运算是做不出来的——必须选一组坐标轴，把每个力、每个加速度都投影上去，才能解方程。 选坐标系的目标只有一个：让某些分量变成零，让方程变简单。

1.3.1 直角坐标：轨迹未知时的默认选择

把 a 写成 ax = ẍ、ay = ÿ（点表示对时间求导），方程拆成：

mẍ = ΣFx    mÿ = ΣFy    （空间问题再加 mz̈ = ΣFz）

什么时候用：力的方向本身沿坐标轴（比如水平面上的推力、竖直方向的重力），或者轨迹是抛物线这类"x、y 独立"的曲线。 抛体运动必须用直角坐标，因为重力只在 y 方向、水平方向完全自由。

1.3.2 自然坐标：轨迹已知时的最佳选择

当轨迹已经确定（圆弧、已知曲线），沿切向 τ 和法向 n 分解最省事。此时加速度有两个分量：

aτ = dv/dt    an = v²/ρ    （ρ 是轨迹在该点的曲率半径）
m dv/dt = ΣFτ    m v²/ρ = ΣFn

什么时候用：一切"沿轨道运动"的问题——单摆、过山车、圆周运动、圆柱面上滑动。 它的威力在于：法向方程里永远只有"合力在法向的分量"，而法向力往往就是待求的支持力或张力。

1.3.3 极坐标：有心力问题的唯一选择

当所有力的作用线都通过某一点（引力、斥力、弹簧力），取那个点为极点，用径向 r 和横向 φ 分解：

m(r̈ − rφ̇²) = ΣFr    m(rφ̈ + 2ṙφ̇) = ΣFφ

为什么横向方程右边常为零：有心力的方向永远沿径向，横向分量为零，于是 rφ̈ + 2ṙφ̇ = 0， 即 d(r²φ̇)/dt = 0 ⟹ r²φ̇ = 常数。这就是"面积速度守恒"（开普勒第二定律）的来源， 它的现代名字叫动量矩守恒——第 3 部分会再遇到它。

选坐标系的决策树（考场上三秒钟判断）：
① 轨迹是直线或抛物线，力沿固定方向 → 直角坐标；
② 轨迹是圆 / 已知曲线，要求张力、支持力、脱离条件 → 自然坐标；
③ 力总指向（或背离）同一点 → 极坐标。

不确定的时候用直角坐标：它最笨但最不会错，只是计算量大。

1.4 反问题的核心：按"力的自变量"选积分路线

为什么这是难点：因为 m dv/dt = F 是个微分方程，能不能解出来，完全取决于 F 里带的是哪个变量。 同一道题，如果 F = F(t) 可以两次直接积分；如果 F = F(v) 就得先"分离变量"再积； 如果 F = F(x) 则要先把 dv/dt 换成 v dv/dx。 选错路线，方程积不出来，题就卡死。

关键恒等式（这一节的灵魂）：

a = dv/dt = (dv/dx)(dx/dt) = v dv/dx

它把"对时间求导"换成了"对位置求导"，于是当 F 只与位置有关时，可以先求出 v 与 x 的关系，绕开时间。

1.4.1 情形一：F = F(t)——直接积分两次

m dv/dt = F(t) ⟹ v = v0 + (1/m)∫0tF(t)dt ⟹ x = x0 + ∫0tv(t)dt

这是最简单的情形，只要会积分就行。

1.4.2 情形二：F = F(x)——换元消去时间

m v dv/dx = F(x) ⟹ (1/2)m v² − (1/2)m v0² = ∫x0xF(x)dx

左边是"动能"，右边是"功"——这就是动能定理。虽然你的课件没有单独讲动能定理，但它在动力学里是自动出现的：只要力只与位置有关，方程积分一次就得到它。

接下来再由 v(x) 求 x(t)：把 v = dx/dt 代入，得 dt = dx/v(x)，再积一次（这一步往往积不出来，考试通常只要求到 v(x)）。

1.4.3 情形三：F = F(v)——分离变量

m dv/dt = F(v) ⟹ dv/F(v) = dt/m ⟹ ∫v0vdv/F(v) = t/m

积出左边之后得到 t 与 v 的关系，再"反解"出 v(t)。空气阻力、粘性阻尼都属于这一类，下面的例 1-4 就是它的标准做法。

最容易犯的错：力是 F(v) 却直接对时间积分。 比如 m dv/dt = −cv，如果有人写 "∫m dv = ∫−cv dt" 再当成 v 是常数积出来，就得到 mv = −cvt， 这是错的——因为积分时 v 是 t 的函数，不能提到积分号外面。正确做法是先把 v 和 t 分到等式两边：dv/v = −(c/m)dt。

1.5 典型约束一：单摆（切向管运动，法向管张力）

为什么用它当第一个样板：因为它把"自然坐标的两个方程各管一件事"演示得最清楚， 而且它的两个结果（振动方程、张力表达式）在考试里反复出现，几乎每年都考。

第 1 步 · 选坐标。摆球沿圆弧运动，轨迹已知 → 自然坐标（τ 沿切线、n 沿半径指向悬点）。

第 2 步 · 受力图。只有两个力：重力 mg（竖直向下）、张力 F（沿绳指向悬点）。

第 3 步 · 切向方程。张力垂直于切向，不贡献切向力；重力在切向的分量是 −mg sinθ（负号表示指向平衡位置）：

m dv/dt = −mg sinθ

而 v = lθ̇（摆长 l 不变），所以 dv/dt = lθ̈，代入得单摆方程：

θ̈ + (g/l) sinθ = 0

小角度时 sinθ ≈ θ，方程变成 θ̈ + (g/l)θ = 0，是简谐振动，周期

T = 2π√(l/g)

第 4 步 · 法向方程。法向（指向悬点）上的力有张力 F（向内）和重力的分量 mg cosθ（向外）：

F − mg cosθ = m v²/l  ⟹  F = m v²/l + mg cosθ
这个式子的物理意义，值得读三遍： 张力 = "托住重力的法向分量"（mg cosθ） + "提供向心加速度"（m v²/l）。
· 摆球静止时（v = 0）：F = mg cosθ，就是"斜面上的法向支持力"；
· 摆球摆到最低点时（θ = 0，速度最大）：F = m v²/l + mg，大于重力——这就是"绳子在最低点最容易断"的原因。
例 1-3 · 模仿（单摆：从偏角到张力）

长 l = 1 m 的细绳悬挂质量 m = 0.5 kg 的小球。把球拉至细绳与竖直方向成 θ0 = 60° 后无初速释放。求球摆到最低点时绳中的张力（g = 9.8 m/s²）。

第 1 步 · 先用能量关系求最低点速度。这是本题的关键：张力公式里含 v²，而 v 未知，必须先从"角度"换算成"速度"。

释放点与最低点的高度差：

h = l(1 − cosθ0) = 1 × (1 − 0.5) = 0.5 m

只有重力做功，机械能守恒（等价于 1.4.2 节那次积分）：

v² = 2gh = 2 × 9.8 × 0.5 = 9.8 (m/s)²

第 2 步 · 代进张力公式。最低点 θ = 0，cosθ = 1：

F = m v²/l + mg = 0.5 × 9.8/1 + 0.5 × 9.8 = 4.9 + 4.9 = 9.8 N

答：最低点张力 9.8 N，正好是重力 mg = 4.9 N 的 2 倍。

经验："从偏角 θ0 无初速释放"这一类题，通用结论是 F最低 = mg(3 − 2cosθ0)。代入 θ0 = 60°：mg(3 − 1) = 2mg ✓。 这个结论值得直接记住，考试时能省一大半时间。

1.6 典型约束二：沿圆柱面下滑——什么时候会"脱离"

为什么这是必考题型：因为它训练一个非常关键的思维习惯——约束力不能为负。 绳子的张力不能小于零（绳子不能推），支持力也不能小于零（地面不能拉）。所以当你解出 N = 0 的那一刻， 就是物体离开约束的那一刻。此后它不再沿面运动，而是做抛体运动。 不做这一步检查，是这类题最常见的失分点。

第 1 步 · 选坐标。轨迹是已知的圆弧 → 自然坐标（切向 + 法向）。

第 2 步 · 受力图。重力 mg、支持力 N（沿半径向外，因为面在被压的一侧）。

第 3 步 · 法向方程（指向圆心为正）。法向力是重力的径向分量（向内，正）与 N（向外，负）：

mg cosθ − N = m v²/R  ⟹  N = mg cosθ − m v²/R

第 4 步 · 求 v²（用能量关系）。从顶点（θ = 0）无初速下滑，下降高度 R(1 − cosθ)：

v² = 2gR(1 − cosθ)

第 5 步 · 代回，找 N = 0 的位置。

N = mg cosθ − m·2g(1 − cosθ) = mg(3cosθ − 2)
N = 0 ⟹ 3cosθ − 2 = 0 ⟹ cosθ = 2/3，θ = 48.2°
三个必须说清的点（答题时缺一句就扣分）：
① 脱离前支持力 N > 0，物块沿面运动；
② 脱离瞬间 N = 0，此后若还要沿面运动，需要 N < 0（面"拉住"物块），这是不可能的；
③ 所以脱离后做斜抛运动，不再是圆周运动——速度方向沿当时的切线。

这个 θ 与质量、半径都无关，只由几何决定。这是"结论可复用"的典型：任何光滑圆柱/球面上无初速下滑，都在 cosθ = 2/3 处脱离。

1.7 典型力一：与速度有关的阻力（分离变量的标准练法）

为什么单独讲：因为这是"F = F(v) 型"反问题的唯一代表性题目， 而且它的结果 v = c·th(gt/c) 里出现双曲函数，是很多人第一次见。 更重要的是它给出"终端速度"这个概念——速度不会无限增大，而是趋于一个极限值。

问题：质量 m 的物体在重力作用下由静止下落，空气阻力 R = −μv（与速度成正比、方向相反）。求 v(t)。

第 1 步 · 列方程（取向下为正）。

m dv/dt = mg − μv

第 2 步 · 判断类型。右边带 v → F = F(v) 型，必须分离变量。

第 3 步 · 分离变量并积分。把含 v 的移到左边、含 t 的移到右边：

dv/(mg − μv) = dt/m

两边从 0 积到 t（初速为 0）：

−(1/μ) ln[(mg − μv)/(mg)] = t/m

第 4 步 · 反解 v。先去掉对数：

(mg − μv)/mg = e−μt/m
v = (mg/μ)(1 − e−μt/m)

第 5 步 · 讨论（这一步是得分点）。

· 当 t → ∞：v → mg/μ，这个极限叫终端速度（此时阻力正好等于重力，加速度为零）；

· 当 t 很小时：e−μt/m ≈ 1 − μt/m，于是 v ≈ gt，退化为自由落体——说明有阻力的结果在短时间内与无阻力一致，这是合理性的验证。

如果阻力是 R = −μv²（高速时更真实）会怎样？做法完全一样，只是积分变成 ∫dv/(g − kv²)，结果是 v = √(g/k)·th(t√(gk))，照样出现终端速度 √(g/k)。
结论：只要阻力随速度增大，就一定有终端速度；这与阻力的具体形式无关。这条定性结论常作为简答题出现。
例 1-4 · 应考（抛体 + 线性阻力，两问）

质量 m = 10 kg 的物体以初速 v0 = 1000 m/s 竖直上抛，阻力 R = −cv，c = 0.02 N·s/m。 (1) 求上升过程中速度随时间的变化；(2) 求能上升的最大高度。

第 1 步 · 列方程（取向上为正）。此时重力与阻力同向（都向下）：

m dv/dt = −mg − cv

第 2 步 · 分离变量积分（F(v) 型）。

dv/(mg + cv) = −dt/m
(1/c) ln[1 + cv/(mg)] = −t/m

反解出速度：

v = (mg/c)(e−ct/m − 1) + v0 e−ct/m

代入 mg/c = 10 × 9.8/0.02 = 4900 m/s，c/m = 0.002 s⁻¹：

v = 4900(e−0.002t − 1) + 1000 e−0.002t = 5900 e−0.002t − 4900 (m/s)

第 3 步 · 求最大高度。最高点 v = 0，先求到顶所需时间：

5900 e−0.002t = 4900 ⟹ e−0.002t = 0.8305 ⟹ t = 92.8 s

再用能量/位置关系。令 v dv/dx = −g − (c/m)v，分离变量：

v dv/(g + hv) = −dx  （h = c/m = 0.002 m⁻¹）
xmax = (1/h)[v0 − (g/h) ln(1 + hv0/g)]

代入 hv0/g = 0.002 × 1000/9.8 = 0.2041，ln(1.2041) = 0.1858，g/h = 4900：

xmax = (1/0.002)[1000 − 4900 × 0.1858] = 500 × (1000 − 910.4) = 44.8 km

答：(1) v = 5900 e−0.002t − 4900 (m/s)；(2) 最大高度约 4.5×104 m（44.8 km）。

对照检验：若没有阻力，xmax = v0²/(2g) = 106/19.6 = 51 km。 有阻力后降到 44.8 km，少了约 12%——量级完全合理。这个"与无阻力结果对比"的动作， 是这类题的标准收尾，写上去能加分。

1.8 典型力二：有心力与椭圆轨道

为什么讲它：因为它是极坐标方程的唯一实战场景，而且结论（椭圆轨道）是"开普勒第一定律"的动力学版本。 这道题在课件里是重点例题，考试常以"证明轨迹是椭圆"的形式出现。

问题：质点质量 m，受指向原点 O 的引力 F = −kr（k 为比例常数）， 初位置 x = b、y = 0，初速度沿 y 方向、大小 v0。求轨迹。

第 1 步 · 选坐标系。力指向原点 → 直角坐标反而最方便，因为 F = −kr 的两个分量特别好写：

Fx = −kx    Fy = −ky

这里有个重要的观察：用直角坐标时，两个方向的方程完全独立（各自只含自己的坐标），于是两个方向的运动可以分别求解，再合成轨迹。

第 2 步 · 列两个独立方程。

mẍ = −kx    mÿ = −ky

第 3 步 · 认出这是简谐振动方程。令 ω = √(k/m)，两式都是 ẍ + ω²x = 0 的形式，通解为：

x = A cos ωt + B sin ωt    y = C cos ωt + D sin ωt

第 4 步 · 用初始条件定常数。t = 0 时 x = b、y = 0 ⟹ A = b、C = 0。

再由速度：ẋ(0) = Bω = 0 ⟹ B = 0；ẏ(0) = Dω = v0 ⟹ D = v0/ω。

x = b cos(ωt)    y = (v0/ω) sin(ωt)，ω = √(k/m)

第 5 步 · 消去 t 得轨迹。由 cos² + sin² = 1：

(x/b)² + (yω/v0)² = 1  ——  椭圆

答：轨迹是椭圆，半轴分别为 b 与 v0√(m/k)，运动周期 T = 2π√(m/k)，与初速度无关。

经验：「有心力 F = −kr」这种线性回复力，在直角坐标下永远分解成两个独立的简谐振动， 两个方向周期相同，合成轨迹必为椭圆（两方向振幅相等时是圆）。这个模式在弹簧摆、三维谐振子里反复出现。

第 2 部分　动量定理与质量流：把方程对时间积一次

为什么要有这一部分？第 1 部分不是已经能算一切了吗？ 能算，但经常算不出来。原因有两个：

第一个原因：力根本不知道。锤子敲钉子、球拍击球、水流冲击叶片——这些力在极短时间内剧烈变化， 你没法写出 F(t) 的表达式。但你不需要知道它：只要知道"前后速度"，就能算出它的时间累积效果。

第二个原因：物体不是一个，而是一堆。一车煤、一股水流、一节链条——由无数质点组成，逐个列方程不可能。 这时把方程对整个系统求和，内力会自动成对消掉，只剩下外力。

这两件事用同一个动作完成：把 ma = ΣF 对时间积分一次。得到的式子叫动量定理。
一句话对比：
· 第 1 部分（牛顿方程）说的是"此刻力与加速度的关系"——是瞬时关系；
· 第 2 部分（动量定理）说的是"一段时间内力与速度变化的关系"——是过程关系。

瞬时关系关心"每一时刻"，过程关系只关心"首尾两个状态"。当中间过程太复杂时，就换用过程关系绕过去。

2.1 动量与冲量：两个新名字

为什么定义这两个量：因为牛顿第二定律的原始形式其实不是 ma = F，而是 F = d(mv)/dt。动量 mv 才是定律里真正的"主角"，加速度只是它在质量不变时的副产品。 这样一来，"力在一段时间里的累积"自然就有了名字：冲量。

动量：p = mv，矢量，单位 kg·m/s（也写作 N·s）。它描述"运动的量"——同样的速度，质量越大越难停下来。

冲量：I = ∫Fdt，矢量，单位 N·s。它描述"力在一段时间里累积的效果"。

为什么是"面积"：把时间分成无数小段 dt，每段的冲量是 Fdt（一个小矩形），加起来就是曲线下的总面积。这就是积分的几何意义。

2.2 质点动量定理

怎么来的：把 F = d(mv)/dt 两边乘 dt，再从 t1 积到 t2。这一步没有任何技巧，纯粹是"把导数移过去再积分"。
F dt = d(mv)  （微分形式）
∫t1t2Fdt = mv2 − mv1  （积分形式）

写成一句话：

I = p2 − p1 = Δp
三条最容易错的地方：
① 它是矢量式。必须写成分量式：Ix = mv2x − mv1x， Iy = mv2y − mv1y。千万不要把大小直接相减—— 速度方向变了（比如反弹），分量是要带正负号的。
② 重力这类常力不能漏。它们的冲量是 mgΔt。碰撞瞬间这个量通常远小于冲击力， 可以先算出来看看能不能忽略，但不能不检查。
③ 求"平均冲力"就用 F̄ = Δp/Δt（这里把 F 当成常量）。
例 2-1 · 看懂（冲量求平均冲力）

质量 m = 0.2 kg 的小球以 v1 = 20 m/s 垂直撞向墙面，反弹速度 v2 = 15 m/s。 球与墙接触时间 Δt = 0.02 s。求墙对球的平均冲力（不计重力）。

第 1 步 · 定正方向。取"离开墙"为正方向（即反弹方向）。于是 v1 = −20 m/s，v2 = +15 m/s。

第 2 步 · 算动量增量。

Δp = m(v2 − v1) = 0.2 × (15 − (−20)) = 0.2 × 35 = +7 N·s

第 3 步 · 求平均冲力。

F̄ = Δp/Δt = 7/0.02 = 350 N（方向离开墙）

答：平均冲力 350 N，方向垂直墙面指向外。

经验：这里 v1 必须写负号，因为动量是矢量。 初学者最常见的错误是写 0.2×(20−15) = 1 N·s，得到 50 N——少了 7 倍。 判断方法：球的速度方向反了 180°，动量变化必然大于"两个速率之和的一半"。

2.3 质点系动量定理：内力为什么会自动消掉

这是全章最重要的一步。因为现实中的物体几乎都不是"一个质点"：一车煤、一箱水、一台由几十个零件组成的机器。 如果要把它们逐个列方程，几十个方程几十个未知数，根本解不出来。 但把方程全部加起来，内力就成对消掉了——这就是"整体法"的数学依据。

推导（三行，但每一步都要看懂）：

对系统中第 i 个质点：miai = Fi外 + ΣjFij（其中 Fij 是第 j 个质点给它的内力）。

把所有 i 的方程加起来。在求和号里，Fij 与 Fji 总是同时出现，由牛顿第三定律它们等值反向，相加为零：

Σimiai = ΣF外

左边可以改写：Σmidvi/dt = d(Σmivi)/dt = dP/dt，其中 P = Σmivi 是系统总动量。于是：

ΣF外 = dP/dt   （质点系动量定理）

再对时间积一次，就是过程形式：

ΣI外 = P2 − P1
三个推论，考试直接可用：
① 动量守恒：若 ΣF外 = 0，则 P = 常矢量（分量也各自守恒：某个方向外力为零，该方向动量就守恒）；
② 近似守恒：碰撞、爆炸这类极短过程中，有限的外力（如重力）冲量很小，可近似认为动量守恒；
③ 内力不改变总动量：不管内部怎么折腾（炸药爆炸、人走动、弹簧弹开），系统的总动量只由外力决定。
例 2-2 · 模仿（反冲：动量守恒的最直白应用）

总质量 M = 200 kg 的小车静止在光滑水平面上，车上有一质量 m = 20 kg 的炮弹。 炮弹以相对地面 v = 100 m/s 的水平速度射出。求小车的反冲速度。

第 1 步 · 判断守恒。水平方向没有外力（光滑地面），水平方向动量守恒；竖直方向重力与支持力抵消，不影响水平问题。

第 2 步 · 写初态与终态。初态：整体静止，P1 = 0。终态：炮弹 mv，小车（含剩余部分）以 V 反冲：

0 = mv + (M − m)V

第 3 步 · 解。

V = −mv/(M − m) = −20 × 100/180 = −11.1 m/s

答：小车以 11.1 m/s 反向运动（负号表示与炮弹方向相反）。

易错：分母写成 M 而不是 (M − m)。因为炮弹飞走后车里少了这 20 kg。 这种"质量变化"的细节，是动量守恒题最常见的坑。

2.4 质心运动定理：为什么"人走船退"

为什么需要质心：因为质点系里每个质点的运动可能很乱（人走了、弹簧伸了）， 但我们往往只关心"整个系统整体往哪儿走"。这时把整个系统的质量"集中"到一个点上，那个点就是质心。 定理说：质心的运动，和把所有外力作用在这个点上、质量等于总质量时的运动完全一样。

质心的定义：

rC = Σmiri/Σmi    （xC = Σmixi/M，以此类推）

质心运动定理：由 P = MvC 两边对时间求导，代入质点系动量定理：

MaC = ΣF外
例 2-3 · 模仿（人走船退）

质量 M = 140 kg 的小船长 L = 4 m，静止在静水中。质量 m = 60 kg 的人从船头走到船尾。 忽略水的阻力，求船移动的距离。

第 1 步 · 判断。水平方向无外力 ⟹ 质心水平位置不变（质心运动定理的直接推论）。

第 2 步 · 写质心守恒式。设船向后退 s，则人对地移动 (L − s)，船对地移动 −s：

m(L − s) + M(−s) = 0

第 3 步 · 解。

s = mL/(m + M) = 60 × 4/200 = 1.2 m

答：船向后退 1.2 m，人对地前进了 2.8 m。

经验：这个 s = mL/(m+M) 的式子值得记住——它是"系统内相对位移如何分配"的通用公式。 注意它与时间无关：不管人走得快还是慢，船退的距离都一样。这一点常作为选择题的考点。

2.5 定常质量流：把"一股水"当成控制体

为什么这一步是"从力学到工程"的跨越：前面研究的都是"固定的几个质点"。 但水在管子里流、空气在压气机里流，物体的身份一直在换——此刻在控制体里的水，下一刻就走了。 这时不能用"质点系"，要用控制体（control volume）：划定一块固定空间，只关心进出它的动量。

推导思路（一句话）：单位时间内流出控制体的动量 − 流入的动量 = 控制体内动量的变化率。 对定常流动（控制体内各点状态不随时间变），控制体内动量不变，于是：

ΣF = qmv2 − qmv1 = qm(v2 − v1)

其中 qm = ρAv 是质量流量（kg/s），v1、v2 是进出口的平均速度。

用这个式子时的四个关键：
① qm 是 kg/s，不是 m³/s。qm = ρQ = ρAv。搞错这一步，答案会差 1000 倍。
② v2 − v1 是矢量差。必须写分量式；90° 弯管时两个分量都要算。
③ 外力包括压力。流体进出控制体时，外面的流体压着它，压力 pA 是外力的一部分，不能只算管壁力。
④ 反作用力。式子的左边是"外界对流体的力"。题目通常问"流体对管壁的力"，那是它的反作用力，方向相反、大小相等。
例 2-4 · 模仿（90° 弯管：管壁受多大力）

水在水平面内的 90° 弯管中流动，质量流量 qm = 10 kg/s，管径不变（A = 0.001 m²）， 进出口压力均为 p = 0.2 MPa。求水流对弯管的作用力。

第 1 步 · 求速度。管径不变 + 水不可压缩 ⟹ 进出口速率相同：

v = qm/(ρA) = 10/(1000 × 0.001) = 10 m/s

第 2 步 · 设坐标。入口沿 +x，出口沿 +y：

v1 = (10, 0)    v2 = (0, 10)  (m/s)

第 3 步 · 列两个分量方程。外力 = 压力（p1A1 推流体向 +x，p2A2 推流体向 −y） + 管壁对流体的力 R：

Rx + pA = qm(0 − 10)  ⟹  Rx = −100 − 200 = −300 N
Ry − pA = qm(10 − 0)  ⟹  Ry = 100 + 200 = +300 N

其中 pA = 0.2×10⁶ × 0.001 = 200 N。

第 4 步 · 求合力与反作用力。

|R| = √(300² + 300²) = 424 N（管壁对流体，指向 −x、+y）
流体对管壁：F = −R，大小 424 N，指向 +x、−y

答：水流对弯管的作用力约 424 N，方向与入口速度同向偏下（把弯管往外推）。

经验：这类题压力项往往比动量项更大（这里 200 N vs 100 N）。 很多人只算 qmΔv 就交卷，答案直接错一半。看到"压力"两个字，就必须把 pA 算进去。

2.6 射流冲击：为什么"移动的板受力更小"

为什么单独讲：因为这里藏着一个非常容易被忽略的概念——相对速度。 射流冲击固定板时，进入控制体的质量流量是 ρAv；但当板以 u 后退时， 射流相对板的速度只有 v − u，所以进入"板这个控制体"的质量流量变成 ρA(v−u)。 用错这个，整道题就错了。

固定平板（射流垂直于板）：射流沿板面分成两股，垂直于板的方向速度从 v 降到 0：

F = qm(v − 0) = ρAv·v = ρAv²

以 u 后退的平板：相对速度 (v−u)，质量流量 ρA(v−u)：

F = ρA(v−u)·(v−u) = ρA(v−u)²

功率：力乘以板速：

P = F·u = ρA(v−u)²u

对 u 求导并令其为零，可得 u = v/3 时功率最大，此时 Pmax = (4/27)ρAv³。这是水轮机设计的基本结论。

例 2-5 · 应考（射流冲击：三问递进）

直径 d = 50 mm 的水射流以 v = 20 m/s 冲击一块平板（ρ = 1000 kg/m³）。 (1) 板固定时，射流对板的力；(2) 板以 u = 5 m/s 同向后退时的力；(3) 板以 u = 20 m/s 同向运动时的力，并解释。

第 1 步 · 算截面积与质量流量。

A = πd²/4 = π × 0.05²/4 = 1.963 × 10⁻³ m²
qm = ρAv = 1000 × 1.963×10⁻³ × 20 = 39.3 kg/s

(1) 固定板：

F = ρAv² = 1000 × 1.963×10⁻³ × 400 = 785 N

(2) 板以 5 m/s 后退：相对速度 15 m/s：

F = ρA(v−u)² = 1000 × 1.963×10⁻³ × 225 = 442 N

(3) 板以 20 m/s 同向运动（与射流同速）：

F = ρA(20 − 20)² = 0

答：(1) 785 N；(2) 442 N；(3) 0 N。第 (3) 问的物理解释：板与射流同速时，射流"追不上"板， 相对速度为 0，没有质量流进入控制体，因此没有动量变化，也就没有力。

这道题的价值：它用三个数字把"力来自相对运动"这件事讲透了。 第 (3) 问的答案看起来"反直觉"，但它恰好暴露了"用绝对速度算流量"这个错误的荒谬—— 如果不用相对速度，第 (3) 问还会算出 785 N，显然不对。

2.7 变质量系统：火箭为什么能飞

为什么这是难点：因为牛顿第二定律 ma = F 的推导前提是质量不变。 火箭一边飞一边喷出气体，质量一直在变，不能直接套 ma = F。 正确做法是回到"动量定理"——因为动量定理对"包含喷出气体的整个系统"仍然成立，而那个系统的质量是不变的。

推导（四步）：

第 1 步 · 取系统。取"火箭 + 将在 dt 内喷出的气体"为系统，这个系统的总质量不变，为 m。

第 2 步 · 写 t 时刻的动量。整体以速度 v 运动：P1 = mv。

第 3 步 · 写 t+dt 时刻的动量。火箭剩 m−dm，速度 v+dv；喷出的 dm 相对火箭速度为 −u（向后）， 故它对地速度为 v − u：

P2 = (m−dm)(v+dv) + dm(v−u)

第 4 步 · 令 P1 = P2（忽略外力）。展开并略去二阶小量 dm·dv：

mv = mv + mdv − vdm + vdm − udm
mdv = udm  ——  火箭方程（微分形式）

积分。设初始质量 m0、初速 0，喷速 u 恒定。分离变量 dv = u dm/m，两边积分：

v = u ln(m0/m)  （齐奥尔科夫斯基公式）

注意 m 在这里是（当前质量），比 m0 小，所以 m0/m > 1，v > 0。这个符号约定一定要和课本核对。

三个必然的结论（简答题常考）：
① 速度与质量比成 对数关系：想让速度翻倍，质量比要平方。这就是为什么必须多级火箭。
② 要提高末速度，两条路：提高喷速 u（改进推进剂）或提高质量比 m0/m（减少结构质量）。
③ 有重力时，方程多一项：mdv/dt = udm/dt − mg，把重力冲量扣掉即可。
例 2-6 · 应考（链条落到秤盘上，动量流的经典题）

柔软链条线密度为 λ（kg/m），一端悬空、另一端自由下落，落到秤盘上堆起来。 当堆起高度为 y 时，求秤的读数。（忽略链条堆起过程的高度变化）

第 1 步 · 想清楚读数由两部分组成。这是本题的关键洞察： ① 已经堆在盘上的链条的重量；② 正在落下的链条撞上盘时，动量被"刹住"所需要的力。

第 2 步 · 第一部分（静重）。堆起高度 y，质量 λy：

F1 = λyg

第 3 步 · 第二部分（动量流）。链条从高度 y 落下，撞盘时速度 v = √(2gy)。 单位时间落到盘上的质量是 λv，这些质量的速度从 v 变为 0，动量变化率为：

F2 = (λv)·v = λv² = λ·2gy = 2λyg

第 4 步 · 相加。

F = λyg + 2λyg = 3λyg

答：秤的读数为 3λyg，是静止堆放的 3 倍。

为什么是 3 倍而不是 2 倍：已堆部分的重量是 1 倍；落下部分"刹停"贡献 2 倍 （其中 1 倍来自"每秒增加的质量带来的动量"，另 1 倍来自"这些质量本身的速度"——这正是 λv·v 中两个 v 的来源）。 这道题是"动量流"最好的思维训练：凡是"有质量持续加入/离开"的系统，都要单独算动量流这一项。

第 3 部分　动量矩定理：把方程再"转"一次

为什么还要再来一个定理？前两个不够用吗？ 不够，而且差得很明显。请看三个场景：

场景一：物体在转动。风车、齿轮、飞轮、方向盘——它们不是"整体往前跑"，而是"绕一根轴转"。 用 ma = ΣF 描述"转"，要先算出每个质点的加速度，几乎不可能。

场景二：想知道"转动的惯性"。同样大的力矩，为什么推一个薄圆盘比推一个同样重的细杆容易？ 质量相同、外力相同，转动效果却不同——说明"转动"有一个和"质量"平行的新概念，叫转动惯量。

场景三：轮子滚下斜坡到底多快。纯滚动的轮子既平动又转动，两个运动绑在一起， 只用 ma = ΣF 会漏掉一半信息（缺"转动"那个方程）。

解决这三件事用同一个动作：把 ma = ΣF 两边同时叉乘位置矢量 r，再对时间积分。 得到的式子叫动量矩定理（也叫角动量定理）。
三个定理是一条流水线，不是三个孤立的知识点：
· 牛顿方程 ma = ΣF —— 力 ↔ 加速度（瞬时）
· 对时间积一次 → 动量定理 —— 冲量 ↔ 动量（过程）
· 两边叉乘 r → 动量矩定理 —— 力矩 ↔ 动量矩（转动版的牛顿方程）

所以第 3 部分的公式长得和第 1、2 部分几乎一样，只是把"力"换成"力矩"、"动量"换成"动量矩"、"质量"换成"转动惯量"。 看懂了这条对应关系，本部分就已经学会一半。

3.1 动量矩（角动量）：转动版的"动量"

定义（对点）：

LO = r × mv

大小：LO = mvd，其中 d 是 O 点到速度作用线的垂直距离（力臂）。方向用右手螺旋判定（四指从 r 转向 v，拇指指向就是 L 的方向）。

定义（对轴）：把对点的动量矩投影到轴上：

Lz = (r × mv)z = m·vxy·dxy

即：对轴的动量矩，只用垂直于该轴的那个速度分量来算。这一点非常重要——沿轴方向的速度分量对绕该轴的转动没有任何贡献。

三个必须知道的特例（后面全靠它们）：
① 质点做圆周运动（半径 r、角速度 ω）：LO = mvr = mr²ω；
② 刚体绕定轴转动：Lz = Jzω，其中 Jz = Σmiri² 是转动惯量；
③ 平动的刚体：LO = MvCd，可以看成"质量全部集中在质心"。

3.2 动量矩定理：从牛顿方程叉乘出来

怎么来的（三行，但要看懂"为什么用叉乘"）：因为力矩的定义就是 M = r × F。 既然力的效果要用叉乘来度量，方程两边就都该叉乘 r。这不是技巧，而是定义的自然结果。

对质点：ma = F。两边左叉乘 r：

r × ma = r × F = MO

左边可以改写。注意 v × mv = 0（自己叉自己为零）：

d(r × mv)/dt = v × mv + r × ma = 0 + r × ma

所以：

dLO/dt = MO   （质点动量矩定理）

对所有质点求和。内力矩也成对抵消——因为两个质点间的内力等值、反向、且作用在同一条直线上（这一点是关键： 如果作用线不同，力臂不同，力矩就不一定抵消了）：

dLO/dt = ΣMO外   （质点系动量矩定理）

投影到定轴 z 上：因为 Lz = Jzω，而 dω/dt = ε（角加速度）：

Jz·ε = Mz   （定轴转动微分方程）

这就是"转动版的牛顿第二定律"：转动惯量 ↔ 质量，角加速度 ↔ 线加速度，力矩 ↔ 力。一一对应。

动量矩守恒（考试极高频）：
若 ΣMO外 = 0，则 LO = 常矢量。
典型例子：花样滑冰收臂加速、直升机尾桨、行星绕日、绳穿过桌孔拉小球。
注意：动量矩守恒比动量守恒"更容易满足"——因为凡是作用线穿过取矩点的力，力矩都是零。 所以"绳子拉小球"这类题，绳的拉力虽然很大，但对孔的力矩为零，动量矩照样守恒。
例 3-1 · 看懂（定轴转动：用 Jzε = Mz 一步求解）

质量 m = 100 kg、半径 R = 0.5 m 的均质圆盘飞轮绕中心轴转动，受恒定力矩 M = 50 N·m。 求角加速度 ε，以及从静止开始 5 s 后的转速。

第 1 步 · 求转动惯量。均质圆盘绕中心轴：

Jz = mR²/2 = 100 × 0.25/2 = 12.5 kg·m²

第 2 步 · 用微分方程求角加速度。

ε = Mz/Jz = 50/12.5 = 4 rad/s²

第 3 步 · 匀角加速，直接积分。

ω = εt = 4 × 5 = 20 rad/s
n = ω/(2π) = 20/6.283 = 3.18 r/s（约 191 r/min）

答：ε = 4 rad/s²；5 s 后 ω = 20 rad/s，约 191 r/min。

经验：定轴转动题的唯一套路就是"J → ε → 积分求 ω、θ"。 用到的积分式和直线运动完全对称：ω = ω0 + εt，θ = ω0t + εt²/2。 把 m→J、v→ω、a→ε、F→M、x→θ 直接替换，公式不用再记一遍。

3.3 转动惯量：为什么"同样的质量，转起来不一样"

定义：

Jz = Σmiri²  （连续体：Jz = ∫r²dm）

它为什么"不等于质量"：因为 r 是到轴的距离。同样的质量，堆得离轴越远，J 越大，越难加速转动。 这就是为什么长杆握中间比握一端好转、轮圈（质量在外缘）比圆盘难刹住。

平行轴定理：若已知绕质心轴的 JC，则绕与之平行的任意轴的转动惯量为：

Jz = JC + md²  （d 是两轴的距离）

只能用于"两轴平行、且其中一根过质心"。若两根轴都不在质心上，要先各用一次平行轴定理把 JC 求出来再算，不能直接相减。

必须背熟的常用值：

刚体转轴J
细杆（长 l）过质心、垂直于杆ml²/12
细杆（长 l）过一端、垂直于杆ml²/3
圆盘/圆柱（半径 R）中心轴（垂直于盘面）mR²/2
圆环/薄圆筒（半径 R）中心轴mR²
球体（半径 R）直径2mR²/5

验证一下平行轴定理：细杆 JC = ml²/12，轴移到一端时 d = l/2：

J端 = ml²/12 + m(l/2)² = ml²/12 + ml²/4 = ml²/3  ✓

能自己验证出来的公式，考试时忘了也能现推。这就是"背少量、推多数"的正确复习方式。

例 3-2 · 模仿（动量矩守恒：绳穿过桌孔拉小球）

光滑水平桌面上，质量 m = 0.5 kg 的小球用细绳系住，绳穿过桌面中心的孔。 小球最初在半径 r1 = 0.5 m 处，以 v1 = 0.4 m/s 做圆周运动。 缓慢拉绳，使半径减小到 r2 = 0.1 m。求此时的速率与绳的张力。

第 1 步 · 判断守恒。绳的拉力始终沿半径方向，穿过孔（取矩点），所以对孔的力矩为零：

ΣMO = 0  ⟹  m v1r1 = m v2r2

第 2 步 · 求新速率。

v2 = v1r1/r2 = 0.4 × 0.5/0.1 = 2.0 m/s

第 3 步 · 求张力。圆周运动，张力就是向心力：

T = mv2²/r2 = 0.5 × 4/0.1 = 20 N

答：v2 = 2.0 m/s，T = 20 N（是最初 T1 = 0.5×0.16/0.5 = 0.16 N 的 125 倍）。

经验：半径缩小 5 倍，速率涨 5 倍，而张力涨 25 倍（因为 T = mv²/r 里 v 是平方、r 在分母）。 "拉得越近越快、而且快得离谱"——这是动量矩守恒最反直觉也最常考的地方。 另外：答案与"缓慢拉"还是"快速拉"无关，因为守恒式与过程无关。

3.4 刚体平面运动：两个方程必须同时用

什么叫平面运动：物体上各点都在平行于某一固定平面的平面内运动（比如车轮沿路滚动、连杆机构）。 关键结论：平面运动 = 质心的平动 + 绕质心的转动，而且这两部分可以分开列方程。

为什么必须绕"质心"取矩：因为只有对质心取矩，"转动"和"平动"才彻底解耦。 若对别的点取矩，方程里会多出惯性力矩项，形式变得很复杂（这就是课本上那个 JAε = ΣMA 的推广式只在特殊情形才好用）。

两组方程（同时成立）：

m aCx = ΣFx    m aCy = ΣFy   （质心平动）
JC·ε = ΣMC   （绕质心转动）

纯滚动（不打滑）的补充条件：

aC = εR    vC = ωR    s = θR
四个最容易错的地方：
① 纯滚动时摩擦力是静摩擦，大小由方程解出，绝不能写 f = μN（μN 只是上限）。
② 解出的 f 若为负，说明方向设反了，改回来即可；若 |f| > μN，说明其实打滑了，假设不成立。
③ 不能对瞬心直接套 JCε = ΣMC，必须对质心取矩。对瞬心要用 J瞬心 = JC + mR²。
④ 纯滚动时摩擦力不做功（接触点无相对滑动），所以机械能守恒可以用——这是很多题的捷径。
例 3-3 · 模仿（定滑轮两侧挂重物：J 不能忽略）

定滑轮质量 M = 2 kg、半径 R = 0.2 m（视为均质圆盘），两侧分别挂 m1 = 3 kg 与 m2 = 1 kg 的重物。 绳与轮间不打滑、绳质量不计。求两物的加速度与绳的张力。

第 1 步 · 分析。三部分：m1 向下加速、m2 向上加速、滑轮转动。 因不打滑，三者的加速度由 a = εR 联系在一起，且绳两侧张力不再相等（因为滑轮有转动惯量，需要力矩差来加速）。

第 2 步 · 列三个方程。设 a 为 m1 下降的加速度，T1、T2 为两侧张力：

m1g − T1 = m1a    T2 − m2g = m2a
(T1 − T2)R = JCε  其中 JC = MR²/2，ε = a/R

第 3 步 · 用 ε = a/R 化简第三个方程。

(T1 − T2)R = (MR²/2)(a/R)  ⟹  T1 − T2 = Ma/2

第 4 步 · 三式联立。把前两式写成 T1 = m1(g−a)、T2 = m2(g+a)，代入：

m1g − m1a − m2g − m2a = Ma/2
a = (m1−m2)g/(m1+m2+M/2) = (3−1)×9.8/(3+1+1) = 3.92 m/s²

第 5 步 · 回代求张力。

T1 = 3×(9.8−3.92) = 17.6 N   T2 = 1×(9.8+3.92) = 13.7 N

答：a = 3.92 m/s²，T1 = 17.6 N，T2 = 13.7 N（两侧张力确实不相等，差 3.9 N）。

这道题的"必考性"：它一次考了三件事——张力不等、ε = a/R 的约束、J 要算进去。 若把滑轮当"理想滑轮"（J=0），会得到 a = (3−1)×9.8/4 = 4.9 m/s²、两侧张力都等于 14.7 N—— 差别 25%。所以凡题目给了滑轮质量或半径，就必须把转动惯量算进去。

例 3-4 · 应考（圆盘沿斜面纯滚动：为什么 a = (2/3)g sinθ）

均质圆盘（质量 m、半径 R）从倾角 θ 的斜面上由静止开始纯滚动下滑。 求质心加速度 aC、所需的摩擦力 f，以及不打滑的最小摩擦因数。

第 1 步 · 画受力图，定正方向。沿斜面向下为正。力有三个：重力 mg、支持力 N、静摩擦 f（设沿斜面向上）。

第 2 步 · 写平动方程（沿斜面）。

mg sinθ − f = m aC

第 3 步 · 写转动方程（对质心取矩）。重力、支持力的作用线都过质心，力矩为零；只有 f 产生力矩：

fR = JCε  其中 JC = mR²/2

第 4 步 · 加纯滚动条件。

aC = εR  ⟹  fR = (mR²/2)(aC/R)  ⟹  f = m aC/2

第 5 步 · 联立求 aC。把 f 代入第 2 步：

mg sinθ − m aC/2 = m aC  ⟹  aC = (2/3)g sinθ

第 6 步 · 求 f 与最小摩擦因数。

f = m aC/2 = (1/3)mg sinθ
N = mg cosθ  ⟹  μmin = f/N = (1/3)tanθ

答：aC = (2/3)g sinθ，f = (1/3)mg sinθ（沿斜面向上）， μmin = (1/3)tanθ。

三个必记对照（考试常拿来对比）：
· 光滑下滑（无转动）：a = g sinθ
· 纯滚动圆盘：a = (2/3)g sinθ —— 慢了 1/3
· 纯滚动圆环（J = mR²）：a = (1/2)g sinθ —— 更慢

规律：J 越大，滚得越慢。因为同样的重力势能要分一部分给转动。 这也是"滚下来的比赛"里，实心球总比空心球先到终点的原因。

C.2 解题的五步固定动作（三部分通用）

① 判类型——问的是"这一刻"还是"一段过程"？是平动、转动，还是两者都有？
② 取系统——单个质点？整个质点系？还是一块控制体？这一步决定内力是否出现。
③ 选坐标/取矩点——直角、自然、极坐标选一个；取矩点优先选力最多穿过的那一点（力矩为零）。
④ 列方程——写清正方向，标好每个量的符号，未知量个数要等于方程个数。
⑤ 回代与检验——量纲对不对？极限情况（θ→0、μ→0、J→0）合不合理？
