1 流体静压强及其特性

1.1 流体静力学的研究对象

流体静力学研究在外力作用下处于力学平衡状态的流体的力学规律及其在工程上的应用。

静止（平衡）的含义

绝对静止：流体相对于惯性坐标系静止。相对静止：流体相对于非惯性参考坐标系静止（容器作等加速直线运动或等角速旋转，流体随容器一起运动）。

两种情形下“流体之间无相对运动”，因而无切向应力，流体静力学只考虑法向应力，即压强 p。静止流体的速度梯度 du/dy = 0，内摩擦力为零——注意此时流体有黏性，只是黏性表现不出来（黏性作用为零而非黏度为零）。

2.1.1 流体静压强的定义

压强：在流体内部或流体与壁面间存在的单位面积上的法向作用力。流体静压强：流体处于静止状态时，在流体内部或流体与固体壁面间存在的单位面积上负的法向表面力。

定义式

p = limΔA→0 ΔP / ΔA，  平均静压强 pm = ΔP / ΔA

单位：帕斯卡（Pa），1 Pa = 1 N/m2。1 工程大气压 = 9.81×104 Pa ≈ 105 Pa。流体静压力与流体静压强都是压力的一种量度，前者是力（N），后者是应力（Pa）。

2.1.2 流体静压强的两个特性

必记结论（高频考点）

特性一静压强的方向总是沿作用面的内法向，即垂直指向作用面。

特性二某一点静压强的大小与作用面的方位无关，即同一点处沿各个方向的流体静压强均相等，p = p(x, y, z) 是空间位置的标量函数（各向同性）。

特性一的理由

  • 静止流体无切向应力，只可能存在法向应力；故压强必垂直于作用面。
  • “指向作用面”等价于绝对压强 p > 0（非负）。压强的物理来源是分子热运动撞击壁面，故压强不能为负。极限情况是真空（无流体）时 p = 0。工程上所谓“负压”指相对压强为负，绝不是绝对压强为负。
  • 该结论对惯性系、非惯性系均成立，只要流体相对该坐标系不动。

特性二的力学证明（微元四面体法）

在 P 点周围取微元四面体 ABCO，三个直角棱长 dx、dy、dz，斜面 ABC 的外法线方向 n 任意。设单位质量力的分量 (fx, fy, fz)，各面压强 px、py、pz、pn。对 x 方向列平衡：表面力与体积力之和为零，两边同除 ΔAx = dydz/2，并令 dx, dy, dz → 0：

px − pn + (1/3)ρfxdx = 0  ⟹  略去高阶小量后 px = pn

同理 py = pn，pz = pn ⟹  px = py = pz = pn

由于 dx、dy、dz 的取法任意，故 n 方向任意，特性二得证。体积力项是比表面力项高一阶的小量，略去高阶小量是证明的关键一步（也是常考的推导细节）。

常见考法

① 判断“静止流体中某点各方向压强不等”“压强方向沿外法线”“绝对压强可为负”等说法的正误；② 写出两个特性并说明理由；③ 简答“为什么静止流体中黏性不产生切应力”。

2 流体平衡微分方程

2.1 欧拉平衡微分方程（1755 年）

在静止流体中任取微元正六面体（边长 dx、dy、dz，中心点静压强 p），作受力分析：表面力只有法向压力，质量力为重力、惯性力，所受合力为零。

推导要点

  1. 表面力：用泰勒展开求六个面中心点的压强。沿 x 轴，左、右两面中心点压强分别略去二阶以上无穷小量后为 p − (∂p/∂x)(dx/2) 与 p + (∂p/∂x)(dx/2)，故左右两面压力为 P左 = [p − (1/2)(∂p/∂x)dx]dydz，P右 = [p + (1/2)(∂p/∂x)dx]dydz。
  2. 质量力：设单位质量力 f = (X, Y, Z)，则 x 向质量力 Fx = ρXdxdydz。
  3. 力平衡：P左 − P右 + Fx = 0，两边除以 ρdxdydz。
欧拉平衡微分方程（矢量式）

f − (1/ρ)∇p = 0

X − (1/ρ)(∂p/∂x) = 0，  Y − (1/ρ)(∂p/∂y) = 0，  Z − (1/ρ)(∂p/∂z) = 0

其中 ∇ = i(∂/∂x) + j(∂/∂y) + k(∂/∂z) 为哈密顿算子。

物理意义与适用范围

物理意义：在静止流体中，单位体积质量力在某一方向的分力，与压强沿该方向的递增率相平衡；质量力作用的方向就是压强递增率的方向。

适用范围：静止或相对静止状态下的可压缩与不可压缩流体。它是流体静力学最基本的方程组，流体静力学的其他计算公式都是从此方程组推导出来的。

2.2 平衡方程的全微分式

将三个分量式分别乘以 dx、dy、dz 后相加（左端恰好是全微分 dp）：

全微分式（必背）

dp = ρ(Xdx + Ydy + Zdz)

由于流体不可压缩时 ρ = 常数，等号右端括号内必须是某个坐标函数的全微分，故令

dW = Xdx + Ydy + Zdz，即 X = ∂W/∂x，Y = ∂W/∂y，Z = ∂W/∂z

则 dp = ρ dW，积分得 p = ρW + C；由 p = p0、W = W0 定出 C = p0 − ρW0，于是

p = p0 + ρ(W − W0)

满足上式的坐标函数 W(x, y, z) 称为力的势函数，具有势函数的质量力称为有势的力。

流体平衡的条件

只有在有势的质量力作用下，不可压缩均质流体才能处于平衡状态。上式 p = p0 + ρ(W − W0) 即不可压缩流体平衡微分方程积分后的普遍关系式。

2.3 等压面

定义

p = 常数 的面称为等压面。由 dp = ρ dW = 0（ρ ≠ 0）得 dW = 0，即 W = 常数。

等压面微分方程

Xdx + Ydy + Zdz = 0

等压面的性质与判据
  1. 等压面即等势面（dW = 0 ⟹ W = 常数）。
  2. 流体质点沿等压面移动距离 dl 时，质量力所作的微功为零，即 f·dl = 0。
  3. 等压面与质量力正交。这是绘制与判断等压面的核心依据：质量力只有重力时，等压面就是水平面。
  4. 判据（构成等压面的三个条件）：同种、连续、静止（相对静止）的流体，其水平面是等压面。
易错点

① 两种流体的分界面和自由面既是水平面又是等压面；不同密度的两种流体各自的水平面才是等压面，不能跨过分界面把一个水平面当作整片等压面。② 非均质流体：静止非均质流体的水平面仍然是等压面，且由 dp = ρ1dh、p1 = p2 推得 ρ1 = ρ2，故水平面同时是等压面、等容重面、等密度面，进而还是等温面。③ 等压面不一定水平（相对平衡时是倾斜平面或旋转抛物面）。

2.4 重力场中的流体静力学基本方程

质量力只有重力时：X = 0，Y = 0，Z = −g，取 z 轴铅垂向上，代入 dp = ρ(Xdx + Ydy + Zdz)：

推导

dp = −ρg dz = −γ dz  ⟹  积分 p = −γz + C

对液面上一点与液体内任意深度 h 处一点应用：p = p0 + γ(z0 − z) = p0 + γh。

液体静力学基本方程（两种形式）

p = p0 + ρgh = p0 + γh  （h 为淹没深度，向下为正）

z + p/γ = 常数  （即各点测压管水头相等）

物理意义与使用条件

第一条式的意义：静止液体中压强随深度按直线规律变化；深度相同的点压强相同（水平面是等压面）；压强的大小与容器的形状无关。

第二条式的几何意义：z 为该点相对于基准面的高度（位置水头），p/γ 为该点在压强作用下沿测压管所能上升的高度（压强水头，此处 p 为相对压强），z + p/γ 为测压管水头（测压管水面相对基准面的高度）。静止液体中各点的测压管水头相等。

能量意义：z 是单位重量流体的重力势能，p/γ 是单位重量流体的压强势能，z + p/γ 是单位重量流体的总势能。静止液体中各点单位重量流体的总势能相等——重力势能与压强势能各自可变，但总和恒定，体现能量守恒。

使用条件：静止、同种、连续流体（三个条件缺一不可）。实际流体、理想流体都适用。

对上式两边取增量 Δp = Δp0（h 不变），即：

水静压强等值传递的帕斯卡定律

2.4.2 气体压强的计算

对不可压缩气体，γ气 很小，在高度差不大时可忽略气体柱重量：

气体：p = p0 + γh ≈ p0

即容器内气体各点压强近似相等（这是测压计问题中“空气柱压强差可忽略”的依据）。

3 压强的计算基准和度量单位

3.1 压强的两种计算基准（三种压强）

名称符号计量基准关系式说明
绝对压强pabs完全真空（绝对零压强）pabs = pa + ρgh恒有 pabs ≥ 0，≥ 0 是压强特性一的要求
相对压强（表压、计示压强）p当地大气压 pap = pabs − pa = ρgh可正可负；水面与大气相通时 p = ρgh
真空度（真空压强）pv当地大气压 papv = pa − pabs = −p仅当 pabs < pa 时存在，pv ≥ 0；真空高度 hv = pv/γ = (pa − p)/γ

pabs = pa + p；  p = pabs − pa；  pv = pa − pabs = −p  （三者都取正值量）

常见考法

① 已知表压求绝对压强／已知真空度求绝对压强；② 判断“真空度就是负的绝对压强”之类错误说法（错，真空度是相对压强的相反数）；③ 水泵吸入管、凝汽器、锅炉炉膛、烟囱底部等“负压”部位给出的压强是表压还是真空度。

3.2 压强的度量单位

  1. 应力单位（唯一 SI 单位）：由定义 p = P/A，单位 Pa（N/m2）、kPa、MPa。
  2. 大气压倍数：1 标准大气压（atm）= 101325 Pa = 760 mmHg（0 ℃、海平面上的压强）；1 工程大气压（at）= 98000 Pa ≈ 98100 Pa = 10 mH2O ≈ 0.1 MPa（海拔 200 m 处正常大气压）。
  3. 液柱高度：由 h = p/γ 换算。
四种单位换算必记数值
基准Pa水柱高（γ = 9810 N/m3）汞柱高（ρHg = 13600 kg/m3）
1 标准大气压10132510.33 m760 mmHg
1 工程大气压98000（≈98100）10 m735.6 mmHg

其中仅有 Pa 是 SI 单位；帕斯卡（Pa）、大气压、液柱高三种表示法在液柱测压计计算中都要熟练互换。

4 液柱测压计

常用测压计包括机械式、电子式和液柱式。液柱式测压计的原理就是液体静力学基本方程 p = p0 + ρgh：以液柱高度变化反映压强大小。

4.1 测压管（结构最简单的液柱式测压计）

直管或 U 形管。直管测压管要求：管径不宜过小（否则受毛细作用影响）、所测压强不能过大（否则 h 过高）、只能测液体压强（气体需用 U 形管配工作液体）。

(a) p = γh  （水面上 p0 = pa，管内液面高出容器液面 h）

(b) p + γh = 0 ⟹ p = −γh，即 pv = γh  （管内液面低于容器液面）

(c) p = γh  （测气体压强，γ 为工作液体容重）

当压强较大时，直管测压计中改用水银（工作液体）：设容器内液面压强为 p，U 形管中水银面高差为 h，容器液面到水银左支管面的高度为 h1，取等压面在水银面较低一侧：

p + γh1 = γHgh  ⟹  p = γHgh − γh1，或写成相对压强比 p/γ = (γHg/γ)h − h1

毛细作用

管径小、精度要求高时需考虑毛细作用：液体在细管中因表面张力和分子间作用力差异而自发上升或下降。附着力大于内聚力时液面上升（如水），反之下降（如水银）。管径越细、表面张力越大，毛细作用越显著，上升高度遵循 H = 2σcosθ/(rρg)，σ 为表面张力系数（N/m）。

4.2 压差计（测定两点间压强差）

采用等压面规律进行压差计算。对图中两点 A、B（容器内液体容重 γA、γB，工作液体容重 γp，水银柱差 h，两测点高差分别为 zA、zB）：

pA + γA(zA + h) = pB + γBzB + γph

⟹ pA − pB = (γp − γA)h + γBzB − γAzA

情形条件压强差结论
(a)A、B 处为同种液体(γp − γ)h + γ(zB − zA)一般式
(b)同种液体，且在同一高程 zA = zB(γp − γ)h容重差乘以水银柱差（最常用）
(c)A、B 处为同一气体γph水银柱差所产生的压强（空气压差计：pA − pB = γph）

4.3 微差计（倾斜式微压计）

工作液体一般采用蒸馏水或酒精；功能是在测定微小压强（或压差）时提高量测精度。

p1 − p2 = γh = γl sinα，  l = h/sinα

α = 30° 时 l = 2h；α = 10° 时 l = 5.76h

结论

倾斜角度 α 越小，l 比 h 放大的倍数越大，量测精度越高；工作液体密度越小，读数越大（故常用酒精而不用水银）。

4.4 测压计计算通用套路

五步法（必背）
  1. 定两端：从已知压强的一端出发，逐段推算到待求压强的一端，中间量（分界面、转向点压强）随即消去。
  2. 逐段加减：沿管内流体从一端走到另一端，向下走（沿重力方向）压强加 ρgh；向上走压强减 ρgh。每段用该段流体的密度。
  3. 取等压面：在同一种连通流体的同一高度上取等压面（通常在两种流体的分界面、U 形管最低液面或同一水平液面处），利用该面上压强相等列方程。
  4. 气体柱：小范围高度内空气质量影响不计，γair ≈ 0，空气段的 ρgh 项可略。
  5. 统一基准：全式统一用绝对压强或统一用相对压强；用相对压强时，与大气相通的液面就是 p = 0 的起点。
易错点

① 忘记区分工作液体与被测流体的密度（水银 13600 kg/m3、水 1000、酒精 800）；② 上下方向搞反导致符号错；③ 在不同流体或不连通的两点取等压面；④ 把工程大气压当标准大气压用（0.5 工程大气压 = 4.905×104 Pa，而 0.5 atm = 5.07×104 Pa）。

例 2-1（压强基准与换算）
某水泵吸入管中水的绝对压强为 78 kPa，当地大气压为 98 kPa，求相对压强与真空度；若改用汞柱表示真空度，汞柱高为多少？（ρHg = 13600 kg/m3，γ水 = 9800 N/m3，g = 9.8 m/s2）

解：真空度 pv = pa − pabs = 98 − 78 = 20 kPa

相对压强 p = −pv = −20 kPa（表压为负，即通常说的“负压”）

汞柱高 hHg = pv/(ρHgg) = 20000/(13600 × 9.8) = 20000/133280 = 0.150 m = 150 mmHg

（若用水柱表示：hv = 20000/9800 = 2.04 mH2O）

答案：p = −20 kPa，pv = 20 kPa，hHg = 150 mmHg（= 2.04 mH2O）
例 2-2（多层液体：先求分界面压强）
密闭容器内盛有三种不相混的液体，自上而下依次为：油层厚 h1 = 1.0 m（γ1 = 8000 N/m3），水层厚 h2 = 1.5 m（γ2 = 9800 N/m3），水银层厚 h3 = 0.4 m（γ3 = 133280 N/m3）。液面压强 p0 = 30000 Pa（相对）。求容器底部及水银层中的压强。

解：多种流体的容器，先求分界面压强，再逐层向下累加 ρgh：

油—水分界面（深度 1.0 m）：p1 = p0 + γ1h1 = 30000 + 8000 × 1.0 = 38000 Pa

水—水银分界面（深度 2.5 m）：p2 = p1 + γ2h2 = 38000 + 9800 × 1.5 = 38000 + 14700 = 52700 Pa

容器底部（深度 2.9 m）：p底 = p2 + γ3h3 = 52700 + 133280 × 0.4 = 52700 + 53312 = 106012 Pa

答案：p1 = 38.0 kPa，p2 = 52.7 kPa，p底 ≈ 106.0 kPa（均为相对压强）
例 2-3（复式 U 形管压力计）
复式 U 形管压力计如图：压力表 M 读数 0.5 工程大气压（表压），h = 0.2 m，h1 = 0.3 m，h2 = 0.3 m，h3 = 0.5 m；水的密度 ρw = 1000 kg/m3，酒精比重 ρa/ρw = 0.8，ρHg = 13600 kg/m3。求 pB。

5 作用于平面的液体总压力

工程上除确定点压强外，还需计算受压面上的总压力（如三峡坝高 181 m、白鹤滩坝高 289 m，坝体需要承受多大的压力？）。静止液体作用在平面上的总压力要回答三个问题：大小、作用点、方向。方法有两种：解析法与图算法（图解法）。

5.1 解析法

总压力的大小

设 h 为倾斜平面上任一点到自由液面的深度，h = y sinα；在深度 h 处取微元面积 dA，由静止液体产生的压强 p = γh，微元面积上受力 dP = γh dA = γy sinα dA。积分：

P = ∫A dP = ∫A γy sinα dA = γ sinα ∫A y dA

受压面 A 对 Ox 轴的静矩 ∫A y dA = yCA，而 yC sinα = hC，故

平面总压力（核心公式）

P = γ sinα yCA = γhCA = pCA

其中 hC 为受压面形心点 C 的淹没深度，yC 为形心点 C 到 Ox 轴的距离，pC 为形心点 C 的压强。

结论

静水总压力大小等于受压面面积与其形心点压强的乘积，方向沿受压面的内法线方向，且与平板的倾斜角度 α 无关。注意是形心点压强 pC，不是平均压强之外的其他量；这里是相对压强计算（与容器形状无关）。

总压力的作用点（压力中心 D）

对 Ox 轴取力矩：合力矩等于各微元力矩之积分，P yD = ∫A γy sinα y dA = γ sinα Jx，其中 Jx = ∫A y2dA 为受压面对 Ox 轴的惯性矩。由平行移轴定理 Jx = JC + yC2A：

压力中心（核心公式）

yD = Jx/(yCA) = yC + JC/(yCA)

ye = yD − yC = JC/(yCA) > 0 ⟹ yD > yC

其中 JC 为受压面对过形心且平行于 Ox 轴的轴的惯性矩，ye 为压力中心沿 y 轴方向至受压面形心的距离。

结论

① JC/(yCA) > 0，故总压力作用点 D 一般位于受压面形心 C 之下（因为压强随淹没深度增加而增大）。② 随着受压面整体深度增加，yC 增大，ye 减小，D 与 C 位置逐渐靠近；当深度趋于无穷时 D 与 C 重合。③ 实际工程中受压平面多数对称，压力中心位于平面的对称中心线上，此时不必求 xD，只需 yD。

使用条件与虚设液面

上述公式只能计算液面压强为大气压强时作用于平面的液体静压力及其压力中心（即以相对压强全为 0 的液面为基准）。若容器封闭、液面压强 p0 ≠ pa，则采用相对压强为 0 的虚设液面：虚设液面在实际液面上方（下方）距离为 (p0 − pa)/γ；当 p0 > pa 时虚设液面在实际液面上方，反之在下方。计算静压力时 hC 用形心至虚设液面的距离代替，计算压力中心时 yC 用形心沿 y 轴方向至虚设液面的距离代替。

5.2 图解法（压强分布图）

静压强分布图：在受压面承压的一面，以一定比例尺的矢量线段，表示压强大小和方向的图形。由 p = p0 + γh 可知图形分两部分：

  • p0 的作用：矩形分布，且左右两边相互抵消，通常不考虑；
  • γh 的作用：三角形分布（起点压强 0，终点压强 γh）。
图解法的三个步骤与结论
  1. 先绘制压强分布图；
  2. 作用力的大小等于压强分布图的面积乘受压面的宽度，即压强分布图的体积；
  3. 作用点的位置相当于压强分布图的形心点位置。

以矩形（宽 b、高 h）竖放挡水为例：压强分布图 ABE 三角形面积 Ω = (1/2)γh h，故

P = Ω b = (1/2)γh2b，与解析法 P = γhCA = γ(h/2)(hb) 完全一致。

常见疑问：为什么这里取 hC = h/2 而不是 2h/3？——h/2 是总压力的计算深度（形心深度），2h/3 是压力分布图三角形的形心纵坐标，即压力中心的深度，两者含义不同，切勿混用。

6 作用于曲面的液体总压力

曲面上的液体总压力与平面上有本质不同：曲面几何形状复杂，压力方向在曲面上各点不同，不能简单沿用平面方法，必须把总压力分解为水平分力与垂直分力分别计算。水平分力的计算类似平面情况，垂直分力与曲面上方液体的虚拟体积（压力体）相关。

6.1 水平分力

设一垂直于底面的柱体（长度 l），受压曲面为 AB；在曲面 AB 上水深 h 处取微元面积 dA，作用在 dA 上的水静压力 dP = γh dA，该力垂直于 dA 并与水平面成夹角 θ。水平方向的分力 dPx = dP cosθ = γh dAz（dAz = dA cosθ 是 dA 在铅垂投影面上的投影），积分得

水平分力

Px = ∫A γh dAz = γhCAz = pCAz

其中 hC 为铅垂投影面积 Az 形心点的淹没深度，pC 为铅垂投影面积形心点的压强，Az 是受压曲面在铅直投影面上的面积。

结论

曲面总压力的水平分力等于该曲面在铅垂投影面上的投影面（平面）上的总压力，大小等于投影面积与其形心点压强之积，方向水平指向曲面。

6.2 铅垂分力与压力体

垂直方向分力 dPz = dP sinθ = γh dAx（dAx = dA sinθ 为 dA 在水平面上的投影），积分：

铅垂分力

Pz = ∫A γh dAx = γV

压力体的定义与组成

定义：压力体是所研究的曲面（淹没在静止液体中的部分）到自由液面或自由液面的延长面间投影所包围的一块空间体积，数学上即 ∫A h dAx = V。

压力体体积的三个组成部分：(1) 受压曲面本身；(2) 通过受压曲面边界线所作的铅垂面；(3) 受压曲面边界线封闭的面积在自由液面（虚设液面）或其延长面上的投影面。

结论：静止液体作用在曲面上的总压力的铅垂分力大小等于压力体中装满此种液体时的重量，并且与压力体内是否真的充满液体无关。

压力体虚实判断（速记）
  • 实压力体：压力体里面有水（压力体与液体同侧），压力指向内法线方向，Pz 铅垂向下。
  • 虚压力体：压力体里面没有水，压力指向外法线方向，Pz 铅垂向上。
  • 同一曲面上下部分可能既有实压力体又有虚压力体，此时 Pz 取二者的代数和（方向相反相减）。

6.3 总压力的大小、方向与作用点

总压力：P = √(Px2 + Pz2)

作用线与水平面的夹角：tanθ = Pz/Px  （θ 也是总压力作用线与水平面的夹角）

作用点：过 Pz 作用线（通过 Ax 上压强分布图的形心，非投影面的形心！！！）和 Px 作用线（通过压力体的形心）的交点，作与水平面成 θ 角的直线即总压力作用线，该线与曲面的交点即为总压力作用点。

6.4 潜体、浮体与阿基米德原理

潜体：物体全部浸入水中；浮体：物体部分浸入水中。此时曲面为封闭曲面，水平分力相互抵消，只剩下铅直向上的压力：

浮力（阿基米德原理）

Pz = γV = ρgV

作用于潜体或浮体的液体压力，只有铅直向上的压力，即浮力，大小等于物体排开液体的重量；浮力作用点（浮心）为排开液体的重心。

7 流体平衡微分方程在相对平衡中的应用

在非惯性参考系中，只需在质量力中加入牵连惯性力（方向与非惯性参考系的加速度方向相反），即可在该参考系中直接使用欧拉平衡方程 dp = ρ(Xdx + Ydy + Zdz)。这正是“相对平衡”问题的统一解法。

7.1 等加速直线运动中液体的平衡

设容器以等加速度 a 沿水平 x 方向运动，流体相对容器静止。质量力 = 重力 + 牵连惯性力：

重力：Xg = 0，Yg = 0，Zg = −g；  牵连惯性力：Xi = −a，Yi = 0，Zi = 0

合成：X = −a，  Y = 0，  Z = −g

dp = ρ(−a dx − g dz) ⟹ 积分 p = ρ(−ax − gz) + C

由边界条件 x = 0、z = 0 处 p = p0 定出 C = p0：

等加速直线运动

p = p0 + ρ(−ax − gz) = p0 + γ(−(a/g)x − z)

相对压强：p = γ(−(a/g)x − z)

自由面方程（等压面）：令 p = 0 得 z = −(a/g)x，即

自由面与等压面

z = −(a/g)x，  tanβ = −a/g

结论与对比

等加速直线运动液体的等压面是倾斜平面，倾角 β 满足 tanβ = a/g，且所有等压面互相平行；自由面仍为平面。与静止液体对比：铅直方向的压强递增率相同（∂p/∂z = −γ），x 方向的压强递增率不相同（静止时 ∂p/∂x = 0，等加速时 ∂p/∂x = −ρa）。

例 2-10（等加速直线运动）
长 L = 6 m、宽 b = 2 m 的矩形水箱内盛水，静止时水深 h0 = 1.8 m。水箱以等加速度 a = 2.0 m/s2 沿箱长方向水平运动。求：① 自由面倾角与箱底最高、最低点处的水深；② 箱底最大压强。（g = 9.81 m/s2）

解：① 自由面方程 z = −(a/g)x，故

tanβ = a/g = 2.0/9.81 = 0.2039，β = 11.5°

水面沿箱长方向的总高差 Δz = L tanβ = 6 × 0.2039 = 1.22 m

由水量守恒（水体体积不变，容器等宽），自由面绕静止水面中点（x = L/2 = 3 m 处）转动：

后壁（加速方向的后端，x = 0）水深最大：hmax = 1.8 + 0.61 = 2.41 m

前壁（x = 6 m）水深最小：hmin = 1.8 − 0.61 = 1.19 m

② 箱底最大压强出现在水深最大处：

pmax = γhmax = 9810 × 2.41 = 23642 Pa

答案：β = 11.5°（tanβ = 0.204）；hmax = 2.41 m、hmin = 1.19 m；pmax ≈ 23.6 kPa

7.2 容器等角速旋转运动时液体的平衡

流体质点与容器一起绕铅垂轴以等角速度 ω 旋转，单位质量力的分量为

X = ω2rcosα = ω2x，  Y = ω2rsinα = ω2y，  Z = −g

代入 dp = ρ(Xdx + Ydy + Zdz) = ρ(ω2x dx + ω2y dy − g dz)

积分（x2 + y2 = r2）：p = ρ(ω2r2/2 − gz) + C

由坐标原点 x = y = z = 0 处 p = p0 定出 C = p0：

等角速旋转

p = p0 + ρg(ω2r2/(2g) − z)，  相对压强 p = γ(ω2r2/(2g) − z)

等压面：令 p = 常数，得

等压面与自由面

z = ω2r2/(2g) + 常数  （旋转抛物面）

自由液面（p = 0）：z = ω2r2/(2g)

结论

① 等角速旋转液体的等压面是旋转抛物面（自由面也是旋转抛物面）；② 在同一水平面处，轴心处的压强最低，边缘的压强最高；③ 与静止液体对比：x、y 方向的压强递增率不为零（∂p/∂x = ρω2x，∂p/∂y = ρω2y），而铅直方向仍为 ∂p/∂z = −γ。

例 2-11（等角速旋转：角速度与最大压强）
半径 R = 0.5 m、高 H = 1.0 m 的开口圆柱形容器内盛水，静止时水深 h0 = 0.5 m。容器绕铅垂中心轴以等角速度 ω 旋转。求：① 使中心处水面恰好降至容器底面（即中心点 r = 0、z = 0 处相对压强为零）时的 ω；② 此时容器底部的最大与最小压强。（g = 9.81 m/s2）

解：取容器底面中心为坐标原点，z 轴铅垂向上，压强公式为

p = γ(ω2r2/(2g) − z)

① 中心处水面降至容器底面，即 r = 0、z = 0 时自由面通过原点，此时 ω 使边缘处水面恰好升到多少？由水量守恒确定。旋转后水体为抛物面下方体积：

静止水量 V0 = πR2h0 = π × 0.52 × 0.5 = 0.3927 m3

由水量守恒（旋转前后水的体积不变）可证：自由面绕轴旋转所得抛物面，其「高出原水面部分」的体积恒等于「低于原水面部分」的体积（两者都是同底同高的旋转抛物体、体积均为 πR2Δz/2），故边缘水位上升量恒等于中心水位下降量。令自由面方程 z = ar2（a = ω2/(2g)），中心水位 h(0) = 0、边缘水位 h(R) = aR2，则由 h(0) + h(R) = 2h0 得 aR2 = 2h0，即

H边 = ω2R2/(2g) = 2h0 = 1.0 m（中心跌至底面时边缘恰好升至 2h0 = 1.0 m，仍在容器高度 H = 1.0 m 之内，水不外溢）

故 ω2 = 2gh0/R2 = 2 × 9.81 × 0.5/0.25 = 39.24，ω = √39.24 = 6.26 rad/s

② 容器底部（z = 0）：

轴心处（r = 0）：pmin = γ(0 − 0) = 0（与中心处自由面在同一等压面）

边缘处（r = R = 0.5 m）：pmax = γ(ω2R2/(2g)) = 9810 × (39.24 × 0.25/19.62) = 9810 × 0.5 = 4905 Pa

（若同时考虑容器侧壁的最大压强，在底部边缘处取最大，即 4905 Pa；若容器底部以上 z 更深处（无底面容器的情形）按 p = γ(ω2R2/(2g) + |z|) 累加。）

答案：ω = 6.26 rad/s；底部轴心最小压强 pmin = 0，边缘最大压强 pmax = 4905 Pa ≈ 4.91 kPa
例 2-12（绕轴旋转的 U 形管）
装有水的 U 形管绕其中心铅垂轴以等角速度 ω 旋转，已知两竖直支管到转轴的距离分别为 r1 = 0.2 m、r2 = 0.4 m，两支管的水面高差 Δz = 0.6 m。求旋转角速度 ω。若某点相对压强为零且位于 r = 0.4 m 处的管口，求此时该处相对压强为零所对应的水柱高度关系。（g = 9.81 m/s2）

解：液体随管作等角速度旋转，处于相对静止状态，其压强满足旋转液体的平衡方程

p = γ(ω2r2/(2g) − z)

在同一液体中任意两点 1、2 之间有

(p2 − p1)/γ = ω2(r22 − r12)/(2g) − (z2 − z1)

两支管水面都与大气相通，故 p1 = p2 = 0：

0 = ω2(r22 − r12)/(2g) − Δz

即 Δz = ω2(r22 − r12)/(2g)

ω2 = 2gΔz/(r22 − r12) = 2 × 9.81 × 0.6/(0.42 − 0.22) = 11.772/0.12 = 98.1

ω = √98.1 = 9.90 rad/s

第二问：凡满足 z = ω2r2/(2g) 的点，其相对压强都为零，它们构成过原点（r = 0、z = 0）的旋转抛物面——即此时液体的自由面。

把 r = 0.4 m 代入：z = 98.1 × 0.16/(2 × 9.81) = 0.80 m。也就是说，右支管内水面恰好位于转轴处水面以上 0.80 m，而两支管水面的高差仍满足第一步的 Δz = ω2(r22 − r12)/(2g) = 0.6 m，两者互不矛盾。

答案：ω = √(2gΔz/(r22−r12)) = 9.90 rad/s；r = 0.4 m 处零压点满足 z = ω2r2/(2g) = 0.80 m
例 2-13（综合题型：闸门总压力与测压计读数）
矩形平板闸门竖直安装，宽 b = 2 m、高 H = 3 m，闸门顶部与水面齐平。为测定闸门前的水深，在闸门底部装一测压管，管内水面高出闸门顶部 3.5 m。求闸门所受的总压力、压力中心位置及闸门底部处的相对压强。（γ = 9810 N/m3）

解：测压管水面即相对压强为零的面（虚设液面），其高出闸门顶部 3.5 m，说明闸门顶部处的相对压强为

p顶 = γ × 3.5 = 9810 × 3.5 = 34335 Pa

闸门顶部在水面以下 0 m（与水面齐平）是题干给定的几何条件，但由测压管读数可知实际作用水头应以虚设液面为基准，故闸门形心处的压强需以虚设液面到形心的距离计算：

hC′ = 3.5 + H/2 = 3.5 + 1.5 = 5.0 m（自虚设液面量起）

总压力：P = γhC′A = 9810 × 5.0 × (2 × 3) = 9810 × 5.0 × 6 = 294300 N

压力中心：yC′ = 5.0 m，JC = bH3/12 = 2 × 33/12 = 4.5 m4

ye = JC/(yC′A) = 4.5/(5.0 × 6) = 0.15 m

yD = 5.0 + 0.15 = 5.15 m（自虚设液面量起，即形心下方 0.15 m）

闸门底部压强：p底 = γ × (3.5 + 3.0) = 9810 × 6.5 = 63765 Pa

答案：P ≈ 294.3 kN；压力中心位于形心下方 0.15 m（自虚设液面量起 yD = 5.15 m）；p底 ≈ 63.8 kPa（相对压强）

8.3 易错清单（考前一小时）

高频陷阱
  1. 特性二不是“压强方向无关”：方向与作用面垂直（特性一），大小与作用面方位无关（特性二）。
  2. 绝对压强不能为负，工程上的“负压”指的是相对压强为负；真空度是相对压强的相反数，恒为正。
  3. 等压面三条件（同种、连续、静止）缺一不可；跨分界面取等压面是最常见的错误。
  4. 压强随深度增加的方向就是质量力的方向，不是“压强指向质量力方向”。
  5. 平面总压力与倾角 α 无关，但压力中心位置沿板面的坐标随 α 变化。
  6. 压力中心在形心之下（yD > yC）；深度越大两者越接近。
  7. 图解法中 hC 取 h/2，压力中心才取 2h/3——一个是形心深度，一个是压强分布图形心。
  8. 曲面水平分力用铅垂投影面的形心深度，不是曲面形心深度，也不是投影面几何中心。
  9. 压力体虚实：实压力体（内有液体）Pz 向下，虚压力体（内无液体）Pz 向上；上下都有曲面时取代数和。
  10. 相对平衡问题统一用 f − (1/ρ)∇p = 0，只需把牵连惯性力并入单位质量力；切勿套用“p = p0 + γh”直接算相对平衡的压强。
  11. 旋转液体同一水平面上不用深度 h 算压强，必须用 p = γ(ω2r2/(2g) − z)，因为此时水平面不再是等压面。
  12. 测压计全式统一基准：要么都用绝对压强，要么都用相对压强，中途换基准必错。

本章小结（课件）：本章讲授流体处于平衡（静止）状态时的力学规律及其在工程中的应用。① 静止流体中只存在压应力——压强，静压强大小与作用面方向无关，是空间坐标的连续函数 p = p(x, y, z)；② 重力作用下的静压强分布（液体静力学基本方程两种形式）；③ 绝对压强、相对压强和真空压强；④ 作用在固体表面的总压力：平面用解析法与图解法（矩形平面），曲面用分力和压力体概念；⑤ 流体平衡微分方程及其全微分式 dp = ρ(Xdx+Ydy+Zdz)；⑥ 等加速直线运动和等角速度旋转下的压强分布。
