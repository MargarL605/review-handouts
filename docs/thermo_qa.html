第一部分　基本概念与第一定律（第 1—7 题）

本部分是全卷推导的“地基”：第 1、2 题是概念定性题，第 3 题是状态与稳定性，第 4—7 题是能量方程的主干链条（闭口 → 吉布斯 → 熵 → 开口 → 两种形式）。四条主线必须能默写：q = Δu + w；δq = Tds；q = Δh + wt；q = Δh + ½Δc2 + gΔz + ws。
通用答题模板（所有“简图 + 能量方程 + 过程特征”题都照这个顺序写）

1画系统简图并画虚线边界，标出入口 1、出口 2，标出 q 与 ws 的方向；2写出一般式 q = Δh + ½Δc2 + gΔz + ws；3按题给条件逐项划零（绝热 q=0；刚性不动 ws=0；忽略宏观动能势能差 ½Δc2=gΔz=0）；4整理出简化式；5写过程特征（定压 / 定温 / 定熵 / 定焓、可逆还是不可逆、压差与温差的方向）。

第 1 题　牛顿力学和热力学主要差别
说明牛顿力学与热力学在研究对象、基本定律、时间方向性等方面的主要差别。

（1）研究对象不同。牛顿力学研究单个（或少数）质点和刚体的机械运动，状态由位置与速度完全确定，是确定性、可逆的描述；热力学研究由大量分子组成的宏观系统，其状态用 p、v、T、u、s 等宏观物理量描述，属于统计性描述。单个分子的运动服从牛顿力学，但大量分子集体表现出的热现象不能由牛顿力学直接给出。

（2）基本定律与内容不同。牛顿力学以牛顿三定律为基础，核心是力与运动、功与机械能的转换；热力学以热力学第零、第一、第二定律为基础，核心是能量及其转换规律与能量品质的差别：第一定律给出能量在数量上的守恒（能量方程），第二定律指出能量存在形式有品质高低之分，给出转换效率的极限与过程进行的方向。

（3）时间的方向性（可逆性）不同。牛顿力学的方程对时间 t → −t 对称，过程原则上可以完全反向复现；热力学第二定律指出一切自发过程都是不可逆的（摩擦耗散、温差传热、压差传功、浓度差传质、化学势差反应……），过程只能朝熵增大的方向发展。因此热力学给出了“时间箭头”，这是牛顿力学所没有的。

（4）状态量与过程量的区分不同。牛顿力学中功与路径无关（保守力）的情况很常见；热力学中必须区分状态参数（p、v、T、u、h、s，其微元是全微分）与过程量（q、w，其微元用 δ 表示，与路径有关）。

（5）研究方法不同。热力学有两条路：以宏观物理量为基础、以经验性物理定律为依据的经典（宏观）方法（本课程内容）；以及从物质微观结构出发、建立宏观性质与微观本质联系的微观统计方法（统计物理学）。

（6）两者的联系。热力学并不否定牛顿力学：热力学第一定律正是能量守恒与转换定律在热现象中的推广，机械能与其他形式能量（内能）之间可以相互转换，转换中总能量守恒。

得分点：① 单个/少量质点 vs 大量分子宏观系统（统计性）；② 三定律 vs 三定律（能量守恒 + 品质与方向）；③ 时间可逆 vs 自发过程不可逆、熵增方向；④ 状态量与过程量的区分；⑤ 宏观与微观两种研究方法。一句话结论：牛顿力学研究可逆的机械运动，热力学研究能量的数量守恒与品质贬值（方向性）。
答题模板（“差别类”简答题五步法）

研究对象 → 基本定律 → 状态描述（状态量/过程量）→ 时间方向性（可逆/不可逆）→ 联系与补充（研究方法）。每一条写 1—2 句即可，切勿只写一句“热力学研究热现象”。

第 2 题　热力学第零定律及意义
叙述热力学第零定律，并说明它的意义。

（1）定律表述。如果两个系统分别与第三个系统处于热平衡，那么这两个系统彼此必然处于热平衡。

（2）物理图像。系统 A 与系统 B 用绝热壁隔开、互不接触，让第三系统 C（温度计）先与 A 达到热平衡，再与 B 达到热平衡；则 A 与 B 若被导热壁连通，彼此不再发生净热交换，说明两者处于同一热平衡状态。

（3）意义。

①　它给出了温度这一状态参数存在的逻辑依据：互为热平衡的所有系统具有一个共同的、数值相等的状态量，这个量就是温度。

②　它使温度测量成为可能：温度计可以“代表”被测系统与其他系统比较，即测温的物理基础；这也是它被称为“第零定律”的原因——逻辑上它先于第一、第二定律，是热力学的起始公式之一。

③　它给出了热平衡的判据：TA = TB ⇔ A、B 热平衡；温差是传热的推动力，无温差则无净传热，这是判断过程方向与可逆性的基础。

④　它与第一定律（能量守恒）、第二定律（方向与品质）共同构成热力学的公理体系，是整个宏观热力学的逻辑起点。

得分点：① 准确复述“与第三系统热平衡 ⇒ 彼此热平衡”；② 温度（态函数）的存在性依据；③ 测温原理与温度计的理论基础；④ 热平衡判据 TA=TB。一句话结论：第零定律解决了“温度是什么、温度能不能测”的问题，是热力学的起始公式。
易错点

① 三个系统必须是两两与第三个热平衡，不能写成“两个系统温度相等所以热平衡”（那是结论不是定律）。② 第零定律只讲热平衡，不讲力平衡与化学平衡。③ 不要与第一定律混答：第零定律不涉及能量数量关系，它只给出温度这一状态参数的存在性。

第 3 题　工质热力性质、物态稳定必要条件
什么是工质的热力性质？物态稳定的必要条件是什么？

（1）工质与热力性质。在热力设备中实现能量转换的媒介物质称工质（工作介质）。工质的热力性质指工质各状态参数之间的相互关系，即

状态方程

f(p, v, T) = 0

以及由此派生的其他热力学关系 u = u(v,T)、h = h(p,T)、s = s(p,T)、cp、cv 等。按状态公理：对单元单相简单可压缩系统，独立状态参数只有 2 个，确定这两个参数，其余参数与全部热力性质就都随之确定。

“物态”即工质所处的相（固相、液相、气相）。工质可能出现的物态与其热力性质密切相关，可用 p-v-T 图（三维状态图）表示：图上有固、液、气三个单相区，以及固–液、液–气、固–气三个两相共存区，三区交线汇于三相点，液–气共存线终止于临界点。

（2）物态稳定的必要条件。物态稳定即系统处于热力学平衡状态，其必要条件（也是热力学平衡的四个条件）是：

平衡条件

① 热平衡：系统各部分无温差，T = 常数（无传热推动力）；
② 力平衡：系统各部分无压差，p = 常数（无传功推动力）；
③ 相平衡：各相之间无相变净迁移，对两相共存必须满足 p = f(T)；
④ 化学平衡：无化学势差，不发生净化学反应。

（3）稳定性的进一步说明。上述四条件保证系统宏观状态不随时间变化、内部不存在任何不平衡势（系统内无统计意义上的宏观物质流与能量流）。对两相共存的物态，还要求该状态位于两相区内且满足 p = f(T)：温度、压力只有一个独立，不能任意给定。此外，稳定平衡还要求处于稳定平衡而非亚稳（如过热液体、过冷蒸汽）——后者虽可短暂存在，一旦受扰动即失稳。

两相平衡

p = f(T)　（饱和压力是饱和温度的单值函数）

得分点：① 工质=实现能量转换的媒介物质，热力性质=f(p,v,T)=0 及派生的 u、h、s、cp、cv 关系；② 状态公理：单元单相简单可压缩系统只需 2 个独立状态参数；③ 物态稳定=热力学平衡，四条件：热平衡、力平衡、相平衡（p=f(T)）、化学平衡。一句话结论：无温差、无压差、无相变净迁移、无化学势差 ⇒ 宏观状态不随时间变化、内部无不平衡势。
易错点

① “物态稳定”≠“状态参数不变”：必须强调内部不存在不平衡势（否则准静态过程的中间状态也会被误认为平衡态）。② 两相共存时独立参数只有 1 个（p 与 T 不独立），不能与单相的 2 个混淆。③ 只说“温度和压力不变”不够，还要写相平衡与化学平衡，才叫完整的必要条件。

第 4 题　工质闭口系统能量方程推导
推导闭口系统的能量方程，并说明其各种形式及适用条件。

（1）系统与假设。取闭口系统（控制质量）：与外界只交换热量和容积变化功，与外界无物质交换，边界可以是移动的。设系统在过程中从外界吸热 Q，对外作总功 W。

（2）能量的储存形式。闭口系统的能量储存有：

宏观动能 Ek = ½mc2　；　宏观势能 Ep = mgz　；　热力学能（内能） U

其中只有内能 U 是工质的热力性质（状态参数），动能与势能属于宏观机械能。注意：U 的实际数值不可知也不可测，只有 Δu、du 才有物理意义。

（3）推导（从能量守恒出发）。对闭口系统，进入系统的能量 − 离开系统的能量 = 系统储存能量的变化量，即

一般式

Q = ΔU + ΔEk + ΔEp + W

若系统宏观静止且无宏观位能变化（ΔEk = ΔEp = 0），则得闭口系统热力学能量方程（最常用形式）：

基本形式

Q = ΔU + W　；　对单位质量：q = Δu + w

写成微元形式（过程中间任意微元段）：

δq = du + δw

（4）总功的分解。闭口系统获得/作出的总功由两部分组成：

δw = pdv − δwdiss　（可逆过程 δwdiss = 0）

式中 pdv 为容积变化功（体积功）；δwdiss 为耗散功（摩擦功）——摩擦、扰动、内部势差等不可逆因素把一部分机械能耗散为内能，这部分功不能输出给外界，故从总功中扣除（前面取负号），且 δwdiss 恒为正值。可逆过程无摩擦耗散且内部无势差，此时 p 既是系统压力也是边界上的外压力，于是

可逆过程

δq = du + pdv　⇒　q = Δu + ∫12pdv

（5）用焓表示的形式。由焓的定义 h = u + pv，取微分 dh = du + pdv + vdp，代入 δq = du + pdv（可逆）得

δq = dh − vdp　⇒　q = Δh − ∫12vdp

（6）适用条件小结。能量方程 q = Δu + w 对闭口系统的任何过程（可逆与不可逆）都成立（第一定律的普遍形式）；而 δq = du + pdv 只对可逆过程成立（此时 w = ∫pdv）。若还有动能、势能变化，必须回到一般式 Q = ΔU + ΔEk + ΔEp + W。

得分点：① 闭口（控制质量）系统定义；② 能量守恒式 Q = ΔU + ΔEk + ΔEp + W → 忽略宏观机械能 → q = Δu + w → δq = du + δw；③ 总功分解 δw = pdv − δwdiss（δwdiss ≥ 0 为耗散功）；④ 可逆时才可写 δq = du + pdv；⑤ 焓形式 δq = dh − vdp。一句话结论：q = Δu + w 普遍成立，w = ∫pdv 只对可逆过程成立。
易错点

① 把 w = ∫pdv 当成普遍式：不可逆过程中 w ≠ ∫pdv，多了耗散功这一项（且数值上还要用外力计算）。② 内能 u 的绝对值没有物理意义，不要写“系统含有多少内能”，只写 Δu。③ 符号规定必须交代：这里取 工质吸热 q 为正、对外作功 w 为正，与 δq = du + pdv 一致；若改用“外界对工质作功为正”，则方程写成 q = Δu − w，务必前后统一。

第 5 题　吉布斯方程（u、h 形式）
写出并说明吉布斯方程，给出内能形式与焓形式。

（1）方程形式。吉布斯（Gibbs）方程是可逆过程下第一定律与第二定律的联合表达式，它把只有状态参数的微分联系了起来：

u 形式

du = Tds − pdv

h 形式

dh = Tds + vdp

（2）推导。由可逆过程的第一定律与第二定律：

①　δq = du + pdv　（可逆，无耗散）

②　δq = Tds　（可逆过程的熵定义式）

③　两式消去 δq：du = Tds − pdv　——u 形式。

④　再对 h = u + pv 取微分：dh = du + pdv + vdp，把 ③ 代入即得 dh = Tds + vdp　——h 形式。

（3）由方程直接得到的结论（考试常考）。

① 定熵过程 ds = 0 ⇒ du = −pdv，即绝热可逆过程中内能的减少全部用于对外作容积功（w = −Δu）。
② 定容过程 dv = 0 ⇒ du = Tds，即 (∂u/∂s)v = T。
③ 定压过程 dp = 0 ⇒ dh = Tds，即 (∂h/∂s)p = T。
④ 定熵过程 ds = 0 ⇒ dh = vdp，即绝热可逆稳定流动中技术功 wt = −∫vdp = −Δh。

（4）由方程得到的偏导数（便于记忆）。

(∂u/∂v)s = −p　；　(∂u/∂s)v = T　；　(∂h/∂p)s = v　；　(∂h/∂s)p = T

（5）意义。吉布斯方程的左右两边都是状态参数的微分（全微分），因此它对任意两状态之间都成立，与过程是否可逆无关（推导时用了可逆条件，但结果只含状态参数，故可作为状态参数间的普遍关系使用）。它是导出马克斯韦尔关系、cp − cv 关系、Tds 方程等全部热力学微分关系的基础。

（6）由它导出的两个常用 Tds 方程（第一、第二 Tds 方程）。把 du = cvdT + [T(∂p/∂T)v − p]dv 代入 u 形式，得

第一 Tds 方程：Tds = cvdT + T(∂p/∂T)v dv　；　第二 Tds 方程：Tds = cpdT − T(∂v/∂T)p dp

对理想气体 pv = RgT，即化为后面第 13、15 题反复使用的 ds = cvdT/T + Rgdv/v 与 ds = cpdT/T − Rgdp/p。

得分点：① u 形式 du = Tds − pdv；② h 形式 dh = Tds + vdp；③ 推导两步（δq=du+pdv 与 δq=Tds 消 δq；焓定义微分）；④ 由它读出的定熵/定容/定压结论。一句话结论：吉布斯方程是“可逆过程条件下导出的、但只含状态参数”的普遍微分关系，是全部热力学微分关系的出发点。
易错点

① 符号写反：u 形式中 pdv 前是负号，h 形式中 vdp 前是正号——记忆口诀“内能看容积（负），焓看压力（正）”。② 用 δq = Tds 时必须是可逆过程（或两状态之间可逆路径），不可逆过程 δq < Tds。③ 不要写成 dq = Tds：q 是过程量，其微元必须写 δq（或 đq），而 ds 是全微分。

第 6 题　推导 δq + δwdiss = Tds
由第一定律与第二定律推导 δq + δwdiss = Tds，并说明各项含义。

（1）出发点：两条定律。

第一定律（任何过程）：δq = du + δw　；　第二定律（熵的普遍定义）：ds = δqrev/T，且对同两状态 δq ≤ Tds（可逆取等号）

（2）把总功分解为容积功与耗散功。闭口系统通过边界对外作出的总功中，一部分是容积变化功 pdv（可对外输出、可利用），另一部分是摩擦、涡流、内部势差等不可逆因素造成的耗散功（摩擦功） δwdiss——它把一部分机械能就地耗散为内能、不能输出，故应从总功中扣除：

δw = pdv − δwdiss　（δwdiss ≥ 0，可逆过程为零）

（3）推导。把上式代入第一定律，再与吉布斯方程联立，消去 du 与 pdv：

①　δq = du + δw = du + pdv − δwdiss

②　移项，把不可逆项单独移到左边：du + pdv = δq + δwdiss

③　由吉布斯方程（可逆关系式，但只含状态参数，故对任意两状态都成立）：du = Tds − pdv ⇒ Tds = du + pdv

④　把 ② 代入 ③ 的右边：

结果

Tds = δq + δwdiss　（即 δq + δwdiss = Tds）

（4）物理含义与几点说明。

①　δq 项：由外界传热引起的熵变（熵流）。对系统加热使 s 增大，放热使 s 减小。

②　δwdiss 项：由不可逆性引起的熵变（熵产）。耗散功是机械能不可逆地退化为内能的过程，它总是使熵增大（δwdiss ≥ 0），这一项与外界是否传热无关。

③　可逆过程 δwdiss = 0，方程退化为 δq = Tds（可逆过程的熵定义式）。

④　绝热过程 δq = 0，则 ds = δwdiss/T ≥ 0：绝热过程熵只增不减（可逆绝热即定熵）。

⑤　该式与第二定律另一写法 ds = δq/T源 + δsg（δsg ≥ 0 为熵产）完全一致：比较两式得 δsg = δwdiss/T，把熵产与机械能损失（耗散功）定量联系起来。

推论

δsg = δwdiss / T ≥ 0　；　不可逆过程 δq < Tds（因 δwdiss > 0）

得分点：① 起手写 δq = du + δw 与 du = Tds − pdv；② 关键一步 δw = pdv − δwdiss（δwdiss ≥ 0，把不可逆性单独提出）；③ 代入消去 du、dv 得 Tds = δq + δwdiss；④ 指出 δq 是熵流、δwdiss 是熵产的来源且恒 ≥ 0；⑤ 可逆时退化为 δq = Tds，绝热时 ds ≥ 0。一句话结论：熵变 = 传热引起的熵流 + 不可逆耗散引起的熵产，后者永远不会为负。

第 7 题　一个入口一个出口稳定流动开口系统能量方程的两种形式（助记导出）
写出一个入口、一个出口稳定流动开口系统能量方程的两种形式，并说明其助记方法。

（1）系统简图。取包围设备的虚线为控制体（开口系统），工质由截面 1 流入、截面 2 流出，设备对外输出轴功 ws，外界向工质传热 q。

（2）进、出口工质携带的能量。单位质量工质流入（或流出）控制体时带入（带出）的能量为

e = u + pv + ½c2 + gz = h + ½c2 + gz

其中 u + pv = h 是内能与流动功之和。流动功（推入功 p1v1 与推出功 p2v2 的代数和）为 p2v2 − p1v1，它是维持工质连续流经控制体所必须付出的代价。把内能与流动功合并成焓，是“开口系能量方程比闭口系多出流动功、因而自然出现焓”的关键。

（3）形式一（焓形式，标准形式）。取控制体，对稳定流动（进、出口状态及流量不随时间变化），由能量守恒与质量守恒 qm1 = qm2 = qm，单位质量工质有

开口系标准式

q = Δh + ½Δc2 + gΔz + ws

式中 Δh = h2 − h1，Δc2 = c22 − c12，Δz = z2 − z1，ws 为轴功（对外作功为正）。这是第一种形式。

（4）形式二（用内能、不含 u、h 的形式）。由 h = u + pv 代入上式：

q = Δu + (p2v2 − p1v1) + ½Δc2 + gΔz + ws

（5）形式三（技术功形式）。定义技术功为动能差、势能差与轴功之和：

技术功定义

wt = ½Δc2 + gΔz + ws

于是能量方程写成极为简洁的形式，且对可逆过程有 wt = −∫12vdp：

技术功形式

q = Δh + wt　；　可逆时 wt = −∫12vdp　（p-v 图上技术功为过程线左侧的面积）

它与闭口系统方程 q = Δu + ∫pdv 形式完全对称，二者的关系为

wt = q − Δh = (Δu + w) − (Δu + Δ(pv)) = w − Δ(pv)　；　可逆时 wt = w − Δ(pv) = ∫pdv − Δ(pv) = −∫vdp

（6）助记导出（考试“助记法”）。

助记：两种形式互换，只换“一对字母”

①　闭口系 ↔ 开口系：q = Δu + ∫pdv（闭口）　→　q = Δh + wt（开口）。把 u → h、pdv → −vdp（即 ∫pdv → −∫vdp）即成对替换，这就是“两种形式”。

②　口诀“内能配容积，焓配压力”：u 与 v 配对出现在闭口系，h 与 p 配对出现在开口系；微分号互换 v 与 p 时符号变号（因 d(pv) = pdv + vdp 的分拆）。

③　“流动功被焓吞掉”：开口系比闭口系多出进、出口流动功 p2v2 − p1v1；把它与 Δu 合并，正好得到 Δh——这就是开口系方程出现焓、闭口系出现内能的根本原因。

④　简化口诀“绝热、不动、不差”：绝热 q = 0；无轴功、无转动 ws = 0；忽略动能势能差 ½Δc2 = gΔz = 0。多数热工设备（换热器、混合室、节流阀）正是靠这三条化简到只剩焓差。

（7）稳定流动的附加条件（写全才给满分）。① 进、出口工质的质量流量相等且不随时间变化；② 进、出口截面上工质的状态参数及流速不随时间变化；③ 控制体内总储存能不随时间变化（不随时间积累）；④ 控制体与外界交换的热量与功不随时间变化。

得分点：① 写出稳定流动假设；② 形式一 q = Δh + ½Δc2 + gΔz + ws；③ 形式二 q = Δu + Δ(pv) + ½Δc2 + gΔz + ws（不含 h）或技术功形式 q = Δh + wt、wt = −∫vdp；④ 助记法：u↔h、pdv↔−vdp 成对替换（流动功被焓“吞掉”）。一句话结论：开口系标准式是“焓差 + 动能差 + 势能差 + 轴功”，与闭口系“内能差 + 容积功”成对偶记忆。
易错点

① 忘记写 ½Δc2、gΔz 就直接写 q = Δh + ws——只有在忽略宏观动能、势能差时才成立（喷管、扩压管恰恰不能忽略）。② 把 ws 与 wt 混用：wt = ½Δc2 + gΔz + ws。③ 技术功 wt = −∫vdp 只对可逆过程成立；不可逆时轴功大于该值。④ p-v 图上 ∫pdv 是过程线下方面积，−∫vdp 是过程线左方面积，两者不可混画。

第 8 题　热交换器：简图、能量方程、过程特征
画出热交换器（换热器）的系统简图，写出能量方程并说明过程特征。

（1）系统简图（以逆流换热器为例）。取虚线为控制体，两种流体在壁面两侧互不混合，高温流体 1→2 放热，低温流体 3→4 吸热。对每一种流体各自取一个控制体：

（2）能量方程。热交换器对外无轴功、忽略宏观动能与势能差（ws = 0，½Δc2 = gΔz = 0），由开口系标准式得

一般式

q = Δh = h2 − h1

对高温流体（放热，q1 < 0）：q1 = h2 − h1 = cp(T2 − T1)；对低温流体（吸热，q3 > 0）：q3 = h4 − h3 = cp(T4 − T3)。对整个换热器（绝热外壳）作能量平衡：

热平衡式

qm1(h1 − h2) = qm3(h4 − h3)　；　即 Φ = qm1cp1(T1 − T2) = qm3cp3(T4 − T3)

（3）过程特征。

①　两种流体分别进行定压过程（p1 ≈ p2、p3 ≈ p4，忽略流道阻力），故 q = Δh，且 ws = 0。因此换热器中流体吸收（放出）的热量等于焓的变化——这就是“定压过程 qp = Δh”的工程意义。

②　能量传递形式是热量（通过壁面导热与对流），不是功；流体之间只有热量的传递，无机械功的输入输出。

③　壁面两侧存在温差 ΔT = T热 − T冷 > 0，是传热的推动力，也正是不可逆性的来源：q 由高温流向低温，熵产 δsg > 0，故过程不可逆；逆流布置可使全段平均传热温差更均匀。极限情况：若换热面积无限大且逆流，T2 可趋近 T3、T4 趋近 T1，即传热温差趋近于零。

④　过程的方向：热流体温度必然下降（T2 < T1），冷流体温度必然上升（T4 > T3），绝不会自发反向。

⑤　稳定流动：各截面状态、流量与换热量均不随时间变化，控制体内无能量积累。

得分点：① 简图标出两股流体、进/出口编号与方向；② 能量方程 q = Δh（ws=0、动能势能差忽略）＋整体热平衡式；③ 过程特征：定压过程各股流体、只传热不传功、温差引起不可逆、热流体降温冷流体升温。一句话结论：换热器是“定压吸/放热”设备，其能量方程就是 q = Δh，对应定压过程 qp = Δh。
易错点

① 误写 q = Δu：换热器是开口系，进出口有流动功，必须用焓。② 忘记“两种流体各取一个控制体”与“整体热平衡”。③ 把换热器的“定压”理解为压力绝对不变——实际有流动阻力，p2 略小于 p1，只是换热计算中按定压处理。④ 说“换热器可逆”不对：壁面两侧有温差，必然是不可逆过程。

第 9 题　喷管、扩压管：两种形式能量方程、过程特性
画出喷管（扩压管）简图，写出两种形式的能量方程，并说明过程特性。

（1）系统简图。喷管是使气流降压增速的通道（p2 < p1，c2 > c1）；扩压管是使气流增速降压反向的设备，即降速增压（c2 < c1，p2 > p1）。两者结构上互为反向，能量方程完全相同。

（2）能量方程的两种形式。喷管、扩压管中：与外界绝热（q = 0）、无轴功（ws = 0），但宏观动能变化必须保留，位能变化一般可忽略（gΔz ≈ 0）。由开口系标准式：

形式一（焓 + 动能）

h1 + ½c12 = h2 + ½c22　⇒　½(c22 − c12) = h1 − h2

即“进、出口截面上工质的焓与动能之和（滞止焓）相等”，这是最常用的形式。若取进口速度很小（c1 ≈ 0），则 c2 = √(2(h1 − h2))。

形式二（内能 + 流动功 + 动能）

u1 + p1v1 + ½c12 = u2 + p2v2 + ½c22

对可逆（定熵）流动还有技术功形式：q = Δh + wt = 0 ⇒ wt = −Δh = ½Δc2，即技术功全部转变为气流的动能增加；且 wt = −∫12vdp > 0（因 dp < 0）。

（3）过程特性。

①　绝热：q = 0（流速高、停留时间短，来不及与外界换热）。

②　无轴功：ws = 0（只有管道，无叶轮）；动能与焓之间直接相互转换。

③　压力与速度的反向变化：喷管 p2 < p1、c2 > c1；扩压管 p2 > p1、c2 < c1。故喷管是降压增速，扩压管是降速增压。

④　理想（可逆）情况为定熵过程：s2 = s1，T-s 图上是一条垂直线（喷管降温，T2 < T1）；实际有摩擦时 s2 > s1，出口速度减小、出口温度略高，过程不可逆。

⑤　流速与截面积的关系：由连续性方程 qmv = cA 与能量方程 dc/c = −dp/(ρc2) 可得 dA/A = (dp/ρc2)(Ma2 − 1)。故亚声速（Ma < 1）时用渐缩喷管；超声速（Ma > 1）时必须用渐缩–渐扩（拉瓦尔）喷管，喉部达临界压力 pcr。

⑥　扩压管：与喷管过程相反，动能转变为焓（压力升高），理想情况同样为定熵过程（T-s 图上的垂直线，气流沿熵不变方向升温升压）。

得分点：① 简图（喷管收缩形、标进出口与压力、速度变化方向）；② 形式一 h1+½c12 = h2+½c22；③ 形式二含内能与流动功的式子；④ 过程特性：绝热、无轴功、降压增速（扩压管相反）、理想为定熵（s 不变垂直线）、实际有摩擦不可逆 s2>s1。一句话结论：喷管与扩压管都是“绝热、无轴功”的流道，其能量方程就是焓 + 动能守恒。
易错点

① 绝对不能把 ½Δc2 当小量忽略——这正是喷管问题的核心项。② 写“定熵过程”时要注意：只有可逆绝热才是定熵；实际喷管 q=0 但 s2 > s1。③ 不要漏掉“无轴功”这一条；也不要写“对外作功”，喷管不输出轴功，它的“收获”是气流动能。④ 分清方向：喷管降压增速，扩压管降速增压，不要背反。

画出绝热混合过程的简图，写出能量方程并说明过程特性。

（1）系统简图。两股（或数股）流体 1、2 在绝热混合室中混合后由 3 流出，混合室对外无轴功，与外界绝热。

（2）能量方程。绝热 q = 0，无轴功 ws = 0，忽略宏观动能与势能差，取虚线为控制体（稳定流动）：

一般式

q = Δh + ½Δc2 + gΔz + ws　⇒　0 = h3 − hin（每千克）

按总质量流量的能量守恒（进入 = 离开）写成混合式：

能量方程

qm1h1 + qm2h2 = qm3h3

由质量守恒 qm3 = qm1 + qm2，可解出出口焓与出口温度（理想气体 h = cpT，取 cp 为常数或平均值）：

混合温度

h3 = (qm1h1 + qm2h2)/(qm1 + qm2)　；　T3 = (qm1cp1T1 + qm2cp2T2)/(qm1cp1 + qm2cp2)

（3）过程特征。

①　绝热 + 无轴功：q = 0、ws = 0，故混合前后总焓守恒（Σqmh = 常数），出口焓为进口焓的质量加权平均值。

②　不可逆过程：混合由两方面的不可逆因素组成——温差传热（两股流体温度不同，直接接触传热）与工质混合（浓度差引起的扩散混合）。因此 s3 > Σsin，熵产大于零，是典型的不可逆过程；混合后不可能自发分离。

③　温度介于两进口温度之间：T3 必在 T1 与 T2 之间（可同种工质，也可不同种工质）。

④　压力取法：一般使 p1 = p2 = p3，以减少不可逆性（避免额外的节流与压差掺混损失）；若两股压力不同，则混合时还伴随节流掺混，不可逆性更大。

⑤　定压近似：混合室中压力基本不变，故 q = Δh 的定压关系仍可用于各股流体；T-s 图上各股流体近似沿定压线变化。

⑥　应用：喷水减温器、表面式与混合式加热器、燃气轮机燃烧室（燃料与空气混合燃烧）、空调送风混合箱、蒸汽减温减压器等。

（3）绝热时的简化式（最合适的形式）。取 q = 0、½Δc2 ≈ 0、gΔz ≈ 0：

绝热叶轮机械

ws = h1 − h2 = −Δh

压气机（耗功设备，以耗功为正来记）：wC = ws,in = h2 − h1 = cp(T2 − T1) > 0（理想气体定比热）。

透平机（作功设备）：wT = h1 − h2 = cp(T1 − T2) > 0。

（4）可逆（定熵）情况的形式。对可逆绝热（定熵）过程，由 dh = Tds + vdp 中 ds = 0 得 dh = vdp，于是

定熵

ws = −Δh = −∫12vdp = wt

即绝热可逆时轴功 = 技术功 = −∫vdp，在 p-v 图上为过程线左侧的面积。理想气体定熵过程代入 pvκ = 常数，得到常用的压气机耗功公式：

wC = h2 − h1 = cp(T2 − T1) = cpT1[(p2/p1)(κ−1)/κ − 1] = (κ/(κ−1))p1v1[(p2/p1)(κ−1)/κ − 1]

（5）为什么用焓形式而不用内能形式。压气机、透平机是典型开口系：工质连续流进流出，进出口存在流动功 p1v1、p2v2，把内能与流动功合并成焓后，方程变为 ws = −Δh，只含状态参数差，最便于计算；若用内能形式则需额外处理流动功项 p2v2 − p1v1，明显不便。故“开口系用焓”是这类题的最合适形式。

（6）过程特征。① 压气机：p2 > p1、v2 < v1、T2 > T1，耗轴功；理想为定熵，实际 s2 > s1（降温比不计），耗功大于定熵耗功。② 透平机：p2 < p1、T2 < T1，输出轴功；实际 s2 > s1，作功小于定熵作功。③ 两者都近似绝热稳态流动。

得分点：① 简图区分耗功（压气机）与作功（透平机）；② 一般式 q = Δh+½Δc2+gΔz+ws；③ 绝热简化式 ws = −Δh（压气机 wC = h2−h1、透平机 wT = h1−h2）；④ 定熵时可写 ws = wt = −∫vdp；⑤ 说明“开口系用焓最合适”的理由。一句话结论：叶轮机械的能量方程就是 ws = −Δh，轴功等于焓降（或焓升）。
易错点

① 符号方向：压气机耗功要写成 wC = h2 − h1 > 0，透平机作功写成 wT = h1 − h2 > 0，别把两者都写成 −Δh 后不加说明。② 忽略 ½Δc2 要说明理由（进出口流速相近），不能无声无息地删掉。③ 不可逆压缩仍满足 ws = −Δh，但此时 ws ≠ −∫vdp（多出耗散部分）。

第 12 题　绝热节流：简图、能量方程、T-s 图
画出绝热节流装置（孔板或节流阀）简图，写出能量方程并画出 T-s 图。

（1）系统简图。工质流经缩口（孔板、节流阀），因局部阻力使压力骤降。取缩口前后足够远的截面 1、2 为进、出口（截面 1–2 之间即控制体）。

（2）能量方程。节流过程与外界绝热（q = 0）、不输出轴功（ws = 0），进、出口截面一般取在管径相同处故 ½Δc2 ≈ 0，位能差 ≈ 0，由开口系标准式：

能量方程

q = Δh + ½Δc2 + gΔz + ws　⇒　h1 = h2

即绝热节流前后焓值相等，h = 常数（节流前后焓不变是节流过程的根本特征；但节流中缩口处的实际状态并不满足 h = 常数，能量在缩口处部分转为动能，故不能把整个节流过程当作等焓过程来求中间状态）。

（3）过程特征。

①　不可逆过程：气流在缩口处产生强烈涡流与摩擦，动能不可逆地耗散为内能，s2 > s1（熵增）。因此节流不是定熵过程，也不是可逆过程，只是“等焓”。

②　压力必然降低：p2 < p1（节流只能降压，不能升压）。

③　理想气体：温度不变。因理想气体 h = h(T)，h 不变则 T 不变（T1 = T2），在 T-s 图上是一条水平线（等温线 = 等焓线）。

④　实际气体：温度可能变化。因 h = h(T, p)，h 不变时 T 随 p 变化。定义绝热节流系数（焦耳–汤姆逊系数）：

节流系数

μJ = (∂T/∂p)h　；　μJ > 0 节流冷效应（T2 < T1）；μJ = 0 节流零效应（T 不变，对应转回温度）；μJ < 0 节流热效应（T2 > T1）

⑤　T-s 图上的画法：由 Tds = dh − vdp，令 dh = 0 得 ds = −(v/T)dp > 0（因 dp < 0），故状态点沿等焓线向右（s 增大）移动；对理想气体是水平线，对蒸汽等实际气体是向右下方（若为冷效应）的等焓线。在 h-s 图（莫里尔图）上则表现为一条水平线。

⑥　应用：测量湿蒸汽的干度（节流式量热计）、制冷装置中的节流降压（毛细管、膨胀阀）、蒸汽的减压减温、气体液化（林德循环）。

得分点：① 简图（缩口 + 截面 1、2）；② h1 = h2（绝热、无轴功、动能势能差可忽略）；③ 过程特征：不可逆（s2 > s1）、降压 p2 < p1、焓不变；④ T-s 图：理想气体为水平线（T 不变），实际气体按 μJ 判断升温或降温，状态点沿等焓线向右移动。一句话结论：绝热节流是“等焓但不等熵、不可逆且必定降压”的过程。
易错点

① 把节流说成“定熵过程”：错！绝热但强烈不可逆，熵增大。② 把“等焓”说成“等温”：只有理想气体才因 h 只随 T 而变温不变。③ 不要写“节流可以升压”。④ h = 常数只在截面 1、2 之间成立，缩口内部不能用。⑤ 节流系数 μJ = (∂T/∂p)h，注意是对压力求偏导（下标 h），不是对 p 求导后取倒数。

第 13 题　推导理想气体定熵过程特征公式
推导理想气体定熵（可逆绝热）过程的特征公式 pvκ = 常数、Tvκ−1 = 常数、Tp(1−κ)/κ = 常数。

（1）条件。理想气体、定比热（cp、cv 为常数）、可逆绝热（即定熵，ds = 0）。

（2）从熵方程出发。由理想气体熵变的微分式（可由吉布斯方程 du = Tds − pdv 与 du = cvdT、pv = RgT 得到）

ds = cv dT/T + Rg dv/v

定熵 ds = 0，两边积分（由上状态 1 积到下状态 2）：

cv ln(T2/T1) + Rg ln(v2/v1) = 0

（3）引入迈耶公式与比热比。由迈耶公式 cp − cv = Rg 及比热比 κ = cp/cv，把 Rg = cv(κ − 1) 代入上式并约去 cv：

ln(T2/T1) + (κ − 1) ln(v2/v1) = 0　⇒　ln[(T2/T1)(v2/v1)κ−1] = 0

特征式 1

Tvκ−1 = 常数　（即 T2/T1 = (v1/v2)κ−1）

（4）化为 p-v 关系。把状态方程 T = pv/Rg 代入上式，Rg 为常数可约去：

(pv)vκ−1 = 常数　⇒　

特征式 2

pvκ = 常数　（即 p2/p1 = (v1/v2)κ）

（5）化为 T-p 关系。由 Tvκ−1 = 常数 中消去 v：v = RgT/p，代入得 T(RgT/p)κ−1 = 常数，即 Tκp1−κ = 常数，两边开 κ 次方：

特征式 3

Tp(1−κ)/κ = 常数　（即 T2/T1 = (p2/p1)(κ−1)/κ）

这三个式子等价（任取一个，配合 pv = RgT 可推出另两个），通常记作定熵过程方程 pvκ = 常数，其指数 κ 称为定熵指数（绝热指数）。

（6）定熵过程的功与内能变化（配套结论）。绝热 q = 0，由第一定律：

w = −Δu = u1 − u2 = cv(T1 − T2) = (RgT1/(κ−1))[1 − (p2/p1)(κ−1)/κ] = (p1v1/(κ−1))[1 − (p2/p1)(κ−1)/κ]

技术功：wt = −Δh = cp(T1 − T2) = κw　（定熵过程 wt = κw，这是定熵过程的独有特征）

一般地，理想气体定熵时 T、p 同升同降、v 反向变化：膨胀（p2 < p1）则 T2 < T1、v2 > v1，对外作功靠消耗内能（温度下降）。

（7）对任意工质的推广。对任意工质，绝热可逆过程可用绝热压缩指数 κv = −(v/p)(∂p/∂v)s 表示过程方程 pvκv = 常数（κv 一般沿过程变化，不是常数）；对理想气体 κv = cp/cv = κ = 常数，上式才成为简单的幂函数形式。

得分点：① 明确条件（理想气体、定比热、可逆绝热 ds=0）；② 起点 ds = cvdT/T + Rgdv/v；③ 积分并用迈耶公式与 κ = cp/cv 化简得 Tvκ−1 = 常数；④ 用 pv=RgT 换成 pvκ = 常数 与 Tp(1−κ)/κ = 常数；⑤ 补充 w = −Δu、wt = κw。一句话结论：定熵过程方程 pvκ = 常数 是“可逆绝热 + 理想气体 + 定比热”三条件下的必然结果。
易错点

① 忘记“可逆”二字：绝热不可逆过程 s 增大，pvκ = 常数不成立（此时 pvn = 常数 中 n > κ）。② 指数不要写反：Tvκ−1（对 v）与 Tp(1−κ)/κ（对 p，指数为负）。③ Rg = cv(κ−1) = cp(κ−1)/κ，用错会把 (κ−1) 位置搞反。④ 三个特征式只对同一定熵过程的两状态之间成立，不能跨过程乱用。

第 14 题　p-v 图：一组定温线、一组定熵线（反映二者关系特征）
在 p-v 图上画出一组定温线与一组定熵线，并说明二者的关系特征。

（1）过程方程与斜率公式。

定温过程：pv = 常数　⇒　斜率 (∂p/∂v)T = −p/v

定熵过程：pvκ = 常数　⇒　斜率 (∂p/∂v)s = −κp/v

（2）两组曲线在 p-v 图上的形状与相对陡缓。

（3）关系特征。

①　同一点处定熵线比定温线陡：因 κ = cp/cv > 1，故 |(∂p/∂v)s| = κ|∂p/∂v)T|，即斜率是定温线的 κ 倍（对双原子气体 κ ≈ 1.4，约 1.4 倍）。

②　两条线都从左上向右下下降（p ↓ v ↑ 或反之），但定熵线下降得更快；二者只能相交于一点，不会相切。

③　同一点上，定温线的切线与 v 轴围成的面积（该压力的 pdv 面积）大于定熵线的对应面积，说明同样膨胀到同一容积，定温过程的膨胀功大于定熵过程（定温过程还同时吸热，而定熵过程的膨胀功全部来自内能下降）。

④　两族曲线的“正交性”：由 du = Tds − pdv，梯度关系为 (∂p/∂v)s = κ(∂p/∂v)T、(∂v/∂p)T = −v/p，可见定熵过程在 p-v 图上的陡缓正是能量方程与状态方程联合作用的结果：定温过程要维持 T 不变必须边走边放热，而定熵过程不允许传热，压力必须掉得更快。

⑤　两族线的相对位置：过同一状态点作两条线，在膨胀（v 增大）方向上，定熵线在定温线下方（压力更低）；在压缩（v 减小）方向上，定熵线在定温线上方（压力更高）——这正是“定熵压缩升温更高、定熵膨胀降温”的几何表现，也是压气机采用中间冷却、等温压缩耗功最小的原因。

得分点：① 写出两过程方程；② 斜率公式 (∂p/∂v)T = −p/v 与 (∂p/∂v)s = −κp/v；③ 结论：定熵线比定温线陡，陡度倍数 = κ（>1）；④ 图上画出两族线并说明膨胀方向上定熵线在下方、压缩方向上在上方。一句话结论：p-v 图上定熵线比定温线陡 κ 倍，因为定熵过程不允许用传热“补偿”压力下降。
答题模板（“画图 + 关系特征”类）

四件套：1过程方程（pvn = 常数）；2斜率公式（求导结果，含符号）；3数值比较（谁陡、陡几倍，用 κ、n 表示）；4几何位置描述（同一点处谁在上、谁在下；沿哪个方向平移得到另一条线）。

第 15 题　T-s 图：一组定压线、一组定容线（反映垂直、水平关系特征）
在 T-s 图上画出一组定压线与一组定容线，并说明其垂直、水平关系特征。

（1）过程方程与斜率公式。由理想气体熵变式 ds = cpdT/T − Rgdp/p = cvdT/T + Rgdv/v，分别令 dp = 0、dv = 0：

定压线：ds = cp dT/T　⇒　斜率 (∂T/∂s)p = T/cp

定容线：ds = cv dT/T　⇒　斜率 (∂T/∂s)v = T/cv

积分形式（用于画线）：定压线 s2 − s1 = cpln(T2/T1)，定容线 s2 − s1 = cvln(T2/T1)，故二者都是对数曲线（在对数坐标纸上为直线）。

（2）关系特征。

①　定容线比定压线陡：因 cv < cp，同一 T 下 (∂T/∂s)v = T/cv > (∂T/∂s)p = T/cp，陡度倍数 = cp/cv = κ（即定容线的斜率是定压线的 κ 倍）。

②　两组线都自左下向右上（T ↑ s ↑），曲率随 T 升高而变缓（斜率 ∝ T）。

③　垂直关系：可逆绝热（定熵）过程是 s = 常数的垂直线，它与水平轴垂直，与每一族定压线（或定容线）各交于一点；可逆定温过程（含两相区的定温定压汽化）是 T = 常数的水平线，与每一族线也各交于一点。

④　水平关系：定温线为水平线，而由 q = ∫Tds，过程线下方的面积就是该过程吸收的热量；水平线下的矩形面积即定温过程的换热量 q = TΔs。

⑤　两族的相对位置：过同一点，定容线在定压线左侧（同一温度下 sv < sp）：由 sp − sv = cplnT + 常数 − (cvlnT + 常数) 及同 T、同 p 时 v < vp 可直接看出；也可以由“加热升温、膨胀作功”理解：定容加热不膨胀、不作功，熵增更大，故同样温升下定容线更靠左、更陡。

同点比较

sp(T) − sv(T) = Rg ln(vp/v) > 0　（同一状态点上，定压线在定容线右侧）

⑥　用途：T-s 图上“面积 = 热量”，故可直观判断过程吸热还是放热（曲线向右 s 增大则吸热，向左则放热）；同时由 q = Δu + w 可知定容线下的面积等于 Δu（因 w = 0），定压线下的面积等于 Δh（因 wt = 0），这也是常考的读图结论。

得分点：① 斜率公式 (∂T/∂s)p = T/cp、(∂T/∂s)v = T/cv；② 定容线比定压线陡 κ 倍，且在同点左侧；③ 定熵线是垂直线（s = 常数），定温线是水平线（T = 常数）；④ 面积 = 热量（定容线下 = Δu，定压线下 = Δh）。一句话结论：T-s 图上“垂直线 = 定熵、水平线 = 定温”，定容线比定压线更陡且更靠左。
易错点

① 把斜率记反：T-s 图上斜率是 T/c，c 在分母，所以 cv 小的定容线更陡；而 p-v 图上斜率含 κ 在分子，定熵线更陡。两个图的“谁更陡”结论恰好都用同一个 κ > 1 解释，但公式形式不同，别混。② 不要漏“同一点”这个前提：不同状态点上的两条线不能直接比陡缓。③ 定温线只有在理想气体或两相区才同时是定压线（两相区 T、p 一一对应）；单相区定温线 ≠ 定压线。

第 16 题　p-v 图、T-s 图：多变过程线斜率公式推导
推导多变过程线在 p-v 图与 T-s 图上的斜率公式。

（1）多变过程方程与指数定义。多变过程满足 pvn = 常数，n 称多变指数；理想气体定比热时，全部四个基本过程都是它的特例：

特例

n = 0 定压　|　n = 1 定温　|　n = κ 定熵　|　n = ±∞ 定容

（2）p-v 图上的斜率。设多变过程 pvn = C1，即 p = C1v−n，直接求导：

(∂p/∂v)n = −nC1v−n−1 = −n(pvn)v−n−1 = −np/v

结论 1

(∂p/∂v)n = −n p/v　（负号表示 p 与 v 反向变化）

也可用隐函数微分法（便于在图上标“斜率 = 切线偏角”）：对 pvn = 常数 取对数 lnp + nlnv = 常数，微分得 dp/p + n dv/v = 0，即 dp/dv = −np/v，与上式一致。斜率只与 n、当前状态点的 p/v 有关，故在 p-v 图上同一状态点处，各过程的陡缓仅由 n 决定：n 越大，线越陡。

（3）T-s 图上的斜率。由理想气体熵变式（第二 Tds 方程，定比热）

ds = cp dT/T − Rg dp/p

对多变过程 lnp + nlnv = 常数 微分得 dp/p = −n dv/v；再对 pv = RgT 取对数微分：dp/p + dv/v = dT/T，两式联立消去 dv/v：

dp/p = −n(dT/T − dp/p)　⇒　(1 − n)dp/p = −n dT/T　⇒　dp/p = [n/(n − 1)] dT/T

代回熵变式并利用迈耶公式 Rg = cp − cv 与 κ = cp/cv：

ds = cp dT/T − Rg[n/(n − 1)] dT/T = {cp − Rgn/(n − 1)} dT/T

整理括号：cp(n − 1) − Rgn = n(cp − Rg) − cp = ncv − cp = cv(n − κ)，于是

ds = cv (n − κ)/(n − 1) · dT/T　⇒　dT/ds = (n − 1)/[cv(n − κ)] · T

结论 2

(∂T/∂s)n = T(n − 1)/[cv(n − κ)]　（可写成 T/cn，其中 cn = cv(n − κ)/(n − 1) 即多变比热）

（4）由斜率公式读出的图形特征（考试重点）。

①　p-v 图上斜率 = −np/v：n = 0 水平线（定压）、n = 1 双曲线（定温）、n = κ 更陡的双曲线（定熵）、n = ∞ 时 −np/v → ∞ 为竖直线（定容）。故一族多变线在 p-v 图上按 n 由小到大“扇形展开”：水平 → 缓降 → 陡降 → 垂直。右半区（v 大）任意两条多变线中 n 大者更陡；左半区（v 小）则以定温线为界发生陡缓互换（因 p ∝ v−n 在 v 小时衰减更快），这一细节常被作为思考题。

②　T-s 图上斜率 = T/cn，而 cn = cv(n−κ)/(n−1)。分母 cn 的符号决定曲线走向：n < 1 或 n > κ 时 cn > 0，T 随 s 增大而升高（向右上）；1 < n < κ 时 cn < 0，T 随 s 增大而下降（向右下，此时“加热反而降温”，例如 n = 1.2 的膨胀）。

③　特例核对：n = κ ⇒ cn = 0 ⇒ 斜率无穷大 ⇒ 垂直线（定熵）；n = 1 ⇒ cn = cv(1−κ)/(0) → ±∞ ⇒ 斜率为 0 ⇒ 水平线（定温）；n = 0 ⇒ 斜率 T/cp（定压线）；n = ∞ ⇒ 斜率 T/cv（定容线，最陡）。与第 15 题结论完全一致。

④　一般地，斜率可统一写成 T/c（c 为该过程的比热）：c = cp（定压）、cv（定容）、∞（定温 Tds = dq 中 dT = 0）、0（定熵）。这是最便于记忆的统一式。

统一式

(∂T/∂s)过程 = T/c　；　(∂p/∂v)过程 = −(cp/cv′)p/v 型（多变时 cp/cv′ → n）

得分点：① p-v 图斜率 (∂p/∂v)n = −np/v（推导：p = Cv−n 求导或取对数微分）；② T-s 图斜率 (∂T/∂s)n = T(n−1)/[cv(n−κ)] = T/cn（推导：ds = cpdT/T − Rgdp/p 配合 dp/p = [n/(n−1)]dT/T）；③ 用四个特例（n = 0、1、κ、∞）核对水平/垂直/最陡；④ cn 的符号决定 T-s 图上曲线走向。一句话结论：p-v 图斜率由 n 决定（n 大则陡，n = ∞ 垂直），T-s 图斜率统一为 T/c（c 为该过程比热）。
答题模板（斜率推导题）

对 p-v 图：① 写 pvn = C；② 两边取对数再微分（最不易错）；③ 整理成 −np/v。
对 T-s 图：① 写 ds = cpdT/T − Rgdp/p；② 由 pvn = C 与 pv = RgT 联立求 dp/p 与 dT/T 的关系；③ 代入整理，用 Rg = cv(κ−1) 化为 cv(n−κ)/(n−1)；④ 用四个特例验证。

第 17 题　多变比热计算式，并进一步求 q、w、wt
推导多变比热的计算式，并进一步给出多变过程的 q、w、wt。

（1）多变比热的定义。多变比热定义为多变过程中“加入的热量与温升之比”：cn = δq/dT（沿多变过程 pvn = 常数）。

（2）推导。取可逆过程能量方程（含耗散时用第 6 题结论，可逆时耗散项为零）：

①　δq = du + pdv = cvdT + pdv　（理想气体 du = cvdT）

②　由 pv = RgT 微分：pdv + vdp = RgdT；由 pvn = 常数 得 vdp = −npdv，代入得

(1 − n)pdv = RgdT　⇒　pdv = RgdT/(1 − n) = −RgdT/(n − 1)

③　代回 ①：δq = cvdT − RgdT/(n − 1) = [cv − Rg/(n − 1)]dT

④　用迈耶公式 Rg = cv(κ − 1) 代入并通分：

cn = cv − cv(κ − 1)/(n − 1) = cv[(n − 1) − (κ − 1)]/(n − 1)

多变比热

cn = cv (n − κ)/(n − 1)　[ J/(kg·K) ]

（3）四个基本过程核对（用 cn 一网打尽）。

过程ncn = cv(n−κ)/(n−1)物理解释
定压0cv·(−κ)/(−1) = κcv = cp等于定压比热
定温1±∞吸热而温度不变
定熵κ0吸热为零
定容±∞cv等于定容比热

（4）q、w、wt 的计算（全部用首末温差与 n 表示）。

热量

q = cnΔT = cv(n − κ)/(n − 1) · (T2 − T1)

膨胀功

w = q − Δu = cnΔT − cvΔT = −Rg(T2 − T1)/(n − 1) = Rg(T1 − T2)/(n − 1)

也可由积分式核对：w = ∫12pdv = p1v1[1 − (p2/p1)(n−1)/n]/(n − 1) = (RgT1/(n−1))[1 − (v1/v2)n−1]

技术功

wt = nw = nRg(T1 − T2)/(n − 1) = −Δh + q ＝ 可逆时 −∫vdp

（5）几个必须记住的关系。

① wt = nw（多变过程）；特别地，定熵 wt = κw，定温 wt = w（n = 1）。
② q : w : Δu = (n − κ) : (1 − n) : (κ − 1)　（三者之比只与 n、κ 有关，与状态点无关）。
③ q/w = (n − κ)/(1 − n)　；　Δu/w = (κ − 1)/(1 − n)。
④ 定温过程（n = 1）：q = w = RgTln(v2/v1) = RgTln(p1/p2)，Δu = 0。
⑤ 定熵过程（n = κ）：q = 0，w = −Δu，wt = −Δh = κw。
⑥ 定容过程（n = ±∞）：w = 0，q = Δu = cvΔT，wt = −vΔp。
⑦ 定压过程（n = 0）：w = pΔv = RgΔT，q = Δh = cpΔT，wt = 0。

（6）吸热范围的判据。由 q = cv(n−κ)/(n−1)·ΔT 与 T-s 图（ds = cndT/T）可得：膨胀（ΔT < 0）时，1 < n < κ 的过程吸热且同时膨胀降温（cn < 0，q > 0）；n > κ 时膨胀过程放热；n < 1 时膨胀升温吸热。这正是 T-s 图上多变线“扇形展开”中走向变化的根源。

得分点：① 定义 cn = δq/dT；② 推导：δq = cvdT + pdv 与 (1−n)pdv = RgdT 联立；③ 结果 cn = cv(n−κ)/(n−1)，并核对四个特例；④ q = cnΔT、w = Rg(T1−T2)/(n−1) = RgT1[1−(p2/p1)(n−1)/n]/(n−1)、wt = nw；⑤ 比值关系 q:w:Δu = (n−κ):(1−n):(κ−1)。一句话结论：多变过程的一切过程量都由“温差 + 多变指数”两个因子决定。
易错点

① n = 1 时 cn 公式出现 0/0 型，必须单独处理（用 q = w = RgTln(v2/v1)）。② w、wt、q 的正负与 n、ΔT 的符号都有关，写答案时注明符号约定。③ cn 不是状态参数也不是物性常数，它随 n 变化，且可正、可负、可为零、可为无穷（定温）。④ wt = nw 只对多变过程（含四个特例）成立，不可乱用。

第 18 题　p-v 图、T-s 图：卡诺正、逆循环，η、ε1、ε2
在 p-v 图与 T-s 图上画出卡诺正循环与逆循环，推导 ηt、ε1、ε2。

（1）组成与循环图。卡诺循环由两个可逆定温过程与两个可逆绝热（定熵）过程组成，工质在恒温热源 T1 与恒温冷源 T2（T1 > T2）之间工作。

（2）正循环（热机）的热效率。四个过程的热量（定熵过程无热交换）：

q1 = RgT1ln(v2/v1) > 0（定温吸热）；　q2 = RgT2ln(v3/v4) < 0（定温放热，|q2| = RgT2ln(v3/v4)）

由两个定熵过程 T1v2κ−1 = T2v3κ−1 与 T1v1κ−1 = T2v4κ−1 相除得 v2/v1 = v3/v4，故

|q2|/q1 = T2/T1

卡诺热效率

ηt,C = w0/q1 = (q1 − |q2|)/q1 = 1 − T2/T1

在 T-s 图上更直接：q1 = T1Δs（上水平线下矩形面积）、|q2| = T2Δs（下水平线下面积）、w0 = (T1 − T2)Δs（矩形面积），于是 ηt,C = (T1−T2)/T1。

（3）逆循环（制冷机与热泵）。循环方向反向：消耗净功 w0，从低温热源吸热 q2，向高温热源放热 q1 = q2 + w0。

制冷系数

ε1 = q2/w0 = q2/(q1 − q2) = T2/(T1 − T2)

供暖系数（热泵）

ε2 = q1/w0 = q1/(q1 − q2) = T1/(T1 − T2)

两者关系：ε2 = ε1 + 1（因 q1 = q2 + w0）。注意 ε1、ε2 均可大于 1，甚至远大于 1（如 T1 = 300 K、T2 = 270 K 时 ε1 = 9、ε2 = 10），这与热效率 ηt < 1 并不矛盾（评价的“收益/代价”不同）。

（4）结论与讨论。

①　卡诺循环效率只取决于两个热源的温度 T1、T2，与工质性质无关；ηt,C < 1，且只有在 T2 = 0 K 或 T1 → ∞ 时才等于 1，故不可能把热量连续全部转变为功（第二定律的 Kelvin 表述）。

②　提高 ηt 的方向：提高 T1、降低 T2；由于 T2 受环境温度限制，实际主要靠提高 T1。

③　卡诺循环在 T-s 图上是矩形，面积 = 净功；T1 与 T2 越接近，矩形越扁，ηt 越低。

④　两个定温过程需要无限大换热面积、且活塞速度受限制，故实际无法完全实现卡诺循环，其价值在于给出了效率的理论上限（见第 19 题卡诺定理）。

⑤　广义（概括性）卡诺循环：若热源温度随换热过程变化（变温热源），可证明其热效率仍为 ηt = 1 − T2m/T1m，其中 T1m、T2m 为换热过程中的平均温度（由 Δs = ∫δq/T 定义），这说明决定效率的是换热时工质的平均吸热温度与平均放热温度。

得分点：① 两图（p-v 图两个定温线 + 两个定熵线，T-s 图矩形；正循环顺时针、逆循环反向）；② q1、q2 的定温换热式与 v2/v1 = v3/v4；③ ηt,C = 1 − T2/T1；④ ε1 = T2/(T1−T2)（制冷）、ε2 = T1/(T1−T2)（供暖），且 ε2 = ε1 + 1；⑤ 效率只与热源温度有关、与工质无关。一句话结论：卡诺循环效率是温度的函数 η = 1 − T2/T1，逆循环的 ε1、ε2 可以大于 1。
易错点

① 忘记“两个定温 + 两个定熵”这一组成，把卡诺循环画成别的形状。T-s 图上卡诺循环一定是矩形（这是最好用的判据）。② T 必须是热力学温度（K），用摄氏度代入必错。③ 逆循环的 ε1、ε2 分母都是净功 w0 = q1 − q2，不要把 q1 或 q2 单独当分母。④ 不要把 ηt 与 ε 混用：热机用 ηt，制冷/热泵用 ε。

第 19 题　卡诺定理、克劳修斯不等式
叙述卡诺定理，写出克劳修斯不等式并证明（或说明）二者的关系。

（1）卡诺定理。工作在给定两个恒温热源 T1、T2（T1 > T2）之间的一切热机，其热效率不可能大于可逆热机（卡诺热机）的热效率：

卡诺定理

ηt ≤ ηt,C = 1 − T2/T1　（等号仅当循环可逆时成立）

它包含两条推论：（a）一切可逆热机工作于同样两热源之间时，效率都相等，与工质种类、循环具体形式无关；（b）一切不可逆热机的效率都小于可逆热机的效率。由（a）可知 ηt,C 只是 T1、T2 的函数，这就为热力学温标提供了客观基础。

（2）克劳修斯不等式。对任意循环，沿整个循环积分

克劳修斯不等式

∮ (δq/T源) ≤ 0　（可逆取等号，不可逆取小于号）

其中 T源 是热源（边界）的温度，不是工质的温度——这是最关键的细节。若循环中有若干段与温度分别为 T1、T2…的热源换热，可写成

Σ(qi/Ti) ≤ 0

（3）从卡诺定理导出克劳修斯不等式（正循环情形）。设热机在 T1、T2 间工作，吸热 q1、放热 |q2|，由卡诺定理

①　ηt = (q1 − |q2|)/q1 ≤ 1 − T2/T1

②　两边同乘（正数）得 1 − |q2|/q1 ≤ 1 − T2/T1　⇒　|q2|/q1 ≥ T2/T1

③　移项并注意放热应取负值（q2 = −|q2|）：

q1/T1 + q2/T2 ≤ 0　⇒　∮(δq/T源) ≤ 0

可逆循环时卡诺定理取等号，于是 ∮(δqrev/T) = 0，这正是熵作为状态参数存在的充要条件：因 ∮ds = 0，ds = δqrev/T 必为全微分。

（4）不等式的意义与推论。

①　它把第二定律的各种文字表述统一成一个数学判据：只要算出 ∮(δq/T源) 的符号，即可判断循环是否可行、是否可逆——> 0 的循环不可能实现。

②　对不可逆循环 ∮(δq/T源) < 0，差额正是循环内部不可逆造成的熵产：∮(δq/T源) = −∮δsg，而 δsg = δq/T源 − δqrev/T ≥ 0。

③　由它可导出熵方程与熵增原理：对任意过程 ds ≥ δq/T源（即 ds = δq/T源 + δsg）；对孤立系统（δq = 0）则 Δsiso ≥ 0，不可逆时严格增大。这就是第 21 题“不可逆损失”的出发点。

④　由它还能直接证明卡诺定理的等价形式：T1、T2 之间的任何循环都有 |q2|/|q1| ≥ T2/T1，故 ηt 有上限。此外它还可用来推导克劳修斯–克拉贝龙方程（两相平衡线的斜率关系）。

⑤　三种温度要分清：T源（热源温度，积分的分母）、T工质（工质温度）、T0（环境温度）。只有可逆时才有 T源 = T工质，此时 ∮(δq/T工质) = 0。

得分点：① 卡诺定理表述（ηt ≤ 1 − T2/T1，等号仅可逆）＋两点推论（可逆热机效率相等、不可逆热机效率更低）；② 克劳修斯不等式 ∮(δq/T源) ≤ 0 并强调 T源 是热源温度；③ 二者关系的证明与统一；④ 由它导出可逆时 ∮δqrev/T = 0（熵存在的依据）与不可逆时 Δsiso > 0。一句话结论：卡诺定理给出效率上限，克劳修斯不等式把它变成可计算的循环判据 ∮(δq/T源) ≤ 0。
答题模板（“定理 + 不等式”类）

先给“文字表述 + 数学表达式”成对（卡诺定理、克劳修斯不等式各一组），再写“推导/说明二者联系”，最后写“推论与用途”（熵的存在性、熵增原理、效率上限、判定循环可行性）。每一条都点明等号条件（可逆）。

第四部分　熵方程、不可逆损失与压气机（第 20—25 题）

本部分收紧到不可逆性及其代价：绝热稳定流动的熵方程（20）→ 不可逆损失的定量计算 wl = T₀sg（21）→ 压气机不可逆压气功的 T-s 表示，即全表示与半表示（22）与 p-v 表示（23）→ 余隙容积的影响（24）→ 多级压缩中间冷却（25）。这几题最容易“写出公式却讲不清物理意义”，答题时要把每个符号对应的面积或焓差说清楚。
第 20 题　一个入口一个出口、绝热稳定流动：熵方程（开口、闭口）
写出一个入口、一个出口的绝热稳定流动开口系统的熵方程，并说明它与闭口系统熵方程的关系。

（1）系统简图与已知条件。取图中虚线所示控制体（开口系统）：一个进口 1、一个出口 2，外壳绝热（δq = 0）、稳定流动（控制体内各点状态不随时间变化，故 dSCV = 0）、无功的输入输出。

（2）开口系统熵方程的一般式。熵是状态参数，控制体的熵变由三部分组成：随热量进出的熵流、系统内部不可逆造成的熵产、随质量流带进带出的熵：

一般式

dSCV = δSf + δSg + Σ sinδmin − Σ soutδmout　，　δSf = δQ/T源　，　δSg ≥ 0

其中 T源 是热源（系统边界）的温度，不是工质温度（只有可逆时二者相等）。对一进一出，δm₁ = δm₂ = δm，一般式成为

dSCV = δQ/T源 + δSg + (s₁ − s₂)δm

（3）代入绝热稳定流动条件。稳定流动：dSCV = 0；绝热：δQ = 0，即熵流 δSf = 0。代入上式并两边同除 δm：

0 = δSg + (s₁ − s₂)δm　⇒　s₂ − s₁ = δSg/δm = sg

开口系熵方程（绝热稳定流动）

s₂ − s₁ = sg ≥ 0　，即　s₂ ≥ s₁

写成有限过程形式（qm 为质量流量，τ 为时间）：

Sg = qmτ(s₂ − s₁) ≥ 0　；　有传热时 s₂ − s₁ = ∫(δq/T源) + sg

（4）闭口系统（控制质量）熵方程。对闭口系，只交换热量而不交换质量，一般式中不含质量流项：

闭口系熵方程

ds = δq/T源 + δsg　（δsg ≥ 0）；有限过程 Δs = ∫δq/T源 + sg

物理含义：熵变 = 熵流 + 熵产。熵流 ∫δq/T源 可正（吸热）、可负（放热）、可零（绝热）；熵产 sg 由摩擦、涡流、温差传热、自由膨胀等不可逆因素造成，恒不为负，可逆过程才为零。绝热闭口系 δq = 0，于是

ds = δsg ≥ 0　（可逆绝热时 ds = 0，即定熵过程）

（5）两者的关系。开口系熵方程就是闭口系熵方程再补上“质量流带进带出的熵”。若把控制体在 dτ 内看成闭口系（控制质量），其熵变为 dSCV，则

dSCV = δQ/T源 + δSg + s₁δm₁ − s₂δm₂　——与（2）式完全相同

可见二者只是“系统取法”不同：闭口系研究控制质量的熵变（熵流 + 熵产），开口系还要加上进、出口质量携带的熵；两者都以 δsg ≥ 0 为第二定律的数学表述。对绝热稳定流动，进出的熵通量之差正好等于熵产，故工程上常用 sg = s₂ − s₁ 直接由进、出口状态算不可逆损失（见第 21、22 题）。

（6）结论与应用。

①　绝热稳定流动：出口比熵不小于进口比熵，s₂ ≥ s₁；差值就是单位质量熵产 sg。

②　可逆（理想）绝热流动 s₂ = s₁，是定熵流动：喷管、扩压管、叶轮机械的理想过程、可逆绝热压缩与膨胀都按此计算。

③　实际过程因摩擦、涡流、分离等不可逆因素，s₂ > s₁，熵增越大说明不可逆损失越大。

④　对孤立系（与外界无热、无质、无功交换）δq = 0，由闭口系熵方程得 Δsiso = sg ≥ 0，这就是熵增原理，也是判断过程能否实现、是否可逆的普遍判据。

得分点：① 一般式 dSCV = δQ/T源 + δSg + Σsinδmin − Σsoutδmout（熵流 + 熵产 + 进出质量熵）；② 绝热稳定流动时 dSCV = 0、δQ = 0，得 s₂ − s₁ = sg ≥ 0；③ 闭口系熵方程 ds = δq/T源 + δsg，绝热时 ds = δsg ≥ 0；④ 可逆绝热（定熵）s₂ = s₁，孤立系 Δsiso ≥ 0；⑤ 熵流可正可负、熵产恒非负。一句话结论：绝热稳定流动的熵方程就是 s₂ − s₁ = sg ≥ 0——出口熵只增不减，可逆即定熵。
易错点

① 绝热 ≠ 定熵：绝热只保证熵流为零，熵产仍可使 s₂ > s₁；只有“绝热 + 可逆”才定熵。② 把熵流与熵产混为一谈：熵流由传热引起、可正可负；熵产由不可逆引起、只能 ≥ 0，两者物理本质不同。③ 写 δq/T源 时误用工质温度：不可逆时 T源 ≠ T工质，若用 T工质 算出的不是熵流。④ 稳定流动 dSCV = 0 说的是控制体总熵不随时间变，不能由此说“进、出口熵相等”。⑤ 别漏质量流项：开口系若把 (s₁ − s₂)δm 丢掉，就会得出“绝热流动必然定熵”的错误结论。

第 21 题　不可逆损失
说明什么叫不可逆损失，写出其与熵产（孤立系熵增）的定量关系，并举例说明减少损失的途径。

（1）什么叫不可逆损失。一切实际过程都有摩擦、温差传热、压差流动、自由膨胀、混合等不可逆因素，它们使一部分本来可以转变为机械功的能量“贬值”为内能（或使得到同样的结果必须多耗功），这部分损失的作功能力称为不可逆损失（有用功损失、作功能力损失），记为 wl，单位 J/kg。它不是能量的数量损失（能量总量由第一定律守恒），而是能量的品质损失——这正是第二定律要回答的问题。

（2）与熵产的定量关系（孤立系熵增法）。把系统与环境（温度 T₀）合起来取作孤立系，则孤立系与外界无任何交换，其熵变全部是熵产：Δsiso = sg ≥ 0，于是

不可逆损失（居伊–斯托多拉公式）

wl = T₀ Δsiso = T₀ sg　≥ 0　（T₀ 为环境温度，K）

即：任何不可逆损失都等于环境温度乘以系统的熵产（或孤立系熵增）。可逆时 sg = 0，损失为零。

（3）公式的推导（闭口系一般情形）。取闭口系由状态 1 变到状态 2，环境温度 T₀、压力 p₀。相对环境而言，工质最大有用功（可逆时能给出的有用功）与系统能量的可用部分有关：

①　最大有用功：wu,max = (u₁ − u₂) + p₀(v₁ − v₂) − T₀(s₁ − s₂)

②　实际有用功（能量方程 q = Δu + w，扣除推挤环境大气的功 p₀(v₂ − v₁)）：wu = q − (u₂ − u₁) − p₀(v₂ − v₁)

③　两者相减：wl = wu,max − wu = T₀(s₂ − s₁) − q

④　由熵方程 Δs = q/T₀ + sg（环境吸热 −q，熵变 −q/T₀），得 Δsiso = s₂ − s₁ − q/T₀ = sg，代入 ③：

wl = T₀(s₂ − s₁ − q/T₀) = T₀ Δsiso = T₀ sg

推导中唯一的“损失”来源就是 sg：凡不可逆必有熵产，凡熵产必折合为 T₀sg 的作功能力损失。

（4）用温差传热验证公式（最直观的例子）。设有热量 q 由温度 T（> T₀）的热源直接传给环境 T₀：孤立系熵增为

Δsiso = q/T₀ − q/T = q(T − T₀)/(T T₀) > 0　⇒　wl = T₀Δsiso = q(T − T₀)/T

而若让这同一份热量 q 先经过可逆热机（工作在 T 与 T₀ 之间），能作出的最大功为 wmax = q(1 − T₀/T) = q(T − T₀)/T，与上式完全一致。可见“直接传热白扔掉的作功能力”正是 T₀Δsiso。

（5）常见不可逆过程的损失表达式。

不可逆过程熵产 sg（或 Δsiso）不可逆损失 wl = T₀sg
温差传热（q 由 T₁ 传至 T₂，T₁ > T₂）q(1/T₂ − 1/T₁)T₀q(T₁ − T₂)/(T₁T₂)
绝热节流（理想气体，p₁ → p₂）Rgln(p₁/p₂)T₀Rgln(p₁/p₂)
摩擦耗散（耗散功 wdiss，绝热）wdiss/TT₀wdiss/T
自由膨胀（理想气体，v₁ → v₂，绝热）Rgln(v₂/v₁)T₀Rgln(v₂/v₁)
绝热混合（两股流体等压混合）s₃ − (qm1s₁ + qm2s₂)/(qm1+qm2)T₀ × 左列

对绝热设备（节流、喷管、扩压管、压气机、透平机）熵流为零，熵产就是进、出口比熵差 sg = s₂ − s₁，故 wl = T₀(s₂ − s₁)。

（6）两种“损失”要分清。

①　作功能力损失（相对环境）：wl = T₀Δsiso，用环境温度 T₀ 折算，衡量的是“这份能量还能作多少有用功”。

②　设备的多耗功 / 少作功（相对理想过程）：如不可逆压缩多耗功 h₂′ − h₂s、不可逆膨胀少作功 h₁ − h₂′ 与理想之差，是在该设备的工作温度下按 Tds 折算的，数值等于 Tm(s₂ − s₁)（Tm 为过程平均温度），一般大于 T₀(s₂ − s₁)。做题时看清题目问的是哪一种（第 22 题用后者）。

（7）减少不可逆损失的途径。一切措施都归结为“减小熵产”：

①　减小温差传热：加大换热面积、采用逆流布置、分段换热、回热，使传热在接近等温或小温差下进行。

②　减小压差流动与节流：避免不必要的节流降压（如用膨胀机代替节流阀）、加大流通截面、减少局部阻力。

③　减小摩擦与涡流：改善润滑、提高叶轮与流道的光洁度、避免分离与冲击。

④　避免混合与自由膨胀：不同参数流体先分别利用再混合；分级压缩、分级膨胀并配中间冷却/再热，使过程尽量接近等温或可逆。

⑤　用可用能（㶲）效率 ηex = wu/wu,max 评价装置完善程度：损失 wl = (1 − ηex)wu,max，比单纯用热效率更能指出薄弱环节。

得分点：① 定义（不可逆使部分作功能力贬值为内能，是能量品质的损失，不是数量损失）；② wl = T₀Δsiso = T₀sg（居伊–斯托多拉公式）；③ 推导：最大有用功与实际有用功之差 + 熵方程；④ 温差传热例验证 wl = q(T−T₀)/T；⑤ 绝热设备 sg = s₂ − s₁；⑥ 减小温差、压差、摩擦，避免混合与自由膨胀。一句话结论：不可逆损失等于环境温度乘熵产，一切减少不可逆的措施都是减少熵产。
答题模板（“不可逆损失”类题四步法）

1定性：说明损失是作功能力（能量品质）的损失，能量数量仍守恒；2取孤立系（系统 + 环境 T₀），算 Δsiso = sg；3写出 wl = T₀Δsiso，并用最大有用功减实际有用功给出一句推导；4举例（温差传热 / 节流 / 摩擦）并写减小损失的途径。若题目问的是设备的多耗功，改用 Tm(s₂ − s₁)，并说明与 T₀(s₂−s₁) 的区别。

第 22 题　压气机不可逆压气功（T-s 图，全表示 / 半表示）
用最合适的能量方程形式说明压气机不可逆压气功的“全表示”与“半表示”，并在 T-s 图上表示出来。

（1）系统与过程。压气机取作绝热稳定流动开口系统：进口 1（p₁、T₁），压缩到同一出口压力 p₂ 时，理想（可逆、定熵）出口为 2s，实际（不可逆）出口为 2′。因不可逆耗散使工质额外受热，必有

T₂′ > T₂s　，　v₂′ > v₂s　，　s₂′ > s₁ = s₂s

而进出口动能差、位能差忽略不计（c₁ ≈ c₂、z₁ ≈ z₂），压气机只与外界交换轴功。

（2）用哪一种能量方程最合适——焓形式。开口系稳定流动能量方程的一般式是

q = Δh + ½Δc2 + gΔz + ws

绝热 q = 0、½Δc2 = gΔz = 0，于是

压气机耗功（最合适的形式）

ws = h₁ − h₂　⇒　wC = −ws = h₂ − h₁ = cp(T₂ − T₁)

为什么不用 wt = −∫vdp 而用 wC = h₂ − h₁：−∫vdp 只对可逆过程成立（此时 wt = −Δh = −∫vdp）；不可逆时二者不等，差值就是耗散部分。而 wC = h₂ − h₁ 只含进、出口两个状态参数，对可逆与不可逆过程都成立，也最便于用 T₁、T₂ 直接计算，所以是本题最合适的形式。

（3）全表示（完整表示）。把实际出口 2′ 的全部焓升都算作耗功：

全表示

wC,全 = h₂′ − h₁ = cp(T₂′ − T₁) = wC,半 + wl

它不区分“压力升高引起的焓升”与“不可逆耗散引起的焓升”，一步就把实际耗功算出来，工程上直接用它求功率 P = qmwC,全。缺点是看不出其中有多少是可以避免的损失。

（4）半表示。只把理想定熵压缩那一段（1 → 2s）的焓升算作耗功：

半表示（理想耗功）

wC,半 = h₂s − h₁ = cp(T₂s − T₁) = cpT₁[(p₂/p₁)(κ−1)/κ − 1]

可逆时它同时等于技术功：wC,半 = −∫12svdp = (κ/(κ−1))p₁v₁[(p₂/p₁)(κ−1)/κ − 1]

它只表示可逆部分，是衡量实际过程好坏的基准（“最少要耗多少功”）。

（5）两者的差 = 不可逆损失（多耗功）。

不可逆多耗功

wl = wC,全 − wC,半 = h₂′ − h₂s = cp(T₂′ − T₂s)

它是在出口压力 p₂ 不变的条件下，由 2s 到 2′ 的焓差；由 dh = Tds + vdp 在 p₂ = 常数下积分：

h₂′ − h₂s = ∫2s2′Tds = Tm(s₂′ − s₁) = Tmsg　（Tm 为 2s → 2′ 的平均温度）

（6）T-s 图上的表示。由定压过程 q = Δh = ∫Tds 可知：T-s 图上定压线下方的面积就是焓差，于是三条“面积”正好对应三个功：

①　半表示：面积 = h₂s − h₁，即 p₂ 定压线上 T₁ → T₂s 一段下方的面积（因 ∫Tds = cpΔT）。

②　全表示：面积 = h₂′ − h₁，即 p₂ 线上 T₁ → T₂′ 一段下方的面积。

③　损失：两种情况面积之差，即 T₂s → T₂′ 之间的面积 h₂′ − h₂s；图上竖直线（1 → 2s）与实际的、向右偏斜的线（1 → 2′）之间夹出的“月牙形”区域就是这份多耗的功。

（7）用压气机定熵效率（绝热效率）衡量不可逆程度。

定熵效率

ηC,s = wC,半/wC,全 = (h₂s − h₁)/(h₂′ − h₁) = (T₂s − T₁)/(T₂′ − T₁) < 1

理想气体定比热时它就是温升之比，故工程上常用“进、出口温度”直接求 ηC,s，再由 T₂′ = T₁ + (T₂s − T₁)/ηC,s 反求实际出口温度。

（8）结论与讨论。

①　全表示 = 实际耗功，可由进、出口状态直接算出（wC,全 = h₂′ − h₁），不必知道过程内部细节；半表示 = 理想耗功，只与 p₁、p₂、T₁、κ 有关，是最小耗功的基准。

②　“半表示”之所以叫“半”，是因为它只用到了实际耗功中可逆的那一半（压升引起的焓升），另一半（耗散引起的焓升）必须靠 ηC,s 或 wl 补上，二者相加才是全表示。

③　不可逆使 s₂′ > s₁、T₂′ > T₂s，耗功增大、排气温度升高；损失随熵产线性增大（系数 Tm）。

④　减小损失的途径：中间冷却、分级压缩（使压缩过程接近等温，理论上等温压缩耗功最小，wT = RgT₁ln(p₂/p₁)）、减小摩擦与涡流、提高 ηC,s。

得分点：① 用焓形式开口系能量方程 wC = h₂ − h₁（说明 wt = −∫vdp 只对可逆成立）；② 全表示 wC,全 = h₂′ − h₁ = cp(T₂′−T₁)；③ 半表示 wC,半 = h₂s − h₁ = cpT₁[(p₂/p₁)(κ−1)/κ−1]；④ 差值 = 多耗功 wl = h₂′ − h₂s = Tm(s₂′−s₁)；⑤ T-s 图上 p₂ 定压线下方面积即焓差，三块面积分别对应半表示、全表示与损失；⑥ ηC,s = (T₂s−T₁)/(T₂′−T₁)。一句话结论：全表示 = 半表示 + 不可逆多耗功，而多耗功在 T-s 图上就是 2s → 2′ 那一块面积。
易错点

① 用 wt = −∫vdp 去算不可逆压气机的耗功：错！只有可逆时才等于 h₂ − h₁，不可逆时必须用 wC = h₂′ − h₁。② 把 2′ 画在 2s 的左边或把实际压缩线画成向左倾斜：不可逆只可能使熵增大，2′ 必在 2s 右侧、温度更高。③ 混淆两种损失：这里问的是多耗的压气功 h₂′ − h₂s = Tm(s₂′−s₁)，不是第 21 题的作功能力损失 T₀(s₂′−s₁)，两者系数不同（Tm ≠ T₀）。④ 用 ηC,s 时别把分子分母写反：分子是理想耗功、分母是实际耗功，故 ηC,s < 1。⑤ 忘记说明“忽略进出口动能差与位能差”，直接套 ws = −Δh 会失分。

第 23 题　压气机不可逆压气功（p-v 图表示）
在 p-v 图上表示压气机的不可逆压气功，并说明各部分面积的物理意义。

（1）系统与过程线。仍取绝热稳定流动压气机：进口 1（p₁、v₁），升压到 p₂。理想定熵压缩 1 → 2s 满足 pvκ = 常数；实际不可逆压缩 1 → 2′ 过程中因耗散使工质温度偏高、比容偏大，可近似用多变指数 n > κ 的多变线 pvn = 常数 表示。由 v = v₁(p₁/p)1/n 与 n > κ 可知：同一压力下

v2′ > v2s　（p₂ 线上实际点 2′ 在 2s 的右侧），且 T₂′ > T₂s、s₂′ > s₁

（2）技术功的面积含义。对可逆稳定流动，轴功等于技术功：

技术功＝左侧面积

wt = −∫vdp　；压缩时 dp > 0，故耗功 wC = ∫p₁p₂vdp

在 p-v 图上，∫vdp 就是过程线与 p 轴（左侧）之间、由 p₁ 到 p₂ 所夹的面积；压缩过程耗功为正（输入功）。

（3）三块面积。

①　理想耗功（半表示）：面积 a-1-2s-b，即曲线 1 → 2s、p 轴、p = p₁ 与 p = p₂ 两条水平线围成的面积（图中蓝区），wC,半 = ∫p₁p₂vsdp。

②　实际耗功（全表示）：面积 a-1-2′-b（蓝区 + 红区），wC,全 = ∫p₁p₂v实际dp > wC,半。

③　不可逆多耗功（损失）：两面积之差，即曲边三角形 1-2s-2′-1（图中红区）：

损失面积

wl = ∫p₁p₂(v实际 − vs)dp = h₂′ − h₂s = Tm(s₂′ − s₁) > 0

实际耗功的分解

wC = h₂′ − h₁ = ∫12′vdp + ∫12′Tds = （p-v 图上的左侧面积）+ Tm(s₂′ − s₁)

即：实际耗功 = p-v 图上的几何面积 + 熵产造成的附加部分；后一项在 T-s 图上表现为 2s → 2′ 的那块面积（第 22 题），两者是同一份损失在两张图上的不同表现。这也说明为什么不可逆压气功最终要用焓差（wC = h₂′ − h₁）来算，而 p-v 图只适合给出“可逆部分”的几何比较。

第 24 题　余隙容积影响，用 p-V 图（示功图）表示
说明余隙容积对活塞式压气机的影响，用 p-V 示功图表示，并导出容积效率公式。

（1）什么是余隙容积。活塞式压气机排气终了时，活塞顶面与气缸盖之间必须留出最小间隙 Vc（避免活塞撞击气缸盖、并容纳气阀通道），称为余隙容积；其相对值 c = Vc/Vh（Vh 为活塞排量）一般为 0.03～0.08。

（2）有余隙时的示功图。排气终了时，压力为 p₂ 的高压气体残留在 Vc 中（图中点 3）。活塞回行，这部分气体先膨胀（3 → 4）降压到 p₁，然后才开始吸入新气（4 → 1）；压缩（1 → 2）与排气（2 → 3）与无余隙时相同。

（3）容积效率的推导。容积效率定义为每转实际吸气量与活塞排量之比：

容积效率定义

λ = V有效/Vh = (V₁ − V₄)/(V₁ − V₃)

①　余隙气体由 3 膨胀到 4 是多变过程，p₂V₃n = p₁V₄n，故

V₄ = V₃(p₂/p₁)1/n = Vcε1/n　（ε = p₂/p₁ 为升压比）

②　代入定义式，注意 V₁ − V₃ = Vh、V₃ = Vc：

λ = [Vh − (V₄ − V₃)]/Vh = 1 − (Vc/Vh)(V₄/V₃ − 1)

容积效率公式

λ = 1 − c(ε1/n − 1) = 1 − (Vc/Vh)[(p₂/p₁)1/n − 1]　< 1

③　极限升压比：令 λ = 0（余隙气体膨胀后恰好占满整个气缸、无法再吸气），得

εmax = (1 + 1/c)n　（即 p₂ 再高则压气机根本吸不进气，无法工作）

（4）影响分析。

①　使容积效率降低：λ < 1，实际吸气量比活塞排量少（V₄ − V₃ 被余隙气体的膨胀“占住”了）。c 越大、ε 越大、膨胀指数 n 越小，λ 越低。

②　对单位质量气体的理论耗功没有影响：由示功图，每转指示功 = 压缩功（1 → 2）− 膨胀回收功（3 → 4）= (n/(n−1))p₁(V₁ − V₄)[ε(n−1)/n − 1]，与吸气量成正比，故比耗功（每 kg 或每 m³ 气体的耗功）只取决于 p₁、p₂ 与 n，与 Vc 无关。余隙容积的危害在于“同样尺寸的气缸产气量变小”。

③　使同样气缸尺寸的产气量下降：要保证产气量就必须加大气缸尺寸或转速，设备变大；当 ε 接近 εmax 时产气量急剧下降，故单级升压比受到限制（这是采用多级压缩的重要理由之一）。

④　实际还带来附加损失：余隙中的气体每转都要被反复压缩、膨胀一次，与缸壁、气阀反复换热且流动有节流，使实际耗功略大于理论值、指示效率下降；残留气中的凝液还可能造成液击。

⑤　余隙并非越小越好：c 太小则活塞与缸盖容易相撞、气阀通道布置困难、制造与热膨胀要求高，故只能“尽量减小”而不能取消。

（5）减小余隙不利影响的措施。① 尽量减小相对余隙 c（提高加工与装配精度、把气阀布置在缸盖的凹腔内、减小阀腔容积）；② 采用多级压缩、中间冷却，把总升压比分配到各级，使每级 ε 减小、各级 λ 提高（见第 25 题）；③ 加强冷却使过程指数 n 减小（由 λ = 1 − c(ε1/n − 1) 知 n 越小、λ 越高）；④ 及时排出级间凝液，防止液击。

得分点：① 余隙容积的定义与 c = Vc/Vh；② 示功图 4-1-2-3 四段（吸气、压缩、排气、余隙气体膨胀）并标出 Vh = V₁−V₃、有效吸气量 V₁−V₄；③ 推导 V₄ = Vc(p₂/p₁)1/n，得 λ = 1 − c(ε1/n − 1) 与极限压比 εmax = (1+1/c)n；④ 结论：降低容积效率、减少产气量、限制单级升压比，但不改变单位质量气体的理论耗功；⑤ 措施（减小 c、多级压缩、加强冷却）。一句话结论：余隙容积“不费功、但费气”——它使实际吸气量减少、容积效率下降，是必须分级压缩的原因之一。
易错点

① 把“余隙容积使耗功增大”当成结论：理论耗功与 Vc 无关（只与 p₁、p₂、n 有关），余隙影响的是容积效率与产气量（实际因反复换热会有少量附加损失，但不是主要结论）。② 容积效率公式的指数写错：是 ε1/n（由膨胀过程 p₂V₃n = p₁V₄n 解出），不是 ε(n−1)/n。③ 忘记 Vh = V₁ − V₃ 是活塞排量而不是气缸总容积 V₁。④ 示功图方向画反：余隙气体先膨胀（3 → 4）再吸气（4 → 1），绝不能画成先吸后膨胀。⑤ 说“余隙容积可以取消”：结构上必须保留，只能尽量减小。

第 25 题　多级压缩中间冷却：使用场合、优点
说明多级压缩、中间冷却的使用场合与优点，并导出最佳中间压力。

（1）什么是多级压缩、中间冷却。把总升压任务分配给两个或多个串联的压气机（级），气体在级间冷却器中被冷却（理想情况冷却回第一级进口温度 T₁）后再进入下一级，这种方案叫多级压缩、中间冷却。流程为：气体 → Ⅰ 级压缩 → 中间冷却器 → Ⅱ 级压缩 → … → 排出。

（2）使用场合（为什么要用它）。

①　需要高升压比的场合：单级压气机的压比受排气温度限制，一般 ε ≤ 3～4；当总压比 ε = p₂/p₁ > 8～10 时（如高压气瓶充装、合成氨与甲醇等化工流程的高压原料气、空分与气体液化、天然气增压与加气站、高压气动系统及风洞、增压内燃机等）都采用多级压缩。

②　排气温度受限制的场合：单级定熵压缩的排气温度 T₂ = T₁ε(κ−1)/κ。取 T₁ = 293 K、κ = 1.4、ε = 9，则 T₂ ≈ 549 K（约 276 ℃），远超润滑油与密封件允许的温度（一般 ≤ 160～180 ℃），必须分级冷却；对易燃易爆、易分解的气体（石油气、氢气、乙炔、氧气压缩机等）更是安全要求。

③　容积效率要求高的场合：由第 24 题 λ = 1 − c(ε1/n − 1)，ε 越大 λ 越低；分级后每级压比小，λ 明显提高，同样气缸尺寸产气量大。

④　需要级间除水、除油与控温的工艺场合：级间冷却可析出凝液（避免带液压缩、防止液击），也便于级间抽气、加气（如合成流程的补气）。

（3）优点。

①　省功（最主要）：由“压缩过程越接近等温越省功”（等温压缩耗功 wT = RgT₁lnε 最小），级间冷却把气体温度降回 T₁ 再压，使整个压缩过程在 T-s 图上呈“阶梯形”逼近等温线，总耗功显著减小。

②　降低排气温度：每级温升小，避免润滑油炭化、结焦，保护气阀、密封与缸体材料，保证安全与寿命。

③　提高容积效率：每级压比小，λ 提高，产气量增加、经济性改善。

④　改善受力与结构：每级压差小，活塞力、连杆与曲轴受力小，级间可布置冷却器与分离器，机器运转平稳、泄漏少。

⑤　代价：级数越多越接近等温压缩，但设备、冷却器、管路、级间压降与投资都增加，故实际常取 2～3 级（每级压比 3～5 左右）。

（4）最佳中间压力的推导（以两级为例）。设两级均按同一多变指数 n 压缩，中间冷却器把气体冷却回 T₁（理想中间冷却），级间压力为 px，忽略动能、位能差，每级都是绝热稳定流动，故每级耗功等于焓升 w = Δh = cpΔT：

Ⅰ 级：w₁ = cpT₁[(px/p₁)m − 1]　；　Ⅱ 级：w₂ = cpT₁[(p₂/px)m − 1]　，m = (n − 1)/n

总耗功

wC = w₁ + w₂ = cpT₁[(px/p₁)m + (p₂/px)m − 2]

令 a = ln(px/p₁)、b = ln(p₂/px)，则 a + b = ln(p₂/p₁) = 常数，总耗功只随 a 变化，对 a 求导取极值：

dwC/da = cpT₁ m(ema − emb) = 0　⇒　a = b　⇒　px/p₁ = p₂/px

最佳中间压力

px = √(p₁p₂)　，即　ε₁ = ε₂ = √ε　（等压比分配、各级耗功相等）

此时 w₁ = w₂ = wC,min/2　，　wC,min = 2cpT₁[ε(n−1)/(2n) − 1]

推广到 z 级：各级压比相等 εi = ε1/z、各级耗功相等，wC,min = z cpT₁[ε(n−1)/(zn) − 1]，级数越多越接近等温压缩的下限。

（6）结论。多级压缩中间冷却适用于高升压比、排气温度受限、要求高容积效率与级间除水的场合；其优点是省功、降低排气温度、提高容积效率、改善受力，代价是设备复杂、投资与级间压降增加，故级数不宜过多，一般 2～3 级，并按各级压比相等（等压比分配）的原则选取中间压力。

得分点：① 使用场合三条（高升压比 ε > 8～10、排气温度受限、容积效率与级间除水）；② 优点（省功——过程逼近等温；排气温度低；容积效率高；受力小、泄漏少；代价是设备投资增加），并给出“等温压缩耗功最小”的依据 wT = RgT₁lnε；③ 推导：wC = cpT₁[(px/p₁)m + (p₂/px)m − 2]，求极值得 px = √(p₁p₂)、各级压比相等且耗功相等；④ T-s 图上“阶梯形”逼近等温线。一句话结论：多级压缩中间冷却的作用是让压缩过程尽量接近等温，从而省功、降温、提高容积效率，最佳中间压力按等压比分配 px = √(p₁p₂)。
