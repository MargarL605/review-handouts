第 1 章　基本概念与能量方程

本章公式与套路

1. 可逆过程的膨胀功（p–V 图面积）

膨胀功

W = ∫12p dV　　w = ∫12p dv　（kJ／kJ·kg−1）

四种常见过程的结果必须背熟（n 为多变指数）：

过程关系式膨胀功 w
定容v = 常数0
定压p = 常数p(v2 − v1)
定温pv = 常数p1v1 ln(v2/v1)
多变pvn = 常数(p1v1 − p2v2)/(n − 1)
定熵pvk = 常数(p1v1 − p2v2)/(k − 1)

2. 由已知两态反求多变指数：n = ln(p1/p2) / ln(v2/v1)。也可由 p1v1n = p2v2n 直接解 v2。

3. 微压计（斜管）测压：液柱垂直高度 h = L sin α，所测表压 Δp = ρgh；绝对压力 p = B ± Δp（测高于大气压用「+」）。注意 ρ 的单位换算：1 g/cm³ = 1000 kg/m³。

4. 热效率与经济性指标

热效率

η = Wnet / Q1 = P / (B·Qe)　（B 为耗煤率 kg/s，Qe 为煤发热量 kJ/kg）

供热系数

εh = Q1 / P，且 Q1 = Q2 + W（Q1 为供热量，Q2 为从低温热源吸热量）

5. 能量守恒的「房间／设备」整体算法：稳态时输入能量 = 输出能量。房内耗电设备（电灯、家电）的功率最终全部转化为热量留在室内，属于向房间的供热，不要当成散热。

套路小结：本章题分三类——(a) 由过程方程求功（1-3、1-5）；(b) 测压换算（1-4）；(c) 能量守恒求效率／功率（1-6～1-9）。(c) 类一定要先画「能量收支账」，把所有以 kW 为单位的量列出来，再列守恒式。

1-3

气体初态 p1 = 0.5 MPa、v1 = 0.172 m³/kg，按 pvn = 常数的规律可逆膨胀到 p2 = 0.1 MPa，试求膨胀功。

①考点：可逆多变过程的膨胀功计算。关键是先用 p1v1n = p2v2n 求终态比体积，再用多变功公式。

②取系统：取 1 kg 气体为闭口系统（题目给的是比体积，故用比量 w，单位 kJ/kg）。

③用方程：过程方程 pvn = 常数；可逆膨胀功 w = ∫pdv = (p1v1 − p2v2)/(n − 1)。

④关键代入式：题目没有直接给 n，但两态的 p、v 都已知，可由过程方程反解：

符号式

v2 = v1(p1/p2)1/n，　n = ln(p1/p2) / ln(v2/v1)

这里题给的是「按 pvn = 常数的规律」，即 n 为待定常数，须由过程自身确定。用 p1v1 = RT1 与 p2v2 = RT2 联立只能确定 v2 与 T2 的关系，故本题按等温（n = 1）与多变两种典型解法说明；教材原意取 n = 1（定温，pv = 常数）：

数字式

v2 = 0.172 × (0.5/0.1) = 0.8600 m³/kg　（n = 1）

若按 n = 1.2 的一般多变过程计算，则：

数字式

v2 = 0.172 × (0.5/0.1)1/1.2 = 0.6577 m³/kg

膨胀功

w = (p1v1 − p2v2)/(n − 1) = (500 × 0.172 − 100 × 0.6577)/0.2 = 101.17 kJ/kg

⑤数值：按定温过程（n = 1，题面「pvn = 常数」在 n = 1 时即 pv = 常数）：

定温

w = p1v1 ln(p1/p2) = 500 × 0.172 × ln 5 = 86.00 × 1.6094 = 138.4 kJ/kg

按 n = 1（定温）：w = 138.4 kJ/kg；若按 n = 1.2 的多变过程：v2 = 0.6577 m³/kg，w = 101.17 kJ/kg。注意两解对应不同过程假设，考试时以题给过程指数为准；本题只给「pvn = 常数」而未给 n，标准取法为定温 n = 1。

1-4

锅炉烟道中烟气压力用上部开口的斜管测量。已知斜管倾角 α = 30°，压力计中酒精 ρ = 0.8 g/cm³，斜管中液柱长 L = 200 mm，当地大气压力 B = 0.1 MPa，求烟气的绝对压力。

①考点：微压计（斜管）测压原理——液柱垂直高度与压强的关系，以及表压／绝对压力换算。

②取系统：不涉及系统，取斜管内酒精液柱为研究对象作力平衡。

③用方程：Δp = ρgh，其中 h = L sin α；烟气压力低于大气压（烟道为负压），故 p = B − Δp。

④关键代入式（全部化为 SI）：ρ = 0.8 × 1000 = 800 kg/m³，L = 0.2 m，B = 100 000 Pa。

符号式

h = L sin α，　Δp = ρgh = ρgL sin α，　p = B − Δp

数字式

Δp = 800 × 9.81 × 0.2 × sin 30° = 800 × 9.81 × 0.2 × 0.5 = 784.8 Pa

绝对压力

p = 100 000 − 784.8 = 99 215 Pa = 99.22 kPa = 0.09922 MPa

⑤数值：注意斜管的作用是把垂直位移放大 1/sin α = 2 倍，读数更精确，但计算必须乘 sin α 还原为垂直高度。

Δp = 784.8 Pa（约 785 Pa）；烟气绝对压力 p = 99.22 kPa ≈ 0.0992 MPa，比大气压低约 0.78 kPa，即烟道处于微负压状态。

1-5

某气缸中有 0.5 kg 气体，从初态 p1 = 0.7 MPa、V1 = 0.02 m³ 可逆膨胀到终态 V2 = 0.05 m³，各膨胀过程维持以下关系：(1) p = 定值；(2) pV = 定值。试计算各过程所作的膨胀功，并示意在 p–V 图上。

①考点：这是本章最典型的「过程功 = p–V 图上过程线下面积」题。定压为水平线，定温（pV = 常数）为双曲线，两者面积不同。

②取系统：0.5 kg 气体为闭口系统，可逆膨胀，用总功 W（kJ）。

③用方程：W = ∫12pdV。

④关键代入式：

(1) 定压过程 p = p1 = 700 kPa

符号式

W = p(V2 − V1)　（矩形面积）

数字式

W = 700 × (0.05 − 0.02) = 700 × 0.03 = 21.0 kJ

(2) pV = 常数（定温）：先求终压 p2 = p1V1/V2

终压

p2 = 700 × 0.02/0.05 = 280 kPa

符号式

W = p1V1 ln(V2/V1) = p1V1 ln(p1/p2)

数字式

W = 700 × 0.02 × ln(0.05/0.02) = 14.0 × ln 2.5 = 14.0 × 0.9163 = 12.83 kJ

⑤数值比较：定压过程功 21.0 kJ > 定温过程功 12.83 kJ。原因：定压过程全程维持 700 kPa 的高压，而定温过程压力从 700 kPa 沿双曲线迅速降到 280 kPa，平均压力低得多，故面积小。可用平均压力粗估：pm = 12.83/0.03 = 427.7 kPa，介于 280～700 kPa 之间，合理。

1-6

某蒸汽动力厂发电量 P = 5×10³ kW，锅炉耗煤率 m = 19×10³ kg/h，煤的发热量 Qe = 3×10⁴ kJ/kg，试求该动力厂的热效率。

①考点：热效率定义——输出功与输入热量之比，核心是单位统一（kW = kJ/s，而耗煤率给的是 kg/h）。

②取系统：整个动力厂为开口（稳态）系统，考查其能量收支。

③用方程：η = Wnet/Q1 = P/(BQe)。

④关键代入式：先把耗煤率化为 SI：B = 19 000/3600 = 5.2778 kg/s。

符号式

η = P / (B·Qe)

数字式

η = 5000 / (5.2778 × 3×10⁴) = 5000 / 158 333 = 0.03158

⑤数值：η = 3.16%。这个数值看似很低，但注意它是全厂发电热效率（含锅炉效率、管道损失、汽轮机与发电机损失），且煤的发热量按低位发热量计，早期中小型电厂 3%～10% 属常见量级。

η = 3.16%（即每消耗 1 kJ 煤的发热量，只得到约 0.032 kJ 的电能）。

1-7

某房间冬季通过墙壁和窗子向外散热 70000 kJ/h，房内有两只 40 W 电灯照明，其他家电耗电约 100 W。为维持室内温度不变，房主购买了供热系数为 5 的热泵，求驱动热泵所需的功率。

①考点：房间的能量平衡 + 热泵供热系数定义。易错点：房内所有耗电设备最终都把电能变成了室内热量，属于向房间的供热而非散热。

②取系统：取房间（连同内部设备与热泵冷凝器）为闭口系统，稳态（室内温度不变）。

③用方程：稳态能量守恒——热泵供热量 + 电灯与家电发热量 = 房间散热量。

能量平衡

Qh + Plamp + Papp = Qloss

热泵

Qh = εh · Php

④关键代入式：先统一为 kW：Qloss = 70 000/3600 = 19.444 kW；Plamp = 2 × 40 = 80 W = 0.08 kW；Papp = 0.1 kW。

数字式

Qh = 19.444 − 0.08 − 0.1 = 19.264 kW

热泵功率

Php = Qh/εh = 19.264/5 = 3.853 kW

⑤数值：驱动热泵需 3.85 kW。反过来算：若不用热泵而直接用电加热（电炉 ε = 1），需要 19.264 kW，是热泵方案的 5 倍，这就是热泵的节能意义。

热泵需从外界吸收的热量即为其供热量 Qh = 19.264 kW（房间净需热量），驱动功率 Php = 3.85 kW。

1-8

据资料统计，上海各发电厂平均发 1 kW·h 的电耗标煤 372 g。若标煤的热值是 29308 kJ/kg，试求上海电厂平均热效率。

①考点：供电煤耗与热效率的换算。1 kW·h = 3600 kJ 是本题唯一的单位桥梁。

②取系统：发电厂整体（开口稳态系统）。

③用方程：η = 输出的功 / 输入的热量。

④关键代入式：

符号式

η = 3600 / (b · Qe)　（b 为每 kW·h 的耗煤量，kg/(kW·h)）

数字式

η = 3600 / (0.372 × 29308) = 3600 / 10902.6 = 0.3302

第 2 章　理想气体性质与状态方程

本章公式与套路

1. 理想气体状态方程（三种形式，务必都会用）

状态方程

pv = RT　；　pV = mRT　；　pV = nRMT

其中 R = RM/M（RM = 8.3144 kJ/(kmol·K)，M 为摩尔质量 kg/kmol）。注意「比量」与「总量」的区别：v 为比体积 m³/kg，V 为总容积 m³。

2. 质量守恒（储气罐类题的核心）

充气／放气

Δm = m2 − m1 = V(p2/T2 − p1/T1)/R　（V = 常数）

适用条件：容积固定的储气罐，两态温度可不同，但必须用绝对压力。这是本章最常考、最易错的一类题——表压一定要加当地大气压。

3. 标准状态换算

标准状态

V0 = V · (p/p0) · (T0/T)　，　m = V0 ρ0 = V0 / v0

空气的 v0 = RT0/p0 = 0.287 × 273.15/101.325 = 0.7737 m³/kg，ρ0 = 1.2925 kg/m³。凡说「标准状态下 V₀ m³/h」的流量，先乘 ρ0 换成 kg/h，再算热量或功。

4. 热量计算的三种精度

方法公式备注
定值比热Q = mcp(t2 − t1)最简单，误差通常 < 5%
平均比热Q = m[cpm]0t2t2 − m[cpm]0t1t1查附表，从 0 ℃ 起算，注意是「差值」而非直接相乘
真实比热Q = m∫cp(T)dT，cp = a0 + a1T + a2T² + a3T³最精确，需积分

5. 真实气体：压缩因子与范德瓦尔方程

压缩因子

Z = pv/(RT)　，　pV = ZmRT；对比参数 Tr = T/Tcr，pr = p/pcr

范德瓦尔

(p + a/vm²)(vm − b) = RMT，　a = 27RM²Tcr²/(64pcr)，　b = RMTcr/(8pcr)

套路小结：本章四大题型——(a) 储气罐质量变化（2-3、2-4、2-5）：先化绝对压力，再用 Δm = VΔ(p/RT)；(b) 变温热量（2-14）：先统一流量单位，再选比热方法；(c) 真实气体压力（2-19）：先算 vm，再比理想与范氏结果；(d) 真实气体容积（2-20）：先算理想值，再查 Z 修正。

2-3

开口系

q = Δh + Δc²/2 + gΔz + wt　→　一般动力设备中忽略动能、位能：q = Δh + wt

3-6

下列各式，适用于何种条件？(1) δq = du + δws；(2) δq = du + pdv；(3) δq = cvdT + pdv；(4) δq = dh；(5) δq = cpdT − vdp。

①考点：热力学第一定律各种微分形式的适用条件。判断的钥匙只有三把：闭口还是开口？可逆还是不可逆？有没有除容积功以外的其他功？

②取系统：逐式判断，不需要统一系统。

③用方程与逐条解答：

(1) δq = du + δws：这是闭口系统第一定律最一般的形式（ws 为总功，含容积功、轴功、电磁功等一切形式的功）。适用条件：闭口系统、任何过程（可逆或不可逆均可）。注意 δws 是过程量，故用 δ 而非 d。

(2) δq = du + pdv：把总功收缩为容积功 δw = pdv。适用条件：闭口系统、可逆（准静态）过程、且系统对外只作容积功（无轴功、无电磁功等）。对于不可逆过程，δw ≠ pdv（因为 p 不是系统边界上的均匀压力），该式不成立。

(3) δq = cvdT + pdv：在 (2) 的基础上用了理想气体 cv = du/dT。适用条件：理想气体、闭口系统、可逆过程、只作容积功。对实际气体 cv 不能单独决定 du，本式不成立。

(4) δq = dh：由 δq = du + pdv 与 dh = du + d(pv) 比较可知，只有当 d(pv) = pdv，即 dp = 0（定压过程）时才成立。适用条件：定压过程、只作容积功、可逆。定压过程中吸收的热量全部用于增加焓，这正是 cp = (∂h/∂T)p 的来源。

3-10

说明以下论断是否正确：(1) 气体吸热后一定膨胀，热力学能一定增加；(2) 气体膨胀时一定对外做功；(3) 气体压缩时一定消耗外功；(4) 应设法利用烟气离开锅炉时带走的热量。

①考点：第一定律的物理理解——热量、功、内能三者相互独立，不能由其中一个的符号推断另一个。

②取系统：概念题，以闭口系统第一定律 q = Δu + w 为判据。

③逐条判断：

(1) 错误。由 q = Δu + w 可知，吸热 q > 0 时，可以是 Δu > 0 且 w > 0（如定压加热膨胀），也可以是 Δu < 0 且 w > q（如气体一边吸热一边对外作功更多的膨胀），还可以几乎全部转为对外作功（如理想气体定温膨胀，Δu = 0）。反例：理想气体定温吸热膨胀，吸热但热力学能不变、体积增大——「热力学能一定增加」是错的。

(2) 错误。膨胀（dV > 0）不一定作功。反例一：自由膨胀——气体向真空膨胀，虽然体积增大，但没有克服外力，W = 0（3-8 题正是这种情况）。反例二：若外界压力为零，dW = p外dV = 0。

(3) 错误。压缩（dV < 0）时外界对气体作正功，但「消耗外功」的说法意味着必须由外界输入机械功，这也不一定：如果同时有外界对气体的加热，气体可以在被压缩的同时对外输出净功（例如与外界有热交换的非绝热压缩过程，也可设计成使 w < 0）。严格地说，「一定」二字使它成为错误论断——压缩时 w < 0 只在绝热压缩等特定场合成立。

(4) 不完全正确（要分清「技术可行」与「热力学极限」）。烟气离开锅炉时温度仍远高于环境，这部分热量是排烟热损失，从能量数量上看应该设法回收（工程上正是这样做的：加装省煤器、空气预热器，即 2-14 题的设备）。但从热力学第二定律看：烟气温度越低，其作功能力（㶲）越小，不可能把排烟带走的热量全部转化为功，也不可能把烟气冷却到环境温度以下。所以正确表述是：应尽可能回收排烟余热（加热给水或空气），以减少排烟热损失；但不能指望把该热量全部转换为功，也不能回收到底。

④方法总结：判断这类「一定」型论断，只需找一个反例即可否定。四个论断中 (1)(2)(3) 都是把「可能」说成「一定」，属典型错误；(4) 错在忽略了「量」与「质（品位）」的区别——这正是第 5 章做功能力损失要讲的内容。

⑤数值：概念题，无数值。

(1) 错误；(2) 错误（自由膨胀不作功）；(3) 错误（「一定」不成立）；(4) 部分正确——回收排烟余热是应该做的，但受第二定律限制不能全部转化为功、也不能回收到底。

①考点：两种「同初终态、不同过程」的对比——功不同（一个作功、一个不作功），但熵变相同（因为熵是状态参数）。这是全讲义最能体现「熵是状态量、功是过程量」的一题。

②取系统：1 kmol 空气为闭口系统。

③用方程：(1) 可逆定温 W = nRMTln(V2/V1)；(2) 自由膨胀 W = 0（无外力抵抗）；熵变两过程都用 ΔS = nRMln(V2/V1)。

④关键代入式：n = 1 kmol，T = 373.15 K，RM = 8.3144 kJ/(kmol·K)，V2/V1 = 10。

(1) 可逆定温膨胀

符号式

W = nRMT ln(V2/V1)　，　ΔS = nRM ln(V2/V1) = Q/T

数字式

W = 1 × 8.3144 × 373.15 × ln 10 = 3102.6 × 2.3026 = 7143.8 kJ

数字式

ΔS = 8.3144 × 2.3026 = 19.14 kJ/K

定温过程 ΔU = 0，故 Q = W = 7143.8 kJ（从外界吸热）。

(2) 向真空自由膨胀

功

W = 0　（向真空膨胀，无外力抵抗）

热

Q = 0（若绝热）；即非绝热，因 ΔU = 0（理想气体定温）也必有 Q = W = 0

熵变

ΔS = nRM ln(V2/V1) = 19.14 kJ/K（与过程无关！）

深刻点自由膨胀 Q = 0，若误用 ΔS = ∫δQ/T 就会得 ΔS = 0，这是典型错误。正确做法是：在初终态之间设想一条可逆路径（本题即定温膨胀），用状态参数式计算。不可逆过程 ΔS > 0 而 Q = 0，正是「熵产」的来源。

将空气从初状态 1（t1 = 20 ℃）定熵压缩到它开始时容积的 1/3，然后定温膨胀，经过这两个过程后，空气的容积和开始时的容积相等。求 1 kg 空气所作的功。

①考点：两个过程串联（先定熵压缩、后定温膨胀），求净功。关键是认清「定熵压缩到 1/3 容积」→「定温膨胀回到原容积」这一路径关系。

②取系统：1 kg 空气为闭口系统，两个过程分别计算膨胀功后代数相加。

③用方程：过程 1-2 定熵 T2 = T1(v1/v2)k−1，w1-2 = R(T1 − T2)/(k − 1)；过程 2-3 定温 w2-3 = RT2ln(v3/v2)。

④关键代入式：T1 = 293.15 K，v1/v2 = 3，v3 = v1，故 v3/v2 = 3。

第一步：定熵压缩 1→2

终温

T2 = T1(v1/v2)k−1 = 293.15 × 30.4 = 293.15 × 1.5518 = 454.92 K = 181.77 ℃

功

w1-2 = R(T1 − T2)/(k − 1) = 0.287 × (293.15 − 454.92)/0.4 = 0.287 × (−161.77)/0.4 = −116.1 kJ/kg

负号表示外界对空气作功（消耗功 116.1 kJ/kg）。

第二步：定温膨胀 2→3（T3 = T2 = 454.92 K）

功

w2-3 = RT2 ln(v3/v2) = 0.287 × 454.92 × ln 3 = 130.56 × 1.0986 = +143.4 kJ/kg

第三步：净功

符号式

wnet = w1-2 + w2-3

数字式

wnet = −116.1 + 143.4 = +27.4 kJ/kg

⑤讨论：净功为正（27.4 kJ/kg），说明对外净输出功。为什么？因为定熵压缩是在较低温度（293 K）下耗功，而定温膨胀是在较高温度（455 K）下作功，后者「单价」更高。这正是燃气轮机循环（布雷顿循环）的雏形：先绝热压缩、再（等压）加热膨胀。本题可作为理解「为什么要把压缩放在低温段、膨胀放在高温段」的入门例子。

1 kg 空气对外净作功 wnet = 27.4 kJ/kg（压缩耗功 116.1 kJ/kg，膨胀作功 143.4 kJ/kg；中间温度 T2 = 454.9 K）。

第 5 章　第二定律、熵与做功能力损失

本章公式与套路

1. 第二定律的三种数学表述（做判断题的法宝）

克劳修斯

∫δQ/T ≤ 0（循环），等号可逆、不等号不可逆

熵增原理

ΔSiso ≥ 0，　Δs = Δsf + Δsg（sf 为熵流、sg 为熵产 ≥ 0）

卡诺定理

ηt ≤ ηC = 1 − T2/T1（一切工作于同温热源之间的循环，效率不超过可逆卡诺循环）

必须记住熵产 sg 只可能 ≥ 0：凡算出 sg < 0 的循环、过程或设备，一律不可能实现。这是「某循环能否实现」类题目的唯一判据。

2. 理想气体熵变的三个常用式

熵变

Δs = cvln(T2/T1) + Rln(v2/v1) = cpln(T2/T1) − Rln(p2/p1) = cvln(p2/p1) + cpln(v2/v1)

符号陷阱压力比出现时是「减 Rln(p2/p1)」，比体积比出现时是「加 Rln(v2/v1)」。压降使熵增、压升使熵减，符号务必按此校验。

3. 孤立系统熵变与做功能力损失（㶲损失）

核心式

ΔSiso = ΔS工质 + ΔS热源/环境，　i = T0·ΔSiso　（做功能力损失 = 环境温度 × 孤立系统熵增）

这是全课程最重要的「工程结论」：只要算出孤立系统的熵增，乘上环境温度 T0 就是被「浪费掉」的可用功。

4. 热量㶲与冷量㶲（求「热量中有多少能变成功」）

热量㶲

温度 T 处的热量 Q：Ex,Q = Q(1 − T0/T)

冷量㶲

温度 T < T0 处吸取的热量 Q0：Ex,Q0 = Q0(T0/T − 1)

5. 热效率与制冷（供热）系数

装置性能指标卡诺（可逆）极限
热机ηt = wnet/q1 = 1 − q2/q1ηC = 1 − T2/T1
制冷机εr = q2/wnetεC = T2/(T1 − T2)
热泵εh = q1/wnetεh,C = T1/(T1 − T2)

套路小结：本章题分四类——(a) 循环效率与卡诺对比（5-1、5-2、5-3、5-4）：先算 η，再与 ηC 比；(b) 不可逆过程的熵变（5-9、5-18）：用状态式算 Δs，负值/正值判断方向；(c) 混合与充气的熵增（5-16）：分别算各部分的熵变再相加，必须为正；(d) 做功能力损失（5-19、5-24）：算 ΔSiso，乘 T0，并用 i = T0Δsiso 校核。

5-2

有一循环发动机，工作于热源 T1 = 1000 K 及冷源 T2 = 400 K 之间，从热源取热 1000 kJ 而做功 700 kJ。问该循环发动机能否实现？

①考点：卡诺定理的正确用法——实算热效率与同温限卡诺效率比较，或用熵增原理判定。

②取系统：取热源、冷源与循环工质组成的孤立系统（最稳妥的判据）。

③用方程：判据一：ηt ≤ ηC；判据二：ΔSiso = −Q1/T1 + Q2/T2 ≥ 0。

④关键代入式：

判据一（效率比较）

实际

ηt = W/Q1 = 700/1000 = 0.700

卡诺

ηC = 1 − T2/T1 = 1 − 400/1000 = 0.600

因 ηt = 0.700 > ηC = 0.600，违反卡诺定理，故该循环不能实现。

判据二（熵增检验）：Q2 = 1000 − 700 = 300 kJ

熵增

ΔSiso = −Q1/T1 + Q2/T2 = −1000/1000 + 300/400 = −1 + 0.75 = −0.25 kJ/K < 0

孤立系统熵变为负，违反熵增原理，同样说明不能实现。

⑤数值与结论：两种判据结论一致，这是必然的（卡诺定理就是熵增原理的推论）。答题技巧考试时两种都写，既证明结论又展示对第二定律两种表述的掌握；若题目给的是「能否实现」，务必明确写出「不能，因为……」。

不能实现。因 ηt = 70% > ηC = 60%，违反卡诺定理；等价地，ΔSiso = −0.25 kJ/K < 0，违反熵增原理。

5-3

某一动力循环工作于温度为 1000 K 及 300 K 的热源与冷源之间，循环过程为 1-2-3-1，其中 1-2 为定压吸热过程，2-3 为可逆绝热膨胀过程，3-1 为定温放热过程。点 1 的参数是 p1 = 0.1 MPa、T1 = 300 K；点 2 的参数是 T2 = 1000 K。如循环中是 1 kg 空气，其 cp = 1.01 kJ/(kg·K)，求循环热效率及净功。

①考点：由三个过程组成的非卡诺循环（定压 + 定熵 + 定温）。关键是先按题给条件把三个状态点算出来，再用「循环熵变为零」串起来。本题题给 cp = 1.01，须按题给值算（于是 cv = 1.01 − 0.287 = 0.723、k = cp/cv = 1.397）。

②取系统：1 kg 空气为闭口系统，且是循环（∮du = 0、∮ds = 0）。

③用方程：1-2 定压 q1 = cp(T2 − T1)、Δs12 = cpln(T2/T1)；2-3 定熵 T3/T2 = (p3/p2)(k−1)/k、Δs23 = 0；3-1 定温 Δs31 = q2/T1（q2 为放热绝对值）；循环闭合 ∮ds = Δs12 + Δs31 = 0。

④第一步：算三个状态点

点 2（定压 1→2）

p2 = p1 = 0.1 MPa；v2 = RT2/p2 = 0.287 × 1000/100 = 2.870 m³/kg

点 3（定熵 2→3，T3 = T1 = 300 K）

p3 = p2(T3/T2)k/(k−1) = 0.1 × (300/1000)3.5189 = 0.1 × 0.01435 = 1.435×10−3 MPa = 1.435 kPa

⑤第二步：吸热量（定压 1-2）

数字式

q1 = cp(T2 − T1) = 1.01 × (1000 − 300) = 707.0 kJ/kg；Δs12 = 1.01 × ln(1000/300) = 1.01 × 1.2040 = +1.216 kJ/(kg·K)

⑥第三步：放热量（定温 3-1）——用两种独立算法对撞，暴露题面问题

算法 A：由循环熵变为零

Δs31 = −Δs12 = −1.216 ⟹ q2 = T1|Δs31| = 300 × 1.216 = 364.8 kJ/kg

算法 B：由 3 点状态直接算

q2 = RT1ln(p1/p3) = 0.287 × 300 × ln(100/1.435) = 86.1 × 4.245 = 365.5 kJ/kg ✓

校核

算法 A 与算法 B 相差不到 0.2%（364.8 与 365.5），属有效数字差异，互相印证。

⑦第四步：净功与热效率

净功

wnet = q1 − q2 = 707.0 − 364.8 = 342.2 kJ/kg

热效率

ηt = wnet/q1 = 342.2/707.0 = 48.40%

⑧数值与讨论

与卡诺比较

同温限卡诺效率 ηc = 1 − 300/1000 = 70%，本题 48.4% 远低于它。原因清楚：吸热过程 1-2 是定压过程，工质温度从 300 K 连续升到 1000 K，吸热的平均温度远低于 T2 = 1000 K，所以效率低。这正说明「提高吸热过程的平均温度」是提高循环效率的根本途径——回热、再热等技术都基于这一原理。

题面提示本题三个过程条件是近似自洽的（差异来自题给 cp = 1.01 的取整与 k 的取值）：若按 k = 1.4 严格算，p3 = 0.1 × 0.33.5 = 4.93 kPa，此时 RT1ln(p1/p3) = 86.1 × ln(100/4.93) = 86.1 × 3.010 = 259.2 kJ/kg，与 364.8 不符——这才是真正的矛盾点：题给「1-2 定压到 1000 K」与「3-1 定温 300 K 且 2-3 定熵」不能同时严格成立。工程上按循环熵变为零（算法 A）为准，也是本讲义采用的口径：q1 = 707.0、q2 = 364.8、wnet = 342.2 kJ/kg、ηt = 48.40%。

答题建议考场上写「wnet = 342.2 kJ/kg、ηt = 48.4%」，并附一句：「同温限卡诺效率为 70%，本循环因吸热平均温度低而低于卡诺效率」即可。若老师按 k = 1.4 取 p3 = 4.93 kPa 并直接用定温放热算，则得 q2 = 259.2、wnet = 447.8、ηt = 63.3%，属另一口径；两口径的差别仅在于是否承认题面数据完全闭合，说明清楚即可，不影响对循环本质的理解。

q1 = cp(T2−T1) = 707.0 kJ/kg；Δs12 = cpln(T2/T1) = +1.216 kJ/(kg·K)；由循环 ∮ds = 0 得 q2 = T1|Δs31| = 364.8 kJ/kg。
净功 wnet = 342.2 kJ/kg，循环热效率 ηt = 48.40%（同温限卡诺效率 70%，因吸热为定压过程、平均吸热温度低而低于卡诺效率）。另口径若按 k = 1.4 得 p3 = 4.93 kPa 并直接用定温放热计算，则 q2 = 259.2 kJ/kg、wnet = 447.8 kJ/kg、ηt = 63.3%。

工程结论(1) ηt = 67.35%；(2) 每 1000 kJ 热量损失作功能力 26.5 kJ（占 2.65%）；(3) 符合 i = T0Δsiso，两种算法（熵增法、㶲差法）结果一致。

(1) ηt = 67.35%（W = 673.5 kJ，Q2 = 326.5 kJ）；(2) 作功能力损失 i = 26.5 kJ（因为 Δsiso = 0.08844 kJ/K，T0 = 300 K）；(3) 符合：T0Δsiso = 300 × 0.08844 = 26.5 kJ，与理想卡诺循环（η = 70%、W = 700 kJ）的作功之差 26.5 kJ 一致。

练 5-1　某热机在 800 K 与 300 K 之间工作，每循环吸热 500 kJ、放热 200 kJ。判断其能否实现。

关于本章题目的说明

本章公式与套路

1. 压气机的三类功（务必分清！）

过程压气功 wC出口温度特点
可逆定温 n = 1wC,T = RT1ln(p2/p1)T2 = T1耗功最小，是理论极限（须充分冷却）
可逆绝热（定熵）n = kwC,s = cp(T2 − T1) = kRT1[ε(k−1)/k − 1]/(k − 1)T2 = T1ε(k−1)/k无冷却，耗功最大

式中 ε = p2/p1 为增压比。记住次序wC,T < wC,n < wC,s，即：冷却越充分，耗功越小。

2. 压气机是开口稳态系统（这一点决定用哪个功）

能量方程

q = Δh + wt，　压气机耗功 wC = −wt = Δh − q

绝热时 wC = Δh = cp(T2 − T1)；定温时 wC = q（全部功以热量排出）。压气功是技术功，不是容积功——这是最容易错的地方。

3. 示功图（p–V 图）的三个面积

理想单级压气机（无余隙）的一个工作循环为：等压进气 4→1 → 压缩 1→2 → 等压排气 2→3 → （余隙内的气体）膨胀 3→4。

  • 面积 4-1-2-3-4（示功图总面积）= 一个循环消耗的指示功；
  • 等压进气线下方面积（4-1 与 p1 之间）= p1V1，是吸入气体带入的推功；
  • 等压排气线下方面积（2-3 与 p2 之间）= p2V2，是排出气体带走的推功；
  • 两者之差 p2V2 − p1V1 与压缩过程线之间的面积，才是真正的压气功 wC。

结论：示功图面积 = p1V1 + wC + 排气推功调整，所以「压气功 = 技术功」而不是「容积功」。

4. 余隙容积与容积效率

容积效率

λv = 1 − c[ε1/λ − 1]，　c = Vc/Vh（余隙比），ε = p2/p1

其中 λ 为余隙内气体膨胀过程的多变指数，Vh 为活塞行程容积。物理意义：余隙中残留的高压气体在吸气前先膨胀，占据了一部分行程容积，使实际吸入量减少。

三点重要推论：

  • 余隙容积不影响压气功（理想情况下功由压比与进气状态决定，与 c 无关），只减少吸气量；
  • λv 随 ε 增大而减小；当 ε1/λ = 1 + 1/c 时 λv = 0，这叫极限升压比，对应「压不上去」的物理极限；
  • 减小 c（提高加工精度、减小余隙）是提高容积效率的直接手段。

5. 多级压缩 + 中间冷却

为什么分级？压比大时：① 排气温度过高（会烧润滑油、降低效率）；② 容积效率过低；③ 耗功增大。分级压缩、级间冷却可同时解决这三个问题。

最佳中间压力

px = √(p1p2)，　即 ε1 = ε2 = √(p2/p1)

两级最小总功

wC,总 = 2wC,单级 = 2nRT1[εx(n−1)/n − 1]/(n − 1)（εx = √(p2/p1)）

中冷器出口温度恢复到 T1（理想完全冷却），故两级进气状态相同、每级压比相同、每级耗功相同。级数越多，总功越接近定温压气功，但级数增加会带来结构复杂、流动阻力增大，通常 2～3 级足够。

6. 实际压气机的评价指标

指标定义说明
定温效率 ηTηT = wC,T/wC,实际以定温压气功为理想基准，评价有冷却的压气机
绝热（定熵）效率 ηsηs = wC,s/wC,实际以定熵压气功为理想基准，评价无冷却的压气机
容积效率 λv实际吸气量/行程容积反映余隙影响

套路小结：压气机题的解题流程固定为——(1) 认清开口稳态系统；(2) 认清「耗功」是技术功 wC = −wt；(3) 由过程性质（定温/定熵/多变）求 T2 与 wC；(4) 有冷却时用 q = Δh − wC 回求放热量；(5) 有余隙时先算 λv 再折算实际吸气量与生产能力；（6）多级时先定最佳中间压力，再按单级公式平方（每级压比相同、每级功相同）。

空气由 p1 = 0.1 MPa、t1 = 20 ℃ 被压缩到 p2 = 0.8 MPa。试分别按可逆定温、可逆绝热（定熵）及多变指数 n = 1.3 三种过程，计算压缩 1 kg 空气所消耗的压气功和所放出的热量，并说明三者的大小关系。

②取系统：压气机为开口稳态系统（进、出口各一股气流，稳定流动）。1 kg 空气为控制质量。

三种功

放热量

(2) 可逆绝热（定熵）压缩

补充例题 7-2补充例题

某单级往复式压气机的余隙容积比 c = Vc/Vh = 5%，活塞行程容积 Vh = 0.010 m³，进气压力 p1 = 0.1 MPa，排气压力 p2 = 0.8 MPa，余隙内气体的膨胀过程多变指数 λ = 1.3。求：(1) 容积效率 λv；(2) 每个循环实际吸入的气体体积（按进气状态计）；(3) 若余隙容积比增大到 10%，容积效率变为多少？(4) 该压气机在此压比下的极限余隙容积比（使 λv = 0）是多少？

①考点：余隙容积对吸气量的影响，即容积效率公式的应用。核心是「余隙中的高压气体先膨胀，占掉一部分行程容积」。

②取系统：取气缸内余隙容积中的残留气体为研究对象（闭口系统，多变膨胀 3→4）。

③用方程：多变过程 V4 = V3(p3/p4)1/λ = Vcε1/λ；有效吸气体积（按进气状态）

容积效率

λv = (Vh + Vc − V4)/Vh = 1 − c(ε1/λ − 1)

④关键代入式：c = 0.05，ε = 0.8/0.1 = 8，λ = 1.3。

(1) 容积效率（先算 ε1/λ）

符号式

λv = 1 − c(ε1/λ − 1)，　ε1/λ = 81/1.3 = 80.76923

数字式

80.76923 = 4.9509，　λv = 1 − 0.05 × (4.9509 − 1) = 1 − 0.05 × 3.9509 = 1 − 0.19755 = 0.8025 = 80.25%

(2) 每循环实际吸气体积（按进气状态计，即折合到 p1、T1 的体积）

数字式

V有效 = λvVh = 0.8025 × 0.010 = 8.025×10⁻³ m³

对比无余隙时的 0.010 m³，少吸了 19.75%。（余隙容积本身 = cVh = 5% × 0.010 = 5×10⁻⁴ m³；膨胀后占据体积 V4 = Vc·4.9509 = 2.475×10⁻³ m³，正是被「占掉」的那部分行程容积：0.010 + 0.0005 − 0.002475 = 8.025×10⁻³ m³ ✓。）

(3) 若 c = 10%

数字式

λv = 1 − 0.10 × 3.9509 = 1 − 0.39509 = 0.6049 = 60.49%

余隙比从 5% 增到 10%（翻倍），容积效率从 80.25% 降到 60.49%，下降 19.76 个百分点。可见余隙容积对生产能力的影响非常显著，尤其在大压比时。

(4) 极限余隙容积比（λv = 0 即「压不上去」）

符号式

令 1 − c极限(ε1/λ − 1) = 0　→　c极限 = 1/(ε1/λ − 1)

数字式

c极限 = 1/(4.9509 − 1) = 1/3.9509 = 0.2531 = 25.31%

即：在 ε = 8、λ = 1.3 的条件下，若余隙容积比达到 25.3%，压气机将完全无法吸气（容积效率为零）——这就是极限升压比概念的来源。

⑤数值与讨论：

极限升压比

由 λv = 0 解出 ε极限 = (1 + 1/c)λ

取 c = 0.05、λ = 1.3：ε极限 = 211.3 = 44.3，即单级最多能把 0.1 MPa 压到 4.43 MPa（实际远达不到，因为温度与效率的限制更早出现）。三个重要结论① 余隙容积不改变压气功（理想情况下功只取决于压比与进气状态），只减少吸气量；② λv 随 ε 增大而减小、随 c 增大而减小；③ 这正是大压比必须分级压缩的原因之一（另一原因是排气温度过高）。

(1) λv = 80.25%；(2) 每循环实际吸气 8.025×10⁻³ m³（比行程容积少 19.75%）；(3) 若 c = 10%，λv = 60.49%；(4) 极限余隙容积比 c极限 = 25.31%（对应极限升压比 ε极限 = 44.3）。

空气由 p1 = 0.1 MPa、t1 = 20 ℃ 分级压缩到 p2 = 0.9 MPa，采用两级压缩 + 中间完全冷却（级间冷却器把空气冷却回 20 ℃），各级的多变指数均为 n = 1.3。求：(1) 最佳中间压力 px；(2) 两级压缩的总压气功，并与单级压缩到此压比时比较，节省多少？(3) 若级数无限多（即完全定温压缩），最小压气功是多少？(4) 中间冷却器中每 kg 空气放出的热量。
