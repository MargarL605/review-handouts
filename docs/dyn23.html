第 2 章 动量定理与质量流

2.1 动量、冲量与动量定理

一、三个基本量的定义

质点的动量：p = mv，矢量，方向与速度同向，单位为 kg·m/s。

质点系的动量：各质点动量的矢量和
p = Σmivi = mvC（m = Σmi，vC 为质心速度）

冲量：力在一段时间内的累积效应，I = ∫t1t2 F dt，单位为 N·s。

二、动量定理（要背到能默写投影式）

质点：m dv/dt = F，即 d(mv)/dt = F（质量恒定时两者等价）。

质点系微分形式：dp/dt = ΣFj(e)，投影式为

2-1

dpx/dt = ΣFjx(e)，  dpy/dt = ΣFjy(e)，  dpz/dt = ΣFjz(e)

质点系积分形式：p2 − p1 = I = ΣIj，即末动量减初动量等于外力冲量的矢量和。

内力不出现在方程中：内力只能改变系统内各质点之间动量的交换，不能改变质点系的总动量。

三、动量守恒（两种提法不要混）

若 ΣF(e) = 0，则 p = p0 = 常矢量（大小、方向都不变）。

若某轴方向 ΣFx(e) = 0，则只在该轴上 px = 常数（其余两轴照常列方程）。

易错点：动量守恒说的是质点系总动量不变，不是每个质点不动；爆炸、碰撞、人走船退都属于这一类。

四、常见刚体（刚体系）的动量计算

平动刚体：p = mvC；定轴转动刚体（质心在轴上）：p = 0；定轴转动刚体（质心不在轴上）：p = mvC，大小为 m·dω，方向垂直于质心到轴的连线。

刚体系：p = ΣmivCi，逐个刚体算出再用矢量（或投影）相加。课件中的判例：半径 r、质量 m 的圆环与质量 2m 的圆环以同一 ω 绕轴转动，环心在轴上时前者 p1 = mrω、后者 p2 = 2mrω，故 p1 < p2——动量大小看的是 m·vC，与转动惯量无关。

例 2-1课件原例起吊机构支座约束力
图示起吊机构，已知吊装物体的重量为 P1、P2，重物上升（下降）的加速度为 a，不计轮子与吊索的重量。试求支座处的约束力。

（1）选取系统与坐标系：取 整个起吊机构 + 被吊物体为质点系（含支架、轮、吊索、重物），建立直角坐标，y 轴铅直向上。

（2）受力分析：外力只有支座约束力 Fx、Fy，机构重量（不计轮重，只剩吊装物体的重量 P1、P2 与支架自重，题中不计支架重量）。绳子张力和轮轴力都是内力，自动抵消。

（3）运动分析：全机构一个自由度，各点加速度都已知为 a（方向铅直）。列出各质点动量在 y 轴的投影

a

py = (P1 − P2)v/g  (两物体速度方向相反，一个上升一个下降)

（4）用质心运动定理（即 dpy/dt = ΣFy）：

b

(P1 − P2)a/g = Fy − P1 − P2

得 Fy = P1 + P2 + (P1 − P2)a/g；因全部外力均为铅直方向，Fx = 0。

（5）讨论：令 P1 = P2 = P（空载或轻载），则 Fy = 2P，与加速度无关——这就是「静止时称出的重量」；只有当两侧物体不等重且作加速运动时才出现附加动约束力 (P1 − P2)a/g。

答：Fy = P1 + P2 + (P1 − P2)a/g（向上为正），Fx = 0，单位 N。
用动量定理解题的固定步骤
  1. 选系统：结构复杂时选整体（内力自动消去）；某处约束力不在整体方程中出现时再拆出局部。
  2. 受力分析：只画外力，逐项核对（重力、支反力、摩擦、流体压力、螺栓力……）。
  3. 运动分析：明确各刚体质心速度/加速度的方向与大小，能写出 p 的投影表达式。
  4. 判断守恒：某一方向外力为零且初动量为零/已知 → 直接用广义动量守恒，跳过求解过程。
  5. 代入 dpx/dt = ΣFx(e)（或积分形式），解出待求量并说明方向与单位。

2.2 质心运动定理与质心运动守恒

一、质心运动定理

由 p = mvC 代入动量定理得

2-2

maC = ΣFj(e)  即  m d²rC/dt² = ΣFj(e)

投影式：maCx = ΣFx(e)，maCy = ΣFy(e)，maCz = ΣFz(e)。

含义：质心的运动只取决于外力系的主矢，内力（爆炸力、肌肉力、齿轮啮合力、绳内张力……）无论多大都改变不了质心的运动状态。质点系质量全部「集中」在质心，外力全部「搬到」质心上——这就是把复杂系统当质点算的合法性来源。

二、质心运动守恒的两种情形（考试高频）

情形 1（全守恒）：ΣF(e) = 0 且初速度 vC0 = 0 ⟹ vC ≡ 0，rC = 常矢量，即质心位置始终不动。

情形 2（沿某轴守恒）：ΣFx(e) = 0 ⟹ vCx = 常数；若再有 vCx0 = 0，则 xC = 常数，即质心在该轴上的坐标不变。

实用写法（求位移的利器）：xC = Σmixi/m = 常数 ⟹ ΣmiΔxi = 0；反冲、人走船退、抛体空中爆炸等问题一步到位。

例 2-2课件原例曲柄滑块机构的铰 O 水平约束力
已知曲柄 OA 长 r、质量为 m（均质杆），滑块 A 的质量为 m（题设已把连杆质量并入滑块），机构置于铅垂平面内，曲柄以匀角速度 ω 绕 O 转动。试用质心运动定理求铰 O 处的水平约束力 FOx。

（1）选系统：取曲柄 + 滑块为质点系（铰 O 与滑道的约束力成为外力）。建立坐标系：x 水平向右，y 铅直向上，圆心 O 为原点；设曲柄与 x 轴夹角 φ = ωt（匀速转动）。

（2）受力分析：外力 = 铰 O 处的约束力 FOx、FOy，滑道的铅直约束力 N，两构件的重力 mg（铅直，故对水平方向无贡献）。

（3）运动分析：杆质心 C1：(r/2·cosωt, r/2·sinωt)；滑块（视为质点）A：(rcosωt, 0)。于是水平动量为

a

px = m[−(r/2)ωsinωt] + m[−rωsinωt] = −(3/2)m r ωsinωt

（4）代入 x 方向动量定理 dpx/dt = ΣFx(e) = FOx：

b

FOx = −(3/2)m r ω²cosωt

（5）讨论：FOx 是周期函数，最大值为 (3/2)m r ω²，且随 ω² 增长——高速机械的动约束力必须按 ω² 校核；若把转角起点改取竖直方向，则结果写成 ±(3/2)m r ω²sinωt，是同一结论的不同相位写法。

答：FOx = −(3/2)m r ω²cosωt（φ=ωt 自 x 轴量起），最大值 (3/2)m r ω²，单位 N。
例 2-3课件原例固定在基础上的电机：螺栓与基础承受的最大力
电动机重 Q1，外壳用螺栓固定在基础上；转轴上装一匀质杆，长 l、重 Q2，杆端固连一重 Q3 的小球（视为质点）。电机以匀角速度 ω 转动，杆在铅垂平面内。试求螺栓和基础作用于电机的最大总水平力及最大铅直力。

（1）选系统：取电机 + 杆 + 小球整体为质点系——螺栓力、基础反力、重力都是外力，轴与杆之间的相互作用力是内力。

（2）受力分析：x 方向只有螺栓的约束力 Fx；y 方向有基础反力 Fy 与三个重力 Q1、Q2、Q3。

（3）运动分析（设杆从水平位置开始计时，转角 φ = ωt）：杆质心坐标 = (l/2·cosωt, l/2·sinωt)，小球坐标 = (lcosωt, lsinωt)，故

a

px = −(Q2/2 + Q3)(lω/g)sinωt，  py = (Q2/2 + Q3)(lω/g)cosωt

（4）列两个方向的动量定理：

b

Fx = dpx/dt = −(Q2/2 + Q3)lω²cosωt/g

c

Fy − Q1 − Q2 − Q3 = dpy/dt ⟹ Fy = Q1 + Q2 + Q3 − (Q2/2 + Q3)lω²sinωt/g

（5）取最大值：|Fx|max = (Q2/2 + Q3)lω²/g；Fy 的最大值出现在 sinωt = −1，即杆转至最上方时，Fy,max = Q1+Q2+Q3 + (Q2/2+Q3)lω²/g。

答：最大总水平力 = (Q2/2 + Q3)lω²/g；最大铅直力 = Q1 + Q2 + Q3 + (Q2/2 + Q3)lω²/g，单位 N。
例 2-4课件原例若螺栓不固定：电机外壳的运动规律
承例 2-3，把电机不固定地放在光滑水平面上（外壳不固定），初始时刻电机静止，并取外壳中心为坐标原点。电机以匀角速度 ω 转动（杆长 l、重 Q2，杆端小球重 Q3）。试求外壳质心的运动规律及平面对电机的正压力。

（1）水平方向：质心守恒。系统（外壳 + 杆 + 小球）在水平方向不受外力，且初始静止 ⟹ xC = 常数，取 xC = 0（以初始位置定原点）。设外壳质量为 Q1/g，其质心坐标为 x1，则杆质心与小球相对外壳的水平偏置分别为 (l/2)cosωt 与 lcosωt，由 Σmixi = 0：

a

(Q1+Q2+Q3)x1 + (Q2l/2 + Q3l)cosωt = 0

b

x1 = −(Q2/2 + Q3)lcosωt/(Q1+Q2+Q3)

即外壳作简谐往复运动，振幅为 (Q2/2+Q3)l/(Q1+Q2+Q3)：杆转半圈，外壳整体倒退一个「质心不动」所要求的距离；杆转一圈，外壳回到原位。

（2）铅直方向：正压力随位置变化。y 方向 py = (Q2/2+Q3)(lω/g)cosωt（例 2-3（a）式同理），故

c

FN = Q1+Q2+Q3 − (Q2/2+Q3)lω²sinωt/g

（3）讨论：当 (Q2/2+Q3)lω²/g > Q1+Q2+Q3 时 FN 会出现负值——物理含义是电机跳离光滑面。这正是课件留下的思考题「若螺栓不固定？」的答案：外壳会一边水平往复、一边可能在高速时跳起。

答：x1 = −(Q2/2+Q3)lcosωt/(Q1+Q2+Q3)（单位 m）；FN = Q1+Q2+Q3 − (Q2/2+Q3)lω²sinωt/g（单位 N）。
考点提醒

「已知加速度求约束力」用质心运动定理（例 2-1～2-3）；「外力为零求位移/运动规律」用质心运动守恒（例 2-4）。两者其实是同一个方程的两种用法，判断标准只有一条：待求量在方程左边（加速度）还是右边（约束力）。

2.3 定常质量流：流体与固体的相互作用

一、什么叫质量流

质量流：非刚性、开放的质点系统（流体、砂石、传送带上的散料、燃气……）在运动过程中与外界不断交换质量。课件把质量流分成三种形式：流体形式（管道中的水、气）、颗粒形式（砂石、谷物、传送带装料）、气体形式（喷气发动机、火箭喷流）。

定常质量流：在每一位置点，流体质点都具有相同的速度（不随时间变化），即流场是定常的。

课件思考题（考点式提问）：把台式电风扇放在光滑台面上通电，会发生什么？——风扇叶片把空气向后（沿轴向）加速排出，气流获得向后的动量，由动量守恒（水平方向外力为零）风扇本体必获得向前的动量，于是风扇自己沿着「吹风的反方向」在台面上滑走。

二、流量与流速的关系
2-3

qV = A v  （体积流量，m³/s）     qm = ρqV = ρA v  （质量流量，kg/s）

其中 ρ 为流体密度，A 为截面面积，v 为该截面上的流速。定常质量流的流量为常数，故变截面管道中 A1v1 = A2v2（连续性条件）。

课件给出的两条理想化假设：① 质量流是不可压缩流动；② 质量流是非黏性的——忽略流层之间以及质量流与管壁之间的摩擦力。做题时若无特别说明，均按此处理。

三、定常质量流的动量定理（控制体积法，必须背熟）

取 t 时刻位于 1—2 两截面之间的流体为考察对象，考察 Δt 内动量的改变：由于定常流动，公共部分 1′—2 的动量不变，动量改变只来自「流入 1—1′ 段」与「流出 2—2′ 段」的差别，于是

2-4

ΣF = qm(v2 − v1) = ρqV(v2 − v1)

式中 ΣF 是作用在这段流体上的全部外力，包括：

  • F1、F2——入口和出口处横截面所受相邻质量流的压力；
  • W——这段质量流的重力；
  • FN——管壁（或固体边界）的约束力合力。

即完整形式为 F1 + F2 + W + FN = qm(v2 − v1)，由此解出 FN 后取反作用力，即得流体对固体的作用力。

附加动约束力：把约束力分解为 FN = FNs + FNd，其中 FNs 是静约束力（流体静止时的约束力），

2-5

FNd = qm(v2 − v1) ——流体流动时的约束力与流体静止时的约束力之差

它只与流量和流速改变有关，与压力无关。弯管、喷嘴、阀门、水轮机叶片所受的巨大冲击力主要来自这一项，且与流速成平方关系。

例 2-5课件原例水射流冲击墙面
水泵以速度 v1 将水垂直喷射在墙面上，水又以速度 v2 沿两侧对称地反射出去，出流方向相对入射方向偏转 β 角。已知体积流量 qV、水的密度 ρ。试求墙面受到的水流作用力。

（1）选系统与坐标系：取贴在墙面上的那部分水流为控制体积，x 轴取水流原方向（指向墙面），y 轴平行墙面。

（2）受力分析：外力 = 墙面对水流的约束力 FN（沿 −x）、水流重力（水平方向投影为零）、入口与出口截面的压力（出口为大气，入口在射流中压力也为大气，故均为零）。

（3）运动分析：入流动量沿 +x，大小 qmv1；出流分成两股、每侧流量 qm/2，两股均向 −x 方向退回、与 −x 轴成 β 角，故 x 向出流动量合计为 −qmv2cos β（两股的 y 向分量等值反向，自动抵消）。

（4）沿 x 向用定常质量流动量定理：

a

−FN = qm(v2x − v1x) = qm(−v2cos β − v1)

b

FN = ρqV(v1 + v2cos β) = ρqV(v1 − v2cos β′)（β′ = 180° − β 为偏转角）

（5）取反作用力：水对墙面的作用力与 FN 等值反向，方向沿射流原方向，大小

c

F = ρqV(v1 + v2cos β)

（6）两个特例（务必记住）：
① 水沿墙面流散（β = 90°，v2 ⊥ v1）：F = ρqVv1 = ρA v1²；
② 理想全反射（β = 0°，v2 = v1）：F = 2ρqVv1 = 2ρA v1²——这就是水轮机（培尔顿水斗）与喷丸强化的理论依据。

答：F = ρqV(v1 + v2cos β)，方向沿射流入射方向；特例 β=90° 时 F = ρqVv1，单位 N。
例 2-6课件原例喷嘴与管道连接的螺栓受力
水流以体积流量 qV 通过内径 d1 的管道，由内径为 d2 的喷嘴射入大气，管道内压力为 p1（表压），水的密度为 ρ。管道与喷嘴之间通过法兰用 6 个螺栓相连。试求每个螺栓的受力。

（1）选系统：取喷嘴内的水流（1—1 截面到 2—2 截面之间的流体）为考察对象，x 轴沿喷嘴轴线、指向出口。

（2）受力分析（三项，缺一不可）：

  • 1—1 截面：上游管道内水流对它的压力 p1A1，方向 +x；
  • 2—2 截面：喷嘴右侧大气对它的压力 p2A2，因射入大气 p2 ≈ 0（表压），此项为零；
  • 喷嘴内壁对水流的约束力 FN，沿喷嘴轴线方向；重力在水平方向无投影。

（3）运动分析（连续性方程定流速）：

a

v1 = 4qV/(πd1²)，  v2 = 4qV/(πd2²)，  A1 = πd1²/4

（4）沿 x 向列定常质量流动量方程（注意出流速度大、入流速度小，动量变化项为 qm(v2 − v1)）：

b

FN + p1A1 − p2A2 = ρqV(v2 − v1)

（5）取反作用力求螺栓力：喷嘴内壁对水流的约束力为 FN = qm(v2 − v1) − p1A1（方向 −x）；水流对喷嘴的作用力与之等值反向，其沿轴线把喷嘴向外（+x）推的分量为

c

FN′ = p1A1 + ρqV(v1 − v2) = p1A1 − ρqV(v2 − v1)

物理解释：入口压力 p1A1 把水向前推，其中一部分用于使水流加速（动量项 ρqV(v2−v1)），余下部分传递给喷嘴。由于 d1 > d2 ⟹ v1 < v2，动量项方向朝管道一侧；正常流量下 p1A1 占优，故 FN′ > 0，法兰螺栓受拉，每个螺栓受力为

d

Fb = FN′/6 = [p1A1 + ρqV(v1 − v2)]/6

（6）讨论：喷嘴出口越细（d2 越小），v2 越大，动量项 ρqV(v2−v1) 越大，螺栓受力越小甚至反向受压；反之若流量很小而压力很高，则 FN′ ≈ p1A1 全部由螺栓承担——这正是高压管路法兰必须按压力项校核的原因。

答：每个螺栓受力 Fb = [p1A1 + ρqV(v1 − v2)]/6，其中 v1 = 4qV/(πd1²)、v2 = 4qV/(πd2²)，单位为 N，方向沿喷嘴轴线（正常流量下为拉力）。
例 2-7补充水平—铅直 90° 变径弯管的受力（含两端压力项）
水在 90° 变径弯管中定常流动：由内径 d1 = 200 mm 的水平管流入（表压 p1 = 20 kPa），从内径 d2 = 100 mm 的竖直管向上流出（表压 p2 = 5 kPa），体积流量 qV = 0.06 m³/s，ρ = 1000 kg/m³，忽略管内水的重力在水平方向的影响。求水流对弯管的作用力。

（3）运动分析：A1 = π(0.2)²/4 = 0.0314 m²，A2 = π(0.1)²/4 = 0.00785 m²；qm = ρqV = 60 kg/s；v1 = qV/A1 = 1.91 m/s，v2 = qV/A2 = 7.64 m/s。

a

x 向：p1A1 + Rx = qm(0 − v1) ⟹ Rx = −(p1A1 + ρqVv1) = −(628 + 115) = −743 N

b

y 向：Ry − p2A2 = qm(v2 − 0) ⟹ Ry = p2A2 + ρqVv2 = 39 + 458 = 498 N

（5）取反作用力：水流对弯管的作用力 F = −R，即

c

Fx = 743 N（沿入流方向），  Fy = −498 N（沿出流的反方向）

d

F = √(743² + 498²) = 894 N，与入流方向成 33.8° 的斜下方

答：F ≈ 894 N，方向与入流方向成 33.8° 斜向下（分量 Fx = 743 N、Fy = −498 N）。

  1. 画控制体积：入口、出口各取一个垂直于流速的截面，边界包含全部与固体接触的面。
  2. 写出入流、出流的速度矢量（大小由 v = qV/A 或连续性条件确定）。
  3. 受力分析四件套：入口压力 p1A1、出口压力 p2A2、重力 W、固体边界约束力 FN（表压为零的截面不要写压力项）。

2.4 变质量系统：落链、传送带装料与火箭拓展

说明：本节内容课件第 2 章只以「质量流的颗粒形式／气体形式」点出（见 2.3 节开头），未展开推导，以下按通用变质量动力学结论补充，公式与 2.3 节课件给出的 ΣF = qm(v2 − v1) 完全一致。
一、变质量系统的基本方程（Meshchersky 方程）

设 t 时刻研究对象质量为 m、速度为 v；在 dt 内有质量 dm 并入（dm > 0）或分出（dm < 0），并入（分出）前该部分质量为 v1。对「主体 + 并入/分出质量」整体用动量定理，得

2-6

m dv/dt = ΣF + (v1 − v) dm/dt

附加力项 (v1 − v)dm/dt 的来源：它不是新的自然界力，而是把「质量进出」折算成对主体的等效作用力——并入的质量带着自己的动量「撞进」主体，其动量改变率就是主体受到的附加反作用（推力/反推力）。因此变质量系统不能直接写 d(mv)/dt = ΣF（那是质量不变时的形式），必须用式（2-6）。

  • 质量并入（落链、装料、雨滴、沾湿的雪球）：dm/dt > 0，附加力方向取决于 v1 − v；
  • 质量分出（火箭、喷流、漏砂的沙漏车）：dm/dt < 0，等效为反推力（thrust）。
例 2-8补充传送带装料：驱动力的「一半能量去哪了」
传送带以恒定速度 v = 1.5 m/s 水平输送散料，料斗在带的铅直上方连续落料，落料的质量流量 qm = 20 kg/s，落料到达带面时的水平速度为零。忽略带与托辊的摩擦，求驱动传送带所需的水平力 F 与驱动功率 P，并比较散料所获得的动能率。

（1）选系统（控制体积）：取带面上「落料点附近、随带一起运动的散料」为控制体积——入口是铅直落下的散料，出口是随带匀速前进的散料。

（2）受力与运动分析：水平方向外力只有皮带对散料的摩擦力（即驱动力 F 通过皮带传来）；入流水平速度 v1x = 0，出流水平速度 v2x = v。

（3）沿运动方向用定常质量流动量定理：

a

F = qm(v2x − v1x) = qmv = 20 × 1.5 = 30 N

（4）驱动功率 P = F v = 30 × 1.5 = 45 W。

（5）能量校核（易错点）：每秒落料 qm 被加速到 v，其动能率 = ½qmv² = ½ × 20 × 1.5² = 22.5 W，只占驱动功率的一半；另一半 22.5 W 消耗在散料与皮带之间的相对滑动摩擦上（散料从 0 加速到 v 的过程中平均相对速度不为零）。所以此类问题不能用动能定理直接求驱动力，必须用动量定理或变质量方程。

答：F = qmv = 30 N（方向沿带运动方向），P = qmv² = 45 W；散料动能率仅 22.5 W。
例 2-9补充落链：台秤读数为什么是 3 倍重量
一条长链从静止开始铅直自由下落，落到水平的秤盘上（链落到盘上后立即静止）。已知链条单位长度的质量为 λ（kg/m），重力加速度为 g。求链条开始下落后 t 时刻（链条尚未落完）台秤的读数。

（1）选系统：取已落到秤盘上的那段链条为研究对象——它是一个质量随时间增加的系统（不断有新的链节并入）。

（2）受力分析：秤盘的支持力 N（向上）、已落段的重力 W = λy g（向下，y 为已落长度），以及新链节并入时的附加力。

（3）运动分析：自由下落段 y = ½gt²，落地速度 v = gt；单位时间落下的质量 dm/dt = λv = λgt。

（4）用变质量方程（或直接算动量流）：已落段速度恒为零（v = 0），并入质量的速度 v1 铅直向下、大小 v，代入式（2-6）：0 = N − λyg + (−v − 0)(λv) ⟹

a

N = λyg + λv² = λyg + λg²t²

（5）化简：由 y = ½gt² 得 λg²t² = λg(gt²) = λg·2y = 2λyg，故 N = 3λyg：落下的冲击附加力恰好等于已落链条重量的 2 倍。

（6）讨论：读完数随时间按 t² 增长，N = (3/2)λg²t²；若链条是匀速（不是自由）落下，则附加力只有 λv²，与「重力项」无关——把链条「从地面匀速提起」时所需拉力 F = λxg + λv² 同理（提链问题与落链问题互为镜像）。

答：N = 3λyg = (3/2)λg²t²，即台秤读数为已落链条重量的 3 倍，单位 N。
例 2-10补充火箭方程与推力来源
某火箭在无外力（太空、忽略引力）中由静止起飞，燃气相对火箭的喷射速度（有效排气速度）恒为 u = 2000 m/s，初始质量 m0，燃料烧完后的质量 m = m0/3。求火箭的最终速度；若改为在地面铅直向上发射（重力加速度 g，燃烧时间 20 s），求最终速度表达式。

（1）选系统与受力分析：取火箭（含剩余燃料）为主体，它是一个不断分出质量的系统。设喷气质量流量 q = −dm/dt > 0，喷出气体相对火箭的速度为 u（方向与火箭运动方向相反）。

（2）用变质量方程求推力：取主体速度 v 为正方向，喷出前的速度 v1 = v − u（沿正方向的分量为 v − u），dm/dt = −q，代入式（2-6）：

a

m dv/dt = ΣF + (−u)(−q) = ΣF + uq  ⟹  反推力 Ft = uq = −u dm/dt

（3）无外力情形的积分（火箭方程）：取 ΣF = 0，则 m dv/dt = −u dm/dt ⟹ dv = −u dm/m，积分得

2-7

v = v0 + u ln(m0/m)

代入数据：v = 0 + 2000 × ln 3 = 2000 × 1.0986 = 2197 m/s。可见提高末速度只有两条路：提高有效排气速度 u（改发动机），或提高质量比 m0/m（多带燃料、减轻结构，因此需要多级火箭）。

（4）地面铅直发射：ΣF = −mg，故 dv = −u dm/m − gdt，积分（v0 = 0）：

b

v = u ln(m0/m) − gt = 2197 − 9.8 × 20 = 2001 m/s

（5）结论与提醒：推力 uq 只取决于排气速度与质量流量，与外界空气无关（所以火箭能在真空中工作）；反推力项是「分出的质量把动量带走」的等效结果，属于式（2-6）的附加力项，不是外加的力。

答：太空情形 v = u ln(m0/m) = 2197 m/s；地面铅直发射 v = u ln(m0/m) − gt = 2001 m/s（取 g = 9.8 m/s²，t = 20 s）。

第 3 章 动量矩定理

本章解决动量定理解决不了的问题：力矩与转动之间的关系。课件用一个判例开场——同一匀质圆盘放在光滑面上，作用力过质心时只平动不转动，作用力偏离质心时边平动边转动；动量定理对两种情形给出的 dp/dt 完全相同，无法区分，必须再补一条关于「矩」的定理。

3.1 动量矩（角动量）的定义与计算

一、质点的动量矩

动量矩 = 动量对某点或某轴的矩。对任意点 O′（可以是动点）：

3-1

LO′ = r′ × mv，  对 z 轴：Lz = Mz(mv) = ±m v·d

其中 r′ 是由取矩点 O′ 引向质点的矢径；d 为速度作用线到 z 轴的距离，正负号按右手螺旋与轴的指向一致取正。

二、质点系的动量矩（三种运动形式要分开记）

质点系对任意点 O′：LO′ = Σr′i × mivi；选质心 C 为取矩点时，把运动分解为「随质心平动 + 相对质心转动」：

3-2

LO′ = rC′ × mvC + LC，  LC = ΣriC × miviC（相对质心的动量矩）

  • 平移刚体：相当于质量集中于质心的单质点问题，LO′ = rC′ × mvC；
  • 定轴转动刚体（对转轴 z）：Lz = Jzω，方向与 ω 相同（Jz = Σmiri² 为刚体对 z 轴的转动惯量）；
  • 平面运动刚体（只研究垂直于运动平面的投影）：Lz = JCω ± m vC·d，即「相对质心转动的动量矩 + 随质心平动的动量对取矩点之矩」。

易错提示：定轴转动刚体对转轴的动量矩是 Jzω，但对其他点（如质心在轴上的情形对轴上另一点）则要用 LO′ = rC′ × mvC + LC 完整计算，不能张口就写 Jω。

例 3-1课件原例轮—凹面—杆系统对 O 点的动量矩
半径为 r 的匀质轮在半径为 R 的固定凹面上只滚不滑，轮重 Q；匀质杆 OC 重 P、长 l = R − r，一端铰接于 O、另一端与轮心 C 相连。图示瞬时杆 OC 的角速度为 ω。试求系统在该瞬时对 O 点的动量矩。

（1）运动分析：杆 OC 定轴转动，角速度 ω；轮心 C 的速度 vC = lω = (R − r)ω，方向垂直于 OC。轮与曲面只滚不滑，接触点为轮的瞬心，故由 vC = ω轮r 得轮的角速度 ω轮 = (R − r)ω/r。

（2）杆对 O 的动量矩（定轴转动，绕端点转动的均质杆 JO = Pl²/(3g)）：

a

LO(杆) = JOω = Pl²ω/(3g) = P(R−r)²ω/(3g)

（3）轮对 O 的动量矩（平面运动，用式 3-2：相对质心 + 随质心平动）：

b

LO(轮) = JCω轮 + (Q/g)vC·l = (Q/2g)r²·(R−r)ω/r + (Q/g)(R−r)²ω

c

LO(轮) = (Q/g)(R−r)ω[r/2 + (R−r)] = (Q/g)(R−r)(R − r/2)ω

（4）叠加（两部分转向相同，代数相加）：

3-3

LO = ω{(P/3g)(R−r)² + (Q/g)(R−r)(R − r/2)}

答：LO = (ω/g)(R−r)[P(R−r)/3 + Q(R − r/2)]，方向与 ω 同向，单位 kg·m²/s。
求动量矩的步骤
  1. 先判定每个刚体的运动形式（平移／定轴转动／平面运动），选定取矩点或取矩轴。
  2. 平移刚体：只算 rC × mvC；定轴转动刚体：对转轴直接 Jzω。
  3. 平面运动刚体：L = JCω ± m vCd，两项转向相同的取「+」。
  4. 多个刚体时代数（或矢量）求和，注意转向相反者要变号。

3.2 质点系动量矩定理

一、对固定点（最基本形式）
3-4

dLO/dt = ΣMO(Fj(e))  （微分形式）    L2 − L1 = Σ∫t1t2 MO(Fj(e))dt （积分形式，右端称冲量矩）

投影式：dLx/dt = ΣMx(F(e))，dLy/dt = ΣMy(F(e))，dLz/dt = ΣMz(F(e))。

守恒：若 ΣMO(F(e)) = 0，则 LO = 常矢量；若 ΣMz(F(e)) = 0，则 Lz = 常数（这就是转速与转动惯量成反比的依据：Jzω = 常数）。

内力与轴力的矩自动消去：这正是动量矩定理能跳过铰链内力、直接联系外力矩与运动的原因。

二、对动点与对质心（修正项什么时候为零）

对任意动点 O′（以随 O′ 平动的坐标系计动量矩）有

3-5

dLO′/dt + m vO′ × vC = ΣMO′(Fj(e))

左侧第二项是修正项（对应于牵连惯性力对 O′ 的矩）。使修正项为零的常见情形：

  • O′ 为固定点（vO′ = 0）；
  • O′ 为质心 C（vO′ = vC，叉积 vC × vC = 0）——于是得到最常用的相对质心的动量矩定理；
  • O′ 作匀速直线运动（vO′ 为常矢量，配合质心运动定理可证）；
  • vO′ ∥ vC（例如轮纯滚动时的速度瞬心 I）。
3-6

相对质心：dLC/dt = ΣMC(Fj(e))；守恒条件：ΣMC(F(e)) = 0 ⟹ LC = 常矢量

两条独立方程：质心运动定理（maC = ΣF(e)）与相对质心动量矩定理（dLC/dt = ΣMC）联立，构成求解质点系平面问题的一组独立动力学方程——这是本章后半部分所有刚体动力学方程的共同来源。

例 3-2补充离合器结合：动量矩守恒与动能损失（冲击类综合题）
飞轮 A 对转轴的转动惯量 J1 = 10 kg·m²，原以角速度 ω0 = 30 rad/s 转动；同轴线的从动盘 B 的转动惯量 J2 = 5 kg·m²，原来静止。二者通过摩擦离合器逐渐结合，结合过程中轴的摩擦力矩可忽略，结合后以同一角速度 ω 转动。求结合后的角速度 ω 以及结合过程损失的动能。

（1）选系统与受力分析：取 A + B 为一个质点系，转轴方向无外力矩（重力、轴承反力对轴的矩为零），离合器摩擦面之间的摩擦力矩是内力矩，自动消去。

（2）动量矩守恒：ΣMz(F(e)) = 0 ⟹ Lz = 常数：

a

J1ω0 = (J1 + J2)ω ⟹ ω = J1ω0/(J1+J2) = 10×30/15 = 20 rad/s

（3）动能核算（转动动能 T = ½Jω²）：

b

T1 = ½×10×30² = 4500 J，  T2 = ½×15×20² = 3000 J，  ΔT = 1500 J

（4）损失的能量去哪了：消耗在离合器摩擦面相对滑动上（发热、磨损）。可见动量矩守恒不等于动能守恒——这与「完全非弹性碰撞动量守恒而动能不守恒」是同一类问题；通式 ΔT = J1J2ω0²/[2(J1+J2)] = 10×5×900/(2×15) = 1500 J，与上面一致。

（5）讨论：若两轮结合后要求「无能量损失」，则必须用可控离合器按无滑动条件匹配角速度，此时动量矩与动能同时满足——实际工程中总是牺牲效率换取结构简单。

答：ω = J1ω0/(J1+J2) = 20 rad/s；损失的动能 ΔT = 1500 J。
例 3-3补充有心力场：桌面小孔拉绳（动量矩守恒 + 能量守恒）
质量 m = 0.1 kg 的小球在光滑水平桌面上运动，用细绳系住，绳穿过桌面中心的光滑小孔 O 由手拉住。初始时小球以半径 r1 = 0.5 m、速度 v1 = 2 m/s 作圆周运动。缓慢拉绳使小球的圆周半径减小到 r2 = 0.2 m。求此时小球的速度 v2、绳中张力 T2 以及拉力所做的功 W。

（1）受力分析：小球受重力、桌面支持力（均为铅直）和绳的张力。张力始终指向小孔 O，对 O 点的矩恒为零，属于有心力；铅直方向的力对 O 的矩也为零。

（2）对 O 点动量矩守恒（含沿轴投影）：

a

m v1r1 = m v2r2 ⟹ v2 = v1r1/r2 = 2×0.5/0.2 = 5 m/s

（3）绳张力（沿半径方向的加速度为 v²/r，由张力提供）：

b

T2 = m v2²/r2 = 0.1×25/0.2 = 12.5 N（对比 T1 = m v1²/r1 = 0.8 N）

（4）能量关系：绳张力（外力）做功，故机械能增加，用动能定理：

c

W = ½m v2² − ½m v1² = ½×0.1×(25 − 4) = 1.05 J

（5）结论与推广：有心力场中角动量守恒（开普勒第二定律的实质）与能量守恒（或动能定理）联立，是不含力矩积分即可求速度的标准套路。同一套路用于平方反比引力：卫星在近地点 r1、远地点 r2 处速度分别为 v1r1 = v2r2 与 ½mv1² − GMm/r1 = ½mv2² − GMm/r2，联立解得 v1 = √[2GM r2/(r1(r1+r2))]。

答：v2 = v1r1/r2 = 5 m/s；T2 = 12.5 N；W = 1.05 J。

3.3 刚体定轴转动微分方程与转动惯量

一、定轴转动微分方程

对可简化为平面问题的定轴转动刚体，把质心运动定理与对转轴的动量矩定理联立：质心运动定理给出轴承约束力，对转轴的动量矩定理给出转动规律——

3-7

Jzε = ΣMz(F(e))  或  Jz d²φ/dt² = ΣMz(F(e))

定轴转动也可看作平面运动的特殊情况，故式（3-7）也可由相对质心的动量矩定理导出。

例 3-4课件原例墙角圆盘：转动停止所需时间
匀质圆盘半径 R、质量 m，放置于墙角（一面竖直墙、一面水平地面），初始角速度为 ω0。由于摩擦阻力使圆盘转动减速，圆盘与墙、与地面之间的摩擦因数均为 f，圆盘中心不动。试求使圆盘停止转动所需的时间。

（1）受力分析与运动分析：圆盘 1 个自由度（绕质心 C 转动），2 个约束力未知。受力：重力 mg（向下）、竖直墙正压力 N1（水平）、地面正压力 N2（向上）、两处摩擦力 F1 = f N1（竖直）、F2 = f N2（水平）。质心不动，故 aC = 0。

（2）质心运动定理（x 水平、y 铅直）：

a

x 向：N1 − F2 = 0，  y 向：N2 + F1 − mg = 0

（3）力的补充方程（滑动摩擦）：F1 = f N1，F2 = f N2，代入（a）解得

b

N2 = mg/(1+f²)，  N1 = f mg/(1+f²)，  F1 + F2 = f mg(1+f)/(1+f²)

（4）对质心的动量矩定理（两处摩擦力的矩方向相同，均为阻力矩，力臂都是 R）：

c

½mR²ε = −R(F1+F2) ⟹ ε = −2fg(1+f)/[R(1+f²)]

（5）积分求时间：ε 为常量，ω = ω0 + εt，令 ω = 0 得

3-9

t = ω0/|ε| = ω0R(1+f²)/[2fg(1+f)]

（6）讨论：t 与初角速度成正比、与摩擦因数近似成反比（注意式中 f 同时出现在分子与分母，摩擦因数过大时 N1 增大反而使总阻力矩的增速变缓）。本题是「质心运动定理 + 对质心动量矩定理 + 摩擦补充方程」三件套的标准范例。

答：t = ω0R(1+f²)/[2fg(1+f)]，单位 s。
例 3-5补充定滑轮—绳—物块系统
定滑轮为匀质圆盘，质量 M = 4 kg、半径 R = 0.2 m，可绕光滑水平轴转动。绳绕在轮缘上，一端悬挂质量 m = 6 kg 的物块，绳不打滑、绳的质量不计。取 g = 9.8 m/s²。求物块下落的加速度 a 与绳中张力 T。

（1）选系统与受力分析：绳不可伸长且不打滑，系统只有 1 个自由度。物块受重力 mg 与绳张力 T；滑轮受重力、轴承约束力、绳的拉力 T（绳两端张力相等，因绳质量不计且轮缘无摩擦）。

（2）物块（平动，用牛顿第二定律）：

a

mg − T = ma

（3）滑轮（定轴转动，用式 3-7），JO = ½MR²：

b

½MR²·ε = T R

（4）运动学补充方程（绳不打滑）：a = Rε，代入（b）得 T = ½Ma；再代入（a）：

c

mg = (m + M/2)a ⟹ a = mg/(m+M/2) = 6×9.8/(6+2) = 7.35 m/s²

d

T = Mmg/(2m+M) = 4×6×9.8/(12+4) = 14.7 N

（5）讨论：a < g，且 T = 14.7 N 远小于物块重量 58.8 N —— 绳中张力不等于悬挂物重量，这是本章与上一章衔接处最容易失分的地方。若滑轮质量可忽略（M → 0），则 a → g、T → 0，退化为自由落体式结论。

答：a = 7.35 m/s²（向下），T = 14.7 N。
定轴转动刚体动力学解题步骤
  1. 确认刚体（或系统）的自由度，选取广义坐标 φ（或 s）。
  2. 受力分析：把每个约束力都画出来，特别注意摩擦力的方向由相对滑动趋势决定。
  3. 写方程：转动部分用 Jzε = ΣMz；需要求轴承约束力时再补质心运动定理。
  4. 补运动学关系：绳不打滑 a = Rε；摩擦用 F = f N；纯滚动用 aC = Rε。
  5. 解出 ε（或 a）后按需积分求 ω、φ、时间，用初始条件定积分常数。

3.4 刚体平面运动微分方程

一、平面运动微分方程（三个方程一套）

对可简化为平面问题的平面运动刚体，用「质心运动定理 + 相对质心动量矩定理」：

3-10

m aCx = ΣFx(e)，  m aCy = ΣFy(e)，  JCε = ΣMC(F(e))

说明：① 取质心为动量矩的取矩点是关键，因为此时式（3-5）的修正项为零；② 平动刚体问题取 ε = 0，即退化为质点动力学；③ 定轴转动是它的特殊情况（质心到轴的距离不变）。

纯滚动（只滚不滑）补充条件：vC = Rω，aC = Rε，摩擦力为静摩擦力（大小由方程解出，不能用 f N 硬套，只能用于检验是否打滑）。

例 3-6补充圆柱沿斜面纯滚动：加速度与最小摩擦因数
均质实心圆柱质量 m、半径 R，沿倾角 θ = 30° 的固定斜面由静止无滑动地滚下。取 g = 9.8 m/s²。求质心加速度 aC、角加速度 ε、斜面对圆柱的摩擦力 Ff，以及保持纯滚动所需的最小摩擦因数 fmin。

（1）受力分析：重力 mg（铅直向下）、斜面正压力 N（垂直斜面）、摩擦力 Ff（沿斜面向上，正是它提供转动的力矩）。坐标：x 轴沿斜面向下，y 轴垂直斜面向外。

（2）平面运动微分方程（JC = ½mR²）：

a

x 向：mgsin θ − Ff = m aC；  y 向：N − mgcos θ = 0

b

对质心：FfR = ½mR²ε

（3）纯滚动补充条件：aC = Rε ⟹ Ff = ½maC，代入（a）：

c

mgsin θ = (3/2)maC ⟹ aC = (2/3)gsin θ = 3.27 m/s²

d

ε = aC/R，  Ff = (1/3)mgsin θ

（4）检验是否打滑：Ff ≤ f N = f mgcos θ ⟹

e

fmin = (1/3)tan θ = (1/3)×0.577 = 0.192

（5）讨论：① 若换成薄壁圆筒（JC = mR²），则 aC = ½gsin θ、Ff = ½mgsin θ、fmin = ½tan θ——转动惯量越大，滚得越慢、越需要摩擦；② 斜面光滑时 Ff = 0，则 ε = 0，圆柱只滑不滚，aC = gsin θ，这正回答课件开头「光滑面上圆盘有无转动」的问题。

答：aC = (2/3)gsin θ = 3.27 m/s²，ε = 2gsin θ/(3R)，Ff = (1/3)mgsin θ，fmin = (1/3)tan θ = 0.192。
本章高频考点小结
  • 求动量矩：分清平移／定轴转动／平面运动三种算法（例 3-1）；定轴转动对转轴直接用 Jzω。
  • 守恒类：Lz = 常数 ⟹ J1ω1 = J2ω2（例 3-2、3-3）；有心力（力矩为零）是角动量守恒的典型场景。
  • 定轴转动动力学：Jzε = ΣMz 配上运动学补充条件（绳不打滑、纯滚动）（例 3-4、3-5）。
  • 平面运动动力学：三方程 + 补充条件，摩擦力是「由方程求出的未知量」而不是 f N（例 3-6）。

三个定理都是「把牛顿第二定律做一次积累」，区别只在用什么去积累、积累了得到什么：

  • 力对时间的积累（冲量）→ 改变动量（矢量式，2～3 个投影方程）；
  • 力矩对时间的积累（冲量矩）→ 改变动量矩（矢量式，对点 3 个／对轴 1 个方程）；
  • 力对路径的积累（功）→ 改变动能（标量式，只有 1 个方程）。

  • 把「动量」当成标量：动量、动量矩都是矢量，投影时先定正方向，答案中负号要有物理解释。
  • 用质心运动定理时忘了「整体为研究对象」：只取一个物体、写错外力，是最常见的错误。
  • 绳中张力直接写成物重 mg：有质量的滑轮、有加速度的系统都不成立（见例 3-5）。
  • 纯滚动问题里用 Ff = fN 直接代入：静摩擦力大小应由方程解出，f 只用于检验是否打滑。
  • 平行轴定理用错轴：必须是「过质心的轴」与其他轴的平行关系，d 是两轴之间的垂直距离。
  • 流体问题漏掉压力项：弯管、喷嘴类题目中入出口的压力 p1A1、p2A2 必须进入控制体的受力分析。
  • 变质量问题的研究对象边界不清：先写清「研究哪部分质量」，再判断并入／分出部分的速度 v1，否则附加力项符号必错。
  • 守恒条件没说清就写守恒：要写明「对哪一点、沿哪个方向、为什么力矩为零」。
三句话收束全章

① 外力主矢决定质心怎么动（动量定理／质心运动定理）；② 外力主矩决定绕质心怎么转（动量矩定理）；③ 外力为零或力矩为零时，对应的动量、动量矩就守恒——把这三句话记牢，本章所有题目都能找到入口。
